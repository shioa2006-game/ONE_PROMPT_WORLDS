# ひつじが いっぴき ― しくみの詳細と各牧場のこつ（ネタバレ）

**遊ぶ前には読まないでください。** 気づく楽しみが なくなります。

## 採用した企画と、選ばなかった案

- **採用：群れ追い（牧羊犬）** … くり返す行為は「カーソルで犬を動かし、群れのうしろに回る」。
  群れが流体のように反応するので、動かすこと自体に手ごたえがある。規則は「歩けば まとまる／走れば 散る」の一つで、
  門・クローバー・やぎ・池との組み合わせから用途が増える。中心の喜びは **習熟・手ざわり（爽快感）・愛着**。
- 却下：**鐘の連鎖シーケンサー**（置いた鐘が波で連鎖して曲になる） … 音は気持ちよいが、判断の材料が画面から読み取りにくく、
  「試したいこと」が配置の総当たりになりやすい。2作目（粒の反応）・7作目（配置パズル）とも手ざわりが近い。
- 却下：**小島のタイル置き（隣接で点が入る箱庭）** … 完成の喜びはあるが、既存の定番に寄りやすく、
  リアルタイムの手ごたえが作れない。4作目（部品を並べる構築）と思考の型が重なる。

## しくみ（これで全部）

1. **ひつじはコロから離れる。** コロのまわりの点線の輪が「気配」の届く範囲。止まると小さく、歩くと中くらい、走ると大きい。
2. **歩くコロには、まとまって逃げる。** 仲間のほうへ寄りながら、押された向きへ進む。
3. **走るコロには、おどろいて散る。** 1秒ほど、コロと反対の ばらばらな向きへ速く走る（「！」が出る）。
4. **クローバーの上で食べはじめたひつじは、歩くコロを気にしない。** 走るコロにだけ驚く。近くのひつじは、押されていなければクローバーへ寄っていく。
5. **やぎは、いつでも歩くコロを気にしない。** 走るコロからは、コロと正反対の向きへ まっすぐ逃げ、すぐ止まる（散らない）。
6. **ひつじ・やぎは水に入れない。コロは泳げる**（速さは半分以下。泳いでいるあいだは走れない＝おどろかせない）。
7. **小屋に入って 0.7 秒たつと落ちつく。** 落ちついた動物は もう驚かない。看板の絵とちがう動物は、その小屋の門を通れない（門が柵と同じになる）。
8. 柵や生け垣のそばでは、動物は内がわへ それる（壁ぎわに追いつめても、はりついたままにはならない）。

## 気づいてほしかったこと

- **走りは「遠まわり」に使う。** 群れから離れているあいだだけ走り、輪が届く前に離す。
- **歩きは ふるいになる。** ひつじとやぎが まざっていても、歩いて押せば ひつじだけが動く（「わける」）。
- **クローバーは わなであり、発射台でもある。** 門のクローバーに ひつじを歩いて入れてから、うしろから走ると、門のむこうへ とび出す（「門番」）。
- **せまい道では、走っても散りにくい。** 柵が散る先をふさぐので、「まがりみち」は走りぬけるほうが速いこともある。
- **やぎは玉つき。** コロ→やぎ の直線の先へ走るので、小屋とやぎを結んだ線の うしろから走りこむ。カーソルは やぎの少し手前に置くと、追いこしにくい。
- **泳ぎは近道。** 池のまわりを回るより、まっすぐ泳いだほうが早く うしろに回れることがある。泳いでいるあいだは群れを驚かせない。

## 各牧場のこつ

1. **はじめの五ひき** … 左から歩いて押すだけ。門の正面にならぶように、少し上下に動いて形をととのえる。
2. **せまい門** … 柵の切れ目へ歩いて押す。走ると柵にそって左右に散り、集めなおしになる。
3. **クローバー** … まんなかの3びきは走って おこす。そのとき左の5ひきが近いと いっしょに散るので、先に3びきを片づけるか、5ひきを上か下へ よけて通す。
4. **いけのむこう** … 池を泳いで右へ。上の群れと下の群れを それぞれ左へ押す。下の道のクローバーは上がわを通す。
5. **まがりみち** … 上の段を右へ、まんなかの段を左へ、下の段を右へ。クローバーは上がわ 80px が あいている。柵のあいだなら走っても散りにくい。
6. **やぎ** … ひつじを歩いて先に入れる（やぎは動かないので じゃまにならない）。そのあと やぎを1ぴきずつ、小屋の門の正面へ走って はじく。
7. **わける** … まず歩いて ひつじだけを左へ。残った やぎを右の小屋へ走って入れる。先に走ると ひつじが散る。
8. **門番** … ひつじを遠ざけてから、左から走って やぎを門のむこうへ。つぎに ひつじを門のクローバーまで歩いて入れ、左から走って むこうへ とばす。
9. **みんな、おかえり** … 左上のクローバーの群れを走って おこし、池の群れと合わせて門へ。右がわの やぎ2ひきは門の先に いるので、ひつじを通す前に下の小屋へ。
   左がわの やぎ2ひきは最後に1ぴきずつ。
