# ひつじが いっぴき ― 牧羊犬コロの一日

マウスの先へ走る牧羊犬コロになって、ひつじの群れを小屋まで送りとどける、群れ追いのゲームです。
歩けば群れは まとまって進み、走れば おどろいて散る。朝から夜まで、九つの牧場をまわります。

## 遊びかた

`index.html` をブラウザで開くだけで遊べます（インストール・サーバー不要、PCブラウザ向け）。

| 操作 | 内容 |
| --- | --- |
| マウスを動かす | コロが カーソルのほうへ歩く |
| クリック長押し（または Shift / Space） | 押しているあいだ コロが走る |
| R | その牧場を やりなおす |
| Esc | 牧場えらびへ（もういちど押すと表紙へ） |
| Enter | クリア後、つぎの牧場へ |
| M | 音のあり・なし |

- 全9牧場と結末。初見で15〜30分ほどを想定しています。
- 失敗で終わることはありません。時間は星（1〜3）の数にだけ関わります。星は結末の夜空にともります。
- 進みぐあいと記録は、ブラウザの localStorage に保存されます。

## ファイル

- `index.html` … 起動ページ
- `js/sim.js` … ルールの核（群れの動き。描画なしで node からも使える）
- `js/levels.js` … 牧場のならび
- `js/game.js` … 画面・操作・進行　／　`js/audio.js` … 音（Web Audio で合成。外部素材なし）
- `tools/` … 検証用の道具（自動プレイの比較・入力記録・通しプレイ・画面撮影）
- `VERIFICATION_検証記録.md` … 実施した検証と、その結果による改善の記録
- `NETABARE_攻略とネタバレ.md` … しくみの詳細と各牧場のこつ。**遊ぶ前には読まないでください。**
