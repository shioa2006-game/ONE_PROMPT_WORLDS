# 天下賽配（てんかさいはい）― 戦国サイコロ国盗り

**サイコロの「表の目」は攻めの力、「裏の目」は政（内政）の力。** 出目を見て内政・調略・合戦を采配し、永禄三年秋から二十季のうちに最大の勢力を築く、1人用の戦国国盗りゲームです。

- 舞台：1560年秋（桶狭間の後）、中部・近畿の20国・20大名（指定データどおり）
- 1ゲーム：20季（1560年秋〜1565年夏）。想定プレイ時間は20〜30分（**設計上の目安。人間による実測はしていません**）
- 相手：残り19家はすべてCPU。CPU同士も内政・調略・合戦を行い、毎回ちがう勢力図になります

## 起動方法

`game14/index.html` をブラウザ（Chrome / Edge 推奨、PC向け）で開くだけです。

- サーバー不要（ファイルを直接開いても動作）。GitHub Pages 等の静的配信でもそのまま動きます
- 外部ライブラリ・外部素材・ネットワーク通信なし。効果音とBGMは Web Audio で合成、地図は自作の経緯度データから生成しています
- セーブは各季節の開始時などにブラウザ（localStorage）へ自動保存され、タイトルの「つづきから」で再開できます

## ルール（要約）

**目的**：20季が終わったとき、支配国数が最も多い大名の勝ち（同数は経済＋軍事＋守備の合計、次に総兵、次に金）。途中で20国すべてを取れば天下統一。自分の国がすべて奪われたら敗北。

**采配ダイス**：毎季サイコロを振り、1個ずつ（同じ目は重ねて）命令に使い、その場で結果が出ます。サイコロは3個から始まり、領国が **2・4・7国** になると1個ずつ増えます（最大6個）。

**表の目と裏の目**：出目（表）は攻めの力。裏の目（7−出目）は内政の力。6は攻めに強く内政に弱い、1は攻めに弱く内政に強い。

| 命令 | 使う目 | 効果 |
|---|---|---|
| 力攻め | 表 | 出陣兵＋出目 ＞ 敵兵＋城（守備力）＋敵のサイコロ なら占領。5差以上は「圧勝」で国衆が加わる |
| 奇襲 | 1・2 | 最大6兵（ゾロ目は9兵）。兵＋出目 ＞ 敵兵＋城 なら**確実に奪取・損害なし**（敵のサイコロと備えは無視）。本城には不可 |
| 調略 | 1〜3（金2） | 隣の敵兵を寝返らせる（裏の目の半分、ただし敵兵の3分の1・最大3まで）。同じ国へは1季1回 |
| 徴兵 | 裏 | 裏の目＋（軍事力による補正）の兵を集める（兵1につき金1、兵の上限まで）。その国はその季、出陣できない |
| 開発 | 裏 | 経済（収入）・軍事（兵の上限・徴兵）・守備（城）のどれかを育てる |
| 移動 | どれでも | 自領伝いに、どの自国へでも兵を送る |

- **本城**：各大名の最初の国。城の値は「守備力×2＋3」で、奇襲が効きません
- **備え**：季節を終えたとき残っていた一番大きい目（最大5）が備えになり、次の自分の番まで、力攻めされたときの守りのサイコロがその目より小さくなりません（使うたびに1減る）。他の残りの賽は金1に
- **兵の上限**：国ごとに 8＋軍事力 の合計。季節ごとに各国の兵が1ずつ自然に増えます（上限まで）
- **季節**：最初の季節（1560年秋）は全家とも合戦なし。秋は収入2倍。冬は雪国（能登・越後・加賀・越中・越前・飛騨・甲斐信濃）への／からの出陣不可
- **包囲網**：5国以上を持ち2位に2国以上差をつけた家には、CPUが優先して攻めかかります（最後の4季は4国・1差から）

マップ上の表示：赤い破線＝攻撃・調略できる敵国、青い「奇」＝今の出目で確実に奇襲できる国、自国の「危○%」＝隣の敵が強い一手を出したときに落ちる危険の目安（備えの予定値込み）、山の連なり（ギザギザの線）＝越えられない国境。

## 設計メモ

### 採用したサイコロのメカニクス
「采配ダイス（表裏）」。振った目を1個ずつ地図上の命令に置き、即時に解決する方式に、**裏の目（7−出目）を内政値にする**ルールを組み合わせました。大きい目は攻めと備え、小さい目は徴兵・開発・調略・奇襲に強く、どの目にも使い道があります。

### 検討した3案（AIの設計担当3名が独立に具体化し、観点の異なるAI審査3名が採点）
| 案 | 中身 | 審査の平均（6観点合計・60点満点） |
|---|---|---|
| A 采配ダイス | 振った目を1個ずつ命令に置いて即時解決。大きい目は力、小さい目は策 | 約39（UX審査・体験審査が1位） |
| B 軍勢ダイス | 各国の軍勢そのものがサイコロ。表は槍（攻め）、裏は鍬（年貢） | 約36 |
| C 軍略の役 | 5個を2回まで振り直して陣形の役を作る。武（表）と政（裏） | 約39（システム審査が1位） |

- **採用理由（A）**：操作が「サイコロ→国→命令カード」の3クリックで完結し、国が増えても命令数は最大6で頭打ち。結果がその場で出るので、次のサイコロの使い道を考え直せる。勝算が画面で読める。
- **B・Cから取り入れた点**：裏の目を内政に使う発想（B・C共通）、振り直し（C）、敵の脅威の可視化（Cの陣触れの軽量版）、季節のリズム（B）。
- **見送った点**：B は国が増えるとサイコロが数十個になり操作が重くなる。C は役と陣形の名前が多く、初見の学習量が大きい。
- 審査で指摘された A の弱点（徴兵ばかり／1は調略ばかり／序盤の弱小滅亡／三好の独走）は、裏の目・調略の上限と費用・本城の強化・CPUの序盤の慎重さ・包囲網で手当てし、シミュレーションで再確認しました（VERIFICATION.md）。

### CPUの設計
- 19家とも人間と同じルール・同じ命令で動きます（ズルなし）
- サイコロ1個ずつ、全命令の候補（攻め・奇襲・調略・徴兵・開発・移動）を厳密な勝率と脅威の見積もりで点数化し、最も良いものを実行する貪欲法。役に立たない目は振り直し、守りが必要なら大きい目を備えに残します
- 大名ごとの性格（攻撃性・慎重さ・内政志向、上杉と武田は互いを宿敵視、伊賀衆は調略好き など）
- 序盤は慎重で年を追うごとに好戦的になります。首位の家（人間を含む）には包囲網で対抗します
- 19家の処理は1季あたり数ミリ秒。画面では国の色が変わる出来事と滅亡・包囲網・自家への攻撃だけを短く演出し、クリックで早送りできます
