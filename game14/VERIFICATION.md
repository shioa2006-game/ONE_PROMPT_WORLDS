- 指示書：`Opus55_Autonomous_Game_Design_Prompt.md`（v1.0, 2026-11-15）＋ 利用者の追加条件（戦国×サイコロ、指定20国・20大名、game14 に実装）
- 制作：Claude Opus 5.5（claude-opus-5-5）、Claude Code デスクトップアプリ。設計比較・審査・音・レビューは同モデルのサブエージェント
- 環境：Windows 11、Node v24.13.1、Python 3.12 + Playwright（Chromium ヘッドレス）
- **人間による試遊は未実施。** 以下はすべてボット／スクリプト／AIによる観察で、面白さの証明ではありません。プレイ時間（20〜30分）は設計上の目安で未実測。音は合成値の計測のみで、耳では聴いていません。

## 実施した検証
1. **機能・進行**（実ブラウザ・通常のUI経路）
   - 20大名すべて：選択画面の旗クリック→出陣→Spaceで賽→サイコロ→国→命令カード→Enterで季節終了。全員OK、コンソールエラー0
   - 20季の通し（自動操作）：北条（期限で勝利画面）、六角（期限）、織田・斎藤（滅亡画面）。エラー0
   - CPU行動中にタイトルへ戻り新規開始（4つのタイミング）：新しいゲームが正常に開始。エラー0
2. **システム・バランス**（`tools/sim.js`、全員CPU 300局ほか）
   - 1局の攻略 約78回（序盤1.3→終盤約4/季）、終局時の生存 約8家、勝者は20家すべてに分散（最多でも約2割）、強大化（7〜15国）が約25%の局で発生
   - CPUの計算：19家で1季あたり約6ms。画面のCPU行動は平均約3秒/季（季節表示込み・通常速度、クリックで早送り）
   - プレイヤー方針の比較（既定AI・攻撃的・守備的・1手先読み・一点集中）：方針で勝率が変わる（例：徳川 0%→20%）。全大名に勝ち筋あり（ただし筒井・足利・神保は至難）
   - 難易度★は「既定AI×40局＋先読み×12局」の平均順位・勝率・生存率から算出（ボット基準の目安）
3. **設計の比較**：3案（采配ダイス／軍勢ダイス／軍略の役）を別々のAIが具体化し、観点の異なるAI審査3名が採点 → 采配ダイスを2対1で採用、他案の「裏の目」「振り直し」などを移植（README参照）
4. **独立レビュー**（AIレビュアー：ルール・UI進行・画面配置）

## 見つけた問題と対応（抜粋）
- 序盤に弱小が全滅、攻略が1局90回超の泥沼 → 徴兵した国は同季出陣不可、本城の城を強化、調略に上限と費用、CPUの序盤の慎重さ、包囲網 → 全員CPUの攻略は約78回、生存約8家に
- 金が余り経済力が無意味に → 軍資金で賽を買える仕組み（終局時の余剰金 約115→約11）
- 開発が中盤で頭打ち → 開発コスト1.5倍
- 同数時の勝者がID順で決まる → 国数→経済＋軍事＋守備→総兵→金で判定
- 調略のログと命令イベントの名前衝突でアニメが停止、インク演出の負の半径、タイトル文字が透明、年号の1年ずれ、サイコロ3と4の向き違い → 修正
- レビュー指摘：CPU行動中にタイトルへ戻ると旧ゲームの処理が続き新ゲームが壊れる（修正・再試験済）、CPU行動中のツールチップが結果を先に表示（修正）、備え表示が「—」（修正）、敗北時の推移グラフ欠け（修正）、遊び方の数値がルールと不一致（RULESから生成に修正）、AIが出目調整の上限を無視（修正）、1600px未満のウィンドウで地図の東端が隠れる（`#stage{flex:none}`で修正）、メニューから開く遊び方が下に隠れる（修正）、オーバーレイ表示中も操作キーが効く（修正）

## 未対応・既知の問題（レビュー指摘のうち未修正）
- ノートPC解像度で一部の文字が小さい（10px未満の要素あり）
- 色覚特性によって隣接する一部の勢力色が見分けにくい（美濃/北近江など）。自国領の縁取りが弱い
- 一部の勢力色（濃色）の文字が暗い背景で読みにくい
- 兵数スライダーがドラッグしにくい（入力ごとに再描画）
- 振り直し／±直後の約0.3〜0.5秒、命令カードの勝算表示が古い
- CPU行動中の再読み込みで季節終了前に戻れる（保存タイミング）
- 結果グラフのラベル重なり、中央メッセージと地名の重なり、短い家名への「家」付与 など軽微な表示
- AIの初見プレイテスト（ソースを読まない担当）は利用上限のため途中で停止し、結果は未回収
