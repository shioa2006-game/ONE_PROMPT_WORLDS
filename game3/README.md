# EMBERDEEP ― 燈守りの坑道

闇に沈んだ坑道を、ランタンひとつで潜っていくトップダウンのアクションRPG。
火鉢を叩いて灯し、カゲと戦い、大燈（だいとう）を灯して区画ごと闇を払いながら、最深部の炉心を目指します。

初見で 15〜30 分ほどの、最初から結末まで遊べるバーティカルスライスです。

## 起動方法

ブラウザで直接開くだけで遊べます（サーバー不要・外部依存なし）。

- `game3/index.html` をダブルクリックして PC ブラウザ（Chrome / Edge 推奨）で開く

ローカルサーバーで開く場合（任意）:

```bash
python -m http.server 8767 --bind 127.0.0.1 --directory game3
```

→ http://localhost:8767/

音が出ます（タイトルで最初にキーかクリックを入れた時点から鳴ります）。

## 知っておくと良いこと（ネタバレなし）

- 倒れても、最後に休んだ大燈からやり直すだけです。レベル・装備・鉱晶は失いません。
- 進行は大燈で休んだときなどに自動保存され、タイトルの「つづきから」で再開できます。
- 行き詰まったら、大燈で鉱晶を使って鍛える・別の道を見に行く、が効きます。

攻略のヒントやストーリー・仕掛けのネタバレは `NETABARE_攻略とネタバレ.md` に分けてあります。初回プレイの前には読まないのがおすすめです。

## ファイル構成

- `index.html` … 本体
- `js/data.js` … 武器・護符・敵・マップ定義
- `js/sim.js` … ゲームロジック（DOM 非依存。Node でも動く）
- `js/render.js` / `js/audio.js` / `js/main.js` … 描画・合成音・入力と UI
- `tools/` … 検証用（通しプレイボット、個別チェック、マップダンプ）
- `VERIFICATION_検証記録.md` … 企画比較・検証と改善の記録（軽いネタバレあり）
- `NETABARE_攻略とネタバレ.md` … 攻略・隠し要素・結末

画像・音声の外部素材は使っていません（すべてコードで描画・合成）。
