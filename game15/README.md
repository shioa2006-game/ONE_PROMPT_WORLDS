# 賽駆け（さいがけ） — 戦国・賽振り行軍記

賽を振り、出目を自分の軍勢に配って日本地図の上を進軍させる、戦国時代のターン制領土争奪ゲームです。
「どの目を、どの軍勢に、どの道で使うか」を考え、敵の城の隣に陣取り、ぴったりの目で奇襲し、勢力の色を地図に広げていきます。

- ONE PROMPT WORLDS 第15作（Claude Opus 5.5 が1つの依頼から企画・実装・検証）
- PCブラウザ向け。マウスで遊べます（キーボード操作もあり）。
- 1ゲームの目安：20〜40分（設計上の目安。人間のプレイ時間は未計測）

## 起動

`game15/index.html` をブラウザで開くだけです。サーバー・外部ライブラリ・外部素材は使いません。
GitHub Pages などの静的配信でもそのまま動きます。

## 遊び方（ゲーム内の「？」でも見られます。初めての出陣時には要点だけを表示します）

1. **賽を振る**（Space）。賽は国の数に応じて3〜6個。
2. **賽 → 軍勢 → 行き先**の順にクリック。1つの賽が1つの軍勢の歩数になる。光る水色のマスへ進める。
   - 「強行軍」ボタン（または Shift＋クリック）で賽を2つ合わせ、1つの軍勢を遠くまで動かせる。
3. **城攻めは城の隣から**。手番のはじめに敵（中立）の城の隣にいる軍勢だけが、その城を攻められる。赤い「陣」の旗が、次の季に城を攻められる陣取りの場所。
4. **勢いと奇襲**。攻めるとき、余った歩数が「勢い」として力に加わる。出目ぴったりで敵に着くと「奇襲」で、守り手は守りの賽を振れない。
5. **合戦**：攻め手＝兵＋勢い＋加勢、守り手＝兵（空き城は守備兵）＋城の守り＋加勢＋守りの賽。隣の味方1つにつき加勢＋2。勝つ見込み（％）は攻め先にマウスを乗せると出る。
6. 敵の軍勢の**隣に入ると足が止まる**。動かなかった軍勢は休んで兵が戻る。峠（▲）は2歩、冬は3歩。
7. **京（山城）を含む18か国**で天下布武。永禄十二年の冬（40季）で時間切れになり、その時の勢力で決着。

| 操作 | |
|---|---|
| クリック | 賽・軍勢・行き先を選ぶ |
| 右クリック／Esc | 選択を取り消す |
| Space | 賽を振る |
| 1〜6 | 賽を選ぶ（Shift で2つ合わせる） |
| Z | 一手戻す（合戦をしていない移動のみ） |
| Enter | 手番を終える |
| F／S | CPUの手番を早送り／飛ばす |
| ホイール／ドラッグ／0 | 地図の拡大／拡大中の移動／全体に戻す |

季節のはじめに自動保存され、タイトルの「つづきから」で再開できます。

## 大名（9家）

織田・今川・武田・上杉・北条・朝倉・三好・毛利・尼子。それぞれに賽や行軍に関わる家風（特性）が1つあります。
斎藤・浅井・六角・北畠などは中立の国（国衆）として登場します。

## 検証用ツール（開発者向け）

- `node tools/rules_test.js` … ルールの自動確認
- `node tools/sim.js world 30` … CPUだけで30局回し、勢力図の推移を見る
- `node tools/peaks.js 12` … 各大名をCPUの思考で動かしたときの最大版図
- `python tools/playthrough.py <大名> --seed N --shots DIR` … タイトルから結末まで実際のクリックで通す（Playwright＋Edge）
- `python tools/shot.py out.png steps.json` … 画面の撮影

検証の内容と結果は `VERIFICATION_15.md` にあります（攻略に触れる内容を含みます）。

## 素材

画像・音声・フォントの外部素材は使っていません。地図は緯度経度のおおよその値から描き、効果音とBGMはブラウザ内で合成しています。
文字は利用者のPCにある明朝体・ゴシック体を使います。
