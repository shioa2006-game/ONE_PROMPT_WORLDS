## 採用した仕組み（概要）

- 季ごとに賽を3〜6個振り、**1つの賽＝1つの軍勢の歩数**として配る。2つ合わせる「強行軍」もできる。
- 盤面は49か国の城と90の国境マス（街道1歩・峠2歩・冬は峠3歩）。敵の軍勢の隣に入ると足が止まる。軍勢どうしは重なれない。
- **城攻めは手番のはじめに城の隣にいる軍勢だけ**。陣取り → 次の季に攻める。
- 攻めは「兵＋勢い（余った歩数）＋加勢（隣の味方×2）」、守りは「兵（空き城は守備兵）＋城の守り＋加勢＋守りの賽」。**出目ぴったりなら奇襲**で守りの賽なし。
- 動かなかった軍勢は休んで兵が戻る。国が増えると軍勢の枠と賽が増える。京を持つと賽＋1。
- 勝利：京を含む18か国。40季で時間切れ。全城を失うと滅亡。首位が大きく抜けると「包囲網」で他家に狙われる。
- 9家（織田・今川・武田・上杉・北条・朝倉・三好・毛利・尼子）に家風が1つずつ。

設計の経緯と3案の比較は `NOTES_15.md`（攻略に触れる）にまとめた。

## 2. ゲームシステム・バランス（ボットによる）

- ボット：CPUと同じ思考（1手ずつの貪欲法。盤面はすべて見えるが、敵が次に振る賽は知らない）。単純ボット（勝率50%以上なら攻め、なければ最寄りの城へ寄る）とも比べた。
- 30局のCPU同士の対戦（`tools/sim.js world 30`）：平均37.9季で決着。首位の国数は 4季5.8 → 12季10.5 → 24季12.1 → 40季13.5。1局あたり合戦約160回・城の奪取約90回（大名家どうし約62回）。CPU同士の戦争で勢力図は毎局変わり、滅亡する家も出る（織田・尼子が滅びやすい）。30局中8局で毛利か三好が天下布武に届く（プレイヤーが止めないと負ける展開）。
- 各大名をCPUの思考で動かしたときの最大版図の中央値（12局ずつ）：三好16、毛利12、上杉11、北条10、今川7、尼子7、朝倉5、織田4、武田4。
- 方針の比較：釣り合いのとれた方針が最も伸び、守り一辺倒は生き残るが伸びず、攻め一辺倒は滅びやすい。単純ボットはどの家でも早く滅びた。極端な一つの作戦だけが最善にはなっていない（ただし人間の作戦の幅は未確認）。
- CPUの思考時間：1家1手番あたり平均0.6ミリ秒、最大8ミリ秒（node）。待ち時間はほぼ演出の時間。
- 早送りなしの CPU の手番（8家ぶん）は1季あたり約3〜7秒（実測、合戦の表示が入るとのびる）。「早送り」「飛ばす」あり。

### シミュレーションで見つけた問題と変更

| 問題 | 変更 | 再検証 |
|---|---|---|
| 空き城が次々に奪われ、1局で約350回の奪取（7割が4季以内の奪い返し）。勢力が育たず地図がちらつく | 城攻めを「手番のはじめに城の隣にいる軍勢だけ」に | 奪取は約90〜125回に。守る側が陣取りを見て対応できるように |
| 軍勢がいる城だけは遠くから攻められてしまう不具合 | 城攻めの条件を軍勢の有無にかかわらず適用 | ルール確認に追加 |
| 今度は全家が城に籠もり、中盤以降に戦争が止まる | 籠城中は守備兵を足さない／CPUの脅威の見積もりを「隣の敵」中心に／城を囲む味方を評価 | 大名家どうしの奪取が1局約60回に。滅亡も起きる |
| 中央の小大名がすぐ滅ぶ（11家のとき） | 斎藤・浅井を中立の国に（9家）、本拠の城の守り+1、最後の一城の守り+2 | 織田の滅亡率は下がったが、なお高め（難易度「難」と表示） |

| 勝利条件 20か国は CPU の思考ではほぼ届かない | 18か国に | CPUの思考で動かした家が届くことがある |

## 3. 画面・操作・初見理解

- 作者は仕様を知った状態で、画面撮影を見ながら確認した（初見確認ではない）。
- 見つけて直したもの：
  - 行軍できるマスの黄色が織田の黄色に埋もれる → 水色＋白い輪に変更。
  - 陣取りの場所が分かりにくい → 赤い「陣」の旗を表示。
  - 敵の届く範囲が薄すぎる → 橙を濃く。
  - 冬の変化がほぼ見えない → 雪の山・霜の色・雪の粒。
  - 国境のマスが海や他の国の中に置かれていた（19か所） → 二国が実際に接する線の上に自動配置し、城から32px以上離した。
  - 軍勢がいる城で城の絵と名前が重なる → 城の絵をずらし、国名を下に。
  - 結果画面のボタンが見出しの文字サイズを受け継いで巨大化 → 修正。
  - 大名選びの画面が地図を隠す → 一覧を海の上に寄せ、選んだ家の城を地図上で光らせる。
  - 出目を見た後に「どの軍勢で何ができるか」を探す手間 → 何も選んでいないとき各軍勢に「奇1」「攻5」などの印（その目で奇襲／有利に攻められる）。賽だけ選んだときも同様。
  - 届かない場所を押しても無反応 → 理由（城攻めは隣から、など）を案内。
- AIの別担当による初見確認：下記「4.」を参照。

## 4. AIの別担当による初見確認

- 別担当：Claude のサブエージェント（汎用）。**人間の代わりではない**。
- 渡した情報：ゲームのファイルの場所（`game15/index.html`）と「PCブラウザ向けのターン制ゲーム」という一言、報告の観点だけ。ゲームのファイル・リポジトリ内の他の文書を読むこと、ページ内の JavaScript で内部状態を見ることは禁止し、Playwright のマウス・キー入力と画面撮影だけで遊んでもらった（本人もそう報告）。
- 遊んだ範囲：三好家で9手番（3か国 → 最大7か国、京は維持）。城攻め約10回。「つづきから」も確認。所要約25分（AIの操作時間で、人間のプレイ時間ではない）。

| 指摘（重要度） | 対応 |
|---|---|
| 加勢＋2・勝利条件・「国が増えると軍勢と賽が増える」を、遊び方を開くまで知らなかった。単独で城攻めを繰り返して退けられた（高） | 初回だけ出陣時に「天下への道」（目的・出目の配り方・城攻めは隣から・加勢）の4点を表示。左上に勝利条件を常に表示。賽や軍勢の枠が増えた季に通知。勝つ見込みが低く加勢がないとき「隣に味方を置くと加勢＋2」と表示 |
| 自分の城に「!」が出ても守り方が分からない（中） | 城の説明に「守り方：城に軍勢を入れる／隣に味方を置いて加勢／陣取った敵を先に攻める」を追加 |
| 移動先のクリックが少しずれると、理由なく選択が外れる（中） | 選択中は届くマス・攻め先を24px以内なら拾う。届かない場所を押したら理由を表示 |
| 軍勢や賽の印が国名に重なって読みにくい（中） | 国名を軍勢より上に描く |
| 力が足りないのに「奇襲 0%」と出て紛らわしい（低） | 0%のときは「奇襲」と出さず、見込みの欄に「奇襲でも力が足りない」 |
| CPU手番の案内が「右上の早送り」だが実際は上中央（低） | 文言を修正 |
| 賽の下の「1:5」が小さく、数字キーが番号か出目か紛らわしい（低） | 「キー1」の表記にして大きく |
| 記録の文字が小さい／「つづきから」で記録が消える（低） | 文字を大きくし、記録も保存して復元 |

- 良かった点として挙がったもの：最初の手番の下部ヒントで1分以内に操作が分かった／攻め先の×と勝率、内訳表示で「どの賽をどこに使うか」比べて決められた／合戦の結果が計算式つきで負けても納得できた／CPUの手番は約3〜4秒で待ちは気にならない／冬の雪景色と峠3歩が分かる／出目の割り振りと押し返してくる周りの大名の緊張感で「もっと続けたい」（AIとしての感想）。
- 修正後の確認は作者が実施した（三好9季・武田40季の通し、画面撮影）。**同じ別担当による再確認はしていない**。

## 5. 未確認事項・既知の問題

- 人間による実プレイ、プレイ時間、音の聴感は未確認。
- 難易度「難」の織田・武田は、CPUの思考で動かすと半分ほど滅びる。人間がどこまで立て直せるかは未確認。
- 地図は緯度経度のおおよその値と「近畿〜東海を拡大する魚眼」で描いており、国境線は実際の国境と一致しない（遊びやすさ優先）。
- スマートフォンは対象外（PCのマウス操作を前提）。
- Firefox・Safari では未確認（Edge／Chromium のみで確認）。

## 6. 人間に確かめてほしいこと

1. 賽を振った直後に「どの目をどの軍勢に使うか」を考える時間が楽しいか、作業に感じるか（1季に3〜6回の「賽→軍勢→行き先」のクリック）。
2. 「城の隣に陣取る → 次の季に攻める」の2拍子が、じれったさより「読み合い」として感じられるか。敵の陣取り（城の「!」）を見て守りに回る判断が面白いか。
3. 1ゲームの長さ（40季）とCPUの手番の待ち時間。難易度「難」の織田・武田で立て直しの余地があるか。
