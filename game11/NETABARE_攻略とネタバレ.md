# ひゅるり、凧びより ― 攻略とネタバレ

**遊ぶ前には 読まないでください。** おたからの 場所、さいごの 章の しかけ、むすび に ふれます。

## そだちかたの こつ

- 育ちは「まきこんだもの の 大きさ の 2乗」に比例します。じぶんと 同じくらいの ものを まきこむと ぐっと 育ちます（画面が ゆれて「○○！」と 大きく 出ます）。ちいさなもの は れんさ の 気持ちよさ 用。
- 大きいものに さわると「○cmから」と 出ます。その 大きさを こえると「○○が まきこめる！」と 知らせが 出るので、そこへ もどると 一気に 育ちます。
- ドンは、まわっている ものを なげて すぐ もどってくるので、何度 つかっても 損は ありません。こわせる入れものの そばでは とりあえず ドン。
- 入れものは、じぶんが その大きさを こえると まるごと まきこめます（なかの おたからも いっしょに 手に入る）。こわすと なかみが ちらばるぶん、たくさん まきこめます。
- 木（うめ・かき・みかん）は ドンで ゆらすと みが おちます（一回で 2〜3こ）。

## その五の しかけ：ねぼすけの ゆきぐも

- れんだこ を あげて おか（すぎばやし の 東）に 入ると、北から ゆきぐも が やってきます。ゆきぐも が いるあいだは、おおだこ に 雪が つもって あがりません。
- ゆきぐも の 下（地面の 青い かげ）では 雪が ふり、まわっている ものが ひとつずつ こおって おちます（2秒ほどで とけて、ふれると もどる）。うごきも すこし おそくなります。
- かげの なかで ドンを 7回 当てると ちぎれます。ちぎれる たびに「ゆきぐもの かけら」が おちてくるので、それを まきこむと 弾（まわるもの）も 大きさ も もどります。
- まわるものが なくなると ドンが 出ません。かげの 外で かけら や こおったものを ひろってから、もう一度 入る、の くりかえし が こつ。
- たおすと 空が はれ、ちぎれた くも が たくさん おちてきます。まとめて まきこむと 22m に とどきます。

## むすび

おおだこ が あがると、村じゅうの 凧が 空に そろい、つむじ が まきこんだ ものを ひとつずつ 村に かえしていく 場面に なります。
「あけまして おめでとう」の あと、あそんだ時間・大きさ・まきこんだ数・まきこみ帳・おたから の 記録が 出ます。
「このまま あそぶ」を えらぶと、むすびの あとの 村で のこりの ものや おたからを さがせます。
