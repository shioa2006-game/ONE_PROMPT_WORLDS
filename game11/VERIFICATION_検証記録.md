## 1. 企画の選定（3案の比較）

| 案 | 主にくり返す行動 | 採否と理由 |
| --- | --- | --- |
| **つむじ風の まきこみ成長「ひゅるり、凧びより」** | マウスの先へ すすみ、じぶんより ちいさなものを まきこむ。まきこんだものを「ドン」と ぶつけて、かたいものを こわす | **採用**。「吸いこんで 育つ」は 馴染みがあり、初見でも 操作と 目的が 伝わりやすい。まきこむ音・れんさ・大きなものを まきこんだときの ゆれ で、くり返しの 手ざわりを 作れる。育つと カメラが ひいて 世界が ひろがるので「次は あれを まきこみたい」が 画面から 自然に 生まれる。凧（子どもたちの 願い）を 節目にして、達成の 目標を 目に見えるものに できる。目押しが いらない。 |
| 振り子ロープで すすむ 探索アクション | ロープを ひっかけて ふる | 不採用。ふる感覚は 気持ちいいが、地形づくりと 操作の 調整の 負担が 大きく、初見で 精密操作が 実行の 負担に なりやすい。 |
| ソリティアの れんさで 絵を めくる 旅 | 数が となりの カードを つづけて とる | 不採用。行為の 体の 手ごたえが うすく、運の 比重が 大きい。盤面パズルは 直前の 作品（game10）と 近い。 |

独自の工夫と、そのねらい：
- **まきこんだものが まわりを まわり つづける**：成果が いつも 目に見える（ボートや テントが ぐるぐる まわる 姿 そのものが ごほうび）。
- **ドン**：まわっている ものを なげて、じぶんより 大きい「入れもの」や 門を こわす。なげたものは すぐ もどるので 損が ない。こわすと なかみが ちらばり、それを まとめて まきこむ という「こわす → ちらばる → まとめて すいこむ」の 気持ちよさを ねらった。大きいほど ドンも 強い（S / min の ダメージ）ので、集める ほど 力が 増す 実感にも なる。
- **凧の 節目**：五人（四人＋村）の 凧を じゅんに あげる。凧は 空に のこり、カメラが ひくたびに 前の 章の 凧が 見える。
- **こえられる 大きさ**：いけがき・いしがき などは じぶんが その高さを こえると とおれる（または ドンで 門を こわす）。新しい 場所へ 出るのが 成長の 結果に なる。
- **ねぼすけの ゆきぐも**（さいごの 章）：雪の かげに 入ると まわるものが こおって おちる。かげに 入って ドン、外で ひろいなおす、の 判断が 少しだけ いる 戦い。たおすと ちぎれた くもを まとめて まきこむ 大きな れんさで しめくくる。

## 2. つくり（概要）

- 世界は 一つの つながった 地図（にわ 6m → のうか 32m → 村 145m → かわら 180m → おか 365m）。大きさ cm で 統一し、カメラの 倍率を つむじの 大きさに あわせて 一段ずつ（1.3倍ごと）ひく。
- 育ち：まきこむと S² += 0.1 × 章ごとの係数 × 重さ × s²。あとの 章ほど 係数を 下げ（1 / 1 / 0.65 / 0.5 / 0.38 / 0.5）、「1こずつの 育ちは 小さく、たくさん れんさで 育つ」ように した（後述 4節の 調整）。
- 凧に ひつような 大きさ：30cm / 1.4m / 4.5m / 11m / 22m。
- ルールの核 `js/sim.js` は 描画なしで node から 動き、ボット・テストと ブラウザが 同じ コードを 使う。

## 5. 画面・演出の確認

- 60fps（ヘッドレス Edge、その五、もの 1655こ、軌道に もの が まわっている 状態）。
- 初期の 撮影で 見つけて 直したもの：
  - 凧が あがる 場面で、あがった 凧が 上の 見出しに 隠れて 小さかった → 凧を 画面の 上側に 大きく、文字を 下に。
  - ひとやすみ・あそびかた の 画面に「つぎは …」の 通知が かさなった → メニュー中は 通知を 出さない。
  - むすびの 文章が ふってくる ものと かさなって 読みにくい → 文字の 帯を しき、ふる量を 半分に。
  - 村に 入った 瞬間に「〜が まきこめる！」通知が 3つ かさなり、章の 見出しと ぶつかった → 1.2 秒以内の 通知は 1行に まとめ、同時に 2つまで。章の 見出しは 画面の 下寄りへ。
  - ゆきぐもが 来る 演出で カメラが 雲を 追わず、雲が 画面の 外 だった／たたかい中に 雲の 場所が 分からない → 演出中は 雲を 追い、画面外なら はしに「ゆきぐも」の 矢印。雲の 真下に いるときは 雲を すかす。
  - 通行人の かさ や かみぶくろ が とんでも「ぼうしが！」と 出ていた → もの の 名前を 出す。
  - 凧の 演出中と むすびで、まわる ものの 回転が 止まっていた → 回しつづける。
  - むすびの あとの「つづきから」で 上の 表示が 空に なった → のこりを さがす 表示に。
- 行きづまり 対策：まわりに まきこめるもの が 少ない 状態が 4 秒 つづくと、画面の はしに 近くの まきこめるものの 矢印、それも 少なければ「ドン」の 赤い 矢印（こわせる入れもの）を 出す。門の そばでは「ドンで こわせる」か「○cm に なったら こわせる」を 一度 出す。
