# ひゅるり、凧びより ― ちびつむじと お正月の村

風のない お正月の朝。にわの かれはから 生まれた ちいさな つむじ風「つむじ」になって、
**じぶんより ちいさなものを まきこみ、どんどん おおきくなって、村の子どもたちの凧を 空へあげる** ゲームです。

- まきこんだものは つむじの まわりを ぐるぐる まわり、**クリックで「ドン」と ぶつける** と、うえきばち・やたい・どんどやき などを こわせます。こわすと なかみが ちらばって、まとめて まきこめます。
- おおきくなると カメラが ひいて、えんがわの にわ → のうか → 村の とおり → かわら → おかの たこあげ広場 と、見える世界が ひろがっていきます。
- まきこんだものは「まきこみ帳」に のります（ぜんぶで 130 しゅるいあまり、おたから 15 こ）。

## 遊びかた

`index.html` をブラウザで開くだけで遊べます（インストール・サーバー不要。PC のブラウザ向けで、Microsoft Edge で確認しています）。音が出ます。

| 操作 | 内容 |
| --- | --- |
| マウスを うごかす | つむじが マウスの ほうへ すすむ（とおくを さすほど はやい） |
| WASD / やじるしキー | キーボードでも うごける |
| クリック / スペース | ドン（まわっている ものを ぶつける）。タイトルでは Enter / スペースで はじめる・つづきから |
| Esc | ひとやすみ（つづける・あそびかた・まきこみ帳・音量・タイトルへ） |
| B | まきこみ帳 |
| M | 音の あり・なし |

- 五つの章（凧が 一つずつ あがる）と むすび。初めてなら 15〜25 分ほどを 想定しています（設計上の めやすで、人が遊んで 測った時間では ありません）。
- 負けや やりなおしは ありません。そだつのに 足りないときは、まきこめるものの 方向を 画面の はしに 矢印で おしえます。
- 進みぐあい・まきこみ帳・音の設定は、ブラウザの localStorage に 自動で 保存されます。タイトルの「つづきから」で 再開できます。
- むすびの あとも「このまま あそぶ」で のこりの ものや おたからを さがせます。

## ファイル

- `index.html` … 起動ページ
- `js/core.js` … 乱数・数学の 小道具
- `js/data.js` … もの・凧・おたから の データ
- `js/world.js` … 世界の 配置（いつも 同じ 種から つくる）
- `js/sim.js` … ルールの 核（うごく・まきこむ・そだつ・ドン・こわす・凧・ゆきぐも・保存。描画なしで node からも 動く）
- `js/art.js` … もの の 絵（すべて Canvas で 描く）
- `js/render.js` … 世界・つむじ・演出 の 描画
- `js/audio.js` … 音（Web Audio で その場で 合成）
- `js/game.js` … 画面の きりかえ・入力・HUD・保存
- `tools/` … 検証用の 道具（自動プレイ・通しプレイ・画面撮影・絵の一覧）と その結果
- `VERIFICATION_検証記録.md` … 実施した 検証と 改善の 記録（しくみの 中身に ふれます）
- `NETABARE_攻略とネタバレ.md` … おたからの 場所・さいごの 章・むすび。**遊ぶ前には 読まないでください。**

外部の 画像・音声・フォント・ライブラリは 使っていません（フォントは OS に 入っているものを 使います）。
