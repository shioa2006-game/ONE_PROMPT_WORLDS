# うしろのハニワ

見ているあいだは、うごかない。背を向けると、ゴト、と寄ってくる。

古墳の石室を一人称視点で歩き、目をさましたハニワたちを「視線」だけで台座まで連れていって、もう一度眠らせるゲーム。
格子状の通路を1マスずつ進み、90度ずつ向きを変える昔ながらのダンジョン探索に、「だるまさんがころんだ」を組み合わせた。

ONE PROMPT WORLDS の6作目。Claude が1つのプロンプトから、企画・実装・検証・改善まで自律的に制作した。

## 起動方法

静的ファイルだけで動く。ビルドや追加インストールは不要。

- `game6/index.html` を PC ブラウザ（Chrome / Edge 推奨）で開く。
- もしくは `game6` フォルダで次を実行し、<http://127.0.0.1:8770/> を開く。

```bash
python -m http.server 8770 --bind 127.0.0.1
```

音が出る（すべてブラウザ内で合成。外部素材なし）。N キーで消音できる。

## あそびかた

- 赤いハニワは、見ているあいだは止まり、見ていないと一歩ずつ寄ってくる。追いつかれると、つかまる。
- ハニワを、腹の印とおなじ印の台座にのせると眠る。全員が眠ると出口がひらく。
- それ以外のことは、石室の中で確かめてほしい。

行動はすべて「1手」単位。こちらが1手動くたびに、ハニワも1手動く。急ぐ必要はない。

## 操作

| キー | 動き |
| --- | --- |
| W / ↑ | 前へ1マス |
| S / ↓ | 前を向いたまま、うしろへ1マス |
| A / ← ・ D / → | 左・右へ90度向きを変える |
| Space | その場で1手待つ |
| Z / Backspace | 一手もどす（何手でも） |
| R | その階をやりなおす |
| M | 大きな地図 |
| H | 直前のことばをもう一度 |
| N | 音のオン・オフ |
| Esc | メニュー（タイトルへ戻る など） |

画面右下の操作ボタンは、マウスやタッチでも押せる。

## 画面の見かた

- 右上：歩いて見た範囲の地図。明るいマスが「いま見えている範囲」。いちど見たハニワの位置も出る。
- 左下：ハニワごとの様子。目のしるしが開いていれば「いま見ている」。
- 画面の左右や下が赤く光って「ゴト」と出たら、そちら側で見ていないハニワが動いた合図。音も同じ側から聞こえる。
- 左上に「行きづまり」と出たら、そのままでは出口に届かない。Z で戻すか R でやりなおす。

## 構成

- 全9階＋結末。初見で20〜30分ほどの想定（人による実測はしていない）。
- 進み具合と記録はブラウザに自動保存される。タイトルの「つづきから」「階をえらぶ・記録」。
- 各階に、少ない歩数の★と、まが玉がひとつある。

## ファイル

- `index.html` / `js/` … ゲーム本体（`rules.js` がルール、`levels.js` が階の定義）
- `tools/` … 検証用のソルバーと通しプレイのスクリプト、その結果
- `VERIFICATION_検証記録.md` … 企画の選定理由、検証と改善の記録
- `NETABARE_攻略とネタバレ.md` … 仕組みの詳細と各階の解き方（遊んでから読むこと）
