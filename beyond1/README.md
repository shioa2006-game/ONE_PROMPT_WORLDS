# 賽駆け 天下（さいがけ てんか） — 戦国すごろく全国版

賽を振り、出目を自分の軍勢に配って、奥羽から九州までの日本地図の上を進軍させる戦国のターン制ゲームです。
城にいる軍勢には、進軍の代わりに内政（徴兵・開墾・築城）を命じることもできます。「今季はどの軍勢に攻めさせ、どの軍勢に国を富ませるか」を考えながら、59の大名家がひしめく全国の勢力図を塗り替えていきます。

- BEYOND ONE PROMPT 第1作。ONE PROMPT WORLDS 第15作「賽駆け」（`../game15/`）を、利用者が書いた設計書（`DESIGN.md`）をもとに Claude Code が発展させたものです。
- PCブラウザ向け。マウスで遊べます（キーボード操作もあり）。
- 1局の長さ：最初の区切りは10年（40季）。区切りごとに「決着」か「5年延長」を選べるので、短くも長くも遊べます（人間のプレイ時間は未計測）。

## 起動

`beyond1/index.html` をブラウザで開くだけです。サーバー・外部ライブラリ・外部素材は使いません。
起動時に全国の地図を描くため、1〜2秒ほど「地図を描いています…」と表示されます。

## 遊び方（ゲーム内の「？」でも見られます）

1. **大名を選ぶ**：主要な15家から選ぶ（織田・今川・武田・上杉・北条・朝倉・三好・毛利・尼子・大友・島津・長宗我部・伊達・龍造寺・佐竹）。家ごとに家風（特性）が1つある。
2. **賽を振る**（Space）。賽の数は領地の石高の合計で増える（京を持つと+1）。
3. **賽 → 軍勢 → 命令**：1つの賽で1つの軍勢に命令する。
   - **進軍**：光る水色のマスへ。2つの賽を「強行軍」で合わせれば遠くまで行ける。
   - **内政**：自分の城にいる軍勢だけ。その季は動かない。
     - 徴兵：兵が戻る（量は国の石高で決まり、どの目でも同じ）
     - 開墾：出目ぶん進み、たまると石高+1
     - 築城：出目ぶん普請が進み、成ると守備兵の上限+1（守備兵もその場で満ちる）
4. **城攻めは城の隣から**：手番のはじめに城の隣にいる軍勢だけが城を攻められる。余った歩数は「勢い」、出目ぴったりで着けば「奇襲」、隣の味方は「加勢」。
5. 命令しなかった軍勢は休む（自分の城なら兵+1）。
6. **臣従**：大きな大名の軍勢が迫ると、小さな大名が戦わずに傘下に入ることがある。あなたへの申し出は受けるか断るかを選べる。
7. **委任とおまかせ**：左の軍勢一覧の「委」を押した軍勢は、手番の終わりに残った賽でCPUの考えにしたがって動く。「おまかせ」は残りの賽をまとめて使う。
8. **区切り・延長・天下統一**：永禄十二年の冬で最初の区切り。石高の順位で決着するか、5年延長するかを選ぶ（何度でも）。全85か国を治めれば天下統一。

| 操作 | |
|---|---|
| クリック | 賽・軍勢・行き先・内政を選ぶ |
| 右クリック／Esc | 選択を取り消す |
| Space | 賽を振る |
| 1〜9 | 賽を選ぶ（Shift で2つ合わせる） |
| Q／W／E | 徴兵／開墾／築城（内政の小窓が出ているとき） |
| Z | 一手戻す（合戦をしていない命令のみ） |
| A | おまかせ |
| Enter | 手番を終える |
| F／S | CPUの手番を早送り／飛ばす |
| ホイール／ドラッグ | 地図の拡大縮小／移動 |
| 0／H | 全国を見る／自分の領地へ |

季節のはじめ・賽を振ったとき・命令のたびに自動保存され、タイトルの「つづきから」で再開できます。メニューの「記録する」で3つの記録枠にも残せます。

## 検証用ツール（開発者向け）

- `node tools/rules_test.js` … ルールの自動確認
- `node tools/map_check.js` … 地図データ（国境・所領・つながり・城の間隔）の確認
- `node tools/sim.js world 10` … CPUだけで10局回し、勢力図の推移を見る
- `node tools/sim.js allseats 10 --policy=smart|nodom|domx2|rush|turtle` … 主要大名を順に方針を変えて動かす
- `node tools/diag.js [seed]` … 1局の行動の内訳
- `python tools/playthrough.py <大名> --seed N --shots DIR [--extend N] [--reload] [--slot] [--delegate]` … タイトルから結末まで実際のクリックで通す（Playwright＋Edge）
- `python tools/shot.py out.png steps.json` … 画面の撮影

## 素材

画像・音声・フォントの外部素材は使っていません。地図は緯度経度のおおよその値から描き、効果音とBGMはブラウザ内で合成しています。
文字は利用者のPCにある明朝体・ゴシック体を使います。
