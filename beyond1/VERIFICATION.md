### 3.2 内政に意味があるか（`node tools/sim.js seat|allseats --policy=...`）

同じ大名を、CPUと同じ思考（smart）と、方針を変えた思考で動かし、40季後の石高の平均を比べた（各8〜12局）。

| 方針 | 内容 | 結果（40季後の石高の平均の例） |
|---|---|---|
| smart | ふつうの思考 | 織田15.6〜19.6・北条18.2〜21.1・島津17.3〜22.0・毛利13.3〜15.5 |
| nodom | 内政をしない | 織田4.3・北条7.5・島津7.5・毛利4.6（滅亡も増える） |
| recruitonly | 徴兵だけ（開墾・築城なし） | 織田12.7・北条11.5・島津11.3・毛利8.2 |
| nodev | 開墾しない | 織田10.5・北条8.1・島津8.7・毛利6.8 |
| nofort | 築城しない | 織田21.5・北条20.8・島津19.0・毛利12.8（築城の見積もり修正後。smartとほぼ同じ） |
| domx2 | 内政の価値を2倍 | smartとほぼ同じ |
| rush | 攻めっ気を強く・慎重さを弱く | 織田16.0（8局中3局で滅亡）・上杉11.6（3局で滅亡） |
| turtle | 守り重視・内政多め | 島津12.3・北条15.9・毛利11.6（伸びが鈍い） |

- 内政をしないと大きく負ける（兵を戻す手段が徴兵しかないため）。開墾をしないと石高（＝賽と軍勢の数）が伸びず、これも大きく負ける。一方、内政を2倍重んじても得はなく、攻め一辺倒は滅びやすく、守り一辺倒は伸びない。
- 築城は、最初の見積もりではCPUが過大に評価し、「築城しない」方針のほうが伸びた（織田 19.6→22.5、島津 17.3→26.3）。見積もりを下げた後は差がほぼなくなり、「脅威が迫った城で使う」状況次第の手になった。
- **一つの単純な方針だけが常に最善にはなっていない**（ただし人間の作戦の幅は未確認）。

## 5. AIの別担当による初見確認

- 別担当：Claude のサブエージェント（汎用）。**人間の代わりではない**。
- 渡した情報：ゲームのファイルの場所と「PCブラウザ向けのターン制戦略ゲーム」という一言、報告の観点だけ。リポジトリ内のファイルを読むこと、ページ内で JavaScript を実行して内部状態を見ることは禁止し、Playwright のマウス・キー入力と画面撮影だけで遊んでもらった（本人もそう報告）。
- 遊んだ範囲：織田家で15季（永禄三年春〜永禄六年冬）。城を2つ（三河・岡崎城、美濃・稲葉山城＝奇襲）取り、石高17・3か国・第2位。内政3種・強行軍・おまかせ・委任・一手戻す・振り直し・記録枠・つづきからを試した。所要約25分（AIの操作時間で、人間のプレイ時間ではない）。
- よかった点として挙がったもの：最初にすることが分かる（大名選びの案内、「まずは賽を振る」）。勝つ見込みが％で出て、ぴったりの出目で奇襲100％になるので賽の配り方に駆け引きがある。城のツールチップの守り方の案内。コンソールのエラー0件。
