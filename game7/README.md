# 切りもどし ― 鋏と春の小さな鉢

枝を切ると、切り口から二つの芽が吹く。春を呼ぶと、芽がのびる。
鋏ひとつで木の形を決めて、ひだまりに花を咲かせる、盆栽の剪定パズルです。

## 遊びかた

`index.html` をブラウザで開くだけで遊べます（インストール・サーバー不要、PCブラウザ向け）。

| 操作 | 内容 |
| --- | --- |
| 枝をクリック | その枝を切る（カーソルを重ねると、切ったあとの芽の向きが先に見える） |
| Space / 「春を呼ぶ」 | 春を1回すすめる |
| Z / 「もどす」 | 一手もどす（何度でも） |
| R / 「やりなおし」 | 鉢を最初から（これも「もどす」で取り消せる） |
| Esc / 「棚へ」 | 表紙の棚へもどる |
| M | 音のあり・なし |

- 全11鉢と、結末のあとにひらく「自由鉢」。初見で15〜30分ほどを想定しています。
- 失敗で終わることはありません。春の回数が「名木のめやす」以内なら、仕上げに「名木」の印がつきます。
- 仕上げた木は表紙の棚にならびます（ブラウザの localStorage に保存）。

## ファイル

- `index.html` … 起動ページ
- `js/core.js` … ルールの核（描画なし。node からも使える）
- `js/levels.js` … 鉢のならび
- `js/game.js` … 画面・操作・進行　／　`js/audio.js` … 音（Web Audio で合成。外部素材なし）
- `tools/` … 検証用の道具（解法探索・分析・通しプレイ・画面撮影）
- `VERIFICATION_検証記録.md` … 実施した検証と、その結果による改善の記録
- `NETABARE_攻略とネタバレ.md` … しくみの詳細と各鉢の手順。**遊ぶ前には読まないでください。**
