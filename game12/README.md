# ころころ、ひらけ列島 ― 三つの鉄道と にっぽん開通すごろく

4月1日。にっぽんの線路は、まだ東京のまわりと東海だけ。ほかの地方は雲の向こう。
三つの小さな鉄道会社が、**サイコロで日本を走り、目的地に一番乗りして、雲の向こうの地方を一つずつひらいていく**、1年がかりのすごろくです。

- あなたは柴犬の「あかつき鉄道」。ライバルはきつねのコン社長（ゆうぐれ急行）と、たぬきのポン社長（つきよ交通）。
- **目的地に一番乗り**すると賞金。さらに、つぎに**ひらく地方をえらべ**ます。ひらいた地方への**関所はその会社のもの**になり、ほかの会社が通るたびに通行料が入ります。
- 駅では各地の**名物**を買えます。季節のおわりの**決算**で収益が入り、名物の**旬**の季節は3倍、駅の名物をぜんぶ持つと**独占**で2倍。
- 3月のおわりに、**総資産（お金＋名物の値段）がいちばん多い会社**の勝ち。

## 遊びかた

`index.html` をブラウザで開くだけで遊べます（インストール・サーバー不要。PC のブラウザ向けで、Microsoft Edge で確認しています）。音が出ます。

| 操作 | 内容 |
| --- | --- |
| クリック | サイコロ・きっぷ・とまるマス・ボタンをえらぶ |
| ドラッグ / ホイール | 地図をうごかす / ズーム |
| スペース / Enter | サイコロをふる・OK・おわる |
| 1〜9 | きっぷ・できごとの えらびを番号でえらぶ |
| やじるしキー → Enter | とまるマスをキーボードでえらぶ |
| Tab | 全体を見る（もう一度で もとにもどる） |
| Esc | ひとやすみ（あそびかた・スタンプ帳・音量・CPUのはやさ・タイトルへ） |
| M | 音の あり・なし |

- サイコロをふると、とまれるマスが光ります。マウスをのせると通る道と、そこで何が起きるかが下に出ます。
- きっぷは1ターンに1まい。快速（サイコロ2こ）・特急（3こ）・各停（すきな数）・ふみきり（相手をおそく）などがあります。
- 出目が目的地までのマス数とぴったり同じなら「ぴったり賞」で賞金1.5倍。
- 1年は24ターン（各月の上旬・下旬）。初めてなら 20〜30分ほどを想定しています（設計上のめやすで、人が遊んで測った時間ではありません）。
- CPUの番は、クリックやスペースをおしたままで早送りできます。CPUの番のはやさは、はじめは「はやい」。メニューで「ふつう」にもできます。
- 地図の駅にマウスをのせると、その駅の名物・旬・持ち主が見られます。
- 進みぐあいは、あなたの番のはじめに自動で保存されます（ブラウザの localStorage）。タイトルの「つづきから」で再開できます。
- はじめて通った駅でもらえる**駅スタンプ**と、持ったことのある**名物**は、ゲームをこえて「スタンプ帳・名物帳」に残ります。

## ファイル

- `index.html` … 起動ページ
- `js/core.js` … 乱数・数学・お金の表示の小道具
- `js/data.js` … 会社・地方・駅と名物・路線・関所・きっぷ・できごとのデータ
- `js/map.js` … 海岸線と、駅・マスの配置（いつも同じ形）
- `js/engine.js` … ルールの核（移動・目的地・地方をひらく・名物・決算・きっぷ・できごと・保存できる状態。描画なしで node からも動く）
- `js/ai.js` … ライバルの考えかた（画面でわかる情報だけで決める）
- `js/art.js` … 社長の顔・列車・マス・名物・きっぷ・サイコロ・駅スタンプの絵（すべて Canvas で描く）
- `js/render.js` … 地図・季節・雲・コマ・演出の描画
- `js/ui.js` … 画面の部品（上の帯・会社の札・手札・駅の画面・できごと・決算）
- `js/audio.js` … 音（Web Audio でその場で合成）
- `js/game.js` … 画面のきりかえ・ターンの演出・入力・保存
- `tools/` … 検証用の道具（ルールのテスト・ボットでのバランス確認・本物のマウスでの通しプレイ・画面撮影）
- `VERIFICATION_検証記録.md` … 実施した検証と改善の記録（しくみの中身にふれます）
- `NETABARE_攻略とネタバレ.md` … 攻略のコツ。**遊ぶ前には読まないでください。**

外部の画像・音声・フォント・ライブラリは使っていません（フォントは OS に入っているものを使います）。
地名・名物は一般的なものを題材にしていますが、名物の店名などはすべてこの作品のための創作です。
