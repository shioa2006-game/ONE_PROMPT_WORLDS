## 1. 企画：3案の比較

参照した過去作で、プレイヤーが見て・決めて・楽しむもの：

- 第5作『REEL DELVE』：止めたリールの3段が三人の通り道になる。**見る**＝窓の並びと三人の得意、**決める**＝どの並びで止めるか、**楽しむ**＝連鎖で稼ぎ、門を開けて深い階へ。
- 第16作『くるり、呪いほどき』：床がリール。同じ紋のつながりで魔物を人にもどす。**決める**＝一コマずらしてつながりを伸ばす、**楽しむ**＝群れがまとめて人にもどる。
- 第17作『ずらり、砦くずし』：横一行が「源・形・力」の呪文になり、三本の道へ飛ぶ。**決める**＝ずらして呪文の形と行き先を変える、**楽しむ**＝貫いた残りが砦に届いて崩れる。

16・17作は「土地を取り戻す → お礼の部品 → 工房」の流れだったので、今回は**主人公が自分から潜りたい理由**を先に決め、目的と探索の遊び方が違う3案を考えた。3案ともリールは「横の行に同じ紋をそろえる」スロットの馴染みのある形を土台にした（16作のつながり、17作の文章型とは別の読み方）。

### 案A「がらり、迷宮ひらき」― 師匠の地図の空白を、自分の目で見て描く（断面図の迷宮・撃ちぬいた先が道になる）【採用】

- **一場面**：地図の上で、いまいる広間の右に、師匠の鉛筆で「茨の奥で、金色の光を見た。炎があれば…」。左の「コウモリの巣」の奥からは赤い光がちらちらしている。先に左へ行き、鍛冶の跡で炎の紋石を3つ拾って、その場で3本のリールに刻んだ。茨の間に入ると、中の段に茨っこ、その奥に茨の壁。回すと中の行は「炎・炎・剣」、3本目のリールの上に炎がはみ出している。上の札を押すと「炎×3＝6」、茨っこに「倒す」、茨に「燃える！」。放つと火の帯が茨っこを貫いて茨に燃えうつり、光が差しこんで奥に宝箱が見える。地図にもどると、茨の奥の小部屋が鉛筆で描きこまれていく。
- **戦ったあとの可能性**：小部屋の「地図の切れ端」に「根の大広間の下の段、壁のひびの向こうに水の音」。親分を倒して4本目のリールが手に入ると、4つそろい（×4）で、そのひびに届く。
- **評価**：「見えるのに行けない」→ 紋を集めて組む → 戦いで撃ちぬいて開く → 新しい「見えるのに行けない」が輪になる。戦いの一手が、そのまま地図を広げる。

### 案B「魔物図鑑の写し紙」― 迷宮の生き物を図鑑に写す（とどめの紋で写しが取れる）

- **一場面**：地底湖の部屋で、水面に光る背びれ。図鑑の空欄に「水晶ガニ：氷でとどめ」。上の行に氷が2つ、ずらして氷×3でとどめを刺すと、殻の写しが取れてリールの「盾」の紋になる。写しを持っていると、殻の道を渡れる…
- **評価**：集める楽しさは強いが、「とどめの紋の条件」が毎戦の作業になりやすい。行きたい場所より「次の魔物」に気持ちが向き、場所を見つけるワクワクが薄い。

### 案C「竜の子を親もとへ」― 迷宮で孵った竜の子を、最下層の巣へ送りとどける

- **一場面**：細い横穴の奥に宝石のきらめき。竜の子はまだ小さく、穴を通れる。宝石を食べさせると息の紋が「火の粉」から「炎」へ育ち、次の戦いでリールに炎が増える。
- **評価**：愛着は強いが、竜の成長が「通れる道」と「リールの紋」の両方を担い、プレイヤー自身が組み立てるより「育てる」側に寄る。竜の成長段階ごとの絵と動きの量が大きく、15〜30分に仕上げる見込みが立ちにくい。

### 比較と採用理由

| | 案A 地図の空白 | 案B 図鑑 | 案C 竜の子 |
| --- | --- | --- | --- |
| 探索そのものへの期待 | ◎ 師匠の下書き・気配・壁の向こうの光。断面図を下へ | ○ 次の魔物 | ○ 竜が嗅ぎつける |
| 一手の気持ちよさ | ◎ 行がそろい、魔物を貫いて壁が崩れる | ○ とどめの条件 | ○ |
| 探索と戦闘のつながり | ◎ 拾った紋で組む ⇄ 撃ちぬいた先が地図になる | ○ | △ 竜が両方を担う |
| 15〜30分に仕上がるか | ○ 3層＋底、25部屋・13戦 | ○ | △ 絵の量 |

**採用：案A**。戦いの結果（余った力が壁に届く）が、そのまま地図に新しい道を描く。逆に、地図で見た壁（茨・湖・歯車・封印・ひび）が「次はどの紋を、どのリールに刻むか」を決める。これを第18作の工夫「**撃ちぬいた先が、道になる**」とした。
案Bは集める楽しさはあるが場所への期待が薄く、案Cは愛着は強いが組み立ての主役がプレイヤーから離れ、量も大きいので見送った。

### 採用案で決めたこと

- **視点**：地図は羊皮紙の断面図（縦にスクロール）。師匠の鉛筆の下書き（部屋の形とメモ）があり、ミオが入った部屋だけが水彩とインクで描きこまれる。戦いは、その部屋の中の横から見た三段の戦場。
- **リール**：3本 → 4本 → 5本。各8コマ、窓に3行。行は左から読み、同じ紋が2つ以上つづくと呪文（2つ×1、3つ×2、4つ×4、5つ×8。星は代わりになり2倍）。行の力＝そろった紋の Lv の合計×倍率。
- **ずらし**：窓の上下にはみ出した札を押すと、その紋が窓に入る（魔力1）。押すものが「入ってくる紋そのもの」なので、第17作で別担当が迷った「▲の下の名前は▼で入る」の取り違えが起きにくい。
- **撃ちぬく**：呪文は手前の魔物から順に貫き、倒すのに使った分を引いた残りが奥へ。段の魔物をみな倒して力が残れば、段の奥の壁に届く。壁は合う紋で、一撃で決まった力以上なら崩れる。
- **紋の性格**：炎（茨・草木と氷の魔物に2倍）、氷（生き残りを凍らせて一歩止める・湖を凍らせる）、雷（列の全員に同じ力・歯車を動かす）、光（封印・骸骨と亡霊に2倍）、星（代わり・2倍）。
- **成長**：宝・戦いのあとの二択・鍛え石。主を倒すとリールが増える。
- **使い切る場面**：第三層の「番人の大回廊」で、これまでの主たちがまとめて押し寄せる。底では三段にまたがる番人と戦い、最後に育てたリールの一撃で「最後の壁」を崩す。
- **結末**：完成した地図と、層ごとの「いちばん強い一行」。クリア後も地図にもどって描き残しを探せる。

## 2. 早めに遊んで確かめたこと（短い区間）

最初に「縦穴の底 → 坑道の広間（戦い）→ コウモリの巣（戦い）→ 鍛冶の跡（炎の発見）→ 茨の間（炎で茨を焼く）→ 茨の奥の小部屋」を遊べる形にし、実際の画面と通常操作（Playwright の本物のクリック）で確かめた。

### 確かめた3点

| 依頼の確認点 | 画面で読み取れたこと |
| --- | --- |
| 初めて見る分岐や発見に、行き先を選ぶ手掛かりがあるか | はじめの地図に、師匠の鉛筆の部屋とメモ（「コウモリだらけ。奥は見ていない」「茨の奥で、金色の光を見た。炎があれば…」「親分がいる。ここで二度、引き返した」）。広間に入ると、となりの部屋の気配（鍛冶の跡なら「赤い光がちらちらしている」と光の印）が描きこまれる。部屋にマウスを重ねると、メモ・気配・行けない理由（「茨の壁にさえぎられて行けない（炎の行で2以上）」）が出る |
| リールの一か所を組み替え、同じ局面で試したとき、何が変わったか読み取れるか | `tools/compare.py`：茨の間で、戦いの前に「詠唱輪を組む」→「試す」（この部屋の様子で試し詠唱）。組み替え前は中の行が「炎×2＝2」、茨に「届く 2（あと1）」→ 炎を3本目のリールのマスに一つ刻んで「同じ回転で」→ 中の行が「炎×3＝6」、茨っこに「倒す」、茨に「燃える！」。放つと茨が燃え落ち、下の文に「同じ止まり方で比べると：組み替え前 倒した 3体・傷の合計 7 → 組み替え後 倒した 3体・傷の合計 7・壁が崩れた　強くなった！」 |
| 探索で得たものを早いうちに戦闘で試せるか／大技の直後に味わう間と、次に見たい対象があるか | 炎は拾った直後に組みかえの画面が開き、2部屋先の茨の間で使える。茨の間のはじめの回転は「一つずらせば炎の行が茨まで届く」止まり方になり、押す札に「ここを押す」。放つと、光の筋・がれき・「茨の壁が燃え落ちた！ 奥に、新しい道が見えた」・崩れた穴の向こうに宝箱。0.7秒の間をおいて残りの行が飛び、結果は画面下の帯に出るので、崩れた壁の向こうが見えたまま。地図にもどると、茨の奥の部屋に金色の輪と「新しく見えた！」、鉛筆が輪郭を描いていく |

### この区間で見つけて直した問題

| 見つけた問題 | 直したこと |
| --- | --- |
| 教える回転の案内が「上にはみ出した『剣』を押すと…」と、押す札の名前を出していた（本当に大事なのは、そのとき中の行に入る「炎」） | 「3本目のリールの上の札を押すと、リールが一コマ下にずれて『炎』が中の行に入り、行がそろう。魔物を貫いて、茨の壁まで届く！」と、入ってくる紋と行を名指しする |
| 勝ったときの表示が画面の真ん中をおおい、崩れた壁の向こうが見えない | 結果を画面下の帯に移した。戦場（崩れた壁と、その向こうの宝箱や光）は見えたまま |
| 親分を倒してリールが4本になった瞬間に、画面が止まる（リールの数と表示用の配列がずれ、描画で例外） | ほうびでリールが増えたら、表示用の配列も足す。例外が起きても描画の繰り返しが止まらないようにした |
| 試し詠唱で茨を崩すと、本物の茨まで開いてしまう | 試し詠唱は地図にも記録にも残さない（ルールのテストで確認） |
| 地図で新しい部屋が見えても、薄い点線が出るだけで気づきにくい | 壁の向こうの部屋は、金色の輪と星・「新しく見えた！」を約4秒。鉛筆の先が輪郭をなぞって描いていく。カメラもその部屋へ向く |
| ずらしの札が光るだけでは、どこを押すか目立たない | 光る札の上（下）に、上下に揺れる矢印と「ここを押す」 |

### 部屋を増やす前に磨いたこと

- **リールが決まる瞬間**：左から順に止まり、止まるたびに「がちん」と少し行きすぎて戻る。止まった時点で行が伸びていれば、そのマスがすぐ光り、そろった数に応じた和音が鳴る。あと一本でそろう行があるときは、最後のリールだけ少し長く回り、金色に明滅する（リーチ）。最後のリールの音は重い。
- **反復のテンポ**：回転は全部で約1秒。放つ演出は行ごとに0.2〜0.5秒、魔物の手番は約0.3〜0.5秒（初見確認のあとに詰めた。下記6.）。演出中はスペースで3倍速、メニューの「演出：はやい」で2倍。地図は一部屋0.34秒で歩き、行ける部屋ならクリック一回で途中の部屋を通って歩く。
- **新しい場所が見える瞬間**：初めて入った部屋は、水彩がにじむように広がり、インクの線が引かれ、和音が鳴る。となりの部屋は鉛筆で描きこまれる。壁の向こうの部屋は上記の金色の輪。

## 3. ゲームシステム・バランス（ボット）

ボットは盤面・魔物・壁（画面に出ている情報）を知っているが、次の回転の出目は知らない。

- 戦い方：smart（魔力の範囲で、ずらし方をすべて試して最善。画面の「ヒント」と同じ計算）／one（魔力を1までしか使わない。静かな部屋では+2まで）／none（ずらさない）
- 組み方：smart（新しい紋は、その紋が少ないリールの空きへ。鍛え石は多く刻んだ紋へ。二択は今の組み方に合うほう）／random（でたらめ）
- 順路は、宝と隠し部屋も含めて全部の部屋をまわる。残った壁は静かな部屋で3回まで試す。

### 最初の版で見つかった問題と変更

| 問題（ボットで観察） | 変更 |
| --- | --- |
| 最後の戦いが勝てない（0%）。それ以外は無傷で勝てる。最強の一行が第一層6 → 最後50 と伸びが小さい | 倍率を 2つ×1・3つ×2・4つ×3・5つ×5 から ×1・×2・×4・×8 に。戦いのあとに「持ち帰る紋の二択」を足し、刻める紋を増やした（4本目・5本目のリールにも属性が入る）。後半の魔物の体力を上げた |
| 茨が崩せないと、ボットが茨の部屋で足ぶみする（静かな部屋で36回詠唱しても崩れない場合があった） | 茨は「炎の行で2以上」に（炎×2でも届く）。静かな部屋は魔力+2 |
| 気軽な遊び方（one）だと最後の番人で何度も負ける | 主に与えた傷は、負けても残る（体力の25%までは残す）。番人の腕・胸の体力と増援を減らし、腕の一撃を4手番ごとに |
| 気軽な遊び方だと、昇降機・閲覧室で10手番以上かかる | ゴーレムの体力 64→56、石の司書 28→22、封印から出る亡霊を5→4 |
| 最後の一撃が、それまでの最強と同じくらいで盛り上がらない | 番人の心核（鍛え石3つ分）を落とすようにし、最後の壁を 120→150 に。鍛えてから狙う一撃にした |

### 現在の数値（各8局、`node tools/bot.js 8 <戦い方> <組み方>`）

| 戦い方／組み方 | 結末まで | 負け（1局あたり） | 詠唱の回数 | 層ごとの最強の一行（第一層 / 第二層 / 第三層 / 底） |
| --- | --- | --- | --- | --- |
| smart／smart | 8/8 | 0 | 68 | 15 / 33 / 113 / 166 |
| one／smart | 8/8 | 0.75（すべて最後の番人。一発で越えたのは25%、平均1.75回目） | 118 | 18 / 35 / 104 / 136 |
| none／smart | 0/8 | 2.1 | ― | 第二層の地底湖（氷で凍らせる壁）で止まる。ずらさないと壁に届く行を作れない |
| one／random | 0/8 | 2.6 | ― | 第二層〜第三層で止まる（でたらめに置くと、氷・雷・光の行がそろわない） |

部屋ごと（smart／smart、one／smart の手番数）：広間 4.0／4.1、コウモリの巣 4.0／4.5、茨の間 5.1／6.1、根の大広間 3.1／4.5、水晶の洞 5.8／6.3、氷の滝 5.1／5.9、湖の渡し 5.9／6.1、古い昇降機 4.1／10.6、骸骨の回廊 5.8／7.5、閲覧室 6.0／9.8、封印の扉 5.3／8.5、番人の大回廊 4.3／9.6、空白の前 4.6／10.9。
静かな部屋で壁を狙った回数は、smart で 1.0〜1.7回、one で 1.0〜3.8回。

読み取れること：

- **ずらしは必須**。ずらさない方針は第一層の広間・コウモリの巣でも負けることがあり（一発成功 88%・75%）、第二層の地底湖を凍らせられずに止まる。一方、魔力を1しか使わない方針でも結末まで行ける。
- **組み方の差が大きい**。新しい紋を1本目のリールにも刻まないと、その紋の行ができない。でたらめに置く方針は中盤で止まる。そのため、静かな部屋とたたかいのはじめに「1本目のリールに『氷』がないので、氷の行ができない」「いまの組み方では、氷の行は最大でも 2（4 要る）」のように理由を出すようにした。
- **伸び**：最強の一行は、smart で第一層 15 → 底 166（約11倍）。4本目（×4）と5本目（×8）のリールが増えたときの伸びが大きい。
- 最後の壁だけは、届いた力が積み重なる（一撃で届かせれば一発。組み方が弱くても行き止まりにならない）。
- 限界：ボットは人間ではない。smart はずらし方を全部試すが、人間は全部は試さない（「ヒント」を使えば同じ答えは見られる）。one を「見こみを見ながら少しずらす人」の目安にしたが、確かめていない。

## 4. 機能・進行の確認

## 7. 設計の要点（まとめ）

- **繰り返す行動**：地図で部屋を選んで歩く → 戦いで回す → 窓の三行（＝三つの段）を見て、はみ出した札を押してずらす → 放つ。ずらしは戻せば魔力ももどるので、魔物の上の「倒す」「−数字」と壁の見こみを見ながら試してから決められる。
- **気持ちよい成功の設計**：リールが左から順に「がちん」と止まり、そろった行がその場で光って和音が鳴る（あと一本でそろうときは最後のリールが長く回る）。放つと、紋ごとの光の帯（炎・氷・雷・光・星）が魔物を手前から貫き、倒すたびに音が上がる。余った力が壁に届くと、光の筋・がれき・壁ごとの崩れ方（燃え落ちる・凍る・歯車が回る・封印がとける）と、穴の向こうに見える宝箱や光。4体以上なら「◯体まとめて！」、6体以上なら「ごっそり◯体！」。
- **次を見たくなる仕組み**：断面図の地図を下へ。師匠の鉛筆の下書きとメモ（師匠が引き返した場所）、まだ見ていない部屋の気配、門の印（茨・湖・歯車・封印・ひび）と、そこに要る紋。壁を崩すと、その向こうの部屋が金色の輪で描きこまれる。隠し部屋は6つ。底には「空白」。
- **往復の工夫（撃ちぬいた先が、道になる）**：地図で見た壁が「次にどの紋をどのリールに刻むか」を決め、戦いでその紋の行を壁まで届かせると地図が広がり、また新しい壁と気配が見える。
- **使い切る場面**：番人の大回廊で、これまでの主たち（親分・ゴーレム・司書）がまとめて押し寄せ、5本そろいの一行が段ごと貫く。底の番人を崩したあと、心核で鍛えて最後の壁へ。結末で層ごとの最強の一行が並ぶ。

## 8. 人間に遊んで確かめてほしい点

1. 地図を見て「あそこへ行ってみたい」と思えるか。師匠のメモ・気配・門の印が、行き先を選ぶ手がかりとして働くか（それとも情報が多すぎるか）。
2. 茨の間などで、自分で刻んだ紋を一つずらして壁まで届かせる一手が、「狙って決めた」手応えになるか。戦いのはじめの「ここを押す」案内が、決められた局面だと感じて冷めないか。
3. 第三層の番人の大回廊と最後の一撃で、育てたリールで「以前は手ごわかった相手をまとめて突破する」気持ちよさがあるか。全体が20〜30分に収まるか（ボットの通しで詠唱およそ65〜120回）。

- 人間のプレイ時間、難しさの体感、面白さ、愛着。
- 音（実際に聴いていない。エラーが出ないことだけ確認）。
- スマートフォン・タッチ操作（ポインタイベントにしたが、実機では確かめていない。画面は PC 向け）。
