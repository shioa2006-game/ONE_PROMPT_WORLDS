# がらり、迷宮ひらき ― 詠唱輪と地図の空白

だれも底を見たことがない大穴「底なし洞」。
地図描きの見習いミオは、師匠が四十年かけて描いた地図の、いちばん下の「空白」を自分の目で見て描くために、縦穴を降りていく。

戦いでは、詠唱輪（リール）を回して止め、横の行に同じ紋をそろえる。そろった行は、その段の魔物を手前から順に貫き、余った力は段の奥の壁に届く。
茨は炎で、地底湖は氷で、歯車は雷で、封印は光で。壁が崩れると、その向こうの部屋が地図に描きこまれる。
見つけた紋を自分のリールに刻み、一コマずらして「いまなら届く」並びを作り、撃ちぬいた先へ進んでいくゲーム。

ONE PROMPT WORLDS の第18作。Claude Opus 5.5 が1つの依頼から企画・実装・検証・改善まで自律的に制作した。

- PCブラウザ向け。マウスだけで遊べる（キーボードも使える）。音が出る。
- 1回の目安：20〜30分（設計上の目安。人間のプレイ時間は未計測）。

## 起動

`game18/index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動く。サーバー・ビルド・外部ライブラリ・外部素材は使っていない。

簡易サーバーで開く場合は、リポジトリ直下で次を実行して <http://127.0.0.1:8018/> を開く。

```bash
python -m http.server 8018 --bind 127.0.0.1 --directory game18
```

進み具合はブラウザの localStorage に保存され、タイトルの「つづきから」で再開できる（戦いの途中でやめた場合は、その部屋に入る前から）。

## 操作

| 操作 | マウス | キー |
| --- | --- | --- |
| 地図で部屋へ歩く | 部屋を押す | ― |
| 地図を上下に動かす | ホイール・ドラッグ | ↑ ↓ |
| 回す／放つ／演出の早送り | 右下の大きなボタン | スペース・Enter |
| リールを一コマずらす | 窓の上下にはみ出した札を押す（ホイール、リールを上下にドラッグでも） | Q W E R T（上の札）／ A S D F G（下の札） |
| ずらしを全部もどす | 「戻す」・右クリック | Z |
| ヒント | 「ヒント」 | H |
| 戦いのあとに持ち帰る紋を選ぶ | 札を押す | 1 ・ 2 |
| 説明を読む | 紋・魔物・壁・行の札にマウスを重ねる | ― |
| あそびかた／音／メニュー | 右上の ？ ♪ ≡ | M（音）・Esc（メニュー） |

詠唱輪を組む画面では、持ち物の紋を押してからリールのマスを押すと刻める。リールのマスを押すと持ち上げて入れかえられ、右クリックで外せる。「鍛える」で鍛え石を使って紋の Lv を上げられる。

メニューでは、音、音量、「演出：はやい」、「自動で回す」を切りかえられる。

## 遊びの流れ

1. **地図**：師匠の鉛筆の下書きと、まだ見ていない部屋の気配（光・足音・風）を手がかりに、行く部屋を選ぶ。初めて入った部屋は色がついて地図に描きこまれる。
2. **戦い**：魔物のいる部屋に入ると戦いになる。
   - 回す：リールが止まる。横の行は左から読み、同じ紋が2つ以上つづくと呪文になる（2つ×1、3つ×2、4つ×4、5つ×8）。上の行は上の段、中の行は中の段、下の行は下の段へ飛ぶ。
   - ずらす：はみ出した札を押すと、その紋が窓に入る。魔力を1使う（戻せばもどる。毎手番、満タン）。魔物の上の「倒す」「−数字」と、壁の上の見こみがその場で変わる。
   - 放つ：呪文は手前の魔物から順に貫き、余った力が段の奥の壁に届く。そのあと魔物が一歩進む。ミオの前まで来た魔物は心を減らす。
3. **壁**：茨・地底湖・歯車・封印・ひびの入った壁は、合う紋の行で、決まった力以上が一撃で届けば崩れる。魔物を追いはらったあとの部屋では、魔物なしで落ち着いて狙える（静かな部屋。魔力+2）。
4. **紋を刻む**：宝や戦いのあとに選んだ紋を、地図の右の「詠唱輪を組む」で刻む。「試す」では、組み替える前と後を同じ止まり方で比べられる。

心が尽きると逃げ帰る（崩した壁と手に入れたものは残る。主に与えた傷も残る）。底の「空白」まで描けば一区切り。そのあとも地図にもどって、描き残した部屋を探せる。

## 検証用ツール（開発者向け）

- `node tools/rules_test.js` … ルールの自動確認
- `node tools/bot.js 8 smart smart` … ルールだけで全編を回すボット（戦い方 none / one / smart、組み方 random / smart）
- `python tools/playthrough.py --fast [--seed N] [--reload] [--keys] [--until 部屋] [--shots DIR]` … タイトルから結末まで、本物のクリックとキーで通す（Playwright＋Edge）
- `python tools/compare.py DIR --search` … 「リールを一か所組み替えて、同じ止まり方で比べる」を本物のクリックで確かめる
- `python tools/shot.py DIR steps.json` … 画面の撮影
- URL に `?seed=N` を付けると、新しく始めたゲームの乱数を固定できる
