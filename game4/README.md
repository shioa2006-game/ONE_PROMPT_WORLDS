# LUMEN REEL（ルーメンリール）― まわる灯台と三つの海路

灯台の灯室が、まるごとスロットになっている。
リールを回して止まった部品の並びが、そのまま光の通り道になり、三つの海路へ伸びていく。
迷った舟に光を届けて港へ帰し、夜明けの工房でリールそのものを組み替えながら、五つの夜を越えるゲーム。

ONE PROMPT WORLDS の4作目。Claude が1つのプロンプトから、企画・実装・検証・改善まで自律的に制作した。

## 起動方法

静的ファイルだけで動く。ビルドや追加インストールは不要。

`game4` フォルダで簡易サーバーを立て、ブラウザで開く。

```bash
python -m http.server 8768 --directory game4
```

開く URL：`http://localhost:8768/`

（`index.html` をブラウザで直接開いても動く。進行状況と記録はブラウザの localStorage に保存される。）

推奨環境：PC のブラウザ（Chrome / Edge）。画面は 16:9 で、ウィンドウの大きさに合わせて伸縮する。音が出る。

## 操作方法

マウスだけでも、キーボードを併用しても遊べる。

| 操作 | マウス | キー |
| --- | --- | --- |
| リールを回す／光を放つ | 右下の大きなボタン | スペース（Enter） |
| 回転中にすぐ止める | 右下のボタン | スペース |
| リールを一コマずらす（上／下） | リールの上下の ▲ ▼ | Q W E R ／ A S D F |
| リールを固定する（回す前） | リール下の「固定」 | 1 2 3 4 |
| 部品・舟の説明を読む | マウスを重ねる | ― |
| リール全体の並びを見る | 「リール表」 | ― |
| あそびかた | 右上の「？」 | ― |
| 音を止める／鳴らす | 右上の「♪」 | M |

工房では、右側の部品や道具を選んでから、左側のリールのコマを押す。Esc か右クリックで持っているものを戻せる。

## 遊びの流れ

1. リールを回す。止まった部品の並びに沿って、光の通り道が点線で見える。
2. 必要なら ▲▼ でリールをずらし、通り道を変える（ゼンマイを使う）。
3. 光を放つ。光は左から右へ進み、三つの海路の舟に届く。
4. 舟は一手ごとに岩礁へ近づく。数字のぶんの光を届ければ港へ帰れる。
5. 夜が明けたら、工房で部品を手に入れ、リールの好きな場所へ組みこむ。
6. 五つの夜を越えると結末。クリア後は「荒海」に挑戦できる。

夜の途中で失敗しても、差し入れをもらって工房からその夜をやり直せる。

## ファイル構成

- `index.html` … 入口
- `js/sim.js` … ルール本体（描画に依存しない。ボットからも使う）
- `js/render.js` … 部品・舟・背景の描画
- `js/audio.js` … 効果音と環境音（すべて WebAudio で合成。外部素材なし）
- `js/main.js` … 進行・入力・画面
- `tools/` … 開発時のバランス確認ボットと、通しプレイ用ドライバ
- `VERIFICATION_検証記録.md` … 実施したプレイテストと改善の記録
- `NETABARE_攻略とネタバレ.md` … 仕組みと攻略の詳細（**遊ぶ前に読まないことをおすすめ**）
