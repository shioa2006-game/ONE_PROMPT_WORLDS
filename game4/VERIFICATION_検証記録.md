# LUMEN REEL ― 検証と改善の記録

制作日：2026-11-15。ここには、企画の選定理由、実際に行った検証、見つけた問題と直した内容、確認できていないことを残す。
仕組みの詳細（ネタバレ）は `NETABARE_攻略とネタバレ.md` に分けてある。この記録にも数値や仕組みの話が少し出てくる。

## 1. 企画の選定

スロットを中心に、遊びの核が違う 3 案を比べた。

| 案 | 核 | 判断 |
| --- | --- | --- |
| A. 一文スロット | 出目を左から順に「主人公の出来事」として読む（剣→怪物なら勝ち、怪物→剣なら負け） | 順番の意味は面白いが、結局は「出目で戦闘結果が決まる」形に寄りやすい。却下 |
| B. 落ちものスロット | 出目が各リールの真下の列へ積み上がり、積んだ盤面で消したり育てたりする | 盤面は残るが、スロット側が「ピースの抽選機」に留まる。却下 |
| C. 光の回路スロット（採用） | 3×3 の出目そのものが光学回路になり、光が左から右へ流れて、行ごとの海路へ出ていく | リールの**列の順番・行・リール上の隣り合わせ**という、スロット固有の構造がそのまま遊びの対象になる |

採用理由：C は「回して結果を見る」行為が、光が流れていく様子として毎回ちがう形で見える。ずらし・固定・リールの組み替えといったスロットらしい操作が、すべて回路いじりとして意味を持つ。灯台の光学部品（炎・レンズ・鏡・プリズム）と題材が一致し、絵としても一目で伝わる。

中心に置いた喜び：**爽快感**（光が束になって伸びる）、**発見**（部品の順番と組み合わせ）、**成長**（自分で組んだ灯室が夜ごとに強くなる）。

## 2. 検証の方法

三つを分けて行った。

1. **ルールのシミュレーション**（node）：`tools/bot.js`。描画なしでルールだけを回し、方針の違う自動プレイを 20〜30 回ずつ通す。
2. **実ブラウザでの通し確認**：`tools/autoplay.js`。ページ上で、**実際のボタン座標を押して**タイトルから結末まで進める。時間は手動でコマ送りする。
3. **実時間・実入力の確認**：ヘッドレスの Edge を Playwright で動かし、マウスのクリックとキー入力のイベントを本物として送る。画面は 1280×720 で撮って目で確認した。

制作環境のブラウザペインのスクリーンショットが途中から不安定になったため、画面の確認は主に 3 の方法（Edge）で行った。

## 3. 機能検証（結果）

| 項目 | 結果 |
| --- | --- |
| タイトル → 第一夜 → … → 第五夜 → 結末までの通し（実ボタン操作） | 完走。コンソールエラー 0 |
| 回す／止める／光を放つ（スペース・ボタンの両方） | 動作 |
| ずらし：消費、上限での拒否、放つ前に戻すと消費が戻る | 動作（3 つ使って 4 つ目は拒否、戻すと 0 に） |
| 固定：指定したリールが回らない、ゼンマイ消費、全リール固定の拒否 | 動作 |
| ゼンマイの巻き戻り（二手で 1 つ） | 動作 |
| 貨物船の積み荷 → 組みこみ → 夜へ復帰 | 動作 |
| 工房：購入、重ね強化、入れ替え、コマを外す、品ぞろえ替え、最初からやり直す | 動作（やり直すと貨幣とリールが元に戻る） |
| 難破 3 隻で失敗 → 差し入れ → 工房 → 同じ夜を再開 | 動作 |
| 保存と「つづきから」（夜の頭・工房の両方から再開） | 動作（第四夜・四本リールの状態で復帰を確認） |
| クリア後の記録保存、保存データの消去、荒海モードの開始 | 動作 |
| 実時間での描画 | ヘッドレス Edge で 約 60fps |

見つけて直した不具合：

- **積み荷を組みこんだ直後に「受け取らずに戻る」を押すと、二重に画面を抜けて例外が出た。** 人間でも 0.5 秒以内に押せば起きる。組みこみ後は入力を止め、戻る処理を一度だけにした。
- 工房や夜明けで出る 404（favicon）をなくした。

## 4. ゲームシステム検証（結果）

`tools/bot-results.txt` に全文がある。主なところ：

| 方針 | 内容 | 夜ごとの一発成功率（1→5 夜） | クリア |
| --- | --- | --- | --- |
| 何もしない | ずらさない。買うのは一度に 4 つまで、空きに適当に置く | 100 / 10 / 13 / 4 / 0 % | 0/30 |
| 配置を考えない | ずらしは上手いが、置き場所は適当。強化も灯芯も使わない | 100 / 97 / 100 / 53 / 21 % | 16/30 |
| ふつう | 危ない時だけ 1 コマずらす。置き場所は 3 候補から選ぶ | 100 / 77 / 77 / 80 / 67 % | 30/30 |
| 工夫する | ずらしを毎手検討し、置き場所も全探索 | すべて 100 % | 30/30 |
| 工夫する（荒海） | 同上、必要な光 1.5 倍 | 100 / 95 / 100 / 95 / 80 % | 20/20 |
| ふつう（荒海） | 同上 | 80 / 5 / 39 / 22 / 19 % | 15/20 |

（「ふつう」は最終の数値で計測。ほかの行は、第二夜の早舟を少し緩める直前の数値で計測した。第二夜以外は同じ。）

読み取れること：

- **同じ連打では通らない。** 回して放つだけ（何もしない方針）では第二夜から厳しい。
- **ずらしの効果が大きい。** 実ブラウザの通しでも、買い方が同じで「ずらす／ずらさない」だけを変えると、やり直しが 0 回と 10 回に分かれた。
- **置き場所・強化の効果は終盤に出る。** 配置を考えない方針は第三夜まで通るが、第四夜・第五夜で大きく落ちる。
- 「工夫する」方針は平均の星明かり（余った光）が「ふつう」の約 2 倍。クリアできるかどうかとは別に、上達の余地が点数として残る。

限界：ボットは人間ではない。「ふつうの方針」が人間の初見プレイヤーに近いかどうかは分からない。難易度の体感は未確認。

## 5. 画面・操作検証（結果）

1280×720 の実画面を撮って確認したもの：タイトル、夜の導入、回転中、リーチ、見こみの点線、照射、ゾロ目、霧の夜、四本リール、嵐の夜と客船、夜明け、工房、積み荷、失敗、あそびかた、リール表、結末。

- 光の通り道（点線）と、海路ごとの数字が読めること。
- 赤い輪の舟（この手で導かないと難破）が他と区別できること。
- 部品・舟にマウスを重ねると、下の欄に説明が出ること。
- 四本リールになっても、灯室・数字・岩礁が重なって読めなくならないこと。

## 6. 検証を受けて直したこと

### ゲームデザイン

1. **ゼンマイが尽きると、残りの手番で何もできなくなっていた。**
   - 当初：夜のはじめに全回復、あとは「2 隻同時」「ゾロ目」での巻き足しだけ。
   - 通しプレイで、夜の前半に 3 つ使うと残り 10 手ほどが「回して放つだけ」になるのを確認した。
   - 変更：一手ごとに半分ずつ巻き戻る（二手で 1 つ）ようにし、巻きかけを表示した。
   - 再検証：ずらしがほぼ毎夜を通して使えるようになった。そのぶん簡単になったので、第二夜〜第五夜の必要な光を引き上げて釣り合いを取り直した（上の表は変更後）。
2. **失敗が続くと進めなくなるおそれ。**
   - ボットでは、空きコマを埋めきったあと貨幣の使い道を見つけられない方針が、同じ夜で止まり続けた。
   - 変更：やり直しの差し入れを、同じ夜で失敗するたびに 3 貨ずつ増やした。
   - 再検証：まったくずらさない自動プレイでも、やり直し 10 回で結末まで到達した。
3. **品ぞろえ替えが安すぎて、欲しい部品だけを引き直し続けられた。** 頼むたびに 1 貨ずつ高くなるようにした（工房を出ると戻る）。
4. **序盤が厳しめだった。** 第一夜・第二夜の必要な光を下げた（第一夜は「ふつう」でも難破 0.3 隻程度）。
5. **新しい種類の舟やカモメの意味が、マウスを重ねるまで分からなかった。** 初めて現れた時に、下の欄へ一度だけ説明を出すようにした。
6. **重ね強化に気づく手がかりがなかった。** 部品を持ってコマにマウスを重ねると、「置き換え／強化／これ以上は強くできない」が出るようにした。

### ビジュアル・操作感

1. 見こみの点線が細く薄くて、通り道を読み取りにくかった → 太く、濃くした。
2. 「-7」「★+13」などの数字が小さかった → 大きくした。
3. 星明かりの数字が、光が届く前に増えていた → 光が当たった瞬間に増えるようにした。
4. 案内文で、行の頭に「。」が来ていた → 句読点が行頭に来ないようにした。
5. 四本リールのとき、海路の数字と岩礁が重なっていた → 岩礁を右へずらした。
6. 夜の導入・夜明け・失敗の表示が灯室に重なっていた → 海側へ寄せた。
7. 結末で、帰ってくる船が成績表の裏に隠れていた → 画面の下を通るようにした。
8. 「リーチ！」「ゾロ目 ×N」の文字が灯室の枠に重なっていた → 枠の外へ出した。

## 7. 確認できていないこと・既知の点

- **人間が遊んで面白いかどうかは、確認できていない。** 上の検証は、動作・数値・画面の読みやすさまでで、感情の確認ではない。
- **音は耳で確認していない。** 合成コードは動いているが、音量の釣り合いや心地よさは未確認。うるさければ右上の「♪」か M キーで止められる。
- 実際の人の手による通しプレイ時間は測っていない。自動プレイでは演出だけで約 5 分かかるので、考える時間と工房を入れて 15〜25 分程度と見積もっている。
- スマートフォンは対象外。タッチで押せるようにはしてあるが、説明がマウスを重ねる前提なので、遊びやすさは保証しない。
- 終盤、リールが部品で埋まるとゾロ目がかなり頻繁に出る（自動プレイで 1 周 20 回前後）。爽快さとして残したが、多すぎると感じるかもしれない。
- 通常の海は、ずらしを毎手きちんと使う人には易しめの可能性がある。その場合の歯ごたえは「荒海」と、難破 0 隻・星明かりの記録に任せている。

## 8. 人に遊んで確かめてほしい点

1. 最初の 1〜2 分で、「回す → 点線を見る → 放つ」の流れが説明を読まずに分かるか。
2. ▲▼ でずらすのは、楽しい工夫に感じるか、それとも面倒な総当たりに感じるか。
3. 工房で「どこに置くか」を考えたくなるか。置き場所の違いを実感できるか。
4. 第三夜（霧の船）と第五夜（ひかり丸）で、灯室の組み方を変えたくなるか。
5. 終わったあと、別の組み方でもう一度やりたくなるか。
