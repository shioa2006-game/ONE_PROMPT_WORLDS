# LUMEN REEL ― 攻略とネタバレ

**この資料は、ゲームの仕組みと攻略をすべて書いています。**
自分で発見する楽しみを残したい場合は、一度クリアしてから読んでください。

---

## 1. 光の計算（すべての土台）

- 三つの海路（行）それぞれに、光源から「もとの光」（最初は 1）が入る。
- 光は左のリールから右のリールへ、一列ずつ進む。各コマの部品が、通る光を変える。
- 同じコマに複数の光が入ったら、足し合わされてから部品のはたらきを受ける。
- 最後のリールを出た光が、その海路の舟へ届く。

| 部品 | はたらき |
| --- | --- |
| 素通しガラス | そのまま通す |
| 炎（+1〜+3） | 光に数字を足す。光が 0 でも自分で灯る |
| レンズ（×2〜×4） | 光を掛ける。光が 0 なら 0 のまま |
| 上向きの鏡／下向きの鏡 | 次の列で、ひとつ上／下の海路へ光を移す。端の行では何も起きない（まっすぐ通る） |
| プリズム | 次の列で、上下の海路にも**同じ量の光を複製**する（中央の行なら合計 3 倍、端の行なら 2 倍） |
| 種火（+1〜+9） | 炎と同じ。**入ってきた光が自分の数字以上**なら、照射のたびに +1 育つ（最大 +9） |

### ここから出てくる発見

- **足してから掛ける。** 炎→レンズは (1+1)×2=4、レンズ→炎は 1×2+1=3。炎は左のリール、レンズは右のリールが強い。
- **鏡で束ねてから掛ける。** 鏡そのものは光を増やさないが、三つの海路の光を一本に集めてからレンズを通せば、一つの海路に大きな光を作れる（霧の船・ひかり丸向き）。
- **プリズムは「増やす」部品。** 複製なので、左寄りに置くほど、その後のレンズが全部の行で効く。
- **種火は置き場所で化ける。** 一本目のリールでは、もとの光（1）以上の数字には育てない（+2 止まり）。強い光が通る二本目以降に置くと、あっという間に +9 まで育つ。灯芯を太くすると、一本目でも育つ上限が上がる。
- **同じコマの縦の並びは、リール上の隣どうし。** 灯室には続いた三コマが見えるので、リールの上で「下向きの鏡・何か・上向きの鏡」と並べておくと、止まり方しだいで三つの光が中央へ集まる「集光の三コマ」になる。

## 2. ゾロ目

- 横一列が**すべて同じ種類の部品**（素通しガラスは除く。強化の段階は問わない。カモメがいる列は不成立）だと「ゾロ目」。
- 三本リールなら全海路の光が **2 倍**、四本リールなら **3 倍**。二列・三列同時なら掛け算で重なる（三本×三列で 8 倍、四本×三列で 27 倍）。
- ゾロ目が出ると、ゼンマイが 1 つ巻き足される。
- 最後の一本を残して揃っていると「リーチ！」の演出が入る（結果は回した時点で決まっており、演出で確率は変わらない）。
- 光を放つ前の見こみにも「ゾロ目 ×N」と表示されるので、**▲▼ でずらしてゾロ目を作る**のは有効な手。
- 同じ部品を偏らせて買い集めると、ゾロ目の頻度が大きく上がる（鏡のゾロ目でも倍率はもらえる）。

## 3. ゼンマイ（ずらし・固定）

- ずらし：光を放つ前なら何度でも戻せる。確定するのは放った瞬間で、ずらした合計コマ数ぶん消費する。一本につき最大 3 コマ。
- 固定：回す前に指定。そのリールは回らない。全部のリールは固定できない。
- 回復：**一手ごとに半分**（二手で 1 つ）。夜のはじめに全回復。
- 追加の巻き足し：**一度の照射で 2 隻以上を導く**と +1、**ゾロ目**で +1。
- 灯室の上下に半分見えているコマが、ずらしたときに入ってくる部品。「リール表」で全体の並びも見られる。
- いい列（たとえばレンズが三つ縦に並んだ列）が出たら、固定して次の手にも使うのが強い。

## 4. 舟

| 舟 | 特徴 |
| --- | --- |
| 小舟 | 数字ぶんの光を、何回かに分けて届ければよい。一手に 1 マス進む |
| 早舟 | 一手に 2 マス進む（猶予は 3 手） |
| 霧の船 | **一度に**数字以上の光でないと届かない。足りない光は霧に飲まれ、後ろの舟にも届かない |
| 貨物船 | 導くと、部品を 3 つから 1 つ無料でもらえる（その場でリールに組みこむ） |
| ひかり丸 | 第五夜の客船。三つの海路それぞれに光が必要（通常 110 ずつ）。二手に 1 マス進む。難破させると、その夜は即やり直し |

- 光は手前の舟から順に使われ、**余りは後ろの舟へ貫通**する。どの舟にも当たらなかった光は「星明かり」（記録用の点数）になる。
- 赤い輪の舟は、その手で導けないと難破する。
- 出現する舟の種類・順番・必要な光は夜ごとに固定。どの海路に出るかだけが毎回変わる。

## 5. カモメ

- 第三夜から、決まった手番に、灯室に見えているコマのどこかへ降りてくる。
- とまられたコマは光を通さない（部品は壊れない）。
- **3 以上の光**が当たると飛び立つ（その光は使われる）。弱い光しか通らない一本目のリールにとまられると厄介。
- 鏡やプリズムで、カモメのいる行を避けて光を回すこともできる。夜明けには全部いなくなる。

## 6. 工房

- 部品の値段：鏡 2、炎 3、種火 5、レンズ 6、プリズム 7。
- プリズムは第二夜のあと、種火は第三夜のあとから並ぶ。
- **同じ部品の上に重ねると強化**される（炎は +3 まで、レンズは ×4 まで）。部品を持った状態でコマにマウスを重ねると、結果が案内欄に出る。
- 灯芯を太く：もとの光 +1（最大 4）。10 → 18 → 26 貨。掛け算の元が増えるので、レンズ中心の灯室ほど効く。
- ゼンマイ追加：最大数 +1（最大 6）。6 → 10 → 14 貨。
- 入れ替え（1 貨）：二つのコマを交換。別のリール同士でもよい。
- コマを外す（4 貨）：リールを短くする（最短 5 コマ）。**素通しガラスを外すと、いい部品が見える確率が上がる。**
- 品ぞろえを替える：1 貨から、頼むたびに 1 貨ずつ高くなる（工房を出ると元に戻る）。
- 「最初からやり直す」で、工房に入った時点まで何度でも戻せる。配置の試行錯誤は無料。
- 夜明けのお礼は 3 ＋ 残っている信頼の数。
- 第四夜のはじめに、四本目のリール（炎とレンズが一つずつ）が自動で増える。

## 7. 失敗とやり直し

- 信頼（ハート）は夜ごとに 3。難破 1 隻で 1 つ減り、0 でその夜は失敗。
- 失敗すると、その夜のはじめの状態に戻り、差し入れ（5 貨。同じ夜で失敗を重ねるたびに +3）をもらって工房からやり直す。
- やり直した夜の難破は通算に数えない。やり直し回数だけ記録に残る。

## 8. 称号と荒海

- 称号は通算の難破数で決まる：0 隻「伝説の灯台守」／ 2 隻まで「名うての灯台守」／ 5 隻まで「頼れる灯台守」／ それ以上「見習い灯台守」。
- 一度クリアすると、タイトルに「荒海に挑む」が出る。舟の求める光がすべて 1.5 倍。

## 9. おすすめの組み方（一例）

1. 第一夜のあと：炎を一本目に、レンズを三本目に寄せる。余った貨幣は残さず使う。
2. 第二夜のあと：灯芯を一段太くするか、プリズムを一本目〜二本目の中央あたりに。
3. 第三夜のあと：種火を二本目以降へ。霧の船が増えるので、鏡で束ねる形か、全体を底上げする形かを決める。
4. 第四夜のあと：四本目にレンズを重ねて強化。素通しガラスを外してリールを短くするのも有効。
5. 第五夜：ひかり丸は 12 手ほどかけて近づく。三つの海路に均等に光が要るので、束ねすぎた灯室は鏡を一部外すとよい。
