# REEL DELVE（リール・デルヴ）― まわる迷宮と三人の旅

五本の石のリールでできた迷宮。
リールを止めると、窓に並んだ3段がそのまま三人の冒険者の通り道になる。
回して下見し、目押しで狙った並びに止め、三人を歩かせて、地下12階の底をめざすゲーム。

ONE PROMPT WORLDS の5作目。Claude が1つのプロンプトから、企画・実装・検証・改善まで自律的に制作した。

## 起動方法

静的ファイルだけで動く。ビルドや追加インストールは不要。

`index.html` をブラウザで直接開けば遊べる。簡易サーバーを使う場合は、リポジトリ直下で次を実行する。

```bash
python -m http.server 8769 --directory game5
```

開く URL：`http://localhost:8769/`

推奨環境：PC のブラウザ（Chrome / Edge）。画面は 16:9 で、ウィンドウの大きさに合わせて伸縮する。音が出る（M で消音）。
最高記録だけがブラウザの localStorage に保存される。途中経過は保存されない（1回の冒険は15〜30分ほどの想定）。

## 遊び方

1. **下見**　リールを自由に回して、三人の通り道（窓の3段）を決める。結果の予測が画面に出る。
2. **目押し**　レバーを引くとリールが回り出す。下見で決めた並びには金の枠がつく。枠が白く光った瞬間に止める。
3. **調整**　ずれたリールは、魔力1につき1コマ直せる。
4. **出発**　三人が左から右へ歩き、踏んだ絵柄の結果が起きる。
5. **野営**　稼いだ金で、リールのマスを書き換えたり、三人を鍛えたりする。

三人には得意がある。

| 冒険者 | 得意 |
| --- | --- |
| 剣士 | 魔物を倒して金にする（ほかの2人は魔物でケガをする） |
| 盗賊 | 宝箱を開ける。罠を外す（ほかの2人は罠でケガをする） |
| 魔導士 | 水晶を魔力に変える |

同じ人が同じ絵柄を続けて踏むと「連鎖」になり、稼ぎが増える。
4階・8階・12階には門があり、その階で決められた数の連鎖を出さないと開かない。

絵柄のはたらきは、画面でカーソルを合わせると表示される。

## 操作方法

マウスだけでも、キーボードを併用しても遊べる。

| 操作 | マウス | キー |
| --- | --- | --- |
| リールを回す（下見・調整） | リールをドラッグ / ホイール / 窓の外の絵柄をクリック | ← → で選び、↑ ↓ で回す |
| レバーを引く / 出発 / 次の階へ | 右下の金色のボタン | SPACE / Enter |
| リールを止める | 止めたいリールをクリック | SPACE（左から順）/ 1〜5 |
| 隊列を入れ替える（魔力1） | 左の ⇅ ボタン | W / S |
| 歩行の早送り | 長押し | SPACE 長押し |
| 野営で買う・置く | 品をクリック → 置くマスをクリック | ESC で置くのをやめる |
| 消音 / 最初から | ― | M / R を2回 |

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` | 入口 |
| `js/rules.js` | ルール本体（描画なし。node からも読める） |
| `js/game.js` | 進行・入力・描画 |
| `js/art.js` | 絵柄と冒険者の描画（すべて Canvas のベクター描画） |
| `js/audio.js` | 効果音と環境音（WebAudio で合成。外部素材なし） |
| `tools/bot.js` | 自動プレイによるバランス検証（`node tools/bot.js 30`） |
| `VERIFICATION_検証記録.md` | 企画の比較、検証と改善の記録 |
| `NETABARE_攻略とネタバレ.md` | 攻略とネタバレ（遊んでから読むことを勧める） |

外部ライブラリ・外部素材は使っていない。
