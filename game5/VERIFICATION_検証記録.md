# REEL DELVE 検証・改善記録

制作日：2026-11-15。攻略上のネタバレは少ないが、数値や仕組みに触れる。

## 1. 企画の比較（3案）

| 案 | 遊びの核 | 評価 |
| --- | --- | --- |
| A. リールが迷宮になる（採用） | 止めた窓の3段が、3人の冒険者の通り道になる。下見→目押し→歩行 | 基本行動（回す・止める）がスロットそのもので手応えを作りやすい。「1回の停止が3人分の運命を同時に決める」という、リールの絵柄の並び順に由来する悩みがある |
| B. 歯車仕掛けの自動機械 | 長さの違うリールを回し続け、周期のずれで絵柄がそろう瞬間を設計する | 仕組みは独自だが、止める行為がなく、決定論的なパズルになる。4作目（光の回路）と手触りが近い |
| C. リール砲台の防衛戦 | 迫る敵に対し、止めた出目で各段から攻撃する | 出目が「攻撃の抽選」になりやすく、既存のスロットRPGに近い。忙しさが考える楽しさを削る |

A を選んだ理由：スロット固有の3要素（決まった並び順の帯・自分で止める・有効ライン）が、
それぞれ「縦3マスは必ず組で出る」「目押し」「人が歩く道がそのまま有効ライン」として遊びに直結するため。

4作目との重なりについて：段が3つあること、合間にリールへ手を入れられることは共通する。
本作は「出目を読む」のではなく「狙って止める」こと、踏んだ絵柄が消えて避けた危険が残り続けること、
同じ人の連鎖で門を開けることを核にしており、遊びの中心は別のものにした。

中心に据えた喜び：判断（どの並びで止めるか）、習熟（目押し）、成長（リールと三人が育つ）。

## 3. 結果

### 機能検証（実ブラウザ）

- 新規開始 → 下見 → 目押し → 調整 → 歩行 → 湧き → 野営 → 次の階、の一巡を確認。
- 1階から12階の踏破（結末画面・評価・最高記録の更新）までを、種を変えて通した（調整の途中を含め5回、最終版で1回）。コンソールエラーなし。
- 全滅（歩行中の体力切れ、門の失敗による体力切れ）から全滅画面へ進むこと、そこから再開始できることを確認。
- 門：開く場合（扉が上がる）、開かない場合（稼ぎの没収・体力−1・同じ階をやり直し）の両方を確認。
- 実入力：ドラッグ、ホイール、窓の外のクリック、矢印キー、W/S と ⇅ ボタンでの入れ替え、SPACE でのレバー、
  枠が光った瞬間の SPACE による実時間の目押し（5本とも狙いどおりに停止）、長押し早送り、野営での購入と設置、ESC、R の確認表示。

### ゲームシステム検証（自動プレイ、各30回、最終版）

| 方針 | 踏破率 | 被害（平均） | 門での失敗（平均） | 稼いだ総額（踏破時の中央値） |
| --- | --- | --- | --- | --- |
| でたらめに止める | 0% | 9.0 | 0.9（平均4階で全滅） | ― |
| 目先の得だけ・正確に止める・種を植えない | 63% | 7.0 | 4.2 | 323 |
| 目先だけ・門も狙わない | 13% | 10.9 | 9.2 | 323 |
| 計画的（門の前は金貨を残し、足りなければ植える）・正確 | 100% | 0.4 | 0.0 | 371 |
| 計画的・目押し2割ミス・魔力で修正 | 100% | 1.3 | 0.0 | 358 |
| 目先だけ・目押し2割ミス・修正しない | 13% | 12.4 | 3.9 | 269 |
| 計画的・強化を買わない | 100% | 0.2 | 0.0 | 281 |

読み取れること：

- 止め方で結果が大きく変わる。でたらめでは4階の門を越えられない。
- 「いま拾う」か「門のために残す」かの判断が効く。目先だけだと門で平均4回つまずき、3回に1回は踏破できない。
- 目押しの失敗は重いが、魔力での修正がそれを吸収する。魔力に役割がある。
- 強化を買うと稼ぎが約3割増える。成長が結果に出る。
- 計画的な方針は全探索で止め方を決めているので、被害 0.4 は「理論上ほぼ無傷で行ける」ことを示すだけで、人にとっての易しさは示さない。

## 4. 見つけた問題と改善

### ゲームデザイン

| 問題（どう見つけたか） | 変更 | 再検証 |
| --- | --- | --- |
| 門でわざと失敗すると階数を稼げ、門を無視する方針が最も儲かった（自動プレイ：所持金 579 対 336） | 門を開けられなかった階の稼ぎは没収にした | 門を無視する方針の稼ぎが他を下回った |
| それでも、失敗のたびに迷宮が湧くので、失敗を重ねるほど後半が豊かになった（総額 421 対 353） | 門で失敗したあとは、ほとんど湧かないようにした。野営の案内で「金貨の種をそろえて植える」ことを伝える | 門を無視する方針は踏破率 13%、総額も同等以下になり、抜け道ではなくなった |
| 1階からいきなり5連が組めて、門の条件が形だけになっていた（通しプレイ） | 初期リールの金貨を左3本に寄せ、金貨の種を値上げ | 全停止位置を検算したところ、魔物の5連・階段をまたぐ宝箱の4連がまだ組めた。初期リールを2度直し、1階の最大連鎖が3、無傷での最大の稼ぎが23になることを確認 |
| 慎重に遊ぶと最後まで危険に追い込まれない（計画的な方針の被害が 0.2） | 中層・深層ほど多く湧くようにした | 全探索の方針の被害は 0.4 でほぼ変わらず。空き床が減って安全な組は少なくなるが、追い込む効果は確認できていない |
| 目押しのミスが続くと魔力が尽き、ケガ→全滅の一本道になる（2割ミス・修正なしで踏破 8%） | 野営のたびに魔力が1戻る。上層の回転を少し遅く | 2割ミスでも魔力で直せば踏破 100%（変更前も 93% で、変更の効果としては小さい） |
| 目押しが「失敗すると損」なだけの作業になりうる | 5本とも狙いどおりなら「ぴたり！」で金がもらえる | 表示と加算を実ブラウザで確認 |

## 5. 未確認事項・限界

- **人間が面白いと感じるかは未確認。** 制作AIはルールと正解を知っており、自動プレイは全探索で止め方を決めている。
  初見の人が、下見の画面から何をすればよいか分かるか、目押しが気持ちよいか、続けたくなるかは、人が遊んで確かめる必要がある。
- 目押しの難しさ：実時間の確認は、枠が光ったことを機械的に検知して押したもの。人の反応速度で、
  上層（1コマ約0.43秒）・深層（約0.27秒）がちょうどよいかは未確認。
- 音：鳴らす処理がエラーなく動くことまで。耳での確認（音量の釣り合い、心地よさ）はしていない。
- プレイ時間（15〜30分）は見積もりで、計測していない。
- Chrome / Edge 以外のブラウザ、タッチ操作、極端に小さい画面は未確認。タッチ操作には対応していない。
- 評価のしきい値（S：440 / A：340 / B：250）は、自動プレイの値から決めた仮のもの。
- 既知の割り切り：途中経過は保存されない。門の前で金も連鎖の材料も尽きると、体力が尽きるまで立て直しにくい。
