## 1. 企画：3案の比較

題材の四つの軸「小さな砦」「迫る敵の予告」「少人数の仲間の持ち場」「その活躍を見届ける」から、主な判断と指示の出し方が違う3案を考え、同じ一場面（正面の石段を小鬼の列がのぼってくる）で比べた。

### 案A「まかせた」― 陣の前に持ち場を決め、迎撃は仲間にまかせて見届ける【採用】

- **敵が来る前に見えるもの**：砦の全景。正面の石段・門の坂道・崖道に、次の陣でどこから何が何体、いつ来るか（予兆の一覧と、道を流れる足跡）。持ち場の旗（踊り場・城壁の上・門の内…）。仲間を旗に置くと、その道で最初に敵を止める所（盾の印）と、攻撃が届く所（足跡の下の色の点）が出る。
- **なぜその仲間にその場所か**：小鬼は一列で石段をのぼる。盾のイルザを踊り場に置けば、先頭がそこで止まり、後ろが詰まる。詰まる所に火のルゥの火球が届くよう、すぐ脇の城壁の上に置く（二人のあいだに「受けて、焼く」の札が出る）。
- **敵が来ると**：仲間は自分で動く。敵が近づくとイルザが向き直って「！」。先頭が盾に当たって火花と金属音、「受け止め！」。後続が段に詰まる。ルゥの足もとに詠唱の輪、詰まった列の上に赤い輪が満ちて、火球が落ちる。「×4」「受けて、焼く」。
- **見届けている間の注目点**：構える瞬間、受け止める瞬間（頭上の枠が埋まる）、援護が届く瞬間（光の弧と「援護」）。形勢が変わる合図（門が破られた・仲間が倒れた・灯が消えた）。
- **次にしたくなること**：陣のあとに「どの道から何体通されたか、なぜか」「だれが何秒で、何に倒されたか」が残る。「門の上にもう一人置けば」「ルゥを弓小鬼から離せば」と、一人だけ持ち場を変えて同じ陣をすぐやり直せる。

### 案B「角笛の号令」― 迎撃の最中に、角笛で数回だけ号令をかける

- **一場面**：仲間は持ち場に立つが、陣の最中に3回まで「ここへ集まれ」「今だ、放て」を指示できる。石段に列が詰まった瞬間に角笛を吹くと、ルゥが大技を放つ。
- **評価**：指示の瞬間は気持ちよいが、見どころが「号令のタイミング」に寄り、地形を読んだ配置の判断が弱まる。指示書の過去の手掛かり（計画を実行する目押しがテンポを損なう）にも当たる。仲間が期待に応える場面が、プレイヤーが押した瞬間に置きかわってしまう。

### 案C「一手ずつの籠城」― 敵の次の一手が見える手番制で、毎手番仲間を動かす

- **一場面**：敵の次の移動が矢印で出る。毎手番、仲間を一人ずつ動かして攻撃する。踊り場にイルザを動かし、次の手番でルゥが範囲魔法。
- **評価**：読み合いは深いが、判断の単位が「毎手番の一手」になり、「持ち場をまかせる」「見届ける」が弱い。15〜30分で必要な手数が多く、繰り返す行為が入力作業になりやすい。

### 比較と採用理由

| | 案A まかせて見届ける | 案B 角笛の号令 | 案C 手番制の籠城 |
| --- | --- | --- | --- |
| 繰り返す判断 | ◎ 持ち場の組み合わせ（毎陣、少しずつ変える） | ○ 配置＋号令の時機 | ○ 毎手番の移動 |
| 読みが当たる気持ちよさ | ◎ 配置の予想が、迎撃の場面でそのまま起きる | ○ 押した瞬間の手応え | ○ 一手ごと |
| 見届ける時間の価値 | ◎ 仲間が自分で構え、受け止め、援護する | △ 号令待ちで画面を見張る | △ 見る時間が短い |
| 守る対象への愛着 | ○ 灯と村の人の様子が、夜ごとに変わる | ○ | ○ |
| 試し直しやすさ | ◎ 同じ陣・同じ敵で、一人だけ変えてやり直せる | ○ 号令の時機が毎回ずれる | △ 長い手順の再現 |
| 15〜30分に仕上がるか | ○ 5夜・10陣 | ○ | △ 手数が多い |

**採用：案A**。依頼の中心（自分で持ち場を決め、仲間が期待に応える瞬間を見届ける）を、遊びの単位そのものにできる。迎撃は乱数を使わない決まった規則で動くので、同じ配置なら同じ結果になり、一人だけ変えた違いを比べられる。案Bは見どころが押す時機に移り、案Cは見届ける時間が短くなるので見送った。

### 採用案で決めたこと

- **砦**：15×15升の砦を一画面に収めた（カメラ移動なし）。上に本丸（扉の上に村の「灯」）、中央に中庭、手前に城壁。進入路は三つ（正面の石段＝一列でしかのぼれない／門の坂道＝門が足止めし、叩かれると壊れる／西の崖道＝本丸の裏へ続く）と、第四夜から空（夜鴉）。持ち場は16の旗（地上9・高所7）。手前が低く奥が高い地形にして、壁が人物を隠しにくくした。
- **仲間**：五人（はじめ二人、陣ごとに加わる）。受け止め役（イルザ3体・ドゥーガン2体）、焼く役（ルゥ、かたまるのを待つ）、射る役（カイ、空と弓小鬼を優先）、支える役（メル、自分は癒やせない）。どの仲間も地上に置けば1体以上受け止める（後衛を前に置くと囲まれて弱い、という形で「弱点」が出る）。
- **敵**：小鬼・狼（速い。門をすぐ破る。槍に弱い）・盾持ち（矢が通りにくい）・弓小鬼（後衛をねらって立ち止まる）・夜鴉（空から灯をねらう）・大鬼（3体ぶんの重さ。イルザしか止められない）。
- **迎撃の規則**：1/60秒刻みの決まった規則で、乱数なし。同じ道の敵は追いこさず、先頭が止まると後ろが詰まる。二番手は肩ごしに打ってくる。高い所からは弓と火が遠くまで届く（高さの差 ×0.5升、最大2升）。
- **勝ち負け**：灯5（贈りもので6）。敵が扉に着くか、城壁の内側に9秒いる（松明を投げこむ）と灯が消える。一体が消す灯は一つまで（大鬼は扉に着くと5つ）。すべて消えると、その陣をやり直す。陣ごとに体力と門は元に戻る（陣ごとに独立した試し直しができる）。
- **見届ける演出**：構え（「！」）、受け止め（火花・金属音・頭上の枠）、詠唱（足もとの輪・敵の上で満ちる赤い輪）、火球（当たった数「×4」、数で大きくなる和音・揺れ）、援護（助けた仲間から助けられた仲間への光の弧と「援護」）、連携（画面上の見出し）、吹き出し、出来事の一覧。
- **振り返り**：結果画面に「どの道から何体、なぜ（すり抜け／門が破られたあと／だれにも止められず）」「だれが何秒で何に倒されたか」「見せ場」「新しい連携」「次に試すなら」。作戦画面に戻ると、前回の要約・すり抜けた所の赤い×・「前回 ここをN体素通り」の札。
- **守るもの**：本丸の扉の上の灯（村の人たち）。夜明けの場面で、中庭に村の人が出てきて夜ごとに増え、大鍋がすえられ、峠の雪が夜ごとにとけていく。村の子ノノは、ゆうべいちばん働いた仲間の持ち場に立って、その仲間のまねをして遊ぶ。結末では、五つの夜でいちばん多く敵を受け止めた持ち場と仲間の名前を、ノノが指さす。
- **キャラクター**：仲間・敵・村人のドット絵（12〜20画素、外枠は自動）。手前向き・奥向きの2方向を描き、左右反転で斜め4方向。姿は「待機・息・歩き・攻撃（踏みこみ）・被弾（白く光る）・倒れる」。8方向は今回は描いていない。

## 2. 早めに作った一戦で確かめたこと（第一夜）

最初に第一夜の二陣（石段だけの陣と、石段＋門の陣）を、タイトル → 作戦 → 迎撃 → 結果 → やり直しまで通常操作で遊べる形にし、敵や陣を増やす前に次の四点を確かめた。確認は Playwright の本物のクリック（札を押す → 旗を押す →「迎え撃つ」）と画面の撮影で行い、作者が仕組みを知った状態での確認である。

### 依頼の4点

| 確認点 | 画面と操作で分かったこと |
| --- | --- |
| ① 配置の前に作戦を立てられるか | 右上の「予兆」に道ごとの敵と到着時刻、地図の上に道を流れる足跡。仲間を置くと、道の上に「最初に止める所」（仲間の色の盾）と「届く所」（足跡の下の色の点）が出て、予兆の一覧の各道に「イルザが止める／門が足止め・カイが届く／止める者なし」が出る。旗を指すと左下に「この仲間なら：止める○○・届く○○・連携○○」。**ここで問題が二つ見つかった**（下の表の1・2） |
| ② 一人だけ持ち場を変えると何が変わるか | 第一夜・二陣で、カイだけを「南壁・東」から「門の上・北」へ移して二度迎え撃った（次の節） |
| ③ 迎撃を見ている時間に見たいものがあるか | 0.25秒ごとに止めて撮ると、敵が近づいた仲間に「！」、受け止めの火花と「受け止め！」と吹き出し、ルゥの足もとの輪と敵の上で満ちる赤い輪、火球と「×3」が順に読めた。**一方で、見どころを隠すもの・まぎらわしいものがあった**（下の表の3〜7） |
| ④ 守れなかったあと、すぐ試し直せるか | 負けると結果画面に、どの道から何体・なぜ通されたかと「次に試すなら：…一人だけ、そちらへ回してみては？」。「持ち場を見直す」で同じ陣の作戦画面に、配置をそのまま残して戻る（1クリック）。作戦画面の左上に前回の要約。**だれにも止められずに通った道は地図に印がなかった**ので足した（表の8） |

### 一人だけ持ち場を変えた例（第一夜・二陣「門を叩く音」）

同じ陣・同じ敵（石段：小鬼8・盾持ち3・小鬼5、門：小鬼9）。イルザ＝踊り場、ルゥ＝南壁・西は同じで、**カイだけ**を動かした。`tools/compare.py` で、配置と開始は本物のクリック、撮影は両方の回で同じ時刻（8・14・19・24秒）にそろえた。下の数字は最終版の規則で撮り直したもの。

| | A：カイ＝南壁・東（石段の反対側の城壁） | B：カイ＝門の上・北 |
| --- | --- | --- |
| どこで敵と出会ったか | 石段の小鬼は、二人の城壁から撃たれて踊り場に着く前に減り、イルザが最初に受け止めたのは **14.0秒**。門の前に詰まった小鬼には、だれの攻撃も届かない | 石段の小鬼は **5.6秒**からイルザの盾に詰まり、ルゥが列ごと焼く（「受けて、焼く」3回、最大4体）。門の前に詰まった小鬼をカイが上から射続ける（9体） |
| 誰が間に合ったか | 門の前には誰もいない。19秒の画面では、門が壊れ、門の坂道を小鬼が列になって中庭へ入ってくる | 19秒の画面では門は残り、門の坂道は空。石段にはまだ小鬼の列 |
| どこを通されたか | **門が18.7秒で破られ**、門の小鬼が中庭を抜けて本丸へ。28.9〜30.9秒に、城壁の内側に入った5体が次々に松明を投げこみ（2体は扉にも着いた）、灯がすべて消えて負け | 通されず。灯5/5 で勝ち（25.4秒）。門は最後まで壊れない |
| 結果画面 | 「門の坂道から2体が本丸へ　門が破られたあと、だれにも止められず」「城壁の内側に入った敵に、松明を5つ投げこまれた」「次に試すなら：…門の坂道の敵を、城壁の外で止めるか、減らしておこう」 | 「イルザが止めた列を、ルゥの火球が4体をまとめて焼いた」「イルザが踊り場で6体を受け止めた」 |

戦闘中の違いは、門の扉が残っているか、門の坂道と中庭に敵の列があるか、で一目で分かった。同じ配置をもう一度迎え撃つと、同じ時刻に同じことが起きる（`rules_test` で決定的であることを確認）。

後半の例（同じ仲間に別の持ち場を任せる）：第五夜・二陣で、ほかの4人はそのままに**イルザだけ**を「踊り場」から「崖道の曲がり角」へ移すと、踊り場のままでは崖道の狼6体が10.0〜13.5秒に次々と扉に着いて負け、曲がり角では灯6/6 で勝った（ノードの規則シミュレーションで確認。`node tools/run.js 5-2 …`）。
