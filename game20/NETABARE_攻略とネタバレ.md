# STAIRWARD ― 攻略とネタバレ

**遊ぶ前に読まないことをおすすめします。** 陣ごとの持ち場の一例、終盤の見せ場、結末、連携の条件を書いています。
持ち場の名前は、旗を指すと左下に出る名前と同じ。迎撃は乱数を使わないので、同じ持ち場なら毎回同じ結果になる。

## 仕組みの要点

- 地上の仲間は、すぐとなり（約1升）を通る敵を受け止める。受け止められる数はイルザ3・ドゥーガン2（籠手で3）・ほか1。数があふれた敵はすり抜ける。
- 同じ道の敵は追いこさない。先頭が止まると、後ろが一列に詰まる。二番手は前の仲間の肩ごしに打ってくる（押し寄せ）。
- ルゥの火球は、近くに3体以上かたまるのを少し待ってから撃つ（扉に近い敵・空の敵がいれば待たない）。詰まった列の上が最高の的。
- 門は敵を止めるが、門の前に詰まった敵みんなで叩かれると壊れる。狼と盾持ちは門を強く叩く。
- 城壁の内側（中庭・本丸の石畳・本丸の石段）に入った敵は、そこに9秒いると本丸へ松明を投げこみ、灯がひとつ消える。内側で受け止めていても数える。だから「本丸のまわりで固める」守り方は、第一夜〜第三夜の一陣までは灯を減らしながら勝てるが、それ以降は負ける。外の石段・門・崖道で止めるのが基本で、中庭の辻や門の内は「すぐ片づける二の陣」。
- 弓小鬼は、ルゥ・カイ・メルを先にねらって立ち止まる。カイは弓小鬼を先にねらう。
- 夜鴉は空を通って扉へ。届くのはカイの矢（2倍）とルゥの火だけ。本丸の張り出し・門の上・北が近い。
- 大鬼は3体ぶんの重さで、イルザ以外は止められない（ほかの仲間の横は押し通り、ぶつかる）。

## 陣ごとの一例（贈りものは毎回1つめを選んだ場合。2つめでもすべて灯を全部守れる）

| 陣 | 持ち場の一例 | ねらい |
| --- | --- | --- |
| 1-1 石段の松明 | イルザ＝踊り場、ルゥ＝南壁・西 | 踊り場で先頭を止め、詰まった列を城壁の上から焼く（受けて、焼く） |
| 1-2 門を叩く音 | イルザ＝踊り場、ルゥ＝南壁・西、カイ＝門の上・北 | 門が足止めしている間に、門の上から射る。カイを南壁にすると門が破られて負ける |
| 2-1 遠吠え | 1-2 と同じ（イルザ＝踊り場、ルゥ＝南壁・西、カイ＝門の上・北） | 狼は門をすぐ破るが、門の前で詰まっている間にカイが射倒す。イルザを石段の下に出し、ルゥを門の上へ回す形でも灯を全部守れる |
| 2-2 弓の列 | イルザ＝踊り場、ルゥ＝門の上・北、カイ＝南壁・東 | 門の盾持ちには矢が通りにくいので、門はルゥの火で（門前の火）。石段の弓小鬼はカイが先に射抜く。前の陣のまま（カイが門）だと、盾持ちが門を破って負ける |
| 3-1 崖をのぼる影 | 2-2 の三人＋ドゥーガン＝崖道の曲がり角 | 崖道の狼をドゥーガンの槍が一突き（槍ぶすま）。崖道を空けると十数秒で負ける |
| 3-2 三方から | 3-1 と同じ | 同じ配置で守れる |
| 4-1 黒い羽 | イルザ＝踊り場、ルゥ＝門の上・北、カイ＝本丸の張り出し、ドゥーガン＝崖道の曲がり角、メル＝南壁・西 | カイを南壁のままにすると夜鴉で負ける。本丸の張り出しへ回す |
| 4-2 月のない夜 | イルザ＝門の内、ルゥ＝南壁・西、カイ＝本丸の石段、ドゥーガン＝崖道の曲がり角、メル＝門の上・北 | 狼7体はイルザが門の内で受け、真上のメルが支える。石段はルゥが城壁から焼き、本丸の石段のカイが夜鴉と、入りこんだ敵を射る。4-1 のままでも灯3つで勝てる |
| 5-1 大鬼 | イルザ＝踊り場、ルゥ＝南壁・西、カイ＝西の岩棚、ドゥーガン＝門の内、メル＝石段の上 | 終盤の見せ場（下） |
| 5-2 夜明け前 | イルザ＝崖道の曲がり角、ルゥ＝門の上・南、カイ＝門の上・北、ドゥーガン＝中庭の辻、メル＝西の岩棚 | 大鬼は崖道から来る。イルザを石段から崖道へ回す。前の陣のままだと負ける |

ほかにも勝てる配置はある（陣ごとの数の目安は検証記録）。

## 終盤の見せ場

- **5-1 大鬼**：大鬼が石段をのぼってくる。踊り場のイルザが「大鬼を止めた！」。後ろに小鬼の列が詰まり、南壁のルゥが列ごと焼く（受けて、焼く・大火球）。石段の上のメルがイルザを癒やし続け（支える手）、8秒受け止めると「鬼受け」。
- **5-2 夜明け前**：こんどの大鬼は西の崖道から来る。いつも踊り場にいたイルザを崖道の曲がり角へ回し、西の岩棚のメルが支える。石段は別の仲間に任せることになる。

## 結末

- 五つの夜を越えると、峠の雪がゆるみ、村の人たちが峠へ向かう。
- 村の子ノノが最後にふりかえり、**五つの夜でいちばん多く敵を受け止めた持ち場と、そこを守った仲間**を指さして「あそこは、○○が守ってくれたんだよ」と言う（遊び方によって変わる。踊り場とイルザになりやすい）。
- 記録の画面に、五人それぞれの主な持ち場、受け止め・倒した数・援護・癒やし、決めた連携、いちばん大きな火球、大鬼を受け止めた時間が出る。
- 夜明けの場面では、ノノがゆうべいちばん働いた仲間の持ち場に立ち、その仲間のまねをして遊んでいる。

## 連携の条件（全12）

| 連携 | 条件 |
| --- | --- |
| 受けて、焼く | イルザが止めた列（先頭が受け止められ、後ろが詰まっている列）を、ルゥの火球が3体以上まとめて焼く |
| 門前の火 | 門の前で詰まった敵を、ルゥが3体以上まとめて焼く |
| 先に射抜く | ルゥをねらっている弓小鬼を、カイが射抜く |
| 援護射撃 | ほかの仲間と戦っている（またはねらっている）敵を、カイが射抜く |
| 盾と槍 | イルザが受け止めている敵を、ドゥーガンが突く |
| 槍と炎 | ドゥーガンが止めた列を、ルゥが3体以上まとめて焼く |
| 槍ぶすま | 無傷の狼を、ドゥーガンが一突きで倒す |
| 夜鴉落とし | 夜鴉をカイが射落とす |
| 支える手 | 2体以上（または大鬼）を受け止めている仲間を、メルが癒やす |
| 間一髪 | 倒れるはずの一撃を、メルの守りの光が受け止める |
| 大火球 | ルゥの火球が5体以上に当たる |
| 鬼受け | イルザが大鬼を8秒以上受け止める |

「間一髪」と「槍と炎」は、ねらわないと出にくい。
