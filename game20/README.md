# STAIRWARD ― 峠の砦と五つの夜

焼け出された村の人たちが、峠の古い砦「きざはし砦」に逃げこんだ。峠の雪がゆるむまで、あと五日。
夜ごとに石段・門・崖道から迫る「夜の群れ」から、本丸の灯を守る。

クォータービューで砦を見わたし、敵の来る道と数（予兆）を読んで、**仲間ひとりひとりの持ち場を決める**。
「迎え撃つ」を押したら、あとは仲間が自分で構え、受け止め、焼き、射て、癒やす。自分の読みが当たり、仲間が期待に応える瞬間を見届けるゲーム。
守れなかったら、どこを通されたか・だれが倒れたかを見て、持ち場を一人だけ変えて、同じ陣をすぐにやり直せる。

ONE PROMPT WORLDS の第20作。Claude Opus 5.5 が1つの依頼から企画・実装・検証・改善まで自律的に制作した。

- PCブラウザ向け。マウスだけで遊べる（キーボードも使える）。音が出る。
- 全5夜・10陣。1回の目安：20〜30分（設計上の目安。人間のプレイ時間は未計測）。

## 起動

`game20/index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動く。サーバー・ビルド・外部ライブラリ・外部素材は使っていない。

簡易サーバーで開く場合は、リポジトリ直下で次を実行して <http://127.0.0.1:8020/> を開く。

```bash
python -m http.server 8020 --bind 127.0.0.1 --directory game20
```

進み具合は陣ごとにブラウザの localStorage に保存され、タイトルの「つづきから」で再開できる。

## 遊びの流れ

- **予兆**：右上に、どの道から何が何体、いつ来るか。地図の上には足跡が道を流れる。
- **持ち場**：16か所の旗。白い旗は地上（来た敵をその場で受け止める）、青い旗は高所（敵に近寄られない。弓と火が遠くまで届く）。
- **灯**：敵が本丸の扉に着くか、城壁の内側（作戦画面でうすく赤い所）に9秒いると、灯がひとつ消える（一体につき一つまで）。すべて消えるとその陣はやり直し。灯と仲間の傷は陣ごとに元にもどる。
- **作戦の読み**：道の上の盾の印＝その道で最初に敵を止める仲間。足跡の下の色の点＝その仲間の攻撃が届く所。点線と札＝連携できそうな二人。
- **仲間**（夜を追うごとに加わる）
  - イルザ（盾の騎士）：3体まで受け止める。大鬼を止められるのは彼女だけ。
  - ルゥ（炎の術師）：かたまった敵を火球でまとめて焼く。近寄られると詠唱できない。
  - カイ（弓の猟師）：遠くから射る。空の敵と弓小鬼を先に狙う。盾持ちには矢が通りにくい。
  - ドゥーガン（槍の鍛冶）：二升先まで突き、後ろの一体ごと貫く。狼を一突き。
  - メル（癒しの薬師）：近くの仲間を癒やし、危ない仲間に守りの光。
- **連携帳**：二人の働きが重なると「連携」が決まる（全12）。
- **夜明け**：夜を越えると、砦の中の村の人たちの様子と、贈りもの（二つから一つ）。

## 検証用ツール（開発者向け）

- `node tools/rules_test.js` … 迎撃の規則の自動確認
- `node tools/run.js 1-2 ilza=s_land ruu=w_sw kai=g_n [-v]` … 一つの陣を指定の持ち場で迎え撃つ
- `node tools/search.js [陣ID...]` … 持ち場の組み合わせを総当たり（4人以上は抽出）して、勝てる配置の多さを調べる
- `node tools/check_solutions.js [--gifts=1,1,1,1]` … `tools/solutions.json` の配置で全陣を通す
- `node tools/policies.js` … 単純な置き方（本丸固め・石段で受ける・前の陣のまま）と工夫した置き方を全陣で比べる
- `node tools/improve.js 陣ID` … 一人ずつ動かして、よりよい配置を探す
- `python tools/playthrough.py [--fast N] [--fail-first] [--reload] [--keys] [--shots DIR]` … タイトルから結末まで、本物のクリックとキーで通す（Playwright＋Edge）
- `python tools/compare.py DIR 陣ID "配置A" "配置B" [時刻,...]` … 同じ陣を持ち場を一人だけ変えて二度迎え撃ち、同じ時刻の画面と出来事を比べる
- `python tools/pickcheck.py` … 旗をマウスで指したとき、狙った持ち場が選ばれるか
- `python tools/fps.py` … いちばん敵の多い陣での描画の速さ
- `python tools/shot.py DIR steps.json` … 画面の撮影
- URL に `?sheet` を付けると、ドット絵の一覧を表示する

## 素材

画像・音声・フォントの外部素材は使っていない。絵はすべて Canvas 2D で描き、効果音と BGM はブラウザ内で合成している。文字は利用者の PC にある日本語フォントを使う。
