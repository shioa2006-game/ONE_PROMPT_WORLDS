# そこから、そら ― 井戸のカエルと 五つの層

井戸の底で生まれたカエルの「アオ」になって、玉を はね返し、頭の上の岩を くずしながら 空をめざす、縦穴のブロックくずしです。
ささえを なくした岩は、かたまりごと がらがらっと落ちます。ねらい線が光るところを うてば、一撃で 大きく くずせます。
上の層へ のぼるほど、むかしの だれかの「おとしもの」が 石の中から見つかります。

## 遊びかた

`index.html` をブラウザで開くだけで遊べます（インストール・サーバー不要、PC ブラウザ向け。Chrome / Edge で確認）。音が出ます。

| 操作 | 内容 |
| --- | --- |
| マウスを動かす | アオが 左右に動く（玉は アオの頭で はね返る） |
| クリック | くわえている玉を はきだす（マウスの方向へ） |
| ボタンを おしたまま待つ | 落ちてきた玉を 舌で くわえる。くわえたまま マウスで ねらい、はなすと はく |
| ← → / A D ・ スペース | キーボードでも遊べます（← → で移動、くわえているときは ねらいの向き。スペースが ボタンの代わり） |
| Esc | ひとやすみ（つづける／やりなおす／へやを えらぶ／タイトル／音の大きさ） |
| M | 音の あり・なし |

- 全5層・15のへや と 結末。初見で20〜30分ほどを想定しています（設計上の目安で、人が遊んで測った時間ではありません）。
- 玉を水に落としても、すぐ くわえ直せます。ゲームオーバーは ありません。
- 進みぐあい・見つけた おとしもの・音の設定は、ブラウザの localStorage に保存されます。「つづきから」「へやを えらぶ」で再開・やりなおしができます。

## ファイル

- `index.html` … 起動ページ
- `js/sim.js` … ルールの核（玉・岩・崩落・生きもの・守り主。描画なしで node からも使える）
- `js/levels.js` … 層・へや・おとしもの のデータ
- `js/render.js` … 描画（すべて Canvas で手続き的に描く）
- `js/audio.js` … 音（Web Audio でその場で合成）
- `js/game.js` … 画面・操作・進行・保存
- `tools/` … 検証用の道具（自動プレイ、しくみの確認、通しプレイ、画面撮影）と結果
- `VERIFICATION_検証記録.md` … 実施した検証と、それによる改善の記録（しくみの中身にふれます）
- `NETABARE_攻略とネタバレ.md` … 各へやの こつ・結末。**遊ぶ前には読まないでください。**

外部の画像・音声・フォント・ライブラリは使っていません（フォントは OS に入っているものを使います）。
