# そこから、そら ― 攻略とネタバレ

> [!WARNING]
> へやの解きかた、守り主の倒しかた、おとしもの の場所、結末の内容が すべて書いてあります。初めて遊ぶ前には読まないでください。

## しくみ

- **崩落**：岩は、岩盤（井戸の壁・天井）か ふた石に、上下左右で つながっているあいだは落ちない。つながりが切れた かたまりは まるごと落ち、着水したときに「マス数ぶん × 1.5 ＋ マス数² × 0.35」の きららになる（1マスずつ こわすより ずっと多い）。中の おとしもの も このとき出てくる。
- **ねらい線**：玉が落ちてくるあいだは、着地点（三角）と、今の位置で はね返したときの道すじが出る。くわえているあいだは、はく向きの道すじが出る。最初に当たるマスが白わく、そのマスを こわすと落ちる かたまりが黄色く光り「がらっ ×数」と出る。
- **はね返る向き**：アオの頭の まんなか で はね返すと まっすぐ上、はしほど ななめ（最大 62°）。
- **くわえる**：ボタンを おしたまま、下りてくる玉が アオの上 200px 以内・左右 140px 以内に来ると くわえる。はなすと ねらいの向きへ はく。
- **はずみ**：はね返す・くわえる で1ずつ ふえ、水に落とすと 0。3で ちから2ばい（いし を1回で わる）、6で「つらぬく」（ひと当てで こわれる岩は はね返らずに つきぬける）。はずみが あがるほど 玉も すこし速くなる。
- **ふた石**：耐久3（はずみ3以上なら2回）。こわすと穴があき、玉を通すと上のへやへ。守り主がいるへやでは、守り主が落ちるまで こわれない（落ちると ふたも いっしょに あく）。
- **はぜ石**：こわれると 0.11秒後に まわり8マスへ 3ダメージ。となりの はぜ石も はぜるので、ななめに つながっていると 連鎖する。
- **生きもの**：こうもり（ねている岩が なくなるか 玉が近づくと 起き、目が赤くなったあと アオへ とびかかる。当たると 0.8秒 目が回る）、どろむし（岩の表面をはい、4〜6秒ごとに となりの すきまを どろで ふさぐ。岩どうしが つながってしまうことがある）、しずくぐも（しずくを落とす。当たると 0.55秒 目が回る）。どれも玉が当たれば たおせる。落ちる岩に まきこんでも たおせる。
- **ビー玉**：ビー玉ぶくろ を わると ビー玉が2つ とびだし、14秒のあいだ いっしょに岩を こわす（くわえられない・落としても何もない）。バンパーに当たると 玉が一瞬 速くなる。

| 1-2 きらら石 | まんなかの大きな かたまり（水晶入り）は、右がわの いしの柱の下はしで つられている。魚の化石は 右上の かたいし の囲いの中（はずみ3以上で わると早い）。 |
| 1-3 おおなまず | 左右の しめなわ（6列目・13列目の縦3マス）を 1か所ずつ切れば落ちる。石つぶては 水面の赤い しるしの下に落ちる。 |
| 2-1 はぜ石 | 左下の はぜ石を1回うつと、ななめの6連鎖で ふたまで道が ひらく。右のかたまり（土器入り）は 右はしの つちの つけねで落ちる。 |
| 2-2 たなの へや | 3段の たなは、それぞれ 壁ぎわの1マスで ささえられている。どろむしが たなと たなの間を ふさぐ前に たおすか、先に つけねを うつ。勾玉は上の たな、やじりは下の たな。 |

| 3-1 つるされた はこ | 左右の はこ は かたいし（4回）で できているが、それぞれ 内がわの つちの つけね（1回）で つられている。寛永通宝は左の はこ。 |
| 3-2 いしの はし | 横いっぱいの いしの はしは、左はしの はぜ石だけで ささえられている。左下から はぜ石を うつと 30マスが いっきに落ち、下の しずくぐも2ひきも まきこむ。鈴は 右上の かたいしの上、かんざしは はしの中。 |
| 3-3 つるべおとし | くさびは 上2本（縦2マス）と 左右。おけは 予告の かげの位置へ落ちてくる。かげから 横へ よければ当たらない。 |
| 4-1 ビー玉の へや | まんなかの かたまり（めんこ・ビー玉ぶくろ2つ入り）は 右の つちの柱の下はしで落ちる。着水すると ビー玉が はね上がる。 |
| 4-2 がらくたの やま | 左のかたまり（ラムネのびん入り）は 右がわの はぜ石1つで つられている。 |
| 4-3 からくり | 体に当てると ビー玉を2つ こぼす（5秒に1回）。くさびは 上2・左右2。コルクは 弧をえがいて 飛んでくる。 |
| 5-1 ねっこの つち | ふたは 左上。左のかたまりは 6列目の根、まんなかの かたまり（十円玉入り）は 12列目の根の下はしで落ちる。 |
| 5-2 つちの なかの てがみ | まんなかの土のかたまり（てがみ入り）は 左右の根（横5マス）で つられている。両方を1マスずつ切ると落ちる。カギは 右上の かたいしの囲い。 |
| 5-3 ねっこの ぬし | くさびは 上2・左右（横2マス）。根は 3.6秒ごとに のび、切った くさびは 10.5秒ごとに（最大5回）つなぎなおされる。石つぶても落ちてくる。 |

てがみ には「いどの カエルさんへ　そらは とっても ひろいよ。いつか 見に きてね。」と書いてある。

## 結末

5-3 で ねっこの ぬし を落とし、最後の ふた（木のふた）の穴へ 玉を通すと、ふたが はじけとび、アオが 井戸から とびだす。
空を見あげる場面から地上へ ゆっくり目をおろし、「そらは、あおかった。」ではじまる4行が出る。てがみを見つけていると3行目が「てがみに かいてあった とおりだ。」に変わる。最後の行で アオは 遠くの海を見て「あれは なんだろう。」と言う。
どんぐりを見つけていると、井戸のそばに 芽が出る。最後に 見つけた おとしもの の一覧（ほんとうの名前つき）が出る。
