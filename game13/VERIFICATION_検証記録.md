- 実行環境：node v24、Python Playwright ＋ Edge（ヘッドレス、1280×720）

## 1. サイコロの仕組み：3案の比較

| | A 表裏の采配（採用） | B 役づくり | C 進軍すごろく |
| --- | --- | --- | --- |
| 中身 | 振った賽を1個ずつ国の采配に割り振る。表の目＝攻め・備え、裏の目（7−表）＝開発・築城・徴兵 | 5個を振り直して役を作り、役ごとに決まった行動が起きる | 賽の目だけ街道を進み、ぶつかったら賽の勝負 |
| 振る楽しさ | ○ 毎季の第一手 | ◎ 役がそろう快感 | ○ |
| 出目で作戦が変わるか | ◎ 6・6・1 と 2・3・4 では季節の使い方が別物 | △ 役と地図の状況がつながりにくい | △ 行き先が目に縛られる |
| 内政と戦争のつながり | ◎ 同じ賽が攻めにも内政にもなる | △ | × 内政の置き場がない |
| ルールの少なさ | ○「表と裏は足して7」の一言 | △ 役の表が要る | ◎ |
| テンポ | ○ 賽→国→ボタン | △ 振り直しが長い | △ 移動の待ち |
| 領土拡大の手応え | ○ | ○ | △ 運の比重が大きい |

A を採用。決め手は「小さい目にも強い使い道がある」を、実物のサイコロの性質（表と裏の和が7）だけで言えること。B は振る楽しさは一番だが、役と20国の地図が別々の遊びになりやすい。C は内政が飾りになる。

## 3. ゲームシステム・バランス（`node tools/sim.js`）

ボットが知っているのは盤面に見えている数字だけで、プレイヤーと同じルール・同じ賽を使う。結果の表は `tools/results/` に。

**全員 CPU の500局**
- 1局の合戦は平均20.0回。国替えは序盤に毎季0.5、終盤に1.7前後。終局まで生き残るのは平均8.6家。
- 首位の国数は中央値8（最小1、最大20）。天下統一は500局で2回。
- 優勝は 三好29%・武田28%・上杉21%・織田9%・北条5% で、残り15家の合計が約1割。どの1家も「毎回勝つ」ではないが、小勢力が CPU 任せで勝つことはほぼない。
- 同じ大名でも結果は散らばる（CPU の攻め気を毎回±0.25ゆらしている）。

**プレイヤー席（先手）に方針の違うボットを座らせた比較（20大名×50局）**

| 方針 | 優勝 | 平均の国数 | 滅亡 |
| --- | --- | --- | --- |
| その大名の気性どおり | 4.4% | 0.96 | 54% |
| 攻め気を高く（bold） | 20.3% | 2.85 | 35% |
| 慎重（careful） | 1.0% | 0.52 | 58% |
| 攻めない（turtle） | 0% | 0.41 | 59% |
| 開発・築城をしない（brawn） | 10.7% | 2.06 | 34% |
| でたらめ | 1.3% | 0.60 | 57% |
| 賽を買わない | 1.1% | 0.55 | 61% |
| 裏返さない | 2.1% | 0.67 | 55% |
| 賽を重ねない | 0% | 0.42 | 58% |
| 備えを使わない | 4.0% | 0.93 | 60% |
| 振り直さない | 4.5% | 0.94 | 54% |

（「賽を買わない」以下の5行は、気性どおりの思考から1つだけ手段を外したもの。比べる相手は1行目）

- 読み取れること：攻めること、賽を重ねること、金を賽に替えること（買う・裏返す）は結果を大きく変える。内政をまったくしない方針は生き残りやすいが、内政もする bold に優勝で負ける。攻めない方針は勝てない。
- bold なら20大名すべてで優勝が出た（最少は今川4%、徳川6%、筒井8%、足利10%。三好は48%）。弱小でも道はあるが、細い。
- 限界：これはボット同士の話で、人間がどう感じるか・どれだけ勝てるかは別。bold と brawn は攻め気が同じなので差は内政の有無だが、ボットの内政の上手さに左右される。

## 4. 見つけた問題と、直したこと

設計を数字で確かめながら、かなり作りなおした。

1. **賽をいくつでも重ねられる初版**：開幕の1季で8家が滅び、国が毎季行ったり来たり → 重ねるのは2個まで、ゾロ目+3、最初の季節は出陣なし。
2. **守りが強すぎる版**：1局の合戦が2〜8回で動かない → 攻められるたび城が1段くずれる、奪った国は1巡「平定」で守られる（取ってすぐ取り返される往復も減った）。
3. **金が余り、全員が上限で張りつく**：兵の上限なし、兵糧（維持費）、傭兵（上限超えは倍額）を順に試したが、兵が30〜40に膨れて賽が効かなくなるか、逆に全員が籠もって動かなくなった → 上限（6＋経済）は残し、金の出口として「裏返し」と「賽の買い足し」を足した。買い足しを入れると、経済の高い大名（織田）の優勝が1%→9%に上がり、内政をしない方針が内政もする方針に負けるようになった。
4. **内政が損**：開発に金がかかりすぎ、内政なしの方針が圧勝 → 開発の金を「上がった後の経済×1」に下げた。
5. **三好が勝ちすぎる**：隣が足利・筒井だけで、優勝が4〜5割 → 軍事力を5→4（必要最小限の変更。README に明記）、CPU の気性を穏やかに、首位を優先して狙う傾向を強めた。3割弱まで下がった。
6. 通しプレイで、終盤の金が数百まで余ると分かった → 賽の買い足しを1季3個まで（金10・20・30）に広げた。
7. 画面：遊び方の行の重なり、合戦の札が戦場の国を隠す、結末の文が「CPU に統一されて滅亡」のとき順位表示になる、を修正。

直さなかったこと：
- 終盤は CPU の金が余る（終局で1家平均72）。CPU は金の使い方が人間より下手、という扱いにした。
- 優勝が5家に偏る。国力の指定を尊重し、三好以外の数値は触っていない。

## 5. 画面・操作・テンポ

- 起動0.9秒、60fps（ヘッドレス Edge）。地図の塗りなおしは1回33ms。
- CPU 19家の番＋季節の札の待ちは、合戦のない季で約1秒、多い季で3〜4秒。早送りあり。
- 勢力が広がっても采配はサイコロの数（最大6＋買い足し3）までで、1季の手数は増えすぎない。奥の国の兵は「出陣→味方の国」で前線へ送る。

## 6. 初見での分かりやすさ（別担当の AI による）

コードも攻略も知らない別担当（同じモデルの別エージェント）に、ゲームのフォルダとページ内部の状態を読むことを禁じ、スクリーンショットと実際のマウス・キー操作だけで遊んでもらった。渡した情報は URL と「初見プレイヤーとして観察を報告する」という依頼だけ。**別担当も AI であり、人間の初見プレイの代わりではない。**

- 遊んだ範囲：織田信長で1560年秋から16季、1564年秋に滅亡して結果画面まで。攻めた合戦6回（4勝）。進行不能・エラーなし。
- 伝わったこと：目標、表と裏の意味、采配の流れは題字・大名選び・右のパネルの説明で分かった。合戦の前に出る「攻め◯対 守り◯〜◯、勝ち目◯%、守りの賽が◯以下なら勝ち」で、勝ち負けの理由も読めた。結果画面の戦績は本人の記録と一致。
- 指摘と対応：

| 指摘 | 対応 |
| --- | --- |
| 遊び方の最下部で2行が重なる | 行の位置を直した（テスターが見たのは直す前の版） |
| 攻められた合戦の内訳が残らない。早送り中は見えない | 自国が攻められた合戦は早送りでも等速・長めに表示。次の自分の番に「誰が・どこを・攻め◯（兵＋賽）対 守り◯ → 結果」を2件まで表示 |
| 出陣の既定が全軍で、留守が兵1になる注意がない | 既定を「その賽で必ず勝てる最小の兵」（無理なら全軍）に変更。留守が手薄なときは赤字で「隣に兵◯」と警告 |
| 「賽を重ねる」が小さく、押せると分かりにくい | 枠付きで大きくし「押して1個」と添えた |
| 1の目の赤丸を特別な目と読み違えた | 赤丸を小さくし、賽の下に「表◯ 裏◯」を数字で表示 |
| 赤い数字の札が「備え」だと分からない | 国にカーソルを置くと「赤い札＝備え+◯」と出る |
| 「平定」の札が数字に重なる | 札の左上へ移した。城・経済の文字を少し大きくした |
| 滅亡させたときの「金+36」の理由が不明、敗残兵の合流が不明 | 「◯◯家の蓄えも手に入れた」「敗れた兵◯が◯◯へ退いた」と知らせる |
| 結果の表に滅んだ家が少ししか載らない | 戦績の行に「滅んだ家 ◯」を追加（表は7行のまま） |
| 国が1〜2で本国が育ちきると、裏の目の使い道がなくなり作業になる。奪った国をすぐ失う | ルールは変えていない。留守の警告と既定の兵数で後者は和らぐ見込みだが、**前者は残る課題** |

- 直した後の再確認は作者（設計を知っている側）がスクリーンショットと通しプレイで行った。初見の再テストはしていない。

## 7. 未確認・既知の問題

- 人間の実プレイなし。プレイ時間、難しさ、気持ちよさは未確認。
- 音は聴いていない。
- スマートフォン・タッチ操作は非対応（マウス前提）。
- 終盤に金が余りやすい。
- 序盤の数季は CPU 同士の合戦が少なく、世界が静かに見えることがある。
- 国が1〜2のまま経済と兵が上限に届くと、小さい目（裏）の使い道が築城くらいしかなくなる（初見テスターの指摘）。
- はじめの兵が徴兵の上限を超えている大名（上杉・武田・北条など）は、減るまで徴兵できない。画面には「兵は上限」と出るが、理由の説明は遊び方の1行だけ。
