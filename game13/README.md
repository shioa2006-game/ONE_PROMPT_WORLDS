# からり、国盗り ― 賽の目 戦国絵巻

ONE PROMPT WORLDS 第13作。1560年秋、桶狭間のあとの中部・近畿20国で、サイコロを振って国を治め、攻め、天下人をめざすターン制のゲームです。

**表の目で攻め、裏の目で治める。** サイコロの表と裏は足すと必ず7。大きい目は攻めに強く、小さい目は裏が大きいので内政に強い ―― 出た目を見て、どの国の何に使うかを決めます。

## 起動

`index.html` をブラウザで開くだけです（PC・マウス操作。サーバー不要、外部ファイルなし）。

## 遊び方（ゲーム内の「？」にも同じ説明があります）

- 20大名から1人を選ぶ。20季（1565年夏）が終わったとき、いちばん国の多い大名が天下人。20国すべてを取れば、その場で天下統一。
- 毎季、サイコロを振る（はじめは3個。国が2つ増えるごとに+1、最大6個）。サイコロ1個につき采配1回。
  - **表の目**：出陣（隣の敵国を攻める／味方の国へ兵を移す）、備え（次の自分の番まで守りに目を足す）
  - **裏の目（7−表）**：開発（裏の目≧今の経済なら経済+1）、築城（裏の目≧今の城なら城+1）、徴兵（裏の目の数まで。兵1＝金2、上限は6＋経済）
- 合戦：攻め＝送る兵＋賽（2個まで重ねられる。ゾロ目は+3）／守り＝兵＋城×2＋備え＋守り手の賽。攻めが上回れば国を奪える。
- 振り直し（残りの賽を1季に1回）、裏返し（金4〜で表と裏を入れ替え）、賽を買う（金10・20・30で1季に3個まで）。余った賽は金1。秋は年貢が2倍。
- 操作：サイコロをクリック → 国をクリック → 右のボタン。キーは 1〜9／スペース／R／F／B／Esc。右上の ♪ で消音。
- 自分の番の初めに自動で保存され、題字の「つづきから」で再開できます。

## 指定の国力から変えた点

- 三好長慶（摂津・河内）の軍事力を 5 → 4 に下げました。隣が足利・筒井という弱い2国だけで、CPU同士の対戦で優勝が4〜5割に偏ったためです（理由と数値は検証記録に）。ほかの19国は指定どおりです。
