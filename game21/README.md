# だれと行く？ ― 風見鶏ギルドの依頼帳

丘の町カザミの冒険者ギルド「風見鶏」。使い走りをして三年、斥候のリコは今日はじめて正式な冒険者の札をもらった。
依頼板から依頼を選び、**同行する仲間を二人選んで**、高低差のあるクォータービューの地図へ出かける。
段差・谷・水・ひび割れた岩を読み、仲間の力（押す・凍らせる・発破）と、リコの弓と鉤縄を組み合わせて依頼を果たす。
帰ってくると報酬が数えあがり、依頼人が広間に顔を出し、飾り棚に品が並び、依頼板に新しい依頼が貼られる。

ONE PROMPT WORLDS の作品。Claude Opus 5.5 が1つの依頼から企画・実装・検証・改善まで自律的に制作した（第19作「せーの、星見の露台へ」のしくみを土台にした、独立した作品）。

- PCブラウザ向け。マウスだけで遊べる（キーボードも使える）。音が出る。
- 依頼6つ＋ギルド。第一章の結末まで。1回の目安：30〜45分（設計上の目安。人間のプレイ時間は未計測）。
- 物語は「第一章　おわり ― 依頼帳は、まだつづく」で一区切り。続きを作る前提の終わり方にしてある。

## 起動

`index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動く。サーバー・ビルド・外部ライブラリ・外部素材は使っていない。

簡易サーバーで開く場合は、このフォルダの一つ上（リポジトリ直下）で次を実行して <http://127.0.0.1:8021/> を開く。

```bash
python -m http.server 8021 --bind 127.0.0.1 --directory game21
```

## セーブと再開

- 進み具合はブラウザの localStorage に自動で保存される（ギルドでの出来事のたび・依頼の地図で一手ごと）。
- タイトルの「つづきから」で再開する。依頼の途中でやめた場合は「依頼のつづきから」で、その地図のその場面から。
- 「はじめから」は、記録があるときは二度押すと記録を消して始める。

## パーティー編成

- 依頼を選ぶと「だれと行く？」の画面になる。**リコは主人公でいつも行く**。加入している仲間から**二人**を選んで出発する（合計三人）。
- 札には仲間の力と、その依頼へのひとこと（手がかり）が出る。下に「この三人でできること／できないこと」。
- はじめの仲間はガルドとセナ。依頼を進めると、新しい冒険者が加わる。
- 依頼板の札には「見どころ」（地形や装置）と「手がかり」（どんな力があると進めやすいか）が書いてある。一度こなした依頼も、別の二人で受けなおせる（「攻略した編成」が残る。報酬は少なめ）。

| 冒険者 | 力 |
| --- | --- |
| リコ（斥候） | 射る（的で仕掛けが動く・高い所から射ると強い）・鉤縄（鉄の輪へ渡る。縄はみんなの道。下から届くのは2段上まで） |
| ガルド（重戦士） | 押す（木箱・岩・敵を一升。段から落とすと足場、水に沈めると飛び石。重い相手も段のふちなら押し落とせる） |
| セナ（氷の術師） | 凍らせる（水を氷の床に・滝を氷の段に・霜の水晶を灯す・敵を一手番止めて、押すとすべらせる） |
| ？？？ | 遊んでのおたのしみ（依頼を進めると加わる） |

## 依頼と成長

- **依頼の種類**：退治・宝物回収・救助・遺跡調査・防衛・強敵討伐。目的は画面の左上に出る。果たすと「依頼達成！」。寄り道してから帰ってもいい。
- **報酬**：銀貨（依頼の報酬・地図の宝箱）と功績。功績がたまるとギルドのランク（★）が上がり、仲間みんなの体力が増え、むずかしい依頼が届く。
- **鍛冶屋のトンボ**：銀貨で仲間の道具を鍛える。鍛えた道具は次の依頼からすぐ使える（矢が強くなる、届く距離が延びる、新しい働きかけが増えるなど）。
- **ギルドの変化**：依頼人や助けた人が広間に来る、飾り棚に品が並ぶ、旗に星が増える。
- 戦いは手番制。仲間はそれぞれ「動いて、一つ行動」。赤い線は「いま手番を終えたら、敵がどう動き、だれが何点受けるか」。手番を終えるまでは何度でも戻せる。負けても、その手番の始めか戦いの前からやり直せる。

## 検証用ツール（開発者向け）

- `node tools/rules_test.js` … ルールとギルドの進み具合の自動確認
- `node tools/solve_check.js [依頼] [greedy|simple]` … 依頼ごと・編成ごとに、解き方の一例（`tools/routes.js`）と戦いのボットで通す
- `node tools/compare.js [依頼] [方針] [--up=gauntlet,...]` … 同じ依頼を三つの編成で攻略し、使った手を比べる
- `python tools/playthrough.py [--fast] [--reload] [--order m1:GS,...] [--shots DIR]` … タイトルから第一章の結末まで、本物のクリックとキーで通す（Playwright＋Edge）
- `python tools/jsrun.py DIR [m1,m2] [--party ST]` … 依頼を手早く通して要所を撮る（演出のエラー探し用）
- `python tools/shot.py DIR steps.json` … 画面の撮影
- URL に `?sheet` を付けると、ドット絵の一覧を表示する

## 素材

画像・音声・フォントの外部素材は使っていない。絵はすべて Canvas 2D で描き、効果音と BGM はブラウザ内で合成している。文字は利用者の PC にある日本語フォントを使う。
