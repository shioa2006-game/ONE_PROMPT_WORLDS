## 1. 企画の選定（3案の比較）

| 案 | 主にくり返す行動 | 採否と理由 |
| --- | --- | --- |
| **なぞって囲む 妖の道中「ぐるり、夜まつり」** | 同じ玉を なぞって つなぐ。花火で となりの妖を おどかし、ぐるっと 閉じた輪で 妖を「ともだち」にする | **採用**。なぞって消す パズルRPG（つなぎ消し＋敵の数字）は 馴染みがあり、初見で操作が伝わる。なぞる途中の音・予告、はなした瞬間の 連続ではじける反応で くり返しの手応えを作れる。「となりに当てる → 巻きつけるほど強い → 閉じれば むすぶ」の一続きで、小さな成功（鎖）と大きな成功（輪）に はっきり差がつく。むすんだ妖が 行列・ともだち帳・ちから になり、「集めたい」と「次の妖・次の景色を見たい」に つながる。ルート（どこを通すか）と組み合わせを考える遊びで、目押しが いらない。 |
| 六角タイルを 置いて 道と村を広げる 旅 | タイルを回して置く。辺が合うと 得点・景色が広がる | 不採用。置く瞬間の気持ちよさが 小さく、戦いの要素が入りにくい。似た既存作の 外観替えに 見えやすい。 |
| 自動攻撃の 群れ退治（生き残り型） | 歩いてよける。レベルアップで 組み合わせを選ぶ | 不採用。よける操作が中心で、組み合わせを考えるのは 選択の瞬間だけ。ジャンルの文法に 意味のある工夫を 足しにくい。リアルタイム戦闘は 3作目と近い。 |

独自の工夫と、そのねらい：
- **輪（ぐるり）**：なぞりはじめの玉に もどると 輪になる。輪の中の妖は ともだちになり、中の玉は ぜんぶ 輪の色として もらえる。鎖の「長さ」とは 別の、形で ねらう 大きな成功。
- **花火は となりに 当たる**：鎖の 花火1つごとに となりの妖へ 1。妖のまわりに 巻きつけるほど 強く、ぐるりと 閉じれば むすべる。「おどかす」と「むすぶ」が 同じ 形の判断の 延長に なる。
- **妖は うかんでいて 落ちない**：玉は 妖の うしろを すりぬけて 落ちる。妖が 盤の 下に たまらないので、どの妖も 囲める位置に いつづける。
- **ひもの 長さ**：つなげる数の 上限（はじめは 6）。鎖が 盤の はしから はしまで つながって 1手で 終わることを ふせぎ、輪（中の玉は 上限の外）を 大きな成功として のこす。夜店や ともだちで のびる＝成長が 目に見える。
- **ともだちの ちから**：むすんだ 種類ごとに 小さな ちから（小判 +1、ひも +1 など）。集めることが 次の戦いの 手ざわりを 少し変える。
- **めずらしい妖**：わかれ道の ★を えらぶと 会える。6手で にげるので「にげる前に むすぶ」目標が はっきりする。休み処と どちらを えらぶか、が 道のりの 判断になる。

## 3. ゲームシステムの検証

### 3-1. しくみが ねらいどおり 成り立つか（`node tools/rules_test.js` → `tools/results/rules-test.txt`、34項目すべて OK）

- 1-1 の 花火3つで 豆だぬきに 3、おいはらうと その場に 小判。1-2 の ひし形 4つで 輪 → ともだち、小判 = 4 + むすんだ ごほうび 2。
- ななめの 交差は つなげない／三角は 輪に ならない（中に マスが ない）／ひもの 長さを こえると「full」／提灯を はさんで つながる／もどると ほどける。
- 花火は となりの 数だけ（4つ → 4）、大玉花火で +1。団子 8つの 輪の 中の 小判は 団子として かぞえて 9。
- 妖は 宙に うかんだまま、上の 玉が 妖を すりぬけて 下へ 落ちる。
- 数字 0 で こうげき、お面が 1回 ふせぐ、こうげき後に 数字が もどる。河童は 小判 3まい。鬼火の 連鎖。
- めずらしい妖：まんなか 3×3 に、となりに 提灯 2つ以上 もって あらわれ、6手で にげる。
- ぬし：花火の 鎖は つないだ数だけ とどき、体力 0 で ともだちに。
- **「かこめる」と 光らせた 妖は、その輪を じっさいに なぞれる：611 / 611**（400 盤 × 4手）。妖が 盤の ふちに あらわれない。**つなげる手が ない 盤が のこらない（1600 盤）**。同じ たねなら 同じ 盤。

### 3-2. 方針の ちがう ボットの 比較（`node tools/bot.js all 8` → `tools/results/bot-results.txt`）

ボットが 知っている 情報：盤の 玉・妖・数字・体力 すべて（人と 同じ ものが 見えている）。入力は「鎖（マスの 列）と 輪かどうか」だけ。手は `sim.searchChains`（深さ優先、手数に 上限）で 探す。人より ずっと 正確で、見おとしも 迷いも ない。わかれ道は 体力が 半分 以上なら ★、未満なら 休み処。夜店は ひも → 大玉花火 → お面 → りんご飴 → … の 順に 買う。負けたら 体力を 上限の 6わりまで もどして やりなおす（6回まで）。

- smart … 輪で むすべるなら むすぶ。あとは あぶない妖から おどかす／体力が へったら 団子（ヒントと 同じ 評価）
- noring … 輪を 使わない。ほかは smart と 同じ
- long … いちばん 長い 鎖を えらぶだけ（輪も 長ければ えらぶ）
- random … 有効な 鎖を でたらめに（3〜6つ）

| 方針 | 1周の 手数 | 負け（やりなおし）/周 | ★めずらしい妖を むすべた | ともだち帳の しゅるい（8周の うち） |
| --- | --- | --- | --- | --- |
| smart | 平均 141 | 0 | 27 / 31 | めずらしい 4体も 6〜8周で |
| noring | 平均 227 | 0 | 0 / 32 | めずらしい 4体は 0周 |
| long | 平均 439 | 1.6（最大 5） | 21 / 32 | ほぼ そろう |
| random | 平均 568 | 10.4（8周中 2周しか 最後まで いけない） | 0 | ほとんど そろわない |

戦いごと（smart、8周の 平均）：ふつうの 戦い 5.6〜12.8手、ぬし 9.3〜16.5手、1戦の 被ダメージ 0〜10.5（いちばん 大きいのは 竹林「月の 竹林」と ぬし戦）。noring では「月の 竹林」が 平均 33手・被ダメージ 30 と 目立って 重い（負けは なし）。

読みとれること：
- 輪を 使うと 手数が 約4わり へり（227 → 141）、めずらしい妖は 輪で しか 会えない。輪は 速さと 集める 楽しみの 両方に 効いている。輪を 使わなくても 最後までは 行ける（輪は 必須の 正解では なく、うまく なるほど 得をする 手）。
- ねらわずに 長さだけを 見る long でも 最後まで 行けるが、時間が 3倍かかり、ときどき 負ける。でたらめでは 竹林の「月の 竹林」（たけのこ坊主が のびる）で 止まる。考えて 鎖を えらぶことが 結果に 効いている。
- smart は 人より ずっと うまい（ねらいが 完ぺき、輪を 見のがさない）。人は ボットより 手数が 多く、被ダメージも 大きいはず。

## 4. 初見理解の 確認（別担当）

- 担当：仕様・コード・攻略を 知らない 別の AI エージェント（Claude。この 制作セッションから 起動した 別担当）。**人では ない**。

## 5. 画面・音・演出の 確認

`python tools/shot.py <出力先> <手順.json>` で、1280×720 の 実画面を 撮って 見た（表紙、はじめの話、地図、各区間の 戦い、ぬし4体の 戦闘中・こうげき、輪の 決まる 瞬間、花火が 空で はじける ところ、負け、結果、夜店、休み処、ともだち帳、遊びかた、むすび、むすびの あとの 表紙）。

- 玉 4種は 色（赤・緑・金・白）と 形（花火玉・3色団子・小判・提灯）の 両方で 見分けられた。つなげない 玉は なぞっている 間 暗くなる。おじゃま（葉っぱ・小豆・泡・石）は 灰色の 台で 区別できた。
- 妖は 色と 形が 種類ごとに ちがい、数字（橙／赤／青）と 体力の 点が 読めた。
- 見つけて 直した もの：かげ絵（知らない 妖）を 描くと 背景ごと 四角く 塗りつぶして いた（別の 紙に 描いてから 重ねる ように）。右の 欄の ボタンの 文字と キー表示が 重なった。ともだち帳の 最下段と「もどる」が 重なった。表紙の 説明文と ゆいの 足が 重なった。ぬしが 玉を 葉っぱ等に かえる ときの 文字が ぬしの 絵に 重なって 読めない（ぬしの 左へ）。ぬし戦の 案内が 盤の 下の 段を かくした（右の 空いた 場所へ）。勝った あと 盤に 穴が あいた まま 結果が 出た（勝った あとも 玉を うめる）。手ほどきの 輪が 団子で「体力 +0（おなか いっぱい）」に なった（小判の 輪に 作り直し）。説明文が ことばの 途中や「（」の あとで 折りかえっていた（わかち書きの 空白で 折りかえす。最後の 修正。その後 手ほどき2戦を 本物の マウスで 再確認、エラー 0）。
- 音は Web Audio の 合成。ヘッドレス 実行のため **音は 耳で 確認していない**（エラーが 出ない ことのみ 確認）。
- 1フレームの 重さは 測っていない。通しプレイ（2〜3倍速）で 目立った 遅れは なかった。

## 6. 想定プレイ時間（見積もり。人で 測って いない）

- smart ボットで 1周 約140手、輪を 使わない noring で 約230手。人は その あいだ〜それ以上と 見て 170〜250手。
- 1手の 演出は 約1.5〜3秒（はじける・落ちる・妖の 番）。考えて なぞる 時間を 3〜5秒と 見ると 1手 5〜8秒。
- 物語・地図・夜店・結果・むすび で 3〜5分。
- **合計で 初見 20〜30分ほどと 見積もった**（設計上の 目安。AI の 操作時間を 人の 時間に 換算した ものでは ない）。

## 8. 未確認の こと・既知の 問題

- 人が 遊んだ 時間・面白さ・難しさ は 測っていない。初見の 確認も AI の 別担当に よるもので、人の 代わりには ならない。
- 音は 耳で 確かめていない（音量の つりあい、BGM の くり返しの 疲れ）。
- 人が ふつうに 遊んで 負ける 回数は 分からない（ボットは 人より 強い）。竹林「月の 竹林」と ぬし戦が いちばん 被ダメージが 大きい。
- 戦いの 途中は 保存しない（その 戦いの はじめから）。夜店で 買った ものは 読みこみなおしても 二重に 買えない ように 記録している。
- スマートフォン・タッチは 指で なぞれる ように してあるが 確認していない（PC 向け）。
- 小判は 最後の 夜店の あとの ぬし戦でも 手に入るので、1周の おわりに 100まい ほど のこる（smart・noring ボット）。むすびの まとめには 出していない。
- 戦いの 盤は 毎回 ちがう（周回の はじめた 時刻を たねに する）。同じ 戦いを やりなおすと 別の 盤に なる。

## 9. 人に 遊んで 確かめて ほしい こと

1. 「花火は となりに 当たる」「ぐるっと 閉じれば むすべる」が、遊びかたを 読まずに 1-1・1-2 の 手ほどきだけで 伝わるか。輪で むすぶ 瞬間が、ふつうの 鎖より はっきり 気持ちよいか。
2. めずらしい妖（6手で にげる）を 自分の 目で 見つけて むすべるか。紅白の 点線の しるし と ヒントが 多すぎ／少なすぎ ないか。
3. 1周に かかる 時間と、竹林・ぬし戦の 手ごたえ（やさしすぎ／つらすぎ）。
