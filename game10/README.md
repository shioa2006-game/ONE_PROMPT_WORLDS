# ぐるり、夜まつり ― ゆいと 妖の 参道

夏まつりの夜、社（やしろ）へ向かう参道は、まつりに入れない妖（あやかし）たちでいっぱい。
女の子「ゆい」になって、同じ玉をなぞってつなぎ、紅白のひもで妖を **ぐるっと囲んで「ともだち」に** しながら、社の夜まつりをめざす、なぞりパズル×たたかいのゲームです。

- 花火の鎖は、となりにいる妖をおどかす（となりの花火の数だけ当たる）。
- なぞりはじめの玉にもどると「輪」になり、**輪の中の妖はともだちに**、中の玉もぜんぶ輪の色としてもらえる。
- むすんだ妖は行列になってついてきて、それぞれ小さな力を貸してくれる。ともだち帳は全16しゅるい。

## 遊びかた

`index.html` をブラウザで開くだけで遊べます（インストール・サーバー不要、PC ブラウザ向け。Chrome / Edge で確認）。音が出ます。

| 操作 | 内容 |
| --- | --- |
| マウスで なぞって はなす | 同じ玉を たて・よこ・ななめに 3つ以上つなぐ（提灯はどの玉ともつながる） |
| はじめの玉に もどる | 輪になる（中の妖がともだちに） |
| なぞりの途中で ひとつ前へ もどる | ひとつほどける |
| 右クリック / Esc（なぞり中） | なぞりをとりけす |
| H または「ヒント」 | おすすめの手を光らせる |
| Esc | ひとやすみ（つづける／やりなおす／遊びかた／音量／タイトルへ） |
| M | 音の あり・なし |

- 4つの区間（あぜ道・竹林・川べり・社の石段）と結末。初見で20〜30分ほどを想定しています（設計上の目安で、人が遊んで測った時間ではありません）。
- たたかいに負けても、その戦いをすぐやりなおせます（むすんだともだちはそのまま）。
- 道のりの進みぐあい・ともだち帳・音の設定は、ブラウザの localStorage に保存されます。「つづきから」で、最後に終えた場所の次から再開できます（戦いの途中は保存しません）。

## ファイル

- `index.html` … 起動ページ
- `js/data.js` … 妖・道のり・夜店・ことば のデータ
- `js/sim.js` … ルールの核（鎖・輪・妖・ぬし。描画なしで node からも使える）
- `js/render.js` … 絵（すべて Canvas で手続き的に描く）
- `js/audio.js` … 音（Web Audio でその場で合成）
- `js/game.js` … 画面の切りかえ・入力・保存・共通の部品
- `js/battle.js` … 戦いの画面
- `js/scenes.js` … 表紙・道のり・夜店・休み処・ともだち帳・遊びかた・結末
- `tools/` … 検証用の道具（自動プレイ、しくみの確認、通しプレイ、画面撮影）と結果
- `VERIFICATION_検証記録.md` … 実施した検証と、それによる改善の記録（しくみの中身にふれます）
- `NETABARE_攻略とネタバレ.md` … こつ・めずらしい妖・ぬし・結末。**遊ぶ前には読まないでください。**

外部の画像・音声・フォント・ライブラリは使っていません（フォントは OS に入っているものを使います）。
