# ひとつぶ庭園

砂・水・種・火種。四つの粒をびんの口から注ぎ、粒どうしの反応だけで、びんの中に小さな夜の庭を咲かせる箱庭パズルです。

## 起動方法

- 検証済みの方法：`game2` フォルダで次を実行し、PC ブラウザ（Chrome / Edge 推奨）で <http://127.0.0.1:8766/> を開く。
- `game2/index.html` をダブルクリックして直接開いても動く作りです（外部読み込みなし）が、こちらは実機確認できていません。

```bash
python -m http.server 8766 --bind 127.0.0.1
```

外部ライブラリ・外部素材・通信はありません。音はすべてブラウザ内で合成しています（最初のクリックで鳴り始めます）。

## 操作

| 操作 | 内容 |
| --- | --- |
| びんの上でマウスボタンを押しっぱなし | 選んでいる粒を、その真上から注ぐ（左右に動かせる） |
| 左の小びんをクリック／`1`〜`4`／ホイール | 粒を切り替える |
| `Enter` / `Space` | 咲かせたあと、つぎのびんへ進む |
| `R` | そのびんをやりなおす |
| `H` | ヒントを開閉する |
| `N` | 発見ノート |
| `Esc` | 棚へもどる |
| `M` | 音の ON / OFF |

進行と発見はブラウザに自動保存されます。棚の画面右下の「消去」で最初からやりなおせます。

## 企画メモ（比較した3案）

1. **粒を注ぐ箱庭（採用）** — 粒は必ず「上から落とす」ことしかできず、屋根の下や高い場所へは粒どうしの反応で届ける。注ぐ行為そのものが手ざわりになり、ルールが少なくても反応の組み合わせで用途が増える。自動操作で解けること・解けないことを検証しやすい点も決め手。
2. 重力スイングのアクション（却下） — 操作の気持ちよさが命だが、制作側が手ざわりを自分で確かめられず、調整の根拠が弱くなる。
3. 環状オルゴールの組み立てゲーム（却下） — 数値バランスへの依存が大きく、短い体験の中で「自分で試したいこと」が生まれにくいと判断。

中心に置いた喜びは **発見**（粒の反応に気づく）、**触る気持ちよさ**（注ぐ・燃える・伸びる）、**完成**（びんが灯って棚にならぶ）の3つです。

## 検証メモ

実ブラウザ（アプリ内ブラウザ、1280×720）で実施。

**機能**
- 記録を消した初期状態から、棚→びん1→…→びん9→棚→エンディング→じゆうのびん、までを通しで確認。「つぎのびんへ」「棚へもどる」「とじる」「発見ノート」は実クリックで操作。
- 粒を注ぐ入力（押しっぱなしドラッグ）、数字キーでの切替、`R`、`Esc`、再読み込み後の記録復帰を確認。
- 各びんの解法そのものは、検証用フック（`window.__t`）からシミュレーションを早送りする自動操作で実行。**人の手で最初から最後まで通して遊んだわけではありません。**

**ゲームシステム（単純な方針と工夫した方針の比較）**

| びん | 単純な方針 | 結果 | 工夫した方針 | 結果 |
| --- | --- | --- | --- | --- |
| 2 | 水を全部注ぐ（5か所で試行） | 届かない | 先に砂でせきを作る | 咲く |
| 3 | 水を全部注ぐ | 届かない | 砂をしずめて水面を上げる | 咲く |
| 4 | 水だけ注ぐ | 届かない | 種→水でつるを伸ばす | 咲く |
| 6・9 | 火種を全部落とす | ランタンに届かない | つるを伸ばしてから点火 | 灯る |
| 9 | 茨の栓を焼かずに水と火種 | 咲かない | 栓を焼く→水→火種 | 咲く |
| 9 | — | — | 左のつぼみは「水＋砂で水位を上げる」別解でも咲く | 咲く |

- シミュレーション1ステップは約0.2ms（60fps に十分な余裕）。

**画面・操作**
- 各びんのプレイ画面、棚、エンディング、発見ノートをスクリーンショットで確認し、下記の改善を実施。

## 検証から行った改善

**ゲームデザイン**
- 水が山のように積もり、びん2で「砂を使わなくても水が段差を乗りこえて届く」ことが判明 → 水の流れを1ステップ2回処理にして素早くならし、段差も深くした。再検証で単純方針は5か所とも失敗、砂のせきでは成功。
- びん8（氷）で、とけた水が後続の火種にすべて蒸発させられ、水がまったく残らなかった → 「氷にふれている火種は水を沸かさない」「とけ水がまわりの氷もゆっくりとかす」「火種は灰を残さない」に変更。再検証で、とかす→砂、砂→とかす、どちらの順でも咲くことを確認。
- びん9で、つるがつぼみの窪みで行き止まりになりランタンへ伸びなかった → 「水が余ったつるは途中から枝を出す」に変更。びん4・6・9を再検証して成立。

**ビジュアル／操作感**
- 閉じたつぼみが小さく暗く、目標がどこか分かりにくかった → 大きく明るくし、先を桃色に、まわりに回る点線の輪を追加。
- 「発見」の通知がびんの中央をふさいでいた → 右の余白へ移動。
- つるが1マス幅の線で味気なかった → 葉を描き足した。
- 開花アニメーションで描画エラーが出ていた（負の半径）→ 修正し、エラー0件を確認。
- 最初のびんの操作案内が一瞬で消えていた → 最初に粒を注ぐまで表示。

## 未確認・既知の点

- 人が初見で遊んだときに「分かるか」「楽しいか」は確認できていません（制作側は答えを知っているため）。特にびん7（湯気）とびん8（氷）のヒントなしでの気づきやすさを見てほしいです。
- 音は例外なく再生処理が走ることまでは確認しましたが、実際に耳で聴いての確認はしていません。
- 粒の動きには乱数があり、同じ注ぎ方でも結果が少し変わります。砂でつぼみを埋めてしまうなど、やりなおし（`R`）が必要になる状況はあります。
- 検証は Chromium 系のみ。Safari では炎のぼかし発光が出ない可能性があります。スマートフォンはタッチで動く作りですが未検証です。
- ネタバレ（各びんの解き方・発見の一覧）は `NETABARE.md` に分けてあります。
