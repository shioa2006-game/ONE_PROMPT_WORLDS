# ネタバレ（遊んでから読んでください）

## 粒の反応（発見ノート14件）

| 名前 | 反応 |
| --- | --- |
| ひらく | つぼみは水にふれるとふくらみ、10粒ぶんで開花する |
| しずむ砂 | 砂は水にしずみ、そのぶん水面を押し上げる |
| めばえ | 地面の上でぬれた種は、つるになって上へ伸びる（水1粒＝つる1マス） |
| すいあげ | つるは吸った水を先へ運び、ふれているつぼみに与える |
| つるの花 | 伸びる先をなくしたつるは、先に花をつける |
| もえる | 茨とつるは火がつくと端から端まで燃える |
| はい | 燃えたあとに灰がのこる |
| ともしび | ランタンは火にふれると灯る |
| みちびき火 | つるを導火線にして、届かないランタンへ火を運べる |
| ゆげ | 火種が水にふれると湯気が出る |
| しずく | 行き場をなくした湯気は水にもどって落ちる |
| ゆげの花 | 湯気もつぼみを咲かせる（湯気は天井づたいに上へ「流れる」） |
| ゆきどけ | 氷は火でとけ、とけ水がまわりの氷もとかす |
| こやし（かくし） | 灰のそばで芽ぶいたつるは、少ない水でよく伸びる。びんの攻略には不要 |

表に出ていない性質：
- つるの先は、近く（約20マス）のまだ目ざめていないつぼみ・ランタンへ曲がって伸びる。
- 水が余ると、つるは途中から枝を出す。
- 氷にふれている火種は、水を沸かさない。

## 各びんの解き方

1. **はじめのひとしずく** — 2つのつぼみに水を注ぐだけ。
2. **すなのせき** — 張り出しのすぐ右の坂に砂を山にしてから、その左側へ水を注ぐ。水が先だと全部右の穴へ逃げる。
3. **かさあげ** — 水を全部くぼみに入れ、砂を足して水面をつぼみの窪みまで押し上げる（順番は逆でもよい）。砂を左の壁ぎわに積みすぎるとつぼみが埋まる。
4. **めばえ** — 崖のすぐそばに種をまき、水をやる。つるが崖をのぼり、つぼみへ曲がって水を運ぶ。崖から離すとつぼみに気づかず上へ伸びてしまう。
5. **ひだね** — 茨のふたに火種を落として焼き、開いた穴へ水。右の台のランタンには火種を直接。
6. **みちびき火** — 種と水でつるを伸ばす→下のつぼみが咲く→つるが上のランタンに届く→根もとに火種。先に燃やすとやりなおし。
7. **ゆげ** — 上の穴（じょうご）から水を注ぎ、同じ穴へ火種。火種は坂を転がって水に入り、湯気が左上がりの天井をつたって、つぼみのある逆さのくぼみにたまる。
8. **こおり** — 氷に火種を少し落とすと、あとは水がつられてとけ続ける。水は中央の穴に落ちるので、砂で穴をうめて（または落ちた水を砂で押し上げて）左の崖の根もとへ流し、そこに種をまく。
9. **よるの庭** — 左：種と水でつる→つぼみ→ランタンに届いたら点火（つぼみは水＋砂で水位を上げても咲く）。右：茨の栓を火種で焼く→穴から水→火種で湯気。

全部咲かせると、棚に目標のない「じゆうのびん」が増えます。
