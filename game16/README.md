# くるり、呪いほどき ― 魔法陣リールと灰の王国

床に描いた魔法陣が、まるごとリールになっている。
回して止まった紋の上に立つ魔物は、詠唱で呪いがほどけて人にもどる。
同じ紋がとなり合えば「つながり」になって力が合わさり、つながりの上に立つ魔物はまとめて救える。
救った人々からもらった紋で自分のリールを組み、一つずらせば大きくつながる並びを育てながら、灰の魔女に呪われた王国を取りもどすゲーム。

ONE PROMPT WORLDS の第16作。Claude Opus 5.5 が1つの依頼から企画・実装・検証・改善まで自律的に制作した。

- PCブラウザ向け。マウスだけで遊べる（キーボードも使える）。音が出る。
- 1回の目安：20〜30分（設計上の目安。人間のプレイ時間は未計測）。

## 起動

`game16/index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動く。サーバー・ビルド・外部ライブラリ・外部素材は使っていない。

簡易サーバーで開く場合は、リポジトリ直下で次を実行して <http://127.0.0.1:8016/> を開く。

```bash
python -m http.server 8016 --bind 127.0.0.1 --directory game16
```

進み具合はブラウザの localStorage に保存され、タイトルの「つづきから」で再開できる（戦いの途中でやめた場合は、その戦いのはじめから）。

## 操作

| 操作 | マウス | キー |
| --- | --- | --- |
| 回す／止める／詠唱する | 右下の大きなボタン | スペース・Enter |
| リールを一コマずらす | リールの上下の ▲ ▼（ホイール、床を上下にドラッグでも） | Q W E R T（上）／ A S D F G（下） |
| ずらしを全部戻す | 右クリック | Z |
| 固定（回す前。そのリールは回らない） | リールの下の「固定」 | 1〜5 |
| ヒント | 右の「ヒント」 | H |
| 説明を読む | 紋や魔物にマウスを重ねる | ― |
| あそびかた／音／メニュー | 右上の ？ ♪ ≡ | M（音）・Esc（メニュー） |

メニューの「演出：はやい」で演出を短く、「自動で回す：する」で手番のはじめに自動で回るようにできる（固定を使うときは「しない」のまま）。

工房では、持ち物の紋を押してからリールのマスを押すと置ける。リールの紋を押すと持ち上げて入れ替え、右クリックで外せる。

## 遊びの流れ

1. **回す**：床の魔法陣（3〜5本のリール）が回って止まる。
2. **ずらす**：▲▼でリールを一コマずらす。魔力を1使う（戻せば戻る）。上下にはみ出した小さな札は、ずらすと入ってくる紋。
3. **詠唱**：紋の上に立つ魔物の呪いがほどける。緑の「ほどける」「−数字」が見こみ。そのあと魔物が一歩進む。
4. 左の結界まで歩かれると、結界がひとつ欠ける。3つ欠けると負け（そのまま、または工房で組み直して再挑戦できる）。
5. 地方ごとの「呪いの主」をほどくと、その地の呪いがまとめてほどける。
6. 戦いのあとは工房。お礼の紋を受け取り、市で紋を分けてもらい、リールに置く。「試し詠唱」では、わら人形を相手に、組み替える前と同じ回転で比べられる。

クリア後は、タイトルから「大詠唱の腕だめし」で、完成したリールの力をもう一度ためせる。

| `NETABARE_攻略とネタバレ.md` | 攻略・結末のネタバレ（**遊ぶ前に読まないことをおすすめ**） |

## 検証用ツール（開発者向け）

- `node tools/rules_test.js` … ルールの自動確認
- `node tools/bot.js 20 smart smart` … ルールだけで全編を回すボット（戦い方 none / one / smart、組み方 random / smart）
- `python tools/playthrough.py --fast --shots DIR [--reload] [--noshift]` … タイトルから結末まで、本物のクリックとキーで通す（Playwright＋Edge）
- `python tools/compare.py DIR` … 試し詠唱で「組み替え前後を同じ回転で比べる」流れを、本物のクリックで確かめる
- `python tools/shot.py out.png steps.json` … 画面の撮影

## 素材

画像・音声・フォントの外部素材は使っていない。絵はすべて Canvas 2D で描き、効果音と BGM はブラウザ内で合成している。文字は利用者の PC にある日本語フォントを使う。
