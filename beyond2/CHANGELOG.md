# 更新履歴

## v0.2（2026-11-28）　成長と収集の土台・第一章の改良

ゲームデザインは Claude Fable 5.2 の拡張設計（`design/`）にもとづき、実装と検証は Claude Opus 5.5 が行った。

- **腕だめしの印**：依頼ごとに三つの任意目標を足した（第一章で18個）。条件は依頼板の札に最初から出ていて、地図の上で条件を満たすと小さく知らせ、達成して帰ると印がつく。
- **ドーラの腕だめし帳**：印の数に応じて、ごほうびを受けとれるようにした（お守り・銀貨・飾り棚の品・称号）。
- **お守り**：一人に一つ持たせる小さな品を足した。「だれと行く？」の札の下の枠で持たせる。鍛冶屋で買える品と、腕だめし帳でもらえる品がある。
- **受けなおしの自由編成**：一度こなした依頼は、はじめに同行が決まっていたものも、だれとでも受けなおせるようにした。地図の宝箱は、一度持ち帰ったら空になる。
- **ギルドランク**を★7まで広げた（第一章で届くのは★4まで）。
- **第一章の後半の依頼を改良した**：仕掛けを手の届く所へ置きなおし、強敵の決まりと台詞・ヒントを見直した。仕掛けを使う作戦が決まりやすく、強敵は動きを読んで攻める戦いになった。
- **戦いの決まりを一部見直した**：転がる物の当たり方、ひっくり返った相手の「すき」の長さ、高い所からの矢、凍った敵の通せんぼ、など。押す前の見こみに、すきの長さや「こらえる」も出る。
- 画面：依頼板の印、「だれと行く？」のお守りの枠、腕だめし帳、記録（印・お守り・仲間ごとの道具）、帰還の場面の印の行、鍛冶屋の「道具／お守り」の見出し。
- 第一章の結末まわりの台詞を少し足した。
- 探索中、ついてくる仲間が、押した物の行き先に立たないようにした。
- 仕掛けの大岩が高い地面のかげに隠れるときは、手前の地面をうすく描くようにした。戦いの中で発破の仲間を選んで物を指すと、寄せた側で発破する見こみが出る。
- 出発の並び（地図の開始位置・札の番号）を、選んだ順ではなく、いつも同じ順にした。
- **v0.1 の保存データを引き継げる**（読みこむときに移す）。v0.1 の「依頼のつづき」だけは、ギルドからの再開になる。
- 不具合の修正：途中で仲間になる冒険者の、戦いのヒントが出なかった／ギルドマスターの、ランクに応じた話が出なかった／戻す・やり直すと、ヒントを使った回数が減ることがあった。
- 開発用：検証ツールを v0.2 の決まりに合わせて広げた。実装と検証の記録は `VERIFICATION_v0.2.md`。

## v0.1（2026-11-28）　BEYOND開発開始・原型移植

- ONE PROMPT WORLDS 第21作「だれと行く？ ― 風見鶏ギルドの依頼帳」（`game21/`）を `beyond2/` に移植し、BEYOND ONE PROMPT 第2作として開発を始めた。ゲーム本体に加えて、設計資料・検証記録・検証用ツールも引き継いだ。
- 作品名を **GUILDWARD** に変えた（タイトル画面・ページの題・資料）。タイトル画面は背景・人物・構図をそのままに、英字の題字が収まるように字の大きさと配置を整えた。
- 主人公リコを、明るく好奇心旺盛な**少年**の斥候にした。一人称を「あたし」から「ぼく」に、まわりの人からの呼び方を「リコちゃん」→「リコくん」、「リコ姉ちゃん」→「リコ兄ちゃん」に変えた。
- 保存先を原型と分けた。進み具合・音などの設定は GUILDWARD だけの記録になり、原型の記録には触れない（原型の記録は引き継がない）。
- ゲームのしくみ・依頼・物語・仲間・敵・成長・バランス・地図・絵・音は、原型のまま変えていない。
- 開発用：本物のクリックで通す検証ツールに、戦いの直後に画面が落ち着くのを待つ処理を足した（ゲームには影響しない）。移植後の検証は `VERIFICATION_v0.1.md`。
