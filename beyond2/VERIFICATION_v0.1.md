## 4. ブラウザでの通し（本物のクリック）

`python tools/playthrough.py --fast --reload`（Playwright＋Edge、本物のマウスとキー。依頼から帰るたびにページを読みなおし、タイトルの「つづきから」で再開）

- タイトル →「はじめから」→ 前口上 → ギルド → 依頼板 → だれと行く？ → 出発 → 依頼1〜6 → 帰還の場面 → 第一章の結末 → ギルドへもどる → 依頼板に第二章の予告、まで通った。ページのエラーなし。
- 6依頼すべて達成。読みなおし後の再開5回すべてギルドに戻り、銀貨も保たれた（110 → 270 → 340 → 490 → 520、最後は 720）。鍛冶屋で2回鍛えた。
- クリック 217・キー 68、戦い 7、手番終了 21。クリックで狙えずルールを直接動かした手（口で代行）が 9（ねらう人や物の絵が重なる場面。原型の記録と同じ傾向）。

### 通しのツールで見つかったこと（ゲームの不具合ではない）

- はじめの2回は、依頼2で止まった（読みなおしのあと、戦いの直後の「ガルドが歩く」が別の升になり、縄をかけられずに進めなくなる）。**原型 `game21/` で同じツールを実行しても、同じ場所で同じように止まった**ので、移植で生じたものではない。
- 調べると、戦いの直後のカメラが探索の位置へ戻る途中にツールがクリックしていた（ねらいを確かめた時と押した時で、画面の位置がずれる）。読みなおさずに通すと止まらない。ルールを直接動かす `jsrun.py` では依頼2を達成できる。
- `beyond2/tools/playthrough.py` に「戦いの直後は、演出が終わるのを待ってから 1.5秒待つ」を足して、上の通しが最後まで通った。原型のツールは変えていない。

## 5. 保存の独立（原型と GUILDWARD）

`file://` で開くと、ブラウザは原型と GUILDWARD の localStorage を同じ場所に置くため、キーを分けたことの確認として、同じブラウザで両方を動かした（スクリプトは作業用。結果をここに残す）。

| 確認 | 結果 |
| --- | --- |
| 原型で「はじめから」・音を「なし」→ `g21_dareto_save`・`g21_dareto_opt` ができる | OK |
| GUILDWARD を開くと、ページの題が GUILDWARD、タイトルに「つづきから」が出ない（原型の記録を読まない）、音は「あり」のまま | OK |
| GUILDWARD で「はじめから」→ `beyond2_guildward_save` ができ、原型の2つのキーの中身は1文字も変わらない | OK |
| GUILDWARD のギルドで音を切ると `beyond2_guildward_opt` に残り、原型の設定は変わらない | OK |
| GUILDWARD を読みなおすと「つづきから（ギルド・見習い）」が出て、押すと進み具合（依頼の達成）と音の設定が戻る | OK |
| 原型にもどると、原型の記録・設定は最初のまま。タイトルに原型の「つづきから」、音は「なし」 | OK |
| 依頼の途中（依頼2で堀を凍らせたあと）で読みなおし →「依頼のつづきから（見張り塔の角笛）」→ 地形と人の位置が読みなおす前と同じ | OK |
