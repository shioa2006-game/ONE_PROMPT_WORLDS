# GUILDWARD

**バージョン v0.3.1**（2026-11-29）　BEYOND ONE PROMPT 第2作

丘の町カザミの冒険者ギルド「風見鶏」。使い走りをして三年、斥候のリコは今日はじめて正式な冒険者の札をもらった。
依頼板から依頼を選び、**同行する仲間を二人選んで**、高低差のあるクォータービューの地図へ出かける。
段差・谷・水・ひび割れた岩を読み、仲間の力（押す・凍らせる・発破）と、リコの弓と鉤縄を組み合わせて依頼を果たす。
帰ってくると報酬が数えあがり、依頼人が広間に顔を出し、飾り棚に品が並び、依頼板に新しい依頼が貼られる。
依頼ごとの**腕だめしの印**を集め、仲間に**お守り**を持たせ、こなした依頼を**別の二人で受けなおす**こともできる。
第一章の結末のあとは、**第二章「北の峠の風」**。雪の峠で、新しい地形と仕掛け、新しい仲間が待っている。

- 原型は ONE PROMPT WORLDS 第21作「だれと行く？ ― 風見鶏ギルドの依頼帳」（`../game21/`）。Claude Opus 5.5 が1つの依頼から自律制作した作品を、継続して開発するために `beyond2/` へ移植した。
- v0.3 は、第二章のはじまり（峠の入口の二つの依頼・新しい仲間・雪の土地）を足した版。v0.2 で成長と収集の土台（腕だめしの印・お守り・受けなおし）と第一章の改良を足している（`CHANGELOG.md`）。ゲームデザインは Claude Fable 5.2 の拡張設計（`design/`）、実装と検証は Claude Opus 5.5。
- PCブラウザ向け。マウスだけで遊べる（キーボードも使える）。音が出る。
- 依頼8つ＋ギルド。第一章（依頼6つ）の結末と、第二章の最初の二つの依頼まで。第二章のつづきは準備中（依頼板に予告の札が出る）。1回の目安：第一章 40〜60分、第二章の二つで 25分前後（設計上の目安。人間のプレイ時間は未計測）。
- 物語は「第一章　おわり ― 依頼帳は、まだつづく」で一区切りして、第二章へ続く。

## 主人公リコ

明るく好奇心旺盛な少年冒険者。冒険者ギルド「風見鶏」に所属する若い斥候で、弓と鉤縄を使う。
正式な冒険者になったばかりで、仲間とともにさまざまな依頼へ挑んでいく。一人称は「ぼく」。

- 職業：斥候（ギルドの依頼にはいつも出る主人公）
- 力：射る（的で仕掛けが動く・高い所から射ると強い）・鉤縄（鉄の輪へ渡る。縄はみんなの道）。第二章では、地図の中で新しい道具も手に入る
- 仲間：重戦士ガルド（ギルドの古株）、氷の術師セナ（学院で遺跡を調べている）、ほか依頼を進めると加わる冒険者（第二章までに4人）

## 起動

`index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動く。サーバー・ビルド・外部ライブラリ・外部素材は使っていない。

簡易サーバーで開く場合は、リポジトリ直下で次を実行して <http://127.0.0.1:8102/> を開く。

```bash
python -m http.server 8102 --bind 127.0.0.1 --directory beyond2
```

## セーブと再開

- 進み具合はブラウザの localStorage に自動で保存される（ギルドでの出来事のたび・依頼の地図で一手ごと）。
- 保存先のキーは `beyond2_guildward_save`（進み具合）と `beyond2_guildward_opt`（音などの設定）。原型（`game21/`）の記録とは別なので、どちらで「はじめから」を選んでも、もう一方の記録は消えない。原型の記録を引き継ぐことはしない。
- タイトルの「つづきから」で再開する。依頼の途中でやめた場合は「依頼のつづきから」で、その地図のその場面から。
- 「はじめから」は、記録があるときは二度押すと記録を消して始める。
- **v0.2 の記録は、そのまま v0.3 で続けられる**（保存の形は同じ）。第一章の結末まで見た記録なら、依頼板に第二章の依頼が貼られている。v0.2 の「依頼のつづき」も、そのまま再開できる。
- **v0.1 の記録も、そのまま続けられる**（読みこむときに v0.2 の形へ移す）。ランク・銀貨・仲間・道具・飾り棚・達成の記録は引き継ぐ。腕だめしの印とお守りは空から始まり、v0.1 でこなした依頼の宝箱は「持ち帰ったもの」になる。v0.1 の「依頼のつづき」（依頼の途中の保存）だけは、ギルドからの再開になる（タイトルに一行出る）。
- 第一章の改良と、印・お守りを最初から味わうには、「はじめから」遊ぶのがおすすめ。

## パーティー編成

- 依頼を選ぶと「だれと行く？」の画面になる。**リコは主人公でいつも行く**。加入している仲間から**二人**を選んで出発する（合計三人）。依頼によっては、選んだ二人に加えて**4人目（同行のゲスト）**がついてくる（札に「同行のゲスト・選ばない」と出る）。
- 札には仲間の力と、その依頼へのひとこと（手がかり）が出る。下に「この三人でできること／できないこと」。
- はじめの仲間はガルドとセナ。依頼を進めると、新しい冒険者が加わる。
- 依頼板の札には「見どころ」（地形や装置）と「手がかり」（どんな力があると進めやすいか）が書いてある。
- **一度こなした依頼は、だれとでも受けなおせる**（はじめの依頼で同行が決まっていたものも。一部、物語の都合で選べない仲間がいる）。「攻略した編成」が残る（仲間4人で6通り）。2回目からの報酬は少なめで、功績はなく、地図の宝箱は前に持ち帰っていれば空。
- 第一章の依頼を、あとから加わった仲間を入れて受けなおすと、**組み合わせと道具によっては目的を果たせない**ことがある。そのときは「だれと行く？」で出発の前に知らせる（`VERIFICATION_v0.3.md`）。
- 出発の前に、同行する三人に**お守り**を一つずつ持たせられる（はじめて一つ手に入れると、札の下に枠が出る）。同じお守りは二つとない。

| 冒険者 | 力 |
| --- | --- |
| リコ（斥候） | 射る（的で仕掛けが動く・高い所から射ると強い）・鉤縄（鉄の輪へ渡る。縄はみんなの道。下から届くのは2段上まで） |
| ガルド（重戦士） | 押す（木箱・岩・敵を一升。段から落とすと足場、水に沈めると飛び石。重い相手も段のふちなら押し落とせる） |
| セナ（氷の術師） | 凍らせる（水を氷の床に・滝を氷の段に・霜の水晶を灯す・敵を一手番止めて、押すとすべらせる） |
| ？？？ | 遊んでのおたのしみ（依頼を進めると加わる。第一章で一人、第二章で一人） |

## 依頼と成長

- **依頼の種類**：退治・宝物回収・救助・遺跡調査・防衛・強敵討伐・荷の回収・装置。目的は画面の左上に出る。果たすと「依頼達成！」。寄り道してから帰ってもいい。
- **報酬**：銀貨（依頼の報酬・地図の宝箱）と功績。功績がたまるとギルドのランク（★）が上がり、仲間みんなの体力が増え、むずかしい依頼が届く。経験値やレベルはない（連れていかなかった仲間も、置いていかれない）。
- **腕だめしの印**：依頼ごとに三つ（その依頼の仕掛けを使う・手際よくこなす・はじめと違う二人でこなす）。条件は依頼板の札に最初から出ている（◇ まだ／◆ とれた）。地図の上で条件を満たすと小さく知らせ、達成して帰ると印がつく。一つにつき一度きり。
- **ドーラの腕だめし帳**：印の数に応じて、お守り・銀貨・飾り棚の品などのごほうびを受けとれる。
- **お守り**：一人に一つ持たせる小さな品（体力が増える、など）。鍛冶屋で買えるものと、腕だめし帳でもらえるものがある。お守りがなくても、どの依頼も達成できる。
- **鍛冶屋のトンボ**：銀貨で仲間の道具を鍛え、お守りを買う。鍛えた道具は次の依頼からすぐ使える（矢が強くなる、届く距離が延びる、新しい働きかけが増えるなど）。
- **記録（リコの依頼帳）**：飾り棚・お守り・腕だめしの印の数・仲間ごとの働きと道具・名場面。
- **ギルドの変化**：依頼人や助けた人が広間に来る、飾り棚に品が並ぶ、旗に星が増える。
- 戦いは手番制。仲間はそれぞれ「動いて、一つ行動」。赤い線は「いま手番を終えたら、敵がどう動き、だれが何点受けるか」。手番を終えるまでは何度でも戻せる。負けても、その手番の始めか戦いの前からやり直せる。

## 検証用ツール（開発者向け）

- `node tools/rules_test.js` … ルール（第二章の地形・働きかけ・敵を含む）・ギルドの進み具合・印・お守り・受けなおし・保存の移行の自動確認
- `node tools/solve_check.js [依頼] [greedy|simple]` … 依頼ごと・編成ごとに、解き方の一例（`tools/routes.js`）と戦いのボットで通す（依頼6は想定攻略手順で戦う。依頼5は大岩の想定手順も試す）
- `node tools/plan_route.js [m5|m6] [GS|GT|ST] [-v]` … 依頼5・依頼6を、想定攻略手順（`tools/plans_lib.js`）どおりにルールだけで通す
- `node tools/compare.js [依頼] [方針] [--up=gauntlet,...]` … 同じ依頼を編成ごと（最大6組）に攻略し、使った手を比べる
- `node tools/replay_pairs.js [依頼] [二人...] [--up=hook,fan] [--goal=x,y] [--depth=N]` … 受けなおしの編成で、探索の道がひらけるかを数手まで調べる
- `python tools/playthrough.py [--fast] [--test [倍率]] [--reload] [--order m1:GS,...] [--replay m1:ST] [--ch2 m7:GT,m8:ST] [--nagi-replay m4:TN] [--shots DIR]` … タイトルから第一章の結末、受けなおし、第二章の二つの依頼、新しい仲間を入れた受けなおしまで、本物のクリックとキーで通す（Playwright＋Edge）
  - `--test [倍率]` … ページを `?test=倍率`（既定 4）で開き、ゲームの時間を速く進める。道具の決まった待ちも短くする
  - `--from ch1|m7|m8 --run m8:ST,m4:TN [--equip]` … タイトルからではなく、第一章の結末まで（`ch1`）・依頼7まで（`m7`）・依頼8まで（`m8`）進めた記録から始め、`--run` に書いた依頼だけを本物のクリックで通す。記録はふつうの通しと同じ編成・同じ買い物で、ゲームのルール（依頼の達成・鍛冶屋・腕だめし帳）を使ってページの中で組み立てる（地図で拾う銀貨や受けなおしの分はないので、銀貨・印・お守りの数は、ふつうの通しより少し少ない）。`--equip` で、お守りを持たせて出る
- `python tools/migrate_test.py --v01 DIR` … v0.1 の保存データを読みこめるかの確認（v0.1 の本体は `git archive abb2b75 beyond2` で取りだす）
- `python tools/migrate_v02_test.py --v02 DIR` … v0.2 の保存データ（第一章の結末まで・依頼のつづき）から v0.3 で続けられるかの確認（v0.2 の本体は `git archive aaa4da5 beyond2` で取りだす）
- `python tools/jsrun.py DIR [m1,m2] [--party ST]` … 依頼を手早く通して要所を撮る（演出のエラー探し用）
- `python tools/shot.py DIR steps.json [?test]` … 画面の撮影
- URL に `?sheet` を付けると、ドット絵の一覧を表示する
- URL に `?test`（または `?test=倍率`、1〜10）を付けると、確認用にゲームの時間を速く進める（既定 4 倍）。付けなければ、ふつうに遊ぶ速さのまま。遊んだ時間の記録は、本当の時間で数える

### 確かめ方の目安

直した中身に合わせて、確かめる範囲を選ぶ。

| 直したもの | 確かめること | かかる時間の目安 |
|---|---|---|
| 台詞・画面の見た目・一つの依頼の中の直し | `node tools/rules_test.js`、関係する依頼だけを `python tools/playthrough.py --fast --test --from m7 --run m8:ST` のように通す | 依頼一つで 30 秒ほど |
| ルール・地図・ギルドの進み具合・保存 | 上に加えて `solve_check.js`・`plan_route.js`、全体の通しを `--fast --test` で | 全体の通しで 5〜6 分ほど |
| 版を出すとき | 上のすべてと、`--test` なしの全体の通し（ふつうの速さでも同じに動くか）、保存の移行の確認（`migrate_test.py`・`migrate_v02_test.py`） | 全体の通しで 12 分ほど |

## 素材

画像・音声・フォントの外部素材は使っていない。絵はすべて Canvas 2D で描き、効果音と BGM はブラウザ内で合成している。文字は利用者の PC にある日本語フォントを使う。
