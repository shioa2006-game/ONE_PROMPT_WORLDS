# GUILDWARD ― 設計の記録

GUILDWARD（BEYOND ONE PROMPT 第2作）の設計資料。現在のバージョンは v0.1。
原型は ONE PROMPT WORLDS 第21作「だれと行く？ ― 風見鶏ギルドの依頼帳」（`../game21/`、制作日 2026-11-28）。この文書は原型の設計資料を引き継いだもの。
依頼ごとの解き方・結末は `NETABARE_攻略とネタバレ.md` に分けた（この文書は仕組みには触れるが、依頼の正解手順は書かない）。

## 1. 企画：ギルドRPGの枠の中での3案

依頼で決まっていたこと：冒険者ギルドRPG／主人公リコ固定＋同行者2人／クォータービューの高低差のある地図で依頼を攻略／ガルド・セナに加えて新しい冒険者を1人以上／成長・報酬・ギルドの変化。
この枠の中で、「何を繰り返し楽しむか」が違う3案を比べた。

### 案A「だれと行く？」― 依頼板と三人一組【採用】

- **一場面**：依頼板に「風見の遺跡：四つの装置のうち三つを動かす」。装置は 的・霜の水晶・重さの床・封印石。札を見て「セナを連れていけば水晶、トビなら封印石と床も…」と考え、二人を選んで出発。遺跡で岩人形を池に吹き飛ばし、門の灯が三つともると扉がひらく。ギルドに戻ると石板が飾り棚に並び、依頼板に新しい依頼が貼られている。
- **繰り返す行動**：依頼を選ぶ →「だれと行く？」で二人を選ぶ → 地図で地形に働きかけて目的を果たす → ギルドに戻って報酬・変化を受けとる。
- **評価**：依頼ごとに目的と地形が違い、仲間の働きが「どの手が使えるか」に直結する。編成が攻略方針そのものを変えるので、依頼の中心にある問い（だれを連れていくか）が遊びの単位になる。

### 案B「遠征キャラバン」― 数日がかりの遠征を、補給と体力をやりくりして進む

- **一場面**：荷馬車で北の峠へ三日の旅。小さな地図を一つずつぬけ、傷は次の地図へ持ちこす。野営地で次の道を選ぶ。
- **評価**：通しで緊張感は出るが、ギルドに「帰る」楽しさが遠征の終わりにしかない。体力のやりくりが中心になると、地形の働きかけより消耗の管理が主役になる。30〜45分では遠征が1〜2本で終わり、編成を変えて遊ぶ区間が短い。

### 案C「討伐番付」― 魔物討伐の手際（手番数・連携）をギルドの番付で競う

- **一場面**：同じ討伐依頼を、別の編成で少ない手番で倒し、番付を上げる。素材で装備を作る。
- **評価**：戦いの手ごたえは出しやすいが、目的が「倒す」に偏る（依頼の「出口へ着くだけ・倒すだけに限定しない」とぶつかる）。素材集めは同じ依頼のくり返しになりやすい。

### 比較と採用理由

| | 案A 依頼板と三人一組 | 案B 遠征キャラバン | 案C 討伐番付 |
| --- | --- | --- | --- |
| ミッション攻略の楽しさ | ◎ 依頼ごとに目的と地形がちがう | ○ | △ 倒すことに偏る |
| パーティー編成の意味 | ◎ 使える手が変わる | ○ 消耗の分担 | ○ 速さの差 |
| 成長・報酬への期待 | ○ 報酬・鍛冶・ランク・仲間 | ○ | ◎ 装備 |
| ギルドへの愛着 | ◎ 帰るたびに広間が変わる | △ 遠征の終わりだけ | ○ 番付 |
| 視覚・操作の気持ちよさ | ◎ 第19作の地形の働きかけを生かせる | ○ | ○ |
| バーティカルスライスとして完成可能か | ○ 6依頼＋拠点 | △ 遠征の分岐が重い | ○ |

**採用：案A**。「どの仲間を連れていくか」が、依頼の見どころ（地形・装置）と結びついて攻略方針を変える。成功の気持ちよさは第19作の「地形が変わる瞬間」を土台に、新しい仲間の「発破」で一度に大きく変わる手を足す。ギルドは帰るたびに飾り棚・人・依頼が増える拠点にする。案Bは帰る楽しさと編成の区間が弱く、案Cは目的が偏るので見送った。

## 2. ゲームループ

```
ギルドの広間 ─ 依頼板で依頼を選ぶ ─「だれと行く？」で二人を選ぶ ─ 出発
      ↑                                                       │
      │                                                       ▼
帰還の場面（報酬・功績・ランク・仲間の加入・新しい依頼）   依頼の地図（探索 → 戦い → 目的）
      ↑                                                       │
      └──────────── 依頼達成 →「ギルドへ帰る」 ←─────────────┘
```

- **ギルドの広間**（クォータービューの部屋）：リコが歩いて、依頼板・受付のミモザ・ギルドマスターのドーラ・鍛冶屋のトンボ・仲間・依頼人に話しかける。依頼を終えるたび、依頼人や助けた人が広間に来て、飾り棚に品が並び、旗の星が増える。
- **依頼板**：受けられる依頼の札（新しい依頼には NEW）。札には目的・見どころ（地形や装置）・手がかり（どんな力があると進めやすいか）・報酬。こなした依頼は「攻略した編成」が残り、別の二人で受けなおせる（報酬は少なめ）。
- **だれと行く？**：リコは主人公でいつも行く。加入済みの仲間から二人を選ぶ。選ぶと「この三人でできること／できないこと」と、その仲間の依頼へのひとこと（手がかり）が出る。
- **依頼の地図**：第19作と同じ操作（物や敵を指すと、だれが・どこに立って・どうなるかが先に見える）。目的を果たすと「依頼達成！」。寄り道（宝箱）をしてから「ギルドへ帰る」。
- **帰還の場面**：報酬が数えあがり、依頼人のひとこと、ランクアップ、仲間の加入、新しい依頼と鍛冶屋の新しい品の知らせが、順に出る。

## 3. ミッション設計

依頼は6つ。目的の種類・地形・仲間の使い方が、それぞれ違うようにした。

| 依頼 | 目的の種類 | 何を考えるか | 同行 |
| --- | --- | --- | --- |
| 1 畑あらしの小鬼 | 退治 | 三人の働き（押す・縄・凍らせる）を一度ずつ。崖っぷちへ押し落とす | ガルド・セナ（固定） |
| 2 見張り塔の角笛 | 宝物回収 | 堀・塔の中段・てっぺん。高所の射手 | ガルド・セナ（固定） |
| 3 石切り場の落盤 | 救助 | 見つけるだけでなく、**縄を渡れない人の帰り道**をつくる。途中で見つけたトビが、歩けないまま発破で手を貸す | ガルド・セナ＋トビ（ゲスト） |
| 4 風見の遺跡 | 遺跡調査 | **四つの装置のうち三つ**。装置ごとに合う力がちがい、どの二人を連れても三つそろう | 自由に選ぶ |
| 5 川辺の村の米倉 | 防衛 | 盗っ人小鬼は米倉へ一直線。橋と飛び石で止める、川へ落とす、大岩を転がす | 自由に選ぶ |
| 6 岩喰い大亀 | 強敵討伐 | 甲羅は矢・押し・爆風をはじく。**段から落としてひっくり返し**、お腹を攻める | 自由に選ぶ |

### 編成による攻略の違い（依頼4〜6）

- **依頼4（遺跡）**：的（リコ・いつでも）＋霜の水晶（セナ）＋重さの床（ガルドが押す／トビが奥で発破して吹き落とす）＋封印石（トビ）。三つでよいので、どの二人でも門はひらくが、使う装置と道すじが変わる。岩人形はガルドでは平らな所で押せない（段のふちなら押し落とせる）。セナなら凍らせてすべらせる、トビなら爆風で池へ吹き飛ばす。
- **依頼5（防衛）**：ガルドは橋に立ってふさぎ、橋の上の小鬼を川へ押す。セナは橋の上の小鬼を凍らせて通せんぼにする。トビは橋の上で発破して、まとめて川へ落とす。大岩は押しても爆風でも転がる。
- **依頼6（大亀）**：ガルドは段のふちで押し落とす（鋼の籠手があれば平らな所でも押せる）・上の段の大岩を転がしてぶつける。セナは凍らせて、押したときにすべらせる（凍った次の手番は振りはらうので、続けては凍らない）。トビは重い大亀も爆風で動かせる。リコは2段以上の高所から射ると、ひっくり返す前でも甲羅のすきまに刺さる。

### 進行不能を避けるための決まり

- 特定の力が要る道には、その力を持たない編成のために別の道か、依頼板の事前情報を用意した。依頼4〜6はどの二人を連れても達成できることを、ボットとルール検証で確かめた（`tools/solve_check.js`・`tools/compare.js`）。
- 地図の中で、選んでいない仲間の力が要る物を指すと「○○がいれば、働きかけられる（いまの編成にはいない）」と出る。
- どこへも行けなくなった敵は、二手番で逃げて戦いが終わる（谷の向こうに取り残された敵で戦いが終わらない、を防ぐ）。
- 手番の中は何度でも戻せる（Z）。負けたら「この手番の始めから」「戦いの前から」。依頼は「はじめからやり直す」「あきらめてギルドへ」もできる。

## 4. キャラクターと固有能力

| 冒険者 | 役どころ | 働きかけ | 人となり |
| --- | --- | --- | --- |
| リコ（主人公・固定） | 斥候 | 射る（的・敵。高所から強い）・鉤縄（鉄の輪へ渡る。縄はみんなの道） | 明るく好奇心旺盛な少年。使い走り三年目で、今日はじめて正式な冒険者になった。前向きで、だれとでも気さくに話す。「ぼく」（原型では少女・「あたし」） |
| ガルド | 重戦士 | 押す（木箱・岩・敵を一升。段から落とすと足場、水に沈めると飛び石。重い相手も段のふちなら押し落とせる） | ギルドの古株。ギルドマスターのドーラと昔組んでいた。師弟ではなく、頼れる年長の仲間。「わし」 |
| セナ | 氷の術師 | 凍らせる（水を氷の床に・滝を氷の段に・霜の水晶を灯す・敵を一手番止めて、押すとすべらせる） | 学院で古い遺跡を調べている。物静かで几帳面、冒険は二回目。「わたし」 |
| **トビ（新しい冒険者）** | **発破師** | **発破**（ひび割れた岩・封印石を砕き、がれきは足場になる。敵や物のとなりの升で発破すると、上下左右のものが外へ吹き飛ぶ。重い相手も動く。仲間は巻きこまない） | 石切り場の若い発破師。落盤で取り残されたところを助けられ、恩返しにギルドへ入る。口ぐせは「〜っす」。高い所がちょっと苦手 |

### トビの設計で守ったこと

- **既存3人と違う個性**：ガルドの「一つを一方向に押す」に対して、トビは「一度に周り全部を外へ」。ねらうのは物そのものではなく「どこで爆発させるか」。
- **地形・仕掛けへの新しい働きかけ**：ひび割れた岩（道をふさぐ・がれきは足場）、封印石（遺跡の装置）、重い物・重い敵を動かす。
- **連携**：凍った敵は爆風ですべっていく（セナ）、ガルドが崖っぷちに寄せた敵をまとめて落とす、リコの縄で渡った先から投げる。
- **見た目から役割が分かる**：紫のバンダナ・真鍮のゴーグル・発破玉を並べた帯・手に火のついた発破玉。働きかけでは、弧を描いて飛ぶ玉と火花、爆風の輪・砂ぼこり。
- **実際に使う**：依頼3で「歩けないけれど投げられるゲスト」として出会い、その場で発破の使い方を覚える。依頼4〜6は自由に編成でき、トビを入れると攻略方針が変わる。

## 5. 編成と成長の仕組み

少ない仕組みで、実際に使って成長を感じられることを優先した。

| 仕組み | 中身 | 何が変わるか |
| --- | --- | --- |
| 仲間の加入 | 依頼3でトビが加わる | 依頼4から「だれと行く？」で選べる。使える手が変わる |
| ギルドランク（功績） | 依頼の初回達成で功績。★1見習い → ★2一人前 → ★3腕きき → ★4風見の星 | ランクが一つ上がるごとに仲間全員の体力 +1。新しい依頼（大亀）が届く。広間の旗の星が増える |
| 報酬の品 | 依頼2で「長い鉤縄」 | 縄の届く距離 5 → 8。依頼3の岩棚・以後の地図で遠くの輪に届く |
| 鍛冶屋（銀貨） | 狩人の長弓（リコ）・氷晶の杖（セナ）・鋼の籠手（ガルド）・大玉の発破（トビ） | 矢 +1・届く距離 +1／乾いた床に氷のかたまり（足場・壁・すべる石）／重い相手を平らな所でも押す・石柱を倒して橋に／爆風で2マス吹き飛ばす |
| 飾り棚・記録 | 依頼ごとの品（大かぼちゃ・見張り塔の旗・記念石・石板・感謝の旗・甲羅のかけら）、仲間ごとの働き、名場面、攻略した編成 | 成果がギルドに残る |

- 銀貨は依頼の報酬と地図の宝箱で手に入る。四つの品を全部そろえるには、寄り道（宝箱・米俵）も拾うとちょうど足りる。何を先に鍛えるかが、次の依頼の編成選びにつながる。
- 同じ依頼をくり返さなくても、最後まで進める（くり返すと報酬は四分の一、功績はなし）。くり返しは「別の仲間で攻略してみたい」ためのもの。

## 6. 第19作から引き継いだもの

- **ルールの土台**（`js/sim.js`）：高さのある升・段差（のぼり1段／飛びおり2段）・谷・水・流れの速い水・氷、押す（すべる・転がる・落ちる・沈む）・射る・鉤縄（縄は双方向の道）・凍らせる（水・滝・敵）、手番制の戦いと敵の思考、「いま手番を終えたら敵がどう動くか」の予告、戦いの決着、道がひらけたときの光の波。
- **描画**（`js/render.js`）：640×360 のクォータービュー（升 32×16、1段 8画素）、段の帯と目地、壁の陰の仲間を色で透かす表示、見る向きの回転、物と人の描画。

## 7. 新しく設計・実装したもの

- **編成式に作りなおし**：固定3人（`HERO_IDS`、名前で決め打ちの行動判定、3枚の札）を、仲間ごとの `verbs`（できる働きかけ）で判定するように変えた。出撃する顔ぶれ（`party`）を地図に渡し、札は3〜4枚に合わせて並べる。キー 1〜4 は出撃した順。
- **新しい働きかけ**：発破（爆心と上下左右、外へ吹き飛ばす・重い物も動く・仲間は巻きこまない・大玉で2マス）、ひび割れた岩と封印石（砕けるとがれきの足場、装置にもなる）、霜の水晶、氷のかたまりづくり（杖）、重い相手を段のふちで押し落とす。

## 8. 将来の差しかえ・拡張のための口

- **キャラクターの絵**：`SPR21.useImage(種類, 画像, { w, h, frames: { F_idle: [列, 行], F_walk1: …, B_idle: … } })` で、外部で作ったスプライト画像（例：SpriteStack Character Lab の書きだし）に置きかえられる。`frame(種類, 画面の向き, 姿勢)` が返す形は同じなので、描画側は変えなくてよい。
- **依頼の追加**：`js/data.js` の `MAPS` に地図を、`REQUESTS` に依頼の札を足す。解放の条件は `unlock(進み具合)`。
- **冒険者の追加**：`js/sim.js` の `HERO` に `verbs` を書き、`js/sprites.js` に絵を足す。行動の判定は `verbs` を見るので、既存の働きかけの組み合わせなら追加のコードはいらない。
