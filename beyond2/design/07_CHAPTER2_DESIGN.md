## 2. 物語

### 2.1 あらすじ

1. **峠の入口**（m7）：ふもとの茶屋が雪小鬼に荷を奪われた。取り返すと、おかみのツルが、亡き夫の山仕事の道具「引き鉤」をリコに預ける。「上の里の風車が止まって、粉がひけない」と聞く。
2. **風守りの里**（m8）：里の子ナギが、ひとりで風鳴り石を鳴らしに行こうとしている。うちわの風が弱く、石のとなりへも行けない。リコたちと力を貸し借りして、三つの石を鳴らす。里にだけ風が戻る。ナギがギルドに加わる。
3. **峠の三つの依頼**（m9・m10・m11。好きな順に二つで先へ進める）：
   - 鏡の湖：氷が割れて、漁師の親子が小島に取り残された。
   - 関所の坂：雪小鬼の大群が、峠の関所へ下りてくる。
   - 風穴：学院の頼み。奥に二枚目の石板があるらしい。
   二枚目の石板をセナが読むと、「風の石が眠ると、番が目ざめる。石を眠らせる者あり」。大亀も、ここの「番」も、だれかが石を眠らせた結果だった。
4. **灰色の狼**（m12）：三段の岩場の岩かげで、けがをしたロウとキヌを見つける。雪狼の群れの中を、荷馬車まで送りとどける。三人目のヤシャは「風を盗むやつを追って、先へ行った」。
5. **頂の祠**（m14）：峠の風の石を、雪喰い大猪が雪で埋めている。倒す（または風鳴り石を鳴らして毛皮の霜をはがす）と、峠に風が戻り、ナギのうちわに風が満ちる。
6. **結び**：祠の雪の上に、祠から南東へ下りていく足あと。ロウ「ヤシャは、霧の谷へ下りたんだろう」。第三章の予告「霧の谷の川下り」。

- 依頼の前（出発の画面）：仲間のひとこと一行ずつ（既存）。

## 6. 第二章の結末と、次への期待

### 結末の語り（案。五枚）

1. 大猪が倒れると、祠の雪が、内側からほどけるように崩れた。奥で、風の石が低く鳴りはじめる。
2. 峠を、ひとすじの風が下りていった。関所の旗が、湖の氷の粉が、里の風車が、順に目をさます。
3. ナギのうちわが、ひとりでにふくらんだ。「……戻ってきた。うちの風や」
4. けれど、祠の雪の上には、峠の向こうへ下りていく足あとが一すじ。ロウが、しゃがんで指でなぞる。「ヤシャだ。風を盗むやつを、追っていった」
5. 石板は二枚になった。読めない文字は、まだ半分。リコの依頼帳は、二冊目に入る。――第二章　おわり。

## 7. 今回、第二章に入れなかったもの（見送りと理由）

| 見送ったもの | 理由 |
| --- | --- |
| 風の通り道（毎手番、列の軽い物が動く地形） | 新しい決まりが多すぎる（05 の新規だけで十分に多い）。予告表示の確認も重い。「風が戻ったあと」の第三章の主役に取っておく |
| 二人目の新しい仲間 | 04 1章 |
| 吹雪の手番しばり・寒さの消耗 | 戦いのあと全快する現行の決まりと合わない。急がせる圧は、護衛（m12）の「けが人が歩く」で作る |
| 敵が仕掛けを使う（雪玉を転がしてくる） | 敵の思考に大きな追加。プレイヤーが仕掛けを使う楽しさを、まず確かめる |
| ギルドの施設の拡張 | 要望がない。帳面一枚（腕だめし帳）だけ足す |
| 仲間ごとの個別の依頼 | 必須の依頼に役を割りふった（m11＝セナ、m12＝ガルド、m8＝ナギ）。依頼の数を増やさない |
