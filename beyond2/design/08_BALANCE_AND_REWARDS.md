# 08　難しさ・成長・報酬のバランス

数値はすべて**初期調整値**。「幅」は、実装担当が検証や実プレイの結果を見て、設計を変えずに動かしてよい範囲。幅をこえる変更と、【必須】の決まりの変更は、設計変更として人に確認する（09 4章）。

## 1. 難しさの曲線（設計上の仮説）

```
難しさ
 ★★★★★                                                     ● m13（任意）
 ★★★★                                                  ● m14
 ★★★☆                                          ● m12
 ★★★                                   ● m11
 ★★☆               ● m6                ● m10（雪玉を使えば ★★）
 ★★        ● m4 m5         ● m8  ● m9
 ★☆                    ● m7

      └─ 第一章 ─────┘ └─────────── 第二章 ───────────────┘
```

| 段 | 依頼 | 何を求めるか | 何は求めないか |
| --- | --- | --- | --- |
| 導入 | m1〜m3 | 三つの力を一度ずつ | 作戦 |
| 編成 | m4・m5 | だれを連れるかで手が変わる。並んだ所へ転がす | 手際 |
| 最初の山 | m6 | さそって当てる、を二度 | 道具（なくても勝てる） |
| 入りなおし | m7・m8 | 新しい物・新しい仲間 | 難しい戦い |
| 広がり | m9・m10・m11 | 既存ルールの応用／爽快／編成 | 三つとも（二つでよい） |
| 手応え | m12 | 先を読む・時を選ぶ | 完璧（けが人が傷を受けても、倒れなければよい） |
| 山 | m14 | 突進の列を読む | 決まった一つの手順 |
| やり込み | m13 | 持っている物を全部 | 物語には不要 |

- 【必須】m7 は m6 より楽にする（章の入口）。m10 は、仕掛けを使えばはっきり楽にする（爽快の回）。
- 失敗の重さは全編で同じ（手番の始め・戦いの前へ戻れる）。

## 4. 調整してよい数値と幅

### 4.1 共通の決まり

| 項目 | 初期値 | 幅 | 動かすときの目安 |
| --- | --- | --- | --- |
| すきの長さ | 次の自分の手番の終わりまで | 固定【必須】 | ― |
| すきの間の傷の上のせ | +1 | +1〜+2 | 強敵戦が長すぎるなら +2 |
| 甲羅・毛皮への高所の矢 | 1（風切りの弓 2） | 1〜2（弓で 2〜3） | 「高所だけで勝てる」に戻らない範囲 |
| 大岩の傷 | 3 | 固定（既存） | ― |
| 雪玉の傷（大きさ1・2・3） | 2・3・4 | 2・3・4〜2・3・5 | 氷の岩人形への効き |
| 雪玉が育つ雪の升の数 | 2升ごと | 1〜2 | m10 で「小さくて止まる」が多すぎるなら 1 |
| 深い雪の歩数 | 2 | 固定 | いらだつなら、雪の升を減らす（地図で） |
| あおぐ距離 | 2（大うちわ 3） | 固定【必須】 | 地図が距離2・3を前提にしている |
| 引く距離・動かす升 | 4・2 | 4〜5・2 | ― |
| 置き発破の数 | 一度に一つ | 1〜2 | ― |

## 5. バランスの心配と、見る場所

| 心配 | 見る場所 | 手当て |
| --- | --- | --- |
| トビを入れておけば足りる | 編成ごとの手番・傷（`compare.js`）と、人が選んだ編成 | 04 4.4 の【検討事項】（3段以上高い升へは投げられない）。**人に確認してから** |
| セナが弱くなりすぎる（凍らない敵・すきの間は止められない） | セナ入りの編成の達成率。人が「連れていく理由がある」と言うか | 霜降りの杖を早く（m9 を三つの最初に置くよう、依頼板の並びで誘う）。氷の岩人形の数を減らす |
| ナギが、谷の多い地図で強すぎる | m8・m12・m13 の、ナギ入りの手番 | 軽い敵の割合を下げる。あおぐ距離は変えない |
| ナギが、重い敵ばかりの依頼で出番がない | m11・m13 の、ナギ入りの手番と感想 | 木箱・つららを足す（当てる物）。風鳴り石のような、ナギの装置を置く |
| ガルドが遅くて間に合わない | m10・m12 で、ガルドが仕掛けに着いた手番 | 韋駄天の足袋（印9つ）。仕掛けを6歩以内に置く原則（05 0章）を守る |
| 強敵が長い | m6・m14 の手番数 | 体力を幅の下へ。すきの上のせを +2 に |
| お守りで数値がふくらむ | 胸当て＋ランクで体力が増えすぎないか | お守りは一人一つ。体力+2 は一つだけ |
| 銀貨が余る・足りない | 3.3 の三つの遊び方で、大猪の前の手持ちと買えた数 | 二段目の値（300〜380 の幅） |
