## 2. 採用した案と、その理由

| 判断 | 理由 | 根拠 |
| --- | --- | --- |
| 拡張の方向は「地方をめぐる依頼帳」 | いまの面白さは、手づくりの地形から生まれている。章で区切れる | 02 1章 |
| 第一章は m5・m6 だけ直す | 人の評価は「どれもよかった」。直すのは、事実で問題が確かめられた所だけ | 01 4章・06 |
| 大岩を「敵が並ぶ列」「手の届く所」へ | 初期の三人では、m5 の大岩を動かせなかった（事実） | 01 4.1 |
| すきを「次の自分の手番の終わりまで」に | ひっくり返したごほうびが、いまは手番の残りだけ（事実）。段取りに報いる | 01 4.2・05 1.1 |
| 高所の矢は甲羅に傷1 | 落としたあと、高所の矢だけで終わる（事実） | 01 4.2・05 1.2 |
| 仕掛けの配置の原則（6歩以内・二つ以上の働きかけ・敵の通り道） | 大岩の分析から。第二章の全依頼に当てた | 05 0章 |
| 経験値を入れない | 出撃しない仲間が置いていかれる。敵も同じだけ強くして帳消しになりやすい | 03 1章 |
| 二段目の道具は「新しい働きかけ」 | いちばん喜ばれている成長（杖で氷のかたまり）と同じ型 | 03 4章 |
| お守りは一人一つ・同じ物は二つとない | 数値の成長と選ぶ楽しさを、少ない決まりで | 03 5章 |
| 腕だめしの印（発見・腕前・別の二人） | 受けなおす理由を、かせぎではなく「別の遊び方」に置く | 03 6章 |
| 新しい仲間は一章に一人 | 新しい働きかけの実装の重さ。組み合わせは6通りで足りる | 04 1章 |
| ナギは「あおぐ」 | 既存の動かす手（となりへ1升・四方へ）にない向き：上へ・越える・仲間を運ぶ。既存の決まり（上から落ちた物は傷3・氷ですべる・沈んで飛び石）と多く噛みあう | 04 3章 |
| 加入の依頼で、ゲストとして先に使う | トビ（m3）で成り立った型 | 04 2.6 |
| リコの手だけで通る本線を置く | どの二人でも詰まない、を簡単に守れる。主人公の成長が全員に効く | 04 6.2 |
| 第二章は、使われていない既存ルールを主役に | 氷ですべる・沈んで飛び石・転がる・上から落とす。新しい決まりを増やす前に | 01 3.3 |
| 水霊・粘体を第二章で使う | 実装ずみで、地図に出ていない | 01 7章 |
| 凍らない敵（氷の岩人形） | 「凍らせて押す」が万能（事実）。別の手を考える理由を作る | 01 1.4・05 4.4 |
| 段をのぼる敵（雪狼） | 高所にいれば安全、をくずす。落としやすい軽さとの組 | 05 4.3 |
| 大猪は「ねらう → 突進」の二拍子 | 敵の次の動きが見える、という既存の魅力を、強敵の中心に置く | 05 4.6 |
| 護衛（m12）を「帰り道を先につくる」に | m3 の学びの発展。下見がそのまま作戦になる | m12 |
| 装置は「六つのうち四つ・リコ二つ・仲間一つずつ」 | m4 の型を、二人とも出番があるように | m11 |
| m10 の坂を、幅1の谷すじ五本に | 現行の敵の思考で動かしたら、広い坂では列に並ばなかった。谷すじにすると並ぶ（確認ずみ） | m10 |
| 保存は移行する | 遊んだ記録を捨てない。ただし評価は最初から | 09 5章 |

## 3. 見送った案

| 案 | 見送った理由 | また考える時 |
| --- | --- | --- |
| 新しい仲間「入れ替わる」（相手と位置を交換する） | セナの氷のかたまりと組むと、探索中はほぼどこへでも行けてしまう。地図づくりの負担が常に残る | ― |
| 新しい仲間「引く」専門 | トビの発破が「どの向きにも動かせる」ので、役がかぶる。主人公リコの成長として入れるほうが、全編成に効く | ― |
| 新しい仲間「風を一列に吹かせる」 | ガルド・トビとかぶる | ― |
| 新しい仲間「火」 | 高さとの噛みあいが弱い。セナと打ち消しあう場面が多い | 第四章（構想） |
| 新しい仲間「おとり・誘う」 | 探索中の使い道が弱い。ただし「仕掛けの列に敵を入れる」役として有力 | 第三章（構想。04 8章） |
| 風の通り道（毎手番、列の物が動く地形） | 新しい決まりが多すぎる。予告の確認が重い | 第三章 |
| 経験値・レベル・スキルツリー・素材と合成 | 03 1章 | ― |
| 手番しばり・寒さの消耗 | 戦いのあと全快する決まりと合わない | 挑戦状（やり込み）として、第三章より先 |
| 敵が雪玉を転がしてくる | 敵の思考への大きな追加。まず、こちらが仕掛けを使う楽しさを確かめる | 第三章より先 |
| 二手に分かれて進む依頼 | 一人で戦う側が、危ないか退屈になる | ― |
| 第一章に依頼を足す（大岩を学ぶ依頼） | m5 の改良で足りる。第一章を長くしない | ― |
| 鍛冶屋の4品の値上げ | 初見確認で「長弓にわずかに足りず、次で買えた流れがよかった」とある。お守り一つを足して、選ぶ余地を作る | ― |
| ギルドの施設・経営 | 要望がない。依頼文の方針 | ― |
| 仲間ごとの個別の依頼を別に立てる | 必須の依頼に役を割りふった。依頼の数を増やさない | 第三章より先 |
| 大亀に新しい行動（突進など）を足す | 大猪との違いがなくなる。大亀は「運ぶ」戦いのまま、数値と配置で直す | ― |

## 7. 今回の作業で、変えていないもの

- ゲーム本体（`beyond2/index.html`・`js/`）・既存の資料・検証ツール（`tools/`）・原型（`game21/`）・ギャラリーのトップページは、**変更していない**。
- 既存の保存データには触れていない。push していない。
- 追加したのは `beyond2/design/` だけ（設計資料と、設計確認用の `design/data/`）。
- 設計確認のための試作（ルールの写しに変更を当てたもの）は、作業用の一時フォルダで行い、リポジトリには置いていない。
