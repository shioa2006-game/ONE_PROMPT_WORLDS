## 1. コアループ

### 1.1 プレイヤーが繰り返す行為

```
依頼板を読む → だれと行く？（二人を選ぶ）→ 地図を見わたす
   → 物・水・岩・敵を指して「だれが・どこに立って・どうなるか」を先に見る → 押す
   → 道がひらける／敵が落ちる・沈む・すべる → 目的を果たす → ギルドへ帰る
   → 報酬・ランク・仲間・新しい依頼・鍛冶屋の品 → 次の依頼
```

### 1.2 その行為そのものの面白さ（維持する）

| 仕組み | 何が面白いか | 根拠 |
| --- | --- | --- |
| 行動の前に結果が見える（`S.preview` をそのまま表示） | 試すのが怖くない。「こうなるはず」という予想と結果が、押す前に一致する | 【事実】見こみはルールで実際に試した結果。【人の感想】戦闘・探索とも「よい」 |
| 戻せる（探索は何手でも、戦いは手番の中） | 仮説 → 試す → 戻す、が速い | 【事実】`undo`・`retryPhase`・`retryFight` |
| 敵の次の動きが赤い線で出る（決定的な思考） | 「いま手番を終えたら何が起きるか」を読んで、位置で受け方を変えられる | 【事実】`S.intents` は敵の手番を写しで実行したもの。乱数はない |
| 高さ1段ずつの升（のぼり1・飛びおり2） | 2段の段差が「道具がいる所」になり、木箱・縄・氷・がれきが同じ問いに別の答えを出す | 【事実】`canStep` |
| 一つの働きかけが、探索と戦いの両方で意味を持つ | 押す＝足場づくり＝崖から落とす。凍らせる＝渡る＝止める＝すべらせる | 【事実】依頼1〜6の使われ方（3章） |
| 物の動きが連なる（すべる・転がる・落ちる・沈む） | 一手で「思ったより大きく」動く瞬間がある | 【事実】`pushEntity` の一つの処理に、氷・転がり・落下・沈みがまとまっている |
| 編成で使える手が変わる | 同じ地図で別の道すじになる | 【事実】依頼4〜6（2章）。【人の感想】「初期の3人でクリアしたのでやってないが、楽しいと思う」＝未体験 |

### 1.3 達成で得られるもの・次を受ける理由

- 【事実】銀貨（依頼の報酬＋宝箱）、功績 → ランク（体力+1）、鍛冶屋の品が増える、仲間（トビ）、飾り棚の品、広間に来る人、名場面の記録、依頼板の NEW。
- 【事実】次の依頼の解放は一本道に近い：m1 → m2 → m3 →（m4・m5 が同時）→ m6。
- 【解釈】「次を受ける理由」は、いまは **物語の続き**と**新しい依頼の題名**が中心。育てたいもの・集めたいもの・試したい編成は、まだ薄い。

### 1.4 長く遊ぶと単調になりそうな所（発展させる）

| 所 | 理由 | 印 |
| --- | --- | --- |
| 成長が4品＋体力で終わる | 鍛冶屋は一人1品。依頼5までの報酬（650）だけで4品（620）がそろう | 【事実】 |
| 「凍らせて押す」が万能 | 依頼1で教わる手が、大亀にもそのまま効く（4章） | 【事実】【解釈】 |
| 受けなおす理由が弱い | 2回目は銀貨4分の1・功績なし。「攻略した編成」の印は残るが、ごほうびはない | 【事実】 |
| 敵の種類が傷と体力の差に寄る | 小鬼・射手・コウモリ・岩人形・盗っ人。地形と噛みあう特徴は「飛ぶ」「重い」「一直線」「甲羅」の四つ | 【事実】 |
| 仕掛けが「あるだけ」になる | 大岩・石柱は、使わなくても勝てる。使うには手間がかかる（4章） | 【事実】【人の感想】大岩は活用できなかった |
| トビが強すぎる可能性 | 発破は「どの升でも・どの向きにも・重い物も」動かせ、傷もある。ボットではトビ入りの編成がいつも速い | 【事実】ボットの結果。【仮説】人が遊んでも同じとは限らない |

## 4. 人の感想と、ルールで確かめたこと

### 4.1 大岩を活用できなかった

- 【人の感想】「大岩は活用できなかった」。初期の三人（リコ・ガルド・セナ）で第一章を終えた。
- 【事実・依頼5】ガルドは二つの大岩を、どの向きにも押せない。

| 大岩 | 東へ | 南へ | 西へ | 北へ |
| --- | --- | --- | --- | --- |
| 左の崖 (1,7) 高さ5 | × 立つ升(0,7)へ行けない | × 立つ升が川 | × 高さの差2 | × 行けない |
| 右の丘 (12,8) 高さ5 | × 高さの差2 | × 行けない | × 行けない | × 行けない |

　トビの発破なら、どちらも動く（左の大岩は東へ転がって橋の出口の列をなぎ倒す）。リコも右の丘へは上がれない。依頼板・戦いのヒント・攻略の資料は「押せば転がる」「右の丘から射ると強い」と案内している。
- 【事実・依頼6】ガルドが上の段の大岩を南へ押すには、開始位置から10歩（4手番）。その道は大亀が下りてくる中央の坂ひとつだけ。大岩の転がる列（x=4・x=10）は、大亀の通り道（x=7）と重ならない。
- 【事実】ボットの比較でも、ガルド＋セナは大岩で一体も倒していない（`VERIFICATION.md` 4章）。
- 【解釈】初期の三人では、**大岩は「使わなかった」のではなく、ほぼ「使えなかった」**。仕掛けの気持ちよさより前に、手が届いていない。
- 【仮説】手が届く所に置き、敵が並ぶ列に向け、見こみで「3体をなぎ倒す」と出れば、使われる。→ m5・m6 の改良で確かめる。

### 4.2 大亀を、なんとなく倒せてしまった

- 【人の感想】「亀もなんとなく倒せてしまった」。
- 【事実】大亀の体力は12。初期の三人で、次の流れが成り立つ（ルールで通した）。

| 手番 | 起きること |
| --- | --- |
| 1〜3 | 大亀が坂を下りて、中段の冒険者のとなりへ来る |
| 4 | セナが凍らせ、ガルドが南へ押す → すべって下の段へ落ち、ひっくり返る（傷2）。リコがお腹へ矢（傷3〜4） |
| 5〜6 | 大亀は下の段。**中段のリコから2段下なので、高所の矢がそのまま刺さる**（傷3〜4 ずつ）→ 倒れる |

- 【事実】「お腹が出ている」のは、ひっくり返したその手番の残りだけ（次の敵の手番で元に戻り、動けないだけ）。凍らせると、ひっくり返りが解ける。
- 【解釈】①依頼1で覚えた「凍らせて押す」が、舞台のどこでもそのまま効く。②落としたあとは、高所の矢が安い決め手になる。③大亀がほとんど動かないので、観察して作戦を立てる間がない。**難しさの問題というより、「気づいて、仕かけて、決まる」という段取りが要らない**ことが、「なんとなく」の中身だと考える。
- 【仮説】体力を上げるだけでは「長いだけ」になる。高所の矢を弱め、お腹の出る時間を「次の自分の手番の終わりまで」に延ばし、大岩を大亀の止まる列へ置けば、「さそう → 当てる → みんなで攻める」が二度まわる戦いになる（試作で 6〜8手番・ひっくり返し2回。06・m6）。

### 4.3 別の編成を試していない

- 【人の感想】「初期の3人でクリアしたのでやってないが、楽しいと思う」。
- 【事実】依頼4〜6は、初期の二人でも詰まない（そう作ってある）。編成を変えるごほうびは「攻略した編成」の印だけ。
- 【解釈】編成が面白くなかったのではなく、**変える理由がなかった**。これは判断できない点として残し、変える理由のほう（依頼板の手がかり・腕だめしの印・仲間の道具）を足す。

### 4.4 簡単である

- 【人の感想】「現状簡単だが、今後のミッションで手ごたえのあるミッションがでてくればよい」。
- 【解釈】第一章は導入としてこのままの難しさでよい。上げるのは第一章の最後（大亀）と、第二章の中盤以降。

## 5. 冒険者の役割

| | リコ（斥候・固定） | ガルド（重戦士） | セナ（氷の術師） | トビ（発破師） |
| --- | --- | --- | --- | --- |
| 体力・移動 | 6・4 | 9・3 | 6・3 | 7・3 |
| 働きかけ | 射る（距離5・傷2・高所+1）／鉤縄 | 押す（となり・1升・傷1） | 凍らせる（距離4） | 発破（距離4・爆心2） |
| 探索 | 鉄の輪へ渡る・的 | 木箱・ブロック・大岩 | 水・滝・水晶 | ひび岩・封印石 |
| 戦い | ただ一人の「まっすぐ傷を与える」役 | 崖・水のそばで一撃。体力で受ける | 止める・すべらせる・高所の射手を落とす | まとめて動かす。重い敵も動かす |
| 得意 | 高所・谷ごし | ふち・橋・狭い所 | 水辺・飛ぶ敵・重い敵 | 群れ・重い敵・壁 |
| 苦手 | 甲羅・体力の多い敵 | 足が遅い・押す側に回りこむ必要・平地の重い敵 | 水のない平地（杖の前）・傷が小さい | となりに仲間がいると投げにくい・高所からは届きにくい |
| 鍛える | 長弓（傷+1・距離+1）・長い鉤縄 | 鋼の籠手（重い敵を平地で・石柱） | 氷晶の杖（距離+1・氷のかたまり） | 大玉（傷+1・2升） |
| 代わりがきく所 | 的・輪は代わりなし | 押す → トビの発破でほぼ代わる | 止める・水を渡る → 代わりなし | ひび岩は代わりなし |

- 【事実】発破は「どの升でも・四方向・重い物も・距離4から」。ガルドの押すは「となり・一方向・立つ升が要る・重い物はふちか籠手」。**動かす力だけを比べると、トビがガルドを含む**。
- 【事実】ボットの手番数は、依頼4〜6のすべてでトビ入りが最短。ただしボットは一手番先しか見ないので、段取りの要るガルドに不利。**これを人の評価やキャラクターの優劣とはみなさない。**
- 【解釈】今後も四人が活躍するには、次が要る。

| 冒険者 | 活躍させるための設計（04・05 で具体化） |
| --- | --- |
| リコ | いつも出るので、成長が全編成に効く。**「引く」を足して、遠くの物・敵を動かす手をどの編成にも持たせる** |
| ガルド | 「転がす物」を手の届く所に置く（大岩・雪玉）。二つまとめて押す。体力の高さを、おとり役として生かす強敵 |
| セナ | 凍らない敵を出して万能さを下げ、かわりに**床を凍らせる**（すべり台づくり）で地形役を強める |
| トビ | 爆風の利かない場面（凍った毛皮の強敵・高い所）を作る。先を読んで**置く**発破で、読みの楽しさへ |

## 8. まとめ：維持するもの・発展させるもの

**維持する（変えない）**

1. 押す前に結果が見える・戻せる・敵の次の動きが見える。
2. 高さ1段の升と、のぼり1・飛びおり2。
3. リコ＋二人の三人一組。依頼板 →「だれと行く？」→ 地図 → 帰還。
4. 一つの働きかけが探索と戦いの両方で意味を持つこと。
5. どの二人を連れても、大事な目的は果たせること。
6. ギルドは経営ではなく、帰る場所。帰るたびに少し変わる。

**発展させる**

1. 成長：一人1品 → 道具の二段目（新しい働きかけ）＋お守り（数値・選ぶ楽しさ）＋腕だめしの印（受けなおす理由）。
2. 仕掛け：手が届き、敵が並ぶ列に向き、見こみで大きな結果が見える配置にする。
3. 強敵：観察 → 仕かけ → みんなで攻める、が二〜三度まわる戦いにする。
4. 編成：仲間を増やし、依頼板の手がかりと印で「別の二人」を試す理由を作る。
5. 使われていない既存ルール（氷ですべる・沈む・転がる・上から落とす）を主役にする。
