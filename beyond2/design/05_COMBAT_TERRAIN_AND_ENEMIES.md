# 05　戦闘・地形・敵・強敵の共通仕様

依頼ごとの仕様書（`missions/`）は、ここの決まりを前提にしている。同じ決まりを依頼の資料にくり返して書かない。

- 【既存】＝ v0.1 の `js/sim.js` にすでにある決まり（変えない）
- 【変更】＝ 既存の決まりを変える
- 【新規】＝ 新しく足す
- 数値は初期調整値（幅は 08）。**太字の【必須】**は設計の意図として守る所。

すべての新しい働きかけは、既存と同じ約束を守る：**押す前に結果が見える（ルールで実際に試した結果を出す）／乱数を使わない／探索中は何手でも、戦いは手番の中で戻せる／仲間は傷つけない。**

## 0. 仕掛けを「使いたくなる」ための配置の原則

01 の分析（大岩はほぼ使えなかった）から、仕掛けを置くときの原則を先に決める。地図を直すときは、これに照らす。

| # | 原則 | 具体的な基準 |
| --- | --- | --- |
| 1 | **手が届く** | 仕掛けを動かす立ち位置は、開始位置から6歩（2手番）以内。**二つ以上の働きかけ**で動かせる（押す／発破／引く／あおぐ／射る のうち） |
| 2 | **列が合う** | 仕掛けの動く列を、敵が必ず通る所（橋・坂・門）か、敵が止まる所（冒険者のとなり）に重ねる |
| 3 | **見える** | 見こみに「3体をなぎ倒す」と数が出る。依頼板の見どころと、最初の会話で一度だけ言う |
| 4 | **待つと得** | 敵の次の動き（赤い線）で、列に並ぶのが見える。並んでから使うほうが大きく決まる |
| 5 | **使わなくても勝てる、使うとはっきり楽** | 目安：手番が半分、または受ける傷が半分 |
| 6 | **一度きりで終わらせない** | 数を置く（m10 は五つ）か、転がった先からもう一度使える形にする |

## 1. 既存ルールの見直し

### 1.1 【変更】すき（ひっくり返る・目を回す）

甲羅（大亀）・凍った毛皮（大猪）の敵に共通の決まり。

| 項目 | v0.1 | 変更後 |
| --- | --- | --- |
| すきができる条件 | 2段以上の落下／大岩・石柱が当たる／物が上から落ちて当たる | 同じ。＋つらら・雪玉・氷の柱・置き発破（大猪）。**転がる物は、1升以上転がってから当たったときだけ**（1.3） |
| できたときの傷 | 2 | 2（氷の柱に突っこんだ大猪は 3） |
| 続く長さ | その手番の残りだけ（次の敵の手番で休み、元に戻る） | **次の自分の手番の終わりまで**。自分の手番にできたすきなら、直後の敵の手番を一回休む。敵の手番にできたすき（突進でぶつかった）なら、その手番はそこで終わり、次の敵の手番はふつうに動く |
| すきの間 | どの攻撃も+1（落下をのぞく） | 同じ。甲羅・毛皮は効かない |
| 重ねがけ | ― | **すきの間に、もう一度条件を満たしても、長さは延びない**（傷は入る） |
| 凍らせる | すきが解ける | **解けない。**霜の傷（1＋1）だけが入り、止める効果は付かない |

- ねらい：ひっくり返したら「次の自分の手番まるごと、みんなでお腹を攻められる」。段取りのごほうびを大きくし、はめ続けることはできないようにする。
- 表示：すきの間は敵の上に「すき あと1手番」。次の敵の手番で動くかどうかを、赤い線の所に「起きあがる」「休む」と出す。
- 実装の目安：`flipped` を「残りの自分の手番の数」として持つ（自分の手番にできたら2、敵の手番にできたら1）。敵の手番で 2 なら 1 にして休み、1 なら 0 にしてふつうに動く。

### 1.2 【変更】高所の矢と、甲羅・毛皮

- すきのない甲羅・毛皮に、2段以上高い所から射た矢は「すきまに刺さる」。その傷は**1に固定**（風切りの弓で2）。v0.1 はふつうの傷（3〜4）がそのまま入っていた。
- すきの間は、ふつうの計算（高所+1、すき+1）。
- ねらい：高い所を取るだけで強敵が片づくのを止める。高所の矢は「どの編成でも少しは削れる手」として残す。

### 1.3 【変更】転がる物の勢い

- 大岩・雪玉は、**1升以上転がってから**敵に当たったときだけ、傷を与え、すきを作る。となりから押して、動かないまま当たったときは「ぶつかって止まった」（傷なし）。
- ねらい：大岩を敵のとなりに置いたまま、押すたびにひっくり返す、という手をなくす。列の端から転がす段取りに意味を持たせる。

### 1.4 【変更】行き場のない盗っ人

- 米倉をねらう盗っ人小鬼は、行き場がなくなっても **4手番**は逃げない（v0.1 は2手番）。ほかの敵は2手番のまま。
- ねらい：m5 の改良で渡り口をふさぐ手が増えるので、「両方ふさいで2手番待つ」だけで波が消えるのを防ぐ。

### 1.5 【変更】凍った重い敵は、どの働きかけでもすべる

- 【既存】凍った敵は、押す・爆風で止まるまですべる（重い敵も）。
- 【新規】引く・あおぐ でも同じ（重い敵は浮かず、その向きに1升すべりだして、止まるまですべる）。

### 1.6 【変更】ついてくる仲間の立つ升（操作の改善）

- 探索中、選んだ一人についてくる仲間は、**その行動で動く物・敵の行き先の升**に止まらない（計画の時点で、行き先は分かっている）。
- v0.1 では、ついてきた仲間が木箱の行き先に立ち、「ぶつかって止まる」ことがある（見こみには出るが、理由が分かりにくい）。

### 1.7 【変更】宝箱と、受けなおし

- 地図の宝箱の銀貨・品は、その依頼の**初回の達成のときだけ**持ち帰る。受けなおした地図では、開けた宝箱は空（「もう持ち帰った」）。
- 同行が決まっている依頼（`fixed`）は、初回の達成のあとは自由に選べる（03 6.1）。

## 2. 働きかけ

### 2.1 【新規】あおぐ（ナギ）`waft`

**となりの軽い物・軽い敵・仲間を浮かせて、反対側へ D 升運ぶ。D＝2（大うちわで3）。**

| 項目 | 決まり |
| --- | --- |
| 相手 | 木箱・氷のかたまり・大きさ1の雪玉／重くない敵（目ざめているもの）／仲間（リコ・セナ・トビ）／風鳴り石 |
| 相手にできないもの | 大岩・石のブロック・大きさ2以上の雪玉・石柱・氷の柱・鉄の輪・宝箱・ひび岩／重い敵（凍っていれば 1.5）／水霊／ガルド／歩けないゲスト・救助される人／上に物や人がのっている物／眠っている敵 |
| 立つ所 | 相手のとなり。運ぶ向きの反対側。高さの差は1段まで（「押す」と同じ） |
| 下りる升の決め方 | d＝D から 1 へ順に調べ、次の二つを満たす最初の d。(a) 途中の升（1〜d−1）は、地面か物の上面が「相手のもとの高さ＋2」以下（谷・水・地図の外は越えられる）。(b) d 升先に下りられる（下の表） |
| 下りられる升 | **物**：谷・地図の外（失う）／水（沈む）／ふさぐ物がなく、高さが＋2以下の床（仲間がいる升は不可。敵がいる升は「当たる」）。**敵**：谷（倒れる）／水（沈む）／だれもいない立てる升で＋2以下。**仲間**：だれもいない立てる升で＋2以下（谷・水・外は不可） |
| どの d もだめ | 行動できない。理由を出す（「下りる先がない」「3段上で届かない」「重すぎる」） |

結果：

| 下りた先 | 物 | 敵 | 仲間 |
| --- | --- | --- | --- |
| 床 | 置かれる。重さの床なら作動。雪玉は同じ向きに転がりだす | もとの高さより2段以上低ければ落下の傷（2段1・3段3・4段以上一撃）。凍っていれば+1（落差がなくても1）。連携の記録（セナ） | 傷なし。その手番の移動・行動は残る |
| 氷の床 | 同じ向きに、止まるまですべる（既存のすべりと同じ処理） | 同じ | すべらない（仲間は踏んばる） |
| 水 | 沈んで飛び石（木箱）・氷の床（氷のかたまり・雪玉） | 沈む（倒れる） | ― |
| 谷・外 | 失う | 落ちる（倒れる） | ― |
| 敵のいる升 | 敵に傷3（理由は「上から落ちた物」。甲羅・毛皮にはすき）。敵が倒れたら物はその升に下りる。倒れなければ、木箱・氷のかたまりは砕ける | ― | ― |

- **飛ぶ敵**：2D 升まで、ぶつかるまで流される。壁・高い物に当たれば傷1で止まる。地図の外へ出れば「飛び去った」（倒した数に入る）。
- **風鳴り石**：となりからあおぐと鳴る（`on` を実行）。一度きり。
- あおぐこと自体の傷はない。行動のあと、ナギはその手番うごけない（既存の「動いて、一つ行動」と同じ）。
- 行動順：仲間を先にあおぎ、そのあとで、あおがれた仲間が動く・行動する、という順が使える。逆も使える。
- 表示：相手の半透明の姿を、弧の点線の先に。字幕に結果（「木箱が岩の上の重さの床にのる」「小鬼は谷へ落ちる」「氷のかたまりが大亀に当たる（ひっくり返る！）」）。向きは「押す」と同じ選び方。
- Undo：ほかの行動と同じ。

### 2.2 【新規】引く（リコ・引き鉤）`pull`

**一直線に並んだ軽い物・軽い敵を、自分のほうへ2升まで引く。レバーを引く。**

| 項目 | 決まり |
| --- | --- |
| 相手 | 木箱・氷のかたまり・雪玉（大きさは問わない）／重くない敵（目ざめているもの）／レバー |
| 相手にできないもの | 大岩・石のブロック・石柱・氷の柱／重い敵（凍っていれば 1.5）／水霊／仲間・救助される人／上に物や人がのっている物 |
| 立つ所 | 相手と同じ列か行（上下左右の一直線）。間の升が1〜3（＝距離2〜4）。レバーは距離1〜4 |
| 高さ | 相手が、リコより**2段上まで**（下はいくらでも） |
| 動き | 相手はリコのほうへ最大2升（リコのとなりで止まる）。1升ごとの処理は「押す」と同じ：段から落ちる／水に沈む／氷の上はすべる／雪玉は転がる／重さの床で止まる／相手より高い升・ふさぐ物・だれかにぶつかれば止まる |
| 傷 | 引くこと自体の傷はない（落下・ぶつかり・雪玉が通った敵への傷は、既存どおり） |
| 動けない | 最初の1升が動けないときは行動できない（「引っかかって動かない」） |
| すべる・転がる | リコのとなりまで来て止まる。リコは傷を受けない |
| レバー | `on` を実行。一度きり |

- 表示：リコから相手への縄の線、相手の行き先の半透明の姿、字幕。立つ升は自動で選ぶ（いちばん歩数の少ない、条件を満たす升）。一直線に並べる升が二つの向きにあるときは、相手の「引きたい側」にマウスを寄せて選ぶ（押すと同じ）。
- 使い分け：鉄の輪を指せば鉤縄（自分が行く）、木箱・敵・レバーを指せば引く。リコを選んでいる戦いの中で敵を指したときは、いままでどおり「射る」。**引くときは、札の上の「引く：入／切」**（セナの「氷をつくる」と同じ場所・同じ作り）。探索中の木箱・レバーは、切りかえなしで引く。

### 2.3 【既存＋新規】射る（リコ）

- 【既存】敵・的。距離5（長弓6）。傷2（長弓+1、風切りの弓+1）。2段以上高い所から+1。凍った敵に+1。
- 【新規】つららを射ると落ちる（3.2）。的と同じ扱い。
- 【変更】甲羅・毛皮への高所の矢（1.2）。

### 2.4 【新規】連ね押し（ガルド・熊の籠手）

- 押した相手の進む先の升に、**押せる物か、敵（強敵をのぞく）がもう一つ**あるとき、先にそちらを同じ向きに1升動かし、つづいて相手を動かす。
- 先のものが動けない（壁・高い升・三つめがある）なら、v0.1 と同じく全体がぶつかって止まる。連ねるのは二つまで。
- 先頭が大岩・雪玉なら転がり、凍った敵・氷のかたまりならすべる（一つずつの「押す」の処理を、先頭から順に行う）。
- 敵を押す傷は 1→2（先の敵にも）。
- 表示：二つの行き先を、半透明の姿で両方出す。

### 2.5 【新規】床を凍らせる（セナ・霜降りの杖）

- セナの切りかえを三つにする：**水・敵（既定）／氷のかたまり（氷晶の杖）／床（霜降りの杖）**。札の上のボタンで順に切りかえる。
- 床：指した升を中心に 3×3 のうち、**乾いた立てる升**（石・草・土・板・石畳・砂・暗い石・深い雪）を、氷の床にする。届く距離は「凍らせる」と同じ。
- 物・敵・仲間がのっていてもよい（のっている敵は凍らない）。依頼が終わるまで続く。
- 効果は【既存】の氷の床と同じ：その上へ押された・引かれた・下りてきた物と敵は、止まらずにすべる。歩くぶんには、ふつうの床（深い雪の上に作れば、歩数は1に戻る）。
- 変わらない升：水・速い水・谷・壁・橋・物の上面。
- 大猪の突進は、氷の床の上では段のふちで踏んばれない（4.6）。
- 表示：凍る升を水色で。字幕「床が凍る（この上で押した物は、止まらずにすべる）」。

### 2.6 【新規】置き発破（トビ）

- 戦いの中だけ。トビの切りかえ：**投げる（既定）／置く**。
- 置く：届く距離・自分のまわりに置けない決まりは、投げる発破と同じ。**その場では何も起きない。直後の敵の手番で、すべての敵が動き終えたあとに爆発する**（爆発の決まりは投げる発破と同じ。大玉も同じ。仲間は巻きこまない）。
- 置けるのは一度に一つ（置いてある間は、次を置けない。投げることはできる）。
- 敵は置き発破を知らない（思考に影響しない）。升に入れる。大猪の突進だけは、踏むとその場で爆発する（4.6）。
- 【必須】**予告に出す。**赤い線（敵の次の動き）と同じ写しの中で爆発まで進め、吹き飛ぶ先・倒れる敵を、手番を終える前に見せる。仲間を動かして敵の行き先が変われば、予告も変わる。
- 戦いが終わったとき残っていれば、消える。
- 実装の順は最後でよい（09）。間に合わない場合の代わり：「発破の届く距離+1」。**これは設計変更として、人に確認する。**

## 3. 地形と物

### 3.1 【新規】深い雪（地面の種類 `n`）

- **戦いの中で**、その升へ入る歩数が2（冒険者と、雪に慣れていない敵）。雪小鬼・雪狼・飛ぶ敵・護衛される人は1。探索中は影響なし。
- 雪玉が通ると、雪玉が大きくなる（雪は残る）。
- 発破の爆心と上下左右の雪は、吹き飛んで土になる。霜降りの杖で氷の床にできる。
- 表示：白い升。歩ける範囲の色は、歩数を反映する（届かない升は色が付かないだけ）。指すと「深い雪（戦いでは2歩ぶん）」。

### 3.2 【新規】つらら `icicle`

- 升の真上にぶら下がる（その升には、ふつうに立てる）。
- 落とす：リコの矢（的と同じ・一度きり）／発破の爆心か上下左右。
- 落ちると：その升に敵がいれば傷3（「上から落ちた物」。甲羅・毛皮にはすき）。敵がいない・倒れた → 升が水なら**氷の床（飛び石）**、床なら**氷のかたまり**が残る。敵が生き残ったら、砕けて何も残らない。
- 仲間・救助される人のいる升のつららは落とせない（「下に仲間がいる」）。眠っている敵の上にも落とせる（当たれば戦いが始まる）。
- 表示：指すと、落ちる升と結果（「落ちて、氷の飛び石になる」「骨の射手に当たる（傷3）」）。

### 3.3 【新規】雪玉 `snowball`

| 項目 | 決まり |
| --- | --- |
| 動かし方 | 押す・爆風・引く・あおぐ（大きさ1だけ）。動くと、**ぶつかるまで転がる**（大岩と同じ処理） |
| 大きさ | 1〜3（はじめは1）。**深い雪の升を二つ通るごとに+1**（最大3）。絵も大きくなる |
| 当たった敵 | 傷：大きさ1は2、2は3、3は4。倒れたら通りぬけて転がりつづける。1升以上転がっていること（1.3） |
| 止まったとき | 敵・壁・高い升にぶつかって止まる。大きさ1・2はそのまま残る（また動かせる）。**大きさ3は砕けて「雪の山」になる**（足場・1段。がれきと同じ） |
| 水・谷 | 水に落ちると氷の床（飛び石）。谷・地図の外は失う。段からは、何段でも落ちて転がりつづける |
| 立てるか | 立てない（ふさぐ物）。重くはない（引ける） |

- 表示：指すと、転がる道すじ・大きくなる所・当たる敵の数（「雪玉は坂を転がってふくらみ、4体をなぎ倒す」）。

### 3.4 【新規】レバー `lever`・風鳴り石 `chime`

- どちらも、ふさぐ物（立てない・押せない）。一度きりの装置で、`on` を実行する（`lower:`・`open:`・`rune:`・`flag:` は既存）。
- レバーはリコの「引く」、風鳴り石はナギの「あおぐ」。力がない編成で指すと、既存と同じく「○○がいれば、働きかけられる（いまの編成にはいない）」。

### 4.6 【新規】雪喰い大猪（強敵）

**通常の敵と違う所**：①凍った毛皮（矢・押し・爆心・霜をはじく。甲羅と同じ）。②**「ねらう」と「突進」を一手番ずつ交互に行う**。突進の列は、一手番前に見える。③何かにぶつかると目を回す（すき）。

#### 状態

- `aim`：なし／向き（上下左右のどれか）。
- すき・凍る・振りはらう は 1.1 と大亀と同じ。凍っている番は休み、ねらいは保つ。

#### 敵の手番の動き

**(A) ねらいがあるとき → 突進する。** いまの升から、ねらった向きへ1升ずつ進む。次の升を、上から順に判定する。

| 次の升にあるもの | 起きること | 突進は |
| --- | --- | --- |
| 冒険者・護衛される人 | その人に傷4。大猪は手前で止まる | 終わり |
| 置き発破 | その場で爆発。爆心の傷は毛皮を通る（3、大玉は4）。**すき** | 終わり |
| 氷の柱 | 柱が砕ける。大猪に傷3。**すき** | 終わり |
| 大岩・大きさ3の雪玉・石のブロック | 大猪に傷2。**すき**。雪玉は砕けて雪の山、大岩・ブロックは残る | 終わり |
| 木箱・氷のかたまり・大きさ1〜2の雪玉・雪の山 | 砕いて進む。大猪に傷1（毛皮を通る） | つづく |
| ほかの敵 | その敵に傷2。大猪は手前で止まる | 終わり |
| 壁・2段以上高い升・動かせない物（風の石・風鳴り石・像）・地図の外 | 手前で止まる（傷なし・すきなし） | 終わり |
| 谷・水 | 手前で踏んばる | 終わり |
| 2段以上低い升 | **いまいる升が氷の床なら、すべって落ちる**（落下：傷2・**すき**）。氷でなければ、手前で踏んばる | 終わり |
| それ以外（同じ高さ・1段上・1段下の立てる升） | 進む | つづく |

突進のあと、ねらいは消える。

**(B) ねらいがないとき → ねらう。**

1. 相手を決める：倒れていない冒険者のうち、**いまの体力がいちばん低い者**（同じなら近い者、それも同じなら出撃の順）。傷を受けた仲間ほど、ねらわれる。
2. 動く：移動2で行ける升のうち、**相手と同じ列か行に並ぶ升**で、いちばん歩数の少ない所へ。並べる升がなければ、相手にできるだけ近づく。
3. 牙ではらう：動いたあと、となりに冒険者がいれば、その一人に傷2（相手を優先）。
4. ねらいを定める：相手と一直線に並んでいれば、その向きを `aim` にする（**間に柱や物があっても、ねらう**）。並んでいなければ、ねらいはなし（次の手番も (B)）。

#### 予告（赤い線）

- ねらいがあるとき：突進の通り道を**赤い帯**で。止まる升、ぶつかる物（「氷の柱にぶつかる → 目を回す」）、当たる冒険者と傷。
- ねらいがないとき：動く先と牙の傷を、ふつうの赤い線で。さらに、**次に定めるねらいの列を、うすい帯**で出す（「次の手番、この列をねらう」）。冒険者を動かすと、相手・並ぶ升・列が変わるのが見える。

#### 攻略の考え方（プレイヤーが気づくこと）

| 気づき | どう分かるか |
| --- | --- |
| 突進は一直線で、止まれない | はじめの突進を、赤い帯で見る。会話で一度だけ（「あいつ、まっすぐしか走れない！」） |
| 列から出れば当たらない。間に物があればぶつかる | 帯の先に「氷の柱にぶつかる → 目を回す」と出る |
| ねらわれるのは体力の低い仲間 | うすい帯が、その仲間に合わせて動く。会話で一度だけ |
| 柱のかげに立つ／柱を背にして立ち、よける | うすい帯が柱を通るように立つと、次の手番の赤い帯が柱で止まる |
| 氷の上では、ふちで止まれない | くぼ地のふちの氷の升を、帯が通りぬけて「すべって落ちる」と出る |

- 一つの正解手順ではない：ぶつける物は、氷の柱4本・つらら3本・雪玉2つ・くぼ地のふち、と、編成ごとの手（大岩がわりの雪玉、床の氷、置き発破、氷のかたまり、木箱）がある（`missions/chapter2/m14`）。
- 【必須】**突進の列は、プレイヤーの手番の前に必ず見えていること。**見えない突進は作らない。

## 5. 目的と、同行の形

### 5.1 【新規】護衛 `escort`

- 救助（【既存】見つける → 縄を使わない道ができたら、自分で歩いて荷馬車へ）の、**戦いの中で歩く**版。
- 護衛される人（`escort: true`）：体力6・移動2。深い雪でも遅くならない。縄は渡れない。攻撃しない。あおげない・引けない。
- 探索中：既存の救助と同じ（道があれば、一気に歩いて荷馬車へ）。
- 戦いの中：見つかっている護衛される人は、**敵の手番のあと、荷馬車までのいちばん短い道を2升進む**（道がなければ動かない。敵のいる升には入らない）。目的の升に着くと「着いた」（以後ねらわれない）。
- 敵は、護衛される人も冒険者と同じようにねらう（点数は冒険者と同じ計算）。
- **失敗**：護衛される人が一人でも倒れたら、依頼は失敗（「この手番の始めから」「戦いの前から」でやり直せる）。
- **達成**：全員が着いたら達成。**戦いの途中でも達成になり、そのまま「ギルドへ帰る」を選べる**（残った敵は追ってこない）。
- 戦いの敵を全滅させた場合は、探索に戻る。道があれば、護衛される人は既存の救助と同じく一気に歩いて着く。
- 【必須】予告：護衛される人の次の2升を、**白い点線**で出す（赤い線と同時に見える）。道が変われば（近道を作る・ふさぐ）点線も変わる。

### 5.2 【新規】同行のゲスト

- 地図に `guest: 'nagi'` があれば、選んだ二人に加えて、その仲間が最初から4人目として出る（ふつうに歩ける。札は4枚）。
- その依頼の受けなおしでも同じ。「だれと行く？」では、ゲストは選ぶ側に出ない。
- v0.1 のトビ（見つけると加わる・歩けない）は、そのまま残す。

### 5.3 【既存】目的の種類

退治 `kill`／回収 `item`／救助 `rescue`／装置 `runes`／防衛 `defend`／強敵 `boss`。第二章でも使う。
