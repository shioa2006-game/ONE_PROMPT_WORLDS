## 2. 体験設計

| 問い | 答え |
| --- | --- |
| 何を楽しむか | **手応え。** 下見をして帰り道をつくり、いつ道をひらくかを決め、歩くけが人を雪狼から守りぬく |
| 期待する発見 | ①けが人は3段の崖を下りられない（2段まで）。**崖の途中に一段あれば下りられる**：木箱・氷の段・がれき。②つくった近道は、段をのぼる雪狼にも近道になる。**早くひらきすぎると、狼が先に来る**。③けが人の次の歩み（白い点線）と、狼の次の動き（赤い線）を見くらべて、間に立つ |
| 立てる作戦 | 「上の近道だけ先にひらき、下の近道は、けが人が着く手番にひらく」「狼は西の坂を回ってくる。中の段の道に大岩を転がす」「下の近道の木箱の上に立って、ふさぐ」 |
| 成功の体験 | 白い点線が、つくった段を通って荷馬車まで一気につながる。狼の列を大岩がなぎ倒す。二人が荷馬車に着く |
| 前の依頼との違い | はじめて「守る相手が歩く」。負けの条件が、けが人が倒れること。探索の時間（下見）が、そのまま作戦の時間になる |
| 成長・編成 | 近道のつくり方が四人それぞれ（木箱・氷の段・がれき）。引き鉤は、道をひらく手でも、**道をはずす手**でもある。置き発破・連ね押し・床の氷（持っていれば）が、追ってくる狼に効く |

## 3. 達成・失敗

| 項目 | 内容 |
| --- | --- |
| 主目的 | ロウとキヌの二人を、荷馬車のまわりの升まで送りとどける |
| 寄り道 | 上の段の西の端の宝箱（銀貨80） |

| 達成 | 二人とも着く。**戦いの途中でも達成になり、そのまま帰れる**（残った敵は追ってこない） |
| 別の達成のしかた | 組2の敵を全滅させると戦いが終わり、探索に戻る。道があれば、二人は一気に歩いて着く（既存の救助と同じ） |

## 6. 攻略の例

### 下見（探索）

1. 出発 → 下の段を西へ → 西の坂 → 中の段（雪狼2と戦い）→ 西の坂 → 上の段 → 東の岩かげへ【冒険者が岩かげ (11,1) まで歩けることを設計確認ずみ】。
2. 途中で、近道の材料（木箱・滝・ひび岩）、大岩、雪玉を見る。**このとき作っておいてもよいし、作らずに残してもよい**。

### 作戦の例（ガルド＋セナ）

| 時 | 動き | ねらい |
| --- | --- | --- |
| 下見 | セナが上の滝 fA だけ凍らせる（A をひらく）。B は閉じたまま。ガルドは木箱 cB を1回だけ押して (11,8) へ（あと1回で (11,7)） | 狼に B を使わせない。B は一手でひらけるようにしておく |
| 見つける | 岩かげのとなりへ。ロウ「…遅いぞ、ガルド」。組2が目ざめる | ― |
| 第1〜2手番 | 二人は A の氷の段を下りて中の段へ。冒険者も一緒に下りる（飛びおり2段ではなく、氷の段を歩く）。狼は B が閉じているので、西の坂へ回る | 白い点線は、B の手前 (11,6) で止まる見こみ |
| 第3手番 | ガルドは大岩の後ろ (14,4) へ。狼が中の段の道（y=4）を東へ走ってくるのを待つ | 赤い線が y=4 に並ぶ |
| 第4手番 | **大岩を西へ**。道の上の狼をなぎ倒す。セナは下の滝 fB を凍らせる（B をひらく）。または、ガルドが下りて木箱 cB を押す | 二人が下の段へ下りはじめる |
| 第5〜7手番 | 下の段。氷の岩人形が荷馬車の近くへ来ている。南のふち（y=11）へ寄ってきたら、ガルドが南へ押し落とす（谷）。残りの狼は、リコの矢とセナの足止めで | 二人が荷馬車へ |

### ほかの編成の要点

| 編成 | 近道 | 狼 | 氷の岩人形 |
| --- | --- | --- | --- |
| トビ入り | ひび岩を、けが人が着く手番に発破（**がれきは一手で道になる**）。早く砕かない | 中の段の道で、大岩を発破で転がす（離れた所から）。置き発破があれば、近道の段の上に置く | 南のふちで、北から発破 → 谷へ |
| ナギ入り | 木箱を一あおぎで段に（(11,6)・(11,10) から）【設計確認ずみ】。けが人が通ったあと、狼が段の上に来たら、あおいで落とす | 段の上・崖のふちの狼を、あおいで下の段へ（3段落ちで一撃） | 動かせない。木箱を上から当てる（中の段のふちから、下の岩人形へ）。リコの矢 |
| リコの引き鉤（どの編成でも） | 上の段 (11,2) から cA を引く → (11,3)。中の段 (11,6) から cB を引く → (11,7)【どちらも設計確認ずみ】。**けが人が下りたあと、下の段から cB を南へ引いて、段をはずす**（狼が追えなくなる） | ふちの狼を、下から引いて落とす | ― |

- どの編成でも、リコの引き鉤だけで A・B の両方をひらける（だれを連れても詰まない）。
- 近道を一つも作らなくても、組2を全滅させれば、二人は西の坂を回って自分で帰る（長いが、行き詰まらない）。

## 7. 編成による違い

| 編成 | 近道 | 追ってくる狼への手 | 苦手 |
| --- | --- | --- | --- |
| ガルド＋セナ | 氷の段（一手ずつ）・木箱（二手ずつ） | 大岩・凍らせて止める・段の上をふさぐ | 岩人形は、ふちへ寄せるまで手がない |
| ガルド＋トビ | がれき・木箱 | 大岩を二人で・発破で崖の下へ | 止める手がない。けが人の前に立つ |
| ガルド＋ナギ | 木箱（一手ずつ） | 大岩・あおいで落とす | 受けはガルドだけ |
| セナ＋トビ | 氷の段・がれき（どちらも一手） | 凍らせて発破・置き発破 | 受けが薄い。けが人より自分たちが危ない |
| セナ＋ナギ | 氷の段・木箱 | 凍らせて、あおいで落とす（砕けやすい） | 岩人形。大岩を動かせない（雪玉はナギが放てる） |
| トビ＋ナギ | がれき・木箱 | 発破・あおいで落とす | 受けが薄い |

- 難しさは同じではない。受けの薄い組は、近道を遅くひらいて狼を遠回りさせる作戦が向く。受けの固い組は、早くひらいて短く済ませられる。
- 重要な目的（二人を帰す）は、どの編成でも果たせる：リコの引き鉤で近道、または全滅させて自力で帰す。
