## 2. 体験設計

| 問い | 答え |
| --- | --- |
| 何を楽しむか | 編成で道すじが変わる。**凍らない重い敵**を、広間の氷の床と谷でどう落とすか |
| 期待する発見 | ①六つの装置のうち、リコが二つ（的・レバー）、仲間が一つずつ。**連れてきた二人の装置を両方動かして、ちょうど四つ**。②氷の岩人形は凍らない。でも**広間のまんなかは氷の床で、その先は谷**。一押し・爆風で、谷まで止まらない。③動かす手がない二人でも、木箱や氷のかたまりを「上から当てる」手がある |
| 立てる作戦 | 「岩人形を氷の床の上へさそって、東へ飛ばす」「谷のふちまで寄ってきた所を押し落とす」「氷のかたまりを作って、あおいでぶつける」 |
| 成功の体験 | 重い岩人形が、氷の上をすうっと滑って谷へ消える。四つめの灯で門がひらく。石板の二枚目 |
| 前の依頼との違い | m4 は「三つでよい」ので、片方の仲間の装置だけでも足りた。ここは**二人とも出番がある**。いつもの「凍らせて押す」が効かない |
| 成長・編成 | 鋼の籠手（氷の上の岩人形を、どこからでも押せる）・氷晶の杖（氷の砲弾）・大玉（2升＝氷の床に届きやすい）・長弓が、それぞれ効く。帰るとトビの置き発破が店に並ぶ |

## 9. 物語・台詞

**依頼板**

- 文：「セナへ、そして風見鶏ギルドのみなさんへ。風見の石板には対になる一枚があり、北の峠の風穴の奥、氷室に納められていると古い記録にあります。門は六つの灯でひらくとのこと。どうか確かめてきてください。――学院　ユズリハ」
- 目的：六つの装置のうち四つを動かし、奥の石板を手に入れる
- 見どころ：的・レバー・霜の水晶・封印石・風鳴り石・重さの床／氷の岩人形（凍らない）／氷の床と谷

**ヒント（探索中）**：その編成で動かせる装置のうち、まだの物を一つずつ（m4 と同じ作り）。風鳴り石は「木箱を、壇のすぐ下へ」→「壇にのぼって、石のとなりから」。四つそろったら「門がひらいた。奥の石板を」。

**戦いのヒント**：ガルド「氷の人形が谷のとなりへ来たら、わしが押し落とす。おとりは任せろ」／トビ「氷の床の上の敵は、西で発破すれば東の谷まですべるっす」／セナ「氷のかたまりを作ります。ナギさん、あれを当ててください」／ナギ「木箱も、つららも、上から当てたら効くで」／リコ「つららの下へさそえば、ぼくが落とすよ」

**帰還の場面**

- セナ「石板は二枚になりました。読めない所は、まだ半分あります」／ドーラ「風を持ち去る者、ね。…ロウたちは、それを追っていたのかもしれないよ」／ミモザ（三つのうち二つめなら）「岩場のほうで、狼の遠ぼえと、人の笛の音がしたって知らせが来てるの」

**成功の演出で感じさせたいこと**：重い物が、氷の上では軽々と滑っていく意外さ（すべる長い音 → 一拍おいて谷底の音）。灯は一つずつ色が違い、だれの手でともしたかが門に残る（リコ＝緑、セナ＝水色、…）。
