## 2. 体験設計

| 問い | 答え |
| --- | --- |
| 何を楽しむか | 探索とパズルが中心。**氷の上へ押した物は、すべって、水に沈み、飛び石になる**。これを使って、湖に道をつくる |
| 期待する発見 | ①岸から木箱を押すと、氷の升をすべって、その先の水で沈む（ねらった升に飛び石ができる）。②飛び石の上まで来た木箱は、そこで止まる。もう一押しで、次の氷をすべって次の水へ。③土手の雪玉は、氷の列を転がって、いちばん奥の水に沈む |
| 立てる作戦 | 「木箱は四つ、雪玉は二つ。すき間は五つ。どれをどこに使うか」。セナがいれば「どこを凍らせると、いちばん少ない手で済むか」 |
| 成功の体験 | 木箱が氷の上をすうっとすべって、ちょうどのすき間にはまる。漁師が、自分の足で氷を渡って帰ってくる |
| 前の依頼との違い | 戦いより、物の数と道すじを考える時間が長い。**新しい決まりは雪玉だけ**で、あとは第一章からある決まり（氷ですべる・沈んで飛び石）の組み合わせ |
| 成長・編成 | 道のつくり方が、四人でまったく違う（6章）。帰ると、セナの霜降りの杖が店に並ぶ |

## 5. ルール

| 決まり | 区分 | ここでの働き |
| --- | --- | --- |
| 氷の上へ押された物は、止まらずにすべる | 既存 | 岸 → 氷 → 水、と進んで沈む |
| 水に沈んだ物は飛び石（木箱）・氷の床（氷のかたまり・雪玉） | 既存／新規（雪玉） | すき間が埋まる |
| 飛び石（沈んだ木箱）は氷ではない | 既存 | すべってきた木箱は、飛び石の上で止まる。もう一押しで先へ |
| 雪玉 | 新規（05 3.3） | 土手から西へ転がすと、氷を転がって最初の水で沈む。ここでは雪を通らないので大きさは1のまま |
| 水霊 | 既存・初登場 | 水の升だけを動く。距離3から射る（傷2）。押せない・引けない・あおげない。水ごと凍らせると倒れる。矢・爆心は効く。転がる雪玉・大岩が通れば傷を受ける |
| 粘体 | 既存・初登場 | 凍らせると氷のかたまりになる（倒したことになる） |
| 行き場のない敵は2手番で逃げる | 既存 | 岸から離れると、水霊はあきらめて去る（倒した数には入らない） |

### セナ（凍らせる）

- ①②③④⑤ を、それぞれ岸・氷の上から凍らせる（3×3 なので、①と③は一度ずつ、②は氷 (3,7)〜(3,9) あたりから）。五つのすき間を5回以内で。
- 水霊は、いる升ごと凍らせると倒れる（印②が取りやすい）。粘体は凍らせて氷のかたまりに。

### トビ（発破）

- 木箱の南の升で発破 → 木箱が北へ1升。2回で、氷をすべって沈む（①で確認）。
- 土手の雪玉は、(14,6)・(14,4) の発破で（④で確認）。(14,6) へは岸の東の端 (14,10) から届く。(14,4) へは土手の上 (14,8) から。
- 水霊は、爆心で傷2（大玉3）。

### ナギ（あおぐ）

| # | 手 | 結果 |
| --- | --- | --- |
| 1 | c1 を (3,12) から北へあおぐ | 2升先は氷 (3,9)。下りてすべり、(3,8) に沈む＝①（一手） |
| 2 | c2 を西へ → (3,11)。北へ | 氷 (3,9) に下りてすべり、飛び石 (3,8) の上で止まる |
| 3 | 氷 (3,9) から、もう一度北へ | 2升先は水 (3,6)。そのまま沈む＝② |
| 4 | 雪玉を (14,6) から西へ | 氷 (11,6) に下りて転がり、(10,6) に沈む＝④ |

- 大うちわ（距離3）があると、岸から3升先の水へ直接置ける所が増える。

### リコ（引く）

- 引くのは「手前へ」なので、すき間の向こう側に立てないと使えない。ここでは、置きまちがえた木箱を引きもどす・並べなおす手として働く。

## 7. 編成による違い

| 編成 | 道づくり | 水霊 | 苦手 |
| --- | --- | --- | --- |
| セナ入り（3通り） | 凍らせるだけ。物は余る | 升ごと凍らせる | ―（楽。印②③をねらう回に） |
| ガルド＋トビ | 木箱はどちらでも。雪玉はトビが遠くから | リコの矢・爆心 | 水霊を止められない。受けはガルド |
| ガルド＋ナギ | ナギが一手で沈め、ガルドが飛び石の上の木箱を押す | リコの矢だけ（体力3に矢2＝2発。長弓で1発） | 水霊に時間がかかる → **岸から離れてやりすごす**手もある |
| トビ＋ナギ | ナギが置き、トビが遠くの雪玉を | リコの矢・爆心 | 受けが薄い |

- どの編成でも、五つのすき間を埋める手がある（セナ：凍らせる。ガルド・トビ・ナギ：木箱と雪玉）。
- 物をむだに沈めても、予備の木箱が一つある。それでも足りなければ、戻す（Z）。**戦いの中で沈めた物は手番をこえて戻せない**ので、戦いの最中に木箱へ発破を投げると損をする、と見こみで分かる（「木箱が沈む。ここは道にならない」）。
