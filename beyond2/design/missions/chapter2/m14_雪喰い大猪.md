## 2. 体験設計

| 問い | 答え |
| --- | --- |
| 何を楽しむか | **突進の列を読み、ぶつける物を用意して、目を回させる。**その一手番に、みんなで攻める |
| 期待する発見 | ①大猪は「ねらう」と「突進」を交互に行う。**突進の列は、一手番前に赤い帯で見える**。②列から出れば当たらない。**列の上に氷の柱があれば、ぶつかって目を回す**。③ねらわれるのは、体力のいちばん低い仲間。**その仲間の立つ場所で、列を決められる**。④氷の上では、ふちで止まれない |
| 立てる作戦 | 「柱を背にして立ち、突進の手番によける」「柱のかげに立つ」「北の壁へ走らせて、頭上のつららを落とす」「くぼ地の手前の氷の升を通らせる」 |
| 成功の体験 | 赤い帯が、自分の仕かけた柱で止まっている。そのとおりに大猪が突っこんで、柱が砕け、目を回す |
| 大亀との違い | 大亀は、ほとんど動かない相手を**こちらが運ぶ**戦い。大猪は、勝手に走る相手の**行き先を仕かける**戦い。読むのは「止まる升」から「走る列」へ |
| 成長・編成 | 置き発破（列に置く）・霜降りの杖（ふちの手前を凍らせる）・熊の籠手（取りまきをまとめて）・大うちわ・風切りの弓が、それぞれ別の手になる。なくても勝てる |

## 6. 攻略の例

### はじめの二手番（どの編成でも同じことが起きる）

- 大猪 (7,3) は、リコ (7,13) と同じ列にいる。第1手番の敵の動きで、体力のいちばん低い仲間をねらう（うすい帯）。
- 列 x=7 を南へ走ると、風の石 (7,7) の手前 (7,6) で止まる。**最初の突進は、何もしなくても石で止まる**（列 x=7 に立ったままなら）。ここで「まっすぐしか走れない・かたい物で止まる」を見せる。
- 会話で一度だけ：リコ「あいつ、まっすぐしか走れない！ 赤い帯の外へ出れば、当たらないよ」／（柱で止まる帯が出たとき）「氷の柱にぶつかるって出てる…！」

### 型1：柱を背にして立ち、よける（だれでも）

1. ねらわれる仲間（体力のいちばん低い者）を、「大猪・仲間・柱」が一直線に並ぶ升に立たせる。たとえば大猪が列 y=11 の西 (2,11) あたりにいるなら、仲間は (4,11)、柱は (5,11)。
2. 敵の手番：大猪がその向きにねらいを定める（赤い帯が、仲間を通って柱で止まる）。
3. 自分の手番：仲間が列から出る。帯の先が「氷の柱にぶつかる → 目を回す」に変わる。
4. 敵の手番：突進 → 柱が砕ける（傷3）・すき。
5. 自分の手番：三人で攻める（すきの間は+1）。

### 型2：柱のかげに立つ（だれでも）

- 「大猪・柱・仲間」の順に並ぶ。大猪は柱ごしにねらう。**よけなくても、柱にぶつかる**。ただし、大猪はねらう前に2升うごくので、並びがずれることがある（うすい帯で確かめる）。

### 型3：北の壁へ走らせて、つらら（リコ）

1. 大猪より北の、列 x=4・7・10 の上にねらわれる仲間を立たせる（たとえば (4,2)）。大猪が南から北へねらう。
2. 仲間がよける → 大猪は北の壁ぎわ (4,1) まで走って止まる（何も起きない）。
3. **真上のつららを、リコが射る** → 傷2・すき。残りの二人が攻める。

### 型4：くぼ地の手前の氷（だれでも。セナは場所を増やせる）

1. ねらわれる仲間が、くぼ地の中の列 y=6 か y=8 に立つ（たとえば (12,6)。坂 (12,10) から下りる）。大猪が西から東へねらう。
2. 仲間がよける（くぼ地の中で列を変える）。
3. 突進 → (10,6) の氷の升で踏んばれず、くぼ地へ落ちる（傷2・すき）。
4. くぼ地のふち（高さ3）から、2段下の大猪を攻める。すきの間は、高所の矢もふつうに入る（+1）。
- セナの霜降りの杖があれば、(10,5)・(10,7)・(10,9) も凍らせて、**どの列でも落ちる**ようにできる。

### 型5：雪玉（ガルド・トビ・ナギ・リコ）

- 大猪が列 y=5 か y=9 にいるとき、西の棚の雪玉を東へ。雪の上を転がって大きくなり、当たって傷2・すき（大きさ3なら砕けて雪の山が残る）。
- ガルドは棚へ上がって押す（坂 (1,11) から。出発の升から8歩前後）。トビは棚の下から、雪玉の西の升へ発破。ナギは棚の上から、あおぐ。リコは列の東側に立って引く。

### 編成ごとの決め手

| 同行 | 持ち味 |
| --- | --- |
| ガルド | 体力が高く、ねらわれにくい（ねらわれるのは体力の低い仲間）。**取りまきと大猪の間に立つ役**。雪玉。すきの間に、ふちの大猪をくぼ地へ押し落とす。熊の籠手なら、狼を二体まとめて |
| セナ | 凍らせると、大猪は一手番休む（次は凍らない）。**突進の番を一つ遅らせて、仕かけを間に合わせる**。霜降りの杖で、ふちの氷を増やす。氷晶の杖の氷のかたまりは、列に置いても砕かれるだけ（大猪に傷1）だが、ナギがあおげば上から当たる（すき） |
| トビ | 置き発破を、赤い帯の上に置く（踏むと傷3〜4・すき）。**柱がなくても、どの列でも目を回させられる**。発破で雪玉・つらら（爆心か上下左右）を落とす。すきの間は爆心の傷も入る |
| ナギ | **風鳴り石を三つ鳴らす**（毛皮がはがれる）。木箱・氷のかたまりを上から当てる（すき）。ねらわれた仲間を、列の外へあおいで逃がす。取りまきの狼・小鬼を、くぼ地へ落とす |

- ひとこと：ガルド「まっすぐ来るなら、読める。わしが前に立つ。おまえたちは、ぶつける物を用意しろ」／セナ「凍らせれば、突進を一手番おくらせられます。ふちの手前を凍らせれば、止まれずに落ちるはずです」／トビ「来る列に、置いとくっす。踏んだらドカン、っす」／ナギ「祠の風鳴り石、三つとも鳴らしたる。風が戻れば、あいつの霜もはがれるはずや」
