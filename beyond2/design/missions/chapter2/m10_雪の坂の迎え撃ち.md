## 2. 体験設計

| 問い | 答え |
| --- | --- |
| 何を楽しむか | **爽快感。** 坂の上から雪玉と大岩を転がして、大群をまとめてなぎ倒す。育てた力で数を圧倒する |
| 期待する発見 | ①雪玉は、雪の上を転がるほど大きくなる。**小さいうちに当てると止まる。遠くまで引きつけず、坂の中ほどから下にいるうちに放つ**。②敵は、ねらった仲間に近い谷すじへ集まる。**立つ場所で、並ぶ列を決められる**。③転がしたあとの谷すじは、敵の通り道のまま。使う順に意味がある |
| 立てる作戦 | 「まんなかに立って中央の三本へ集め、三体並んだら雪玉」「狼の波は大岩で（どこで当てても倒せる）」「氷の岩人形には、大きく育った雪玉を」 |
| 成功の体験 | 見こみに「雪玉は坂を転がってふくらみ、4体をなぎ倒す」。そのとおりに、白い玉が大きくなりながら列を消していく |
| 前の依頼との違い | 敵が多い（16体）。仕掛けが五つあり、使うと手番が半分になる。第一章 m5（改良）の「並んだ所へ転がす」を、数と育つ雪玉で大きくしたもの |
| 成長・編成 | 長弓・大玉・鋼の籠手がそのまま効く。転がす手は四人それぞれ。帰るとガルドの熊の籠手が店に並ぶ |

## 5. ルール

| 決まり | 区分 | ここでの働き |
| --- | --- | --- |
| 雪玉は、深い雪を二つ通るごとに大きくなる（1→2→3）。傷は 2・3・4 | 新規（05 3.3） | y=4 は石なので育たない。**y=5・6 を通って大きさ2、y=7・8 を通って大きさ3**。y=5〜6 の敵には傷2（倒れず、雪玉は止まる）。y=7 から下の敵には傷3以上（雪小鬼・雪狼・射手は倒れ、通りぬける） |
| 大岩の傷は3（どこで当てても） | 既存 | 雪小鬼・雪狼・射手は一撃。氷の岩人形（体力8）には止められる |
| 1升以上転がってから当たる | 変更（05 1.3） | y=4 に上がってきた敵（転がす物のとなり）には効かない。**上がりきる前に放つ** |
| 深い雪 | 新規（05 3.1） | 冒険者は坂へ下りると足が重い（関所の段は石なので、上にいるかぎり遅くならない）。雪小鬼・雪狼は遅くならない |
| 雪狼・氷の岩人形 | 新規（05 4.3・4.4） | 狼は移動5で、波が出た次の手番には谷すじにいる。岩人形は移動2で、坂をのぼるのに6手番かかる |
| 敵の思考 | 既存 | 届く相手へ。届かなければ、いちばん近い「冒険者のとなりの升」へ向かう → **冒険者に近い谷すじへ集まる** |

## 6. 攻略の例

### ガルド＋セナ

| 手番 | 動き |
| --- | --- |
| 1 | 三人とも関所の段で待つ。リコは (7,2) のまま（中央の雪玉の真後ろ）。ガルドは (5,2) へ。射手はいないので、届く小鬼を射る |
| 2 | 赤い線で、列 x=7・x=5 に並ぶのを見る。セナは、谷すじの出口へ上がってきそうな先頭を凍らせて、後ろを詰まらせる |
| 3 | **ガルドが (7,2) へ戻るか、または (5,2) から大岩 bdL を南へ**（x=5 の2体）。中央は次の手番に3体そろう。どちらを先に放つかは見こみの数で決める |
| 4〜5 | 第二波の狼は速い。y=4 に上がりきる前に、残りを放つ。上がってきた狼は、関所の段のふちから谷すじへ押し落とす（1段なので傷は押しの1だけ。凍らせて押すと、谷すじをすべり下りる） |
| 6〜 | 最後の波：氷の岩人形は、大きく育つ列（y=9 より下で当たる）に来たところへ雪玉。残りは矢と押しで |

ガルドは五つとも転がせる（立つ升はどれも関所の段の上）。

### トビ入り

- 転がす物の北の升（(2,2)・(5,2)・(7,2)・(9,2)・(12,2)）で発破。**その場から動かずに、離れた列を放てる**【(12,2) の発破で右の雪玉が転がることを設計確認ずみ】。
- 谷すじの出口（y=4）に上がってきた敵のとなりで発破 → 谷すじへ落として列に戻す。

### ナギ入り

- 雪玉（大きさ1）を北からあおぐ → 2升先 (x,5) に下りて、そのまま転がる（大うちわなら (x,6) から）。大岩はあおげない。
- 木箱 c1 (4,2)・c2 (10,2) を、谷すじの出口の敵の上へあおぐ（傷3）。
- 上がってきた狼を、関所の段のふちから坂へあおぐ。

### リコ（引く）

- 坂へ下りて谷すじの下（たとえば (7,8)）に立ち、雪玉を引く → 手もとまで転がってくる（間の敵をなぎ倒す。リコのとなりで止まる）。危ないが、**転がす仲間がいなくても、リコだけで雪玉を放てる**。

### セナ（霜降りの杖を持っていれば・受けなおし向け）

- 谷すじ（y=5〜7）を凍らせておくと、関所の段から押し落とした敵が、横の道まですべり落ちる。

## 7. 編成による違い

| 編成 | 転がす手 | 上がってきた敵への手 | 苦手 |
| --- | --- | --- | --- |
| ガルド＋セナ | ガルドが五つ（歩いて回る） | 凍らせて押す | ガルドが列から列へ歩く時間 |
| ガルド＋トビ | 二人で。同じ手番に二本放てる | 押す・発破 | 止める手がない |
| ガルド＋ナギ | ガルド五つ、ナギは雪玉三つ | 押す・あおぐ | ― |
| セナ＋トビ | トビが遠くから五つ | 凍らせる・発破 | 受けが薄い（上がられる前に放つ） |
| セナ＋ナギ | ナギが雪玉三つ（大岩は動かせない。リコの「引く」でも大岩は不可） | 凍らせる・あおぐ | **大岩二つが使えない**。そのぶん、氷のかたまり・木箱をあおいで当てる |
| トビ＋ナギ | 二人で。雪玉はどちらでも | 発破・あおぐ | 受けが薄い |

- どの編成にも、雪玉三つを放つ手がある（ガルド・トビ・ナギのだれか、またはリコの「引く」）。
- 仕掛けを一つも使わなくても、関所の段の上で受けて勝てる（石の上は足が重くならず、敵は幅1の出口から一体ずつ上がってくる）。ただし長くなる。
