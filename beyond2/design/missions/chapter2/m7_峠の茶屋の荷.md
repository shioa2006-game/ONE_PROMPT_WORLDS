## 2. 体験設計

| 問い | 答え |
| --- | --- |
| 何を楽しむか | 雪と氷の新しい土地で、**リコの矢と新しい道具が、地形を動かす** |
| 期待する発見 | ①つららは射ると落ちる。水の上なら飛び石、床なら足場、敵の上なら武器。②雪の中は足が重い。土の見える道を歩けば、いつもどおり。③引き鉤は、谷の向こうのレバーも、柱の上の木箱も、手もとへ |
| 立てる作戦 | 「射手の頭上のつららを落とす」「橋の上で迎えうつ」 |
| 成功の体験 | つららが落ちて、渡れなかった小川に氷の飛び石ができる。引き鉤でレバーを引くと、はね橋が下りる |
| 前の依頼との違い | 第一章では「リコの手で道がひらく」のは鉄の輪と的だけだった。ここでは**本線がリコの手だけで通る**。仲間の力は、別の道（凍らせる・木箱・ひび岩）になる |
| 成長・編成 | 引き鉤を地図の中で手に入れ、その場で二度使う。長弓があれば、眠っている射手に気づかれずにつららを落とせる |
