## 2. 体験設計

| 問い | 答え |
| --- | --- |
| 何を楽しむか | 渡り口は二つ。**どちらで止め、どこでまとめて倒すか**を決めて、そのとおりになる |
| 期待する発見 | ①赤い線を見ると、盗っ人が橋の上に一列に並ぶ。**並んでから大岩を転がすと、まとめてなぎ倒せる**。②右の大岩は、飛び石の上で止まって**栓**になる |
| 立てる作戦 | 「右を栓でふさいで、全部を橋へ集め、橋でまとめて転がす」／「橋はガルドがふさぎ、右はリコが丘から射る」など |
| 成功の体験 | 大岩が橋をぬけて、3体をなぎ倒す。飛び石の向こうで盗っ人の赤い線が、橋のほうへ曲がる |
| 前の依頼との違い | はじめて、こちらが守る側。はじめて、仕掛け（大岩）が主役 |
| 成長・編成 | 大岩は、ガルド（押す）でもトビ（発破）でも動く。セナは凍らせて列を作る（橋の上で止めれば、後ろが並ぶ） |

## 3. 達成・失敗（変更なし）

- 三つの波（はじめ4・第3手番4・第5手番5）をしのぎ、米俵がひと俵でも残れば達成。全部盗まれるか、全員倒れると失敗。
- 入るとすぐ戦い。負けたら「この手番の始めから」「戦いの前から」。

## 5. ルール

| 決まり | 区分 |
| --- | --- |
| 大岩は押す・発破で、ぶつかるまで転がる。当たった敵に傷3、倒れたら通りぬける | 既存 |
| **1升以上転がってから当たったときだけ傷**（05 1.3） | 変更（共通） |
| 飛び石の上で止まった大岩は、その升をふさぐ（立てない） | 既存 |
| 盗っ人は、行き場がなくても4手番は逃げない（05 1.4） | 変更（共通） |

- 橋の大岩を北へ：(4,7)→橋(4,6)(4,5)→(4,4)→(4,3) で止まる（(4,2) は高さ4）。通り道の敵すべてに傷3。
- 北の岸で止まった大岩は、(4,2) の側から南へ転がし返せる（トビの (4,2) の発破／橋を渡ったガルド）。南へ転がると、村を通って地図の外へ出る（そこで失う）。**二度使える**。
- 右の大岩を北へ：(11,7)→飛び石(11,6)→(11,5) で止まる（(11,4) は高さ3で上がれない）。

## 6. 攻略の例

### ガルド＋セナ（初期の二人）

1. 第1手番：ガルドは (4,9) へ。リコは橋の出口が見える (6,8) あたり、セナは (5,9)。
2. 盗っ人は移動4。左の二体は第2手番の終わりごろ橋へ入る。赤い線が橋の列（x=4 の y=4〜7）に重なるのを待つ。先頭を橋の出口でセナが凍らせると、後ろが橋の上に詰まる。
3. 並んだ手番に、ガルドが大岩を北へ。列の全員に傷3（盗っ人は体力3で一撃）。
4. 右から来る二体は、リコの矢と、ガルドが戻るまでの時間かせぎ（セナが飛び石の上で凍らせる）。または、はじめにガルドが (11,9) へ回って右を栓でふさぎ（2手番）、そのあと橋へ戻る。
5. 第二波・第三波は、北の岸の大岩を使えない（ガルドは橋の南）。橋の上で凍らせて押す・川へ落とす、の v0.1 の手で。

### ガルド＋トビ／セナ＋トビ

- トビは (4,9)・(11,9) の発破で、離れた所から同じことができる。
- 北の岸で止まった大岩を、(4,2) の発破で南へ転がし返す（橋の上の第二波をもう一度なぎ倒す）。ただし (4,2) に届くのは、南側では橋の上 (4,5)・(4,6) だけで、そこは大岩の通り道（仲間の手前で大岩は止まる）。**二度目を使うには、北の岸へ渡って、列の外（たとえば (2,4)）から投げる**必要がある。敵の側へ出るかどうかが判断になる。
- 橋の上の発破でまとめて川へ（v0.1 の手）も、そのまま使える。

### リコ

- 第1〜2手番で右の丘へ（開始から (12,10) まで8歩）。丘（高さ5）から飛び石（高さ2）・北の岸（高さ3）の敵へ、高所の矢。右を一人で受け持てる。

## 7. 編成による違い

| 編成 | 大岩 | 橋 | 右の渡り口 | 苦手 |
| --- | --- | --- | --- | --- |
| ガルド＋セナ | ガルドが押す（一度ずつ） | 凍らせて列を作る → 大岩／立ってふさぐ | 栓、または凍らせて止める | 大岩の二度目が使えない |
| ガルド＋トビ | どちらも。二度目も | まとめて川へ／大岩 | 栓／発破 | 止める手がない（凍らせられない） |
| セナ＋トビ | トビが発破で | 凍らせて列 → 大岩／まとめて川へ | 栓／凍らせる | 受けが薄い |

どの編成でも、大岩を一度も使わずに達成できる（v0.1 と同じ手）。使うと、第一波がほぼ一手番で片づく。
