## 2. 体験設計

| 問い | 答え |
| --- | --- |
| 何を楽しむか | 硬くて攻めが通らない相手を、**舞台の仕掛けでひっくり返し、その一手番にみんなで攻める** |
| 期待する発見 | ①大亀は、ねらった仲間のとなりへ来て止まる（赤い線）。**立つ場所で、止まる列を決められる**。②中段の左右の端の大岩は、その列を端から端まで転がる。③ひっくり返すと、次の自分の手番の終わりまでお腹が出ている |
| 立てる作戦 | 「リコをおとりに立たせ、ガルドは大岩の後ろで待つ → 来たら転がす → 三人でお腹」「二度目は、凍らせて段のふちから落とす」 |
| 成功の体験 | 読んだとおりの升に大亀が来る。大岩が当たって、甲羅が裏返る。「すき あと1手番」の間に、三人の傷が全部通る |
| 前の依頼との違い | 敵の動きを**先に読んで、待つ**。一つの手を二度は使いにくく、二つめの手を考える |
| 成長・編成 | 鋼の籠手（平地で押せる・石柱）・長弓・大玉が、それぞれ別の「ひっくり返す手」「お腹への傷」になる |

## 5. ルール

| 決まり | 区分 |
| --- | --- |

| すきのない甲羅への高所の矢は**傷1** | 変更（05 1.2） |
| 大岩は**1升以上転がって**当たればひっくり返す（傷2） | 変更（05 1.3） |

| なぎ払い（ねらった相手に3、となりのほかの冒険者に2） | 既存 |

大亀の止まる升：大亀は「届く相手のうち点数の高い所」へ動く（既存の思考）。開始位置 (7,7) にリコが立ったままなら、大亀は第2手番の敵の動きで (7,6) へ来る（試作で確認）。**その升は大岩の列の上**。

## 6. 攻略の例

### ガルド＋セナ（道具なし）

| 手番 | 動き |
| --- | --- |
| 1 | ガルド (5,7)→(2,7)。リコは (7,7) のまま小鬼を射る。セナは (9,7) から小鬼を凍らせる |
| 2 | ガルド →(0,6)（大岩の後ろ）。リコは動かない（おとり）。赤い線で、大亀が (7,6) へ来るのを確かめる |
| 3 | ガルドが大岩を東へ。(2,6)…(6,6) を転がって (7,6) の大亀に当たる → **ひっくり返る**（傷2）。リコがお腹へ矢（3）、セナが霜（2）。残り15 |
| 4 | すきの続き。リコ3、セナ2、ガルドは追いついて押す（2）。残り8。この手番の終わりにすきが切れる |
| 5〜 | 二度目：(a) 大亀を凍らせて南へ押す → 中段のふち (y=7) から下の段へ落ちる（傷2・すき）／(b) 右の大岩 (13,6) を西へ／(c) 最初の大岩は (6,6) に止まっている。列に大亀がいれば、(5,6) から東へ**1升以上転がる位置なら**使える |
| 7〜8 | お腹へ。倒す |

試作（作業用のルールの写しで手順を通した）：8手番・受けた傷14・大亀の攻撃3回・ひっくり返し2回。

### ガルド＋トビ

- 第3手番は同じ（大岩はガルドでも、トビの (0,6)・(14,6) の発破でも）。お腹へリコ3・トビ3（大玉4）・ガルド2。
- 二度目：トビが、ふちの手前で大亀の北の升に発破 → 下の段へ落ちる。
- 試作：4〜6手番・受けた傷5。

### セナ＋トビ

- 大岩はトビの発破で（開始位置 (9,7) から (14,6) の発破はすぐ届く。東の大岩が西へ転がる）。
- 二度目：セナが凍らせ、トビの爆風ですべらせて落とす（連携）。
- 試作：6手番・受けた傷7。

### 道具があると

| 道具 | 増える手 |
| --- | --- |
| 鋼の籠手 | 平らな所でも大亀を押せる（ふちまで1升ずつ寄せる）。石柱を倒す：下の段の列 y=9 にいる大亀に当たればすき |
| 長弓 | お腹への矢が4 |
| 氷晶の杖 | 氷のかたまりを、中段のふちから下の段の大亀の上へ押し落とす（上から落ちた物＝すき） |
| 大玉 | 爆風で2升。ふちから遠くても落とせる |

## 7. 編成による違い

| 編成 | 一度目のすき | 二度目のすき | お腹の一手番の傷（道具なし） | 苦手 |
| --- | --- | --- | --- | --- |
| ガルド＋セナ | 大岩（ガルド） | 凍らせて押す／もう一つの大岩 | 3＋2＋2 | 大岩まで歩く2手番、ガルドが前線にいない |
| ガルド＋トビ | 大岩（どちらでも） | 爆風で落とす／ふち押し | 3＋3＋2 | 止める手がない。取りまきのコウモリ |
| セナ＋トビ | 大岩（トビ） | 凍らせて爆風 | 3＋2＋3 | なぎ払いを受けると薄い |

- どの編成にも、すきを作る手が二つ以上ある。高所の矢（傷1）は、どの編成でも少しずつ削れる保険。
- 一つの手だけでは終わらない体力（22）にしてあるが、同じ手を二度使うことは禁じていない（位置が合えば使える）。
