# 04　冒険者・固有能力・パーティー編成

**提案**である。働きかけの細かい決まり（発動条件・例外・見こみの出し方）は 05 の2章にまとめ、ここでは人物と役割、組み合わせ、編成の楽しさを書く。

---

## 1. 人数の判断

- 第二章で加える冒険者は **一人**（風守りナギ）。
- 理由：①新しい働きかけは、計画・実行・見こみ・入力・絵・音のすべてに手が入るので、一章に一つが実装の上限。②仲間4人で組み合わせは6通りになり、第一章（3通り）の倍。依頼板の「攻略した編成」を埋める量としてちょうどよい。③同じ章でリコ・ガルド・セナ・トビにも二段目の道具（新しい働きかけ）を渡すので、覚えることはすでに多い。
- 第二章には、次の仲間の**予告**として「灰色の狼」の三人（ロウ・キヌ・ヤシャ）が出る。加入はしない（8章）。

### 2.3 固有能力「あおぐ」

> **となりの軽い物・軽い敵・仲間を、ふわりと浮かせて、向こうへ2升運ぶ。2段上まで上がり、谷も水も飛びこす。**

| 項目 | 内容 |
| --- | --- |
| 相手 | 木箱・氷のかたまり・小さい雪玉／重くない敵／仲間（リコ・セナ・トビ。重いガルドは不可）／風鳴り石（鳴らす） |
| 立つ所 | 相手のとなり。運びたい向きの反対側（押すと同じ） |
| 動き | 相手は、ナギと反対の向きへ **2升先**に下りる（大うちわで3升）。途中の谷・水・低い物・敵は飛びこす。**下りる升は、もとの高さより2段上まで** |
| 下りた先 | 谷 → 落ちる（敵は倒れる・物は失う）／水 → 沈む（敵は倒れる・物は飛び石）／2段以上低い → 敵は落下の傷／敵の上 → 物は当たって傷3（甲羅もひっくり返る）／氷の床 → そのまますべる |
| 傷 | あおぐこと自体の傷はない。地形と物で倒す |
| 仲間 | 傷を受けない。運ばれた仲間は、その手番の移動と行動をそのまま使える |
| できないこと | 重い敵・大岩・石のブロック・ガルドは動かせない。**自分は運べない**。救助される人は運べない |

### 2.6 仲間になるまで

1. 第二章の最初の依頼 m7 の帰り、峠の茶屋で「里の風車が止まって、粉がひけない」と聞く。
2. m8「風守りの里」で、風鳴り石を鳴らしに行くナギと出会う。ナギは「うち一人でできる」と言うが、**自分は運べない**ので、石のとなりへ行けない。リコを谷の向こうへあおぎ、リコが鉤縄をかけて戻り、その縄でナギが渡る。「……借りは返すわ」。
3. 三つの石を鳴らすと、里にだけ風が戻る。峠の上はまだ止まったまま。ナギは祖母に送りだされ、ギルドへ。

## 3. 「あおぐ」と既存ルールの相互作用

### 3.1 既存ルールのどこに作用するか

| 既存の決まり | あおぐと、どうなるか | 生まれる攻略 |
| --- | --- | --- |
| のぼりは1段まで | 物と仲間だけは2段上がる | 2段の段差の上に、木箱や仲間を先に置く |
| 押された物は、高い所にぶつかって止まる | 浮いているあいだは、低い物・敵・谷を越える | 柵ごし・谷ごし・敵の頭ごしに物を置く |
| 物が敵の上に落ちると傷3（甲羅もひっくり返る） | 段がなくても「上から落とす」が起きる | 木箱・氷のかたまりが飛び道具になる |
| 氷の上の物はすべる | 下りた先が氷なら、そのまますべる | 氷の湖のまんなかへ飛び石を送りこむ（m9） |
| 水に沈んだ物は飛び石 | 岸から2〜3升先に飛び石を置ける | 岸から順に沈めなくてよい |
| 重さの床は、物がのると動く | 2段上の床にも物を置ける | m8 の風鳴り石B、m11 |
| 凍った敵は押すとすべる | 凍った**軽い**敵は、下りたとき砕けやすい（落下の傷+1）。凍った**重い**敵は、浮かないが1升すべりだす | セナと組むと、重い敵も段から落とせる |
| 飛ぶ敵（コウモリ） | 倍の距離を流される。地図の外まで流れたら逃げる | 飛ぶ敵に強い（セナの「凍らせて落とす」とは別の手） |

### 3.2 仲間との連携

| 相手 | 連携 | 字幕の例 |
| --- | --- | --- |
| リコ | リコを谷の向こう・高い所へ送る → 鉤縄で道をつくる／高所の矢。リコが「引く」で手もとへ寄せた木箱を、ナギが向こうへ送る（引くと、あおぐは逆向きの一対） | 「連携！ ナギの風にのって、リコが谷を越えた」 |
| ガルド | ガルドは重い物・重い敵と地面の一押し、ナギは軽い物と空の2升。**二人で動かせない物がなくなる**が、凍らせる・砕くはできない。ナギが木箱を段の上へ上げ、ガルドがそれを敵の上へ押し落とす | 「連携！ ナギが上げた木箱を、ガルドが落とした」 |
| セナ | セナ（氷晶の杖）が氷のかたまりを作り、ナギが敵へあおぐ＝**氷の砲弾**（二人の行動で傷3。甲羅もひっくり返る）。セナが凍らせた敵を、ナギが落として砕く。セナが床を凍らせ、ナギが下ろした物がすべっていく | 「連携！ セナの氷を、ナギが大亀に当てた（ひっくり返った！）」 |
| トビ | ナギが敵を一か所へ寄せ、トビがまとめて飛ばす。トビを高い所へ上げて、上から投げさせる。置き発破の升へ、敵をあおいで入れる | 「連携！ ナギが寄せた小鬼を、トビがまとめて吹き飛ばした」 |

### 3.3 既存の仲間の代わりにならないか

| 比べる相手 | 違い | 結論 |
| --- | --- | --- |
| ガルド「押す」 | ガルド：地面を1升、重い物も、転がる物・すべる物が主役。体力9。／ナギ：空を2升、軽い物だけ、上と向こうへ。体力6 | 持ち場が違う。大岩・ブロック・重い敵・石柱はガルドだけ |
| トビ「発破」 | トビ：離れた升から、四方へ、重い物も、傷あり、ひび岩。／ナギ：となりから、一方向へ、軽い物だけ、傷なし、**上へ・谷ごし・仲間も** | 「上へ」「越える」「仲間を運ぶ」はナギだけ |
| リコ「鉤縄」 | リコ：自分が鉄の輪へ渡り、縄がみんなの道になる。／ナギ：仲間を送れるが、自分は残る | 鉄の輪のない谷を仲間だけ越えられる。ただしナギ自身の道は別に要る |
| セナ「氷のかたまり」 | セナ：どこにでも足場を作れる（杖）。／ナギ：ある物を動かすだけ | セナの氷は、ナギにとって「運ぶ物」。競わずに組む |

### 3.4 強すぎる組み合わせの心配と、手当て

| 心配 | 手当て（05 に規則として書く） |
| --- | --- |
| 谷や水の多い地図で、軽い敵をつぎつぎ落とす | となりへ行く必要がある（体力6）。重い敵・凍らない敵・段をのぼる雪狼を混ぜる。2升先がちょうど床なら、敵は下りるだけ |
| 氷の砲弾をくり返して強敵をはめる | 二人の行動を使って傷3。ひっくり返っている間は、当ててもひっくり返りは延びない（05 3.1） |
| 仲間を高所へ上げて、高所の矢で強敵を削る | ひっくり返す前の甲羅・毛皮には、高所の矢は傷1（風切りの弓で2）。決め手にはならない |
| リコを谷の向こうへ送って、地図の錠を飛びこす | 設計で受けいれる（編成で道すじが変わる例）。止めたい所は、幅3以上の谷・3段以上の崖・鉄の輪の置き方で作る。ナギ自身は残るので、全員は進めない |
| 木箱を自在に運んで、重さの床を一人で片づける | 止めたい床には `need: 'block'`（石のブロックだけで沈む）を付ける（m11） |
| 氷晶の杖の氷＋あおぐで、どこへでも足場を送る | 氷のかたまりは1段ぶん。3段の崖は越えられない。セナとナギの二人を連れている編成のごほうびとして認める |

### 3.5 プレイヤーへの伝え方

- 札の説明：「あおぐ：となりの軽い物・敵・仲間を、2升先へ運ぶ（2段上まで・谷も越える）。重い物と自分は運べない」。
- 見こみ：相手の半透明の姿が、**弧を描く点線**の先に出る。下りた先で起きること（「谷へ落ちる」「水に沈んで飛び石になる」「小鬼に当たる（傷3）」「重さの床にのる」）を字幕で。運べないときは理由（「重すぎる」「下りる先がない」「3段上で届かない」）。
- 向きの選び方は「押す」と同じ（相手の、運びたい側と反対側にマウスを寄せると矢印）。
- 加入の画面（現行のトビと同じ形）に三行：「軽い物・敵・仲間を、2升先へ運ぶ」「2段上へも、谷の向こうへも」「重い物と、自分は運べない」。

## 4. 既存の冒険者：第二章での持ち場と調整

基本の数値（体力・移動・届く距離）は**変えない**。変えるのは、道具の二段目と、出番になる地形・敵。

### 4.1 リコ（斥候・主人公）

- 一人称「ぼく」。明るく前向き、だれとでも気さくに話す（現行のまま）。
- **引き鉤**（m7）で「引く」を覚える。鉤縄が「自分が行く」、引き鉤が「向こうを寄せる」。いつも出る主人公が持つので、**どの編成にも「遠くの物を動かす手」が一つ入る**。初期の三人で遊ぶ人にも、仕掛けを動かす手が増える。
- つらら（射ると落ちる）で、矢が地形に働きかける手になる。
- 風切りの弓は終盤（m12 のあと）。強敵の甲羅・毛皮に高所の矢が少し通るようになるが、決め手にはしない。

### 4.2 ガルド（重戦士）

- 第二章の出番：雪玉と大岩（m9・m10・m12・m14）、凍らない重い敵をふちから落とす（m11・m13）、体力の高さで強敵のおとり役。
- **熊の籠手**：連ね押し。二体並んだ敵、木箱＋敵、雪玉＋雪玉をまとめて動かせる。「一つを一方向に」から「一列を」へ。
- 物語：ロウ（「灰色の狼」の頭）は、ガルドとドーラの昔の仲間。m12 はガルドにとっての依頼。

### 4.3 セナ（氷の術師）

- 第二章の出番：氷の湖（m9）、滝の氷の段（m12）、水霊と粘体。石板の二枚目を読む（m11）。
- **凍らない敵**（氷の岩人形）と、凍っても次は振りはらう強敵で、「凍らせて押す」だけでは済まなくなる。かわりに：
- **霜降りの杖**：床を凍らせる。段のふちまで氷の道を作っておけば、ガルドの一押し・トビの爆風・ナギがあおいだ物・リコが引いた物が、ふちの外まですべる。**敵を止める役から、地形を作る役へ**。

### 4.4 トビ（発破師）

- 第二章の出番：ひび岩・封印石（m7・m11・m12）、雪玉・大岩を離れた所から転がす（どの依頼でも）、重い敵を飛ばす。
- 強敵「大猪」の凍った毛皮は爆心の傷を通さない（爆風では動く）。
- **置き発破**：敵の次の動き（赤い線）を読んで、来る升に置く。「どこで爆発させるか」から「いつ・どこで」へ。
- 【検討事項・人の判断を仰ぐ】ボットではトビ入りの編成がいつも速い（01 5章）。人が遊んでも「トビを入れておけば足りる」と感じるなら、**「自分より3段以上高い升へは投げられない」**を足す案がある（高い所の物・敵には、のぼるか、仲間に上げてもらう必要が出る）。今回の仕様には**入れていない**。v0.2〜v0.4 の実プレイで判断する。

## 6. パーティー編成の楽しさ

### 6.1 選びたくなる理由を、どこに置くか

| 場所 | 中身 |
| --- | --- |
| 依頼板の「見どころ」 | 地形と敵の**性質**を書く（「凍らない重い敵」「段をのぼる雪狼」「氷の湖・土手の雪玉」）。答え（だれを連れていけ）は書かない |
| 仲間のひとこと | その仲間なら何をするか、を一行（現行のまま）。四人ぶん |
| できること／できないこと | 現行のまま。「引く」はリコの欄に足す |
| 腕だめしの印 ③ | 初回と違う二人で達成すると印 |
| 攻略した編成 | 六通りの組み合わせを並べ、済んだ組に ✓ |
| 道具の出番 | 鍛えた直後に、その道具が光る依頼が依頼板にある（03 4.3） |

### 6.2 どの二人でも通れる、を守る方法

1. **リコの手だけで通れる本線**を、まず一本置く（つらら・引き鉤・鉄の輪）。仲間の力は、近道・楽な道・大きく決まる手にする。
2. 装置の依頼は「N個のうちM個」。リコが二つ、仲間が一つずつ持つ（m11）。
3. 強敵と高難度は、編成ごとに「ひっくり返す手」を二つ以上数える（各依頼の編成表）。
4. 編成で**難しさは同じにしない**。楽な組・手のかかる組があってよい。ただし、手のかかる組にも「決まると気持ちいい手」を一つ置く。

### 6.3 六通りの編成の色（第二章）

| 編成 | 得意 | 苦手 | 一言 |
| --- | --- | --- | --- |
