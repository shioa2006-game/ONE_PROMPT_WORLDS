# 06　第一章の改良

**提案**である。人の評価では第一章の依頼は「どれもよかった」ので、変えるのは、分析（01）で**事実として問題が確かめられた所**だけにした。

---

## 1. 依頼ごとの判断

| 依頼 | 判断 | 変えること | 変えない理由／変える理由 |
| --- | --- | --- | --- |
| m1 畑あらしの小鬼 | **現状維持** | 腕だめしの印を付けるだけ | 三つの力を一度ずつ教える役を、きちんと果たしている |
| m2 見張り塔の角笛 | **現状維持** | 印だけ | 高所の射手・上から落とす足場・道具の報酬。問題は見つからない |
| m3 石切り場の落盤 | **現状維持** | 印。受けなおしではトビを選べない | 新しい仲間をゲストで先に使わせる型。第二章の手本 |
| m4 風見の遺跡 | **現状維持** | 印だけ | 編成で道すじが変わる型。第二章 m11 の手本 |
| m5 川辺の村の米倉 | **地図と敵の決まりを小さく変える** | 大岩の位置（2個）・右の丘へ上がる段（1升）・盗っ人が逃げるまでの手番・台詞とヒント | 初期の三人では大岩を動かせない（事実）。資料と台詞が「押せる」と言っている |

| 共通 | **成長の土台を入れる** | 腕だめしの印・お守り・受けなおしの自由編成・宝箱は初回だけ | 第二章から急に入れるより、第一章で覚えてもらう |

依頼の順番・解放条件・報酬・功績・鍛冶屋の4品の値段は**変えない**。依頼の追加もしない。

## 2. 維持する案と、改良する案の比較

| | 維持する（v0.1 のまま第二章へ） | 改良する（この文書の案） |
| --- | --- | --- |
| 大岩 | 第二章で雪玉を出しても、「転がす物は使いにくい」という第一章の印象が残る | 第一章のうちに「並んだ所へ転がす」成功を一度味わえる。第二章の雪玉（m10）につながる |
| 大亀 | 第一章の山場が「なんとなく」のまま。第二章の大猪で急に作戦を求めることになる | 「さそう → 当てる → みんなで攻める」を第一章の最後に覚え、大猪で発展させられる |
| 成長 | 第二章で、印・お守り・二段目が一度に出る | 印とお守りを第一章で一つずつ覚える。二段目だけが第二章の新しさになる |
| 既存の面白さ | そのまま | m1〜m4 はそのまま。m5 は渡り口の読み合いに一手増えるだけ。m6 は長くなる（試作で 6〜8手番） |
| 危険 | ― | m5 が楽になりすぎる／m6 が手間に感じられる。どちらも数値で戻せる（08） |
| 実装 | なし | 地図の差分は物4個と1升。ルールは 05 の 1.1〜1.4（小さい） |

**結論：改良する。** 変更は小さく、戻せる。人が「これでいいのかな」と感じた二点に、事実の裏づけがある。
