# GUILDWARD 拡張設計 ― はじめに読む文書

作成日：2026-11-28　対象：GUILDWARD v0.1（`beyond2/`）　設計担当：Claude Fable 5.2

GUILDWARD を、長く遊べる冒険者ギルドRPGへ育てるための設計資料。
**ここにあるのは提案である。** 確定しているのは v0.1 の現行仕様だけ。人のレビューで採否を決めたあと、実装担当（Claude Opus 5.5）に渡す。
ゲーム本体・既存の資料・保存データは、今回の作業で**何も変えていない**。足したのはこの `design/` フォルダだけ。

> **どの文書も、仕組み・解き方・物語の結末に触れる。** 遊ぶ前に読まないことをおすすめ。

## 1. 一目で分かるまとめ

### 推奨する方向

> **「地方をめぐる依頼帳」**：章＝ひとつの地方。手づくりの依頼を8つ前後、新しい仲間をひとり、強敵をひとつ。
> 成長は、経験値ではなく、**新しい働きかけが手に入る道具**と、**一人一つ持たせるお守り**と、**別の遊び方に報いる腕だめしの印**。
> 仕掛け（大岩・雪玉・つらら・氷の床）は、手の届く所に、敵が並ぶ列へ向けて置く。強敵は、動きを読んで仕かけ、決まった一手番にみんなで攻める。

### 第一章の、どこを変えるか

| 変える所 | 中身 | 理由（確かめた事実） |
| --- | --- | --- |
| m5 川辺の村の米倉 | 大岩二つを、崖の上から**渡り口の列**へ下ろす。右の丘へ上がる段を一つ | 初期の三人では、ガルドは大岩をどの向きにも押せなかった（崖に上がれない） |
| m6 岩喰い大亀 | 体力 12→22。ひっくり返すと**次の自分の手番の終わりまで**お腹が出る。高所の矢は甲羅に傷1。大岩を**大亀が止まる列**の両端へ | 「凍らせて押す」一回と、高所の矢だけで倒せた。大岩までは10歩 |
| 共通 | 腕だめしの印・お守り・受けなおしの自由編成 | 成長と編成を、第一章のうちに覚えてもらう |
| m1〜m4 | **変えない**（印を付けるだけ） | 人の評価で「どれもよかった」。問題は見つからなかった |

### 第二章「北の峠の風」で、何を足すか

| 足すもの | 中身 |
| --- | --- |
| 依頼 8つ | m7 峠の茶屋の荷／m8 風守りの里／m9 氷の湖の漁師小屋／m10 雪の坂の迎え撃ち／m11 風穴の氷室／m12 灰色の狼の足あと／m13 氷瀑の上の巣（任意・高難度）／m14 雪喰い大猪（強敵） |
| 新しい仲間 | **風守りナギ**。「あおぐ」：となりの軽い物・敵・仲間を、2升先へ・2段上へ・谷ごしに運ぶ。重い物と自分は運べない |
| 地形 | 深い雪・つらら・雪玉・氷の床が谷や水へつづく地形・はね橋とレバー・風鳴り石・氷の柱 |
| 敵 | 雪小鬼・雪狼（段を2段のぼる）・氷の岩人形（凍らない）。使われていなかった水霊・粘体 |
| 強敵 | **雪喰い大猪**。ねらってから突進する。突進の列が、前の手番に見える |
| 遊ぶ時間 | 必須だけで 1.5〜2 時間（見積もり） |

### ゲーム全体として、何が面白くなるか

1. **仕掛けが決まる**：見こみに「3体をなぎ倒す」と出て、そのとおりになる。
2. **強敵に作戦がいる**：大亀は「さそって当てる」を二度。大猪は「突進の列に、ぶつける物を用意する」。
3. **育てると手が増える**：鍛えるたびに、前の依頼にも別の解き方が生まれる。
4. **だれと行くかを考える**：仲間4人・6通り。どの二人でも詰まず、二人とも出番がある。
5. **続きが気になる**：二枚目の石板、帰ってこない仲間、風を盗むもの。

## 3. 重要な設計判断（要約）

| 判断 | ひとことで |
| --- | --- |
| 大岩は「使わなかった」のではなく「使えなかった」 | 配置を直す。難しさは上げない |
| 大亀の「なんとなく」は、段取りが要らなかったから | 体力だけでなく、すきの長さと高所の矢を直す |
| 成長は、数より「できること」 | 二段目の道具は、必ず新しい働きかけ |
| 経験値は入れない | 出撃しない仲間を置いていかない |
| 新しい仲間は、向きで持ち場を分ける | 手前へ（リコ）・向こうへ1升（ガルド）・四方へ（トビ）・**上へ・谷ごしに（ナギ）** |
| リコの手だけで通る本線を置く | どの二人でも詰まない。主人公の成長が全員に効く |
| 新しい決まりを足す前に、使われていない既存ルールを主役に | 氷ですべる・沈んで飛び石・転がる・上から落とす |
| 万能の手を、敵の性質でほどく | 凍らない・段をのぼる・一直線に突っこむ |
| 受けなおす理由は、かせぎではなく印 | 一度きり。別の遊び方を試すごほうび |
| 風の通り道・二人目の仲間・手番しばりは、今回は入れない | 覚えることの量を守る |

## 4. この資料の確かさ

| 区分 | 中身 |
| --- | --- |
| **確かめた事実** | v0.1 のルールと数値（コード）。m5 の大岩をガルドが押せないこと。m6 が一度のひっくり返しと高所の矢で終わること（現行ルールで手順を動かした） |
| **設計段階で確かめたこと** | 地図10枚の寸法・配置・主な道すじ（`check_maps.js`、2316項目）。m5 の改良（現行ボット）。m6 の改良（ルールの写しの試作）。m10 の敵の並び |
| **計算だけのこと** | 第二章の敵・強敵の数値、手番数の見つもり、印の条件、経済 |
| **まだ分からないこと** | 人が遊んで面白いか・難しさ・時間。新しい絵と音。画面での選びやすさ |

実装もプレイもしていないことを、検証ずみとは書いていない（10 の1章）。
