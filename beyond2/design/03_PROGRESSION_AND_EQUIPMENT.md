# 03　成長・装備・報酬の仕組み

**提案**である。数値は初期調整値で、調整してよい幅は 08 にまとめた。
【必須】と書いた所は、設計の意図を保つために実装で守ってほしい所。

---

## 1. 成長の方式の比較と採否

| 方式 | 採否 | 理由 |
| --- | --- | --- |
| キャラクターレベル・経験値 | **採らない** | 出撃しない仲間が置いていかれ、「だれと行く？」が育てた二人に固定される。敵も同じだけ強くすることになり、帳消しになりやすい。かせぎの周回を生む |
| スキルツリー | **採らない** | 働きかけが一人1〜3個のゲームで、枝を作るほどの選択肢がない。画面と説明が増える割に、地図の上の遊びが増えない |
| 素材収集・クラフト | **採らない** | 同じ依頼のくり返しになりやすい（原型の企画でも見送り）。銀貨と宝箱で足りる |
| **ギルドランク（功績）** | **採る（現行を延長）** | 全員に効くので、だれも置いていかれない。数値の成長と、依頼・品の解放を兼ねる |
| **道具（鍛冶屋）と、その二段目** | **採る（現行を発展）** | いまの面白さの中心（杖で氷のかたまりを作れるようになる、など）。**二段目は必ず「新しい働きかけ」を一つ持つ** |
| **お守り（装備の収集・一人一つ）** | **採る（新規）** | 数値の成長と、選ぶ楽しさ・集める楽しさを、少ない決まりで足せる |
| **固有能力の発展** | **採る（道具の二段目として）** | 別の仕組みにせず、道具に乗せる |
| **腕だめしの印（任意目標）** | **採る（新規）** | 受けなおす理由。かせぎではなく「別の遊び方」に一度だけ報いる |
| 仲間との連携能力（名前つきの技） | **今回は採らない** | 連携はいまも自然に起きている（凍らせて押す、など）。名前つきの技は、仲間が5人をこえる第三章より先で考える |

【必須】成長の仕組みは **ランク・道具・お守り・印** の四つまで。これ以上の資源や画面を足さない。

## 4. 道具（鍛冶屋のトンボ）

### 4.1 考え方

- 一人につき道具の筋が一本（リコだけ「弓」と「縄」の二本）。**一段目は第一章、二段目は第二章**で手に入る。
- 【必須】**二段目は、数値ではなく「できることが一つ増える」**。その道具の出番になる依頼を、同じころに依頼板へ出す。
- 二段目を鍛えるには、一段目を持っていること。買った道具は、はずせない（常に効く）。効果は重なる。
- 道具は仲間ごとに買うので、連れていかない仲間のぶんは後回しにできる。**あとから鍛えても、その場で同じ強さになる**（経験値がないので、置いていかれない）。

## 5. お守り（集めて、一人に一つ持たせる）

- 一つずつ名前と由来のある品。**同じ物は二つとない**。出発の画面で、同行する三人に一つずつ持たせる（持たせなくてもよい）。
- 効果は小さな数値か、小さな例外。新しい働きかけは持たせない（それは道具の役目）。
- 【必須】お守りがなくても、どの依頼も達成できること。

## 6. 腕だめしの印（任意目標）

### 6.1 決まり

- 依頼ごとに三つ。**①発見**（その依頼の仕掛けを使う）、**②腕前**（手際・無傷など）、**③別の二人**（初回と違う二人で達成する）。
- 一つにつき一度きり。とれた印は依頼板の札に ◆、まだの印は ◇ と条件の文で出す（条件は最初から見える）。
- 【必須】印は、**銀貨をかせぐ周回ではなく、別の遊び方を一度試すこと**に報いる。印がなくても物語は進む。
- 【必須】同行が決まっていた依頼（m1〜m3・m8）も、**初回の達成のあとは、だれとでも受けなおせる**。
  - m3 を受けなおすとき、トビは選べない（岩棚にいる側だから）。m8 を受けなおすとき、ナギは選べない（同行のゲストとして必ずいる）。

## 7. 仲間の加入と、連れていかない仲間

| 問い | 答え |
| --- | --- |
| 新しい仲間は、加入したとき弱いか | **弱くない。** 体力はランクで全員同じだけ上がる。道具は一段目が加入と同時に店へ並ぶ（ナギの大うちわ 220）。第一章を終えた時点の持ち越し（150〜300 の見こみ）で、すぐ鍛えられる |
| 連れていかない仲間は育つか | 育てる物が本人にない（経験値がない）ので、差がつかない。道具だけは買ったぶんだけ。**あとから買えば追いつく** |
| 使わない仲間が、ますます使われなくなる心配 | ③の印（別の二人）、依頼板の手がかり、その仲間の道具の出番になる依頼（4.3）で誘う。固定はしない |
| 加入の依頼で、新しい力を使えるか | m8 はナギがゲストとして最初からいる。地図の本線はナギの「あおぐ」で進む |

## 9. 第一章から第二章への引き継ぎ

- 第一章の結末（m6）を見たあと、ギルドに戻ると依頼板に m7 が貼られる（予告の札が本物になる）。
- ランク・銀貨・道具・お守り・印・攻略した編成は、そのまま持ちこす。
- 第二章の最初の依頼 m7 は、第一章の道具を**一つも買っていなくても**通れる（リコの矢とつららで本線が進む）。持っていれば楽になる所を、わざと置く（長弓で眠っている射手を落とせる、など）。

## 10. 成長でバランスがこわれないための決まり

| 心配 | 手当て |
| --- | --- |
| 道具が強すぎて、地形を無視できる | 二段目は「地形に働きかける手」だけ（引く・連ねて押す・床を凍らせる・置く）。どれも**地形がないと効かない**。まっすぐな傷を上げるのは弓だけで、甲羅・毛皮には通らない |
| 強くなっても敵が同じだけ強くなり、実感がない | 第二章の敵の体力は第一章とほぼ同じ（雪小鬼3・雪狼3）。数と「いつもの手が効かない」性質で手応えを作る。受けなおした第一章は、はっきり楽になる |
| 一つの道具・編成だけが正解になる | 強敵と高難度の依頼には、どの二人にも「ひっくり返す手」を二つ以上用意する（各依頼の仕様の編成表）。凍らない敵・あおげない重い敵・爆風の利かない毛皮で、万能な手をなくす |
| 連れていかない仲間が育たない | 7章 |
| 報酬のために同じ依頼をくり返す | 2回目の報酬は4分の1、宝箱は一度きり、印は一度きり。必須の依頼の報酬だけで、必要な道具は買える（08） |
| 収集が作業になる | お守り7・印42。どれも「どこで・何をすると」が依頼板と依頼帳に出ている。隠し条件はない |
