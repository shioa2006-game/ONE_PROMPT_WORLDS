# ずらり、砦くずし ― 攻略とネタバレ

**この資料は、仕組みの数値・攻略・結末をすべて書いています。**
自分で見つける楽しみを残したい場合は、一度クリアしてから読んでください。

---

## 1. 呪文の計算

横一行 ＝ 一つの呪文。1行目は上の道、2行目は真ん中の道、3行目は下の道へ飛ぶ。上の行から順に放たれる。

**力 ＝ 源の力 × 力のリールの倍率（二本あれば掛け算）**

| 源 | Lv1 / Lv2 / Lv3 | はたらき |
| --- | --- | --- |
| 剣 | 2 / 4 / 6 | ふつう |
| 炎 | 3 / 5 / 8 | いちばん強い |
| 氷 | 2 / 3 / 5 | 当たって生き残った相手を凍らせる（次の手番は動かない・撃たない・砦は守備兵を出さず大矢も止まる） |
| 雷 | 2 / 4 / 6 | 盾兵の「半分」を無視する |
| 光 | 2 / 3 / 5 | 砦の部分に2倍 |

| 形 | 当たり方 |
| --- | --- |
| 空き | 呪文にならない |
| 一点 | その道のいちばん手前の一体に、力の2倍 |
| 貫く | その道を手前から順に。倒した相手の体力ぶん力が減り、残りが奥へ。最後は砦の部分に当たる |
| なぎ払い | 三本の道それぞれの、いちばん手前に力そのまま（行の位置に関係なく同じ） |
| はじける | その道のいちばん手前の相手を中心に、3×3（となりの道も）に力そのまま。中心が砦なら砦のまわり |
| あらし | 戦場のすべて（砦の三部分も）に力の半分 |

| 力 | はたらき |
| --- | --- |
| なし | ×1 |
| 二倍・三倍 | ×2・×3 |
| 二度 | 同じ呪文をもう一度（一度目で倒れた相手は数えなおす） |

| 響（五本目） | はたらき |
| --- | --- |
| 上へ・下へ | その行の呪文を、となりの道でも放つ |
| 三道 | その行の呪文を、三本の道すべてで放つ |

- 「砦は道のいちばん奥（列7）にいる大きな相手」として扱われる。だから、道が空いていれば一点もはじけるも砦に当たる。
- **盾兵**は正面からの「一点」「貫く」を半分にする（雷は無視）。貫くは盾兵を通るとき力を2倍消費する。上・横からの「なぎ払い」「はじける」「あらし」には盾が効かない。
- 見こみ（敵の頭の上の数字、砦の札、左下の文）は、実際に放つのと同じ計算。

## 2. ずらし

- 一コマにつき魔力1。毎手番、満タンにもどる（2 → 3 → 4）。戻せば魔力ももどる。一本のリールは最大3コマまで。
- 工房で新しく刻んだ言葉があると、次の戦いの最初の回転は「その言葉が窓のすぐ外にあり、一つずらせば見こみが大きく伸びる」止まり方が選ばれる（見つからなければふつうに回る）。二つ目の砦では「2体以上倒して砦まで届く」止まり方。
- 最初の砦のはじめの3手番は、止まり方が決まっている（教えるため）。
- ▲ はリールが上へ動く（下にはみ出していた言葉が3行目に入る）。▼ はその逆。
- **一本ずらすと、そのリールの3行すべてが動く**。形のリールをずらすと三本の道の「形」がいっぺんに入れかわる。いい行を作ると、別の行が崩れることがある。
- 工房で、**同じリールの上下に並べた言葉は、窓の中でも上下に並ぶ**。たとえば力のリールに ×3 を二つ続けて置くと、二つの道が同時に ×3 になりやすい。逆に、強い言葉は散らしておくと、どの位置で止まっても一つずらせば届きやすい。

## 3. 魔王軍と砦

| 魔物 | 体力（基本） | 特徴 |
| --- | --- | --- |
| 小鬼 | 1 | 一歩ずつ |
| 黒狼 | 2 | 二歩ずつ |
| 盾兵 | 4 | 正面の攻撃を半分 |
| 弓兵 | 2 | 列4で止まり、2手番に1回陣を撃つ（守り−1） |
| 大鬼 | 12 | 2手番に一歩。陣に着くと守り−3 |
| 黒騎士 | 18 | 盾持ちで、2手番に一歩。陣に着くと守り−3 |

- 後半の砦では体力に倍率がかかる（森1.3・丘1.8・鉄の谷2.5・城3.5。大軍勢は2）。
- 砦の部分は「守備兵」を決まった数だけ、決まった間隔で出す。**部分を崩すと、その道の魔物と、まだ中にいた守備兵がまとめて逃げる**（逃げた分も倒した数と金貨に入る）。早く崩すほど得。
- **大矢**：部分ごとに「N手番ごとに守り−1（城門などは−2）」。札の数字が撃つまでの手番。凍らせると一手番止まる。崩せば止まる。
- 退却しても、**砦の部分に与えた傷（崩した部分も）は残る**。守備兵は最初から。

| 砦 | 部分の体力 | 大矢 |
| --- | --- | --- |
| 国境の見張り砦 | 10 / 12 / 10 | なし |
| 渡し場の砦 | 14 / 20 / 14 | 櫓：5手番ごと |
| 黒い森の砦 | 24 / 34 / 24 | 4・5・4 |
| 風の丘の砦 | 54 / 72 / 54 | 4・5・4 |
| 鉄の谷の砦 | 140 / 180 / 140 | 4・4（−2）・4 |
| 黒鉄の城 | 300 / 420 / 300 | 3・4（−2）・3 |

## 4. 工房と成長

| 砦を落とすと | お礼（固定） | 選べるお礼 | 市に並ぶもの |
| --- | --- | --- | --- |
| 見張り砦（学者ノーラ） | 貫く | 炎・×2・氷 | 炎・氷・×2・貫く・なぎ払い |
| 渡し場（鍛冶屋ゴドー） | 四本目のリール（力） | 雷・×2・なぎ払い | 雷・鍛える（Lv2） |
| 黒い森（司祭セリス） | 魔力の器+1 | 光・はじける・×3 | 光・はじける・×3・鍛える（Lv3） |
| 風の丘（からくり師ピコ） | 五本目のリール（響） | **三道**・×3・あらし | 二度・上へ・下へ・あらし |
| 鉄の谷（騎士団長レオン） | 守り+1・魔力+1 | **三道**・×3・はじける | ― |

- 市の言葉は、工房に寄るたびに各一つずつ買える。
- 「三道」は市では買えない。お礼で選ぶしかない（最大二つ）。
- 鍛えるのは源の言葉だけ（Lv2：金貨6、Lv3：金貨10）。炎Lv3は8、×3×3と重ねると一行で72。

### 強い組み方の例

- **序盤**：形のリールの空きを埋めるのが最優先（空きの行は何もしない）。貫くは「小鬼が一列に並んだ道」で、砦まで届く。
- **中盤**：炎を鍛える。力のリールに ×2 / ×3 を増やす。光の貫くは砦に強い。盾兵が多い砦では雷か、はじける・なぎ払い。
- **終盤**：三道を、炎Lv3・はじける（または貫く）・×3・×3 の行にずらして合わせると、一つの呪文が三本の道ぜんぶで炸裂する。黒鉄の城の部分も一撃で崩せる。
- 大矢が「！」になったら、その部分を先に崩すか、氷で止める。

## 5. 物語と結末

- 王の街道ぞいに、魔王軍が黒鉄の砦を建てた。見習い魔術師リコは、亡き師匠の「詠唱盤」と老騎士バルドとともに、砦を一つずつ崩していく。
- 砦を落とすたびに、とらわれていた町の人々が帰り、その中の一人が仲間になる（学者・鍛冶屋・司祭・からくり師・騎士団長）。地図の町に明かりがともる。
- 黒鉄の城（王都）を落とすと、エレナ女王が救い出される。だが魔王が残りの軍勢を呼び集めていた。
- **最後の戦い「魔王の大軍勢」**：戦場の全マスが魔物で埋まり、詠唱は三度だけ。魔物は倒しても奥から次々と押し寄せる。両側の軍旗を崩すとその道の軍勢が逃げ、真ん中の奥の**魔王（体力640）を崩すと全軍が退いて、その場で決着**する。三度のうちに魔王まで届かなくても、軍勢は退いていき結末へ進む（言葉が少し変わる）。
- 結末では、砦ごとの「一手の呪文で与えたダメージの最大」（と一手で倒した数）が棒グラフで並び、最後の一手が最初の砦の何倍になったかが出る。
- 退却するたびに、その砦では援軍が来て陣の守りが1増える（最大+3）。砦の傷も残るので、挑み直すほど楽になる。
- クリア後は、タイトルの「大詠唱の腕だめし」で、完成した詠唱盤で大軍勢に何度でも挑める（倒した数の記録が残る）。
