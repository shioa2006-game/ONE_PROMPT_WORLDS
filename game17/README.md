# ずらり、砦くずし ― 詠唱盤と黒鉄の街道

言葉を刻んだリールを回すと、止まった横一行が、そのまま一つの呪文になる。
左から「源（なにで）」「形（どう撃つ）」「力（何倍）」。1行目の呪文は上の道へ、2行目は真ん中、3行目は下の道へ飛んでいく。
リールを一コマずらせば、言葉が隣の行へ移り、呪文の行き先と形が変わる。
救った人々からもらった言葉で自分の詠唱盤を組み、育て、魔王軍が街道に建てた黒鉄の砦を崩していくゲーム。

ONE PROMPT WORLDS の第17作。Claude Opus 5.5 が1つの依頼から企画・実装・検証・改善まで自律的に制作した。

- PCブラウザ向け。マウスだけで遊べる（キーボードも使える）。音が出る。
- 1回の目安：20〜30分（設計上の目安。人間のプレイ時間は未計測）。

## 起動

`game17/index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動く。サーバー・ビルド・外部ライブラリ・外部素材は使っていない。

簡易サーバーで開く場合は、リポジトリ直下で次を実行して <http://127.0.0.1:8017/> を開く。

```bash
python -m http.server 8017 --bind 127.0.0.1 --directory game17
```

進み具合はブラウザの localStorage に保存され、タイトルの「つづきから」で再開できる（戦いの途中でやめた場合は、その戦いのはじめから）。

## 操作

| 操作 | マウス | キー |
| --- | --- | --- |
| 回す／止める／放つ／演出の早送り | 右下の大きなボタン | スペース・Enter |
| リールを一コマずらす | リールの上下の ▲ ▼（窓の外の小札を押す・ホイール・リールを上下にドラッグでも） | Q W E R T（▲）／ A S D F G（▼） |
| ずらしを全部もどす | 「ずらしを戻す」・右クリック | Z |
| ヒント（一度目は手がかり、二度目でいちばん効くずらし方） | 「ヒント」 | H |
| 説明を読む | 言葉・魔物・砦・呪文の札にマウスを重ねる | ― |
| あそびかた／音／メニュー | 右上の ？ ♪ ≡ | M（音）・Esc（メニュー） |

メニューでは、音量、「演出：はやい」、「自動で回す」を切りかえられる。

工房では、持ち物の言葉を押してから、同じ役割のリールのマス（光る）を押すと刻める。リールのマスを押すと持ち上げて同じリールの中で入れ替えられ、右クリックで外せる。

## 遊びの流れ

1. **回す**：詠唱盤の3〜5本のリールが回って止まる。横一行ごとに、その道へ飛ぶ呪文の札（形と数字）が出る。
2. **ずらす**：▲▼ でリールを一コマずらす。魔力を1使う（戻せばもどる。毎手番、満タンになる）。窓の上下の小札が、ずらすと入ってくる言葉（上の札は▼、下の札は▲で入る）。魔物と砦の上の数字が、放ったときの見こみ。
3. **放つ**：上の行から順に呪文が飛ぶ。そのあと魔王軍が一歩進み、砦は守備兵を出し、ときどき「大矢」で陣を撃つ。
4. 道ごとの砦の部分を三つとも崩せば勝ち。陣の守りが尽きると退却（砦の傷は残り、次の挑戦では援軍が来るので、組み直して挑み直せる）。
5. 戦いのあとは地図と工房。救った人々からお礼の言葉をもらい、市で言葉を買い、リールに刻む。「試し撃ち」では、組み替える前と同じ回転で比べられる。

## 検証用ツール（開発者向け）

- `node tools/rules_test.js` … ルールの自動確認
- `node tools/bot.js 6 smart smart` … ルールだけで全編を回すボット（戦い方 none / one / smart、組み方 random / smart）
- `python tools/playthrough.py --fast [--seed N] [--reload] [--keys] [--noshift] [--shots DIR]` … タイトルから結末まで、本物のクリックとキーで通す（Playwright＋Edge）
- `python tools/compare.py DIR` … 「工房でリールを一か所変える → 試し撃ちで同じ回転を比べる → 次の戦いでずらして使う」を本物のクリックで確かめる
- `python tools/shot.py DIR steps.json` … 画面の撮影
- URL に `?seed=N` を付けると、新しく始めたゲームの乱数を固定できる

## 素材

画像・音声・フォントの外部素材は使っていない。絵はすべて Canvas 2D で描き、効果音と BGM はブラウザ内で合成している。文字は利用者の PC にある日本語フォントを使う。
