## 1. 企画：3案の比較

3案とも「剣と魔法の世界で、自分で組んだリールを回し、出目をずらして使う」条件の中で考え、プレイヤーの目的と、リールの結果として世界に起きることを変えた。
リールの形は3案で共通の「詠唱盤」を土台にした：**横一行がそのまま一つの呪文**になり、左から「源（なにで）」「形（どう撃つ）」「力（何倍）」と読む。一コマずらすと、言葉が隣の行へ移る。

### 案A「黒鉄の砦くずし」― 魔王軍の砦を崩して、王の街道を取りもどす（攻略・解放）【採用】

- **見て狙うもの**：三本の道の奥に黒い砦。下の道には小鬼が2体並び、その奥の南の櫓（体力14）が数手番後に大矢を撃ってくる。
- **効く場所とずらし**：前の工房で、形のリールの空きに「貫く」を刻んだ。いま「貫く」は窓の下にはみ出している。形のリールを ▲ で一つずらすと、3行目が「炎・貫く・×2＝6」になり、小鬼2体を貫いて、残りの4が櫓に届く（そのかわり1行目の形が空きになる）。
- **育ったリールなら**：「炎Lv3・はじける・×3・×3・三道」の行に合わせて放つと、72の爆発が三本の道すべてで起き、「光・貫く・×2・×3・三道」が三つの砦の部分をまとめて砕く。戦場を埋めた軍勢21体と両側の軍旗が一手で消え、逃げ出す兵の向こうで王国の旗が上がる。
- **次に試したくなること**：救った鍛冶屋が五本目のリール「響」をくれた。次の城では、三道をいちばん強い行に合わせられるよう、力のリールに ×3 を続けて並べてみたい。
- **評価**：一手で「砦が崩れる」「道の敵が逃げる」「町に明かりが戻る」と、世界が目に見えて変わる。貫いた残りが砦に届く手応えは LUMEN REEL の「ごっそり通過」に通じるが、仕組みは別物（行ごとの言葉の組み合わせ、形で当たり方が変わる、ずらすと呪文が別の道へ移る）。

### 案B「地底王国の発掘」― 山を掘りぬいて、眠る王国と伝説の剣を見つける（探索・発掘）

- **見て狙うもの**：断面図の岩盤。固い岩の下に、宝箱が縦に3つ埋まっている。
- **効く場所とずらし**：形のリールに「柱（縦に掘る）」を刻んでおいた。一つずらすと柱が宝箱の列にそろい、6マスの岩を掘りぬいて宝箱が3つこぼれ出る。
- **育ったリールなら**：あらしの形で大きな空洞が開き、地下に沈んだ古い町並みがまるごと現れる。
- **次に試したくなること**：溶岩の層に備えて氷の言葉を増やし、もっと深い層へ。
- **評価**：未知の場所を開く楽しさは強い。ただ相手が動かない岩なので、毎手番が「いちばん多く掘れる形を探す」最適化になりやすく、「次に何が起きるかを見て作戦を立てる」要素が弱い。岩・宝・水・溶岩など地形の種類が多く、15〜30分の完成品に仕上げる量が大きい。

### 案C「春呼びの大魔法」― 氷に閉ざされた国に、春を呼びもどす（再生）

- **見て狙うもの**：氷河の向こうに、凍りついた村。氷河には厚み（体力）がある。
- **効く場所とずらし**：陽の言葉を村の行にずらして合わせると、ぬくもりが氷河を溶かしきり、残りの熱で村の氷もとける。
- **育ったリールなら**：一つの呪文で谷じゅうの雪が消え、花畑と人々がよみがえる。
- **次に試したくなること**：吹雪の谷に備えて、風の言葉で道を開く組み方へ。
- **評価**：世界の変化は美しいが、「人や土地を元にもどす」喜びが第16作と重なる。冬が押し返してくる緊張を作りにくく、源（陽・風・雨）の役割分けも作りものになりやすい。

### 比較と採用理由

| | 案A 砦くずし | 案B 発掘 | 案C 春呼び |
| --- | --- | --- | --- |
| 自分で組む楽しさ | ◎ 相手（盾・弓・大鬼）と砦に合わせて、源・形・力を組む | ○ 地層に合わせて形を組む | ○ |
| 一手が決まる気持ちよさ | ◎ 貫いた残りが砦に届き、部分が崩れると道の敵がまとめて逃げる | ○ 掘れる量が増える | ○ 溶ける範囲が広がる |
| 世界で成果を見る魅力 | ◎ 砦が崩れ旗が変わる／地図の町に明かり／救った人が工房に並ぶ | ◎ 埋もれた町が現れる | ◎ 景色がよみがえる |
| 次の局面を見て作戦 | ◎ 魔物の動き・大矢の手番・守備兵の数が見える | △ 相手が動かない | △ |
| 15〜30分に収まるか | ○ 5つの砦＋城＋大軍勢 | △ 地形の作り込みが重い | ○ |
| 第4作・第16作との違い | ○ 攻める側。行ごとの呪文の組み立て | ○ | △ 第16作と喜びの種類が近い |

**採用：案A**。リールの一行が「自分で組んだ呪文」として読め、一コマずらすと言葉が隣の道へ移るので、「ここに刻んだから、いま一つずらせばあの道に届く」がそのまま狙いになる。成果は「砦が崩れる・敵が逃げる・町に明かりが戻る」と世界に残る。
案Bは探索の魅力は強いが、相手が動かず作戦が最適化に寄り、作る量も大きいので見送った。案Cは変化の美しさはあるが、第16作と喜びが近く、緊張を作りにくいので見送った。

## 2. 遊びの核の確認（最初に行ったもの）

依頼の「リールの一か所を自分で変える → 局面を見て出目をずらす → 仕込んだ変更が結果に表れる」を、最初の工房・試し撃ち・二つ目の砦のはじめの回転で遊べる形にした（`tools/compare.py`、すべて本物のクリック）。

- 最初の砦（国境の見張り砦）は、はじめの3手番だけ止まり方を決め、「一行が一つの呪文」「形が空きの行は呪文にならない（形のリールを ▼）」「×2 を ▼ で2行目へ下げると炎・一点・×2＝12 で砦門が一撃」を順に体験させる。押すべき ▲▼ は光る。
- 砦を落とすと、学者ノーラから「貫く」をもらう。工房では、持ち物の「貫く」を押すと、置ける「形」のリールのマスが光る。置いた言葉には「新」の印。
- 工房の「試し撃ち」で、組み替える前に回しておき、組み替えたあと「同じ回転で」を押すと、同じ止まり方で比べられる。

### 組み替え前後の比較（試し撃ち、同じ回転）

| | リールの窓 | 結果 |
| --- | --- | --- |
| 組み替え前 | 形のリールの2行目が「空き」。2行目は呪文にならない | 2体倒した・合計2 |
| 組み替え後（同じ回転） | 空きだったマスに刻んだ「貫く」（新）が2行目に入り「剣・貫く＝2」 | 4体倒した・合計4。左下に「組み替え前 2体・合計2 → 組み替え後 4体・合計4 強くなった！」 |

### 二つ目の砦のはじめ（同じ局面で、ずらす前と後）

二つ目の砦のはじめの回転は、刻んだ言葉が窓のすぐ外にあり、**一つずらせば道に入って砦まで届く**止まり方を、その場の配置から探して選ぶ（`findTeachSpin`。「貫く」を形のリールのどこに置いても見つかることを node で確認：8か所すべて）。

| | 画面 | 見こみ |
| --- | --- | --- |
| ずらす前 | 「貫く」（新）は窓の下にはみ出した小札。形のリールの ▲ が光り、左下に「形のリールを ▲ で一つずらすと3行目に入り、魔物を貫いて砦まで届く」 | 倒す2体・砦に0 |
| ▲ を一回 | 3行目の札が「貫く 6」に。下の道の小鬼2体に「倒す」、南の櫓に「−4」。かわりに1行目は空きになる | 倒す2体・砦に4 |
| 放つ | 炎の光の帯が小鬼2体を抜けて櫓に刺さり、「−1」「−1」「−4」が順に出る | 同じ |

この確認で次の問題が見つかり、直した。

| 見つけた問題 | 直したこと |
| --- | --- |
| 序盤の「貫く」（力2〜3）では、体力2の小鬼を1体倒すと止まり、砦まで届く局面がほとんどない（教える回転が見つからない置き場所があった） | 小鬼の体力を1に（黒狼2・盾兵4・弓兵2）。後半は砦ごとの体力倍率で硬くする |
| 試し撃ちの差が小さい（合計8→10） | わら人形の体力を1にし、並びを列に。差は「2体→4体」に |
| 試し撃ちで、放った直後に人形が立ち直り、結果が見えない | 次に回すまで倒れたまま残す |
| 「同じ回転で」は、変えたマスが窓に入っていないと差が出ない | 「新しい言葉で」ボタン（刻んだ言葉が真ん中の行に来る止まり方）を追加。差が出ないときは「変えたマスが窓に入っていないかも」と出す |
| 砦の見こみの札（−4）が大矢の札と重なる | 見こみの札を部分の中央へ |

## 3. ゲームシステム・バランス（ボット）

ボットは盤面・魔物・砦・次の手番の予告（画面に出ているものと同じ情報）を知っているが、次の回転の出目は知らない。

- 戦い方：none（ずらさない）／one（魔力を1までしか使わない）／smart（魔力の範囲で、ずらし方をすべて試して最善。画面の「ヒント」と同じ計算）
- 組み方：random（買う物も置き場所も適当）／smart（優先順に買い、ランダムな回転50回で平均が上がるマスに置く。源を鍛える）

### 最初の版で見つかった問題と変更

| 問題（ボットで観察） | 変更 |
| --- | --- |
| 二つ目の砦で決着がつかない（60手番でも砦が残る）。砦が魔物を出し続け、行の呪文が手前の魔物に吸われる | 砦の守備兵を「決まった数」にした。部分を崩すと、その道の魔物と中に残った守備兵がまとめて逃げる（砦の上に「守備兵 N」） |
| 見こみの計算が、本物のリールの位置まで動かしていた（写しが浅い） | 見こみ用の写しを作る関数に分け、テストで「見こみは状態を変えない」を確認 |
| ずらさなくても、ずらしても結果がほぼ同じ（どの行も必ず呪文になるため） | 「形」のリールに「空き」のコマを入れた。空きの行は呪文にならない。工房で空きを埋めるほどリールが育つ |
| 全編が25手番で終わる・陣が一度も削られない（攻撃が先頭の魔物に当たるので、攻めがそのまま守りになる） | 砦の体力を大きく、後半の魔物に体力倍率。砦の部分に「大矢」（N手番ごとに陣を撃つ。札に残り手番。凍らせると止まり、崩せば止まる）を追加 |
| 大矢を入れると、組み方の粗いボットが城で何度も負けて先へ進めない | 退却しても砦の傷（崩した部分も）は残るようにした |
| 「三道」を市で買い集めると、終盤が2〜3手番で終わる | 三道はお礼でだけ（最大二つ）。市には上へ・下へ |
| 序盤の「貫く」が小鬼1体で止まり、砦に届かない | 小鬼の体力1など（上の「核の確認」参照） |
| 大軍勢（最後の戦い）の一手が、城の戦いより見劣りする | 魔物の倍率を下げ、軍旗・魔王を崩すと道の軍勢が逃げる（魔王なら全軍）ようにした |

### 現在の数値（各8局、`node tools/bot.js 8 <戦い方> <組み方>`）

一発成功率（その砦を負けずに落とした割合）と平均手番：

| 戦い方／組み方 | 見張り | 渡し場 | 黒い森 | 風の丘 | 鉄の谷 | 黒鉄の城 | 全体の手番 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| smart／smart | 100%・6.4 | 100%・6.9 | 100%・8.5 | 100%・6.5 | 100%・5.7 | 100%・3.8 | 41 |
| one／smart | 100%・8.3 | 100%・9.4 | 100%・9.8 | 88%・9.8 | 67%・6.1 | 83%・6.4 | 57 |
| none／smart | 100%・11.8 | 100%・12.4 | 63%・12.4 | 0%・11.0 | 25%・6.6 | 75%・6.1 | 85 |
| one／random | 100%・8.3 | 100%・9.3 | 88%・11.1 | 38%・10.0 | 13%・9.2 | 0%・9.2 | 113（ボットの上限6回の挑戦で、8局中6局が城を越えた。城の平均挑戦回数4.6） |

（鉄の谷の塔の大矢を3→4手番ごと、城門を3→4手番ごとにし、城の体力を 360/500/360 → 300/420/300 にした後の数値。one／smart の一発成功率は鉄の谷 38%→67%、城 50%→83% に。smart／smart は城を4手番ほどで落とす）

組み方が粗い（random）と城で何度も退却する。そこで、**退却しても砦の傷は残り、同じ砦に挑み直すたびに援軍で陣の守りが1増える（最大+3）**ようにした。挑むたびに必ず前へ進む。
ボットの「random」は、強い言葉の上に弱い言葉を重ねることもあり、鍛えもしないので、人間の組み方よりかなり悪い想定。

一手で倒した最多（smart／smart の平均）：見張り 2.9 → 渡し場 4.4 → 黒い森 9.4 → 風の丘 10.4 → 鉄の谷 14.8 → 黒鉄の城 23.5 → 大軍勢 21（戦場いっぱい）。
一手のダメージ最大：15 → 17 → 27 → 65 → 219 → 556 → 784。

ずらしの効果（`node tools/shiftgain.js 3`、各手番で「ずらさない」と「最善のずらし」を比べる）：

| 砦 | 平均ダメージ（ずらさない→最善） | ずらすと明らかに良い手番 |
| --- | --- | --- |
| 国境の見張り砦 | 1.3 → 4.8 | 42% |
| 渡し場の砦 | 4.4 → 8.2 | 56% |
| 黒い森の砦 | 8.0 → 14.5 | 88% |
| 風の丘の砦 | 10.9 → 22.4 | 97% |
| 鉄の谷の砦 | 29.9 → 71.3 | 95% |

読み取れること：

- **ずらしの効果は大きい**。最善のずらしで1手番のダメージはおよそ2倍。ずらさない方針は、丘から先で何度も退却する（傷が残るので、最後には越えられる）。
- **組み方の差は、勝ち負けと速さの両方に出る**。適当に置く方針は、城で何度も負ける。
- 限界：ボットは人間ではない。smart はずらし方を全部試すが、人間は全部は試さない（「ヒント」を使えば同じ答えは見られる）。one は「見こみを見ながら少しずらす人」の目安にしたが、確かめていない。組み方 smart も、人間よりは機械的。

## 7. 設計の要点（まとめ）

- **繰り返す行動**：回す → 窓の三行（＝三本の道の呪文）を見て ▲▼ でずらす → 放つ。ずらしは戻せば魔力ももどるので、札の数字・魔物と砦の見こみ・下の文を見ながら試してから決められる。
- **気持ちよい成功の設計**：上の行から順に呪文が飛ぶ（一点の光球、貫く光の帯、なぎ払いの弧、はじける輪、あらし）。貫くは魔物を一体ずつ抜けて、残りが砦に刺さる。倒すたびに音が上がり、金貨が上の欄へ飛ぶ。砦の部分が崩れると、土煙・がれき・王国の旗・逃げる魔物・駆け出す町の人。5体以上なら「ごっそり N体！」、砦の部分が落ちれば「◯◯が崩れた！ 中の守備兵 N人も逃げ出した」。部分が落ちるほど、砦の上の魔の雲が晴れる。
- **次を見たくなる仕組み**：救った人がお礼の言葉・市・鍛冶・新しいリール（力、響）・魔力の器をくれる。地図の町が一つずつ明るくなり、工房に人が増える。砦ごとに石の色・景色・相手（盾・狼・弓・大鬼・黒騎士）が変わる。戦いのはじめには「工房で刻んだ言葉を一つずらせば効く」局面が来る。
- **強いリールを使い切る場面**：最後の「魔王の大軍勢」。戦場の全マスが魔物で埋まり、詠唱は三度。両側の軍旗を崩せばその道の軍勢が逃げ、魔王（真ん中の奥）を崩せば全軍が退いて決着。結末で「一手のダメージの最大」が砦ごとに並び、最初の砦の何倍になったかが出る。クリア後は「大詠唱の腕だめし」。

## 8. 人間に遊んで確かめてほしい点

1. 二つ目以降の戦いのはじめに「工房で刻んだ言葉を一つずらす」案内が出たとき、それが「自分で仕込んだから狙えた」手応えとして感じられるか（決められた局面だと感じて冷めないか）。
2. 鉄の谷と黒鉄の城の難しさ。ボットでは、ずらしを考えれば退却0〜1回、ずらさないと数回の退却（傷と援軍で必ず前へ進む）。退却がやり直しの手間に感じられないか。全体の長さ（ボットの通しで40〜45手番）が20〜30分に収まるか。
3. 最後の大軍勢で、育てたリールの力を「存分に使えた」と感じるか。三道を一番強い行に合わせる一手が、狙って決まる気持ちよさになっているか。

## 9. 確認できていないこと・既知の制限

- 人間のプレイ時間、難しさの体感、面白さ、愛着。
- 音（実際に聴いていない。エラーが出ないことだけ確認）。
- スマートフォン・タッチ操作（ポインタイベントにしたが、実機では確かめていない。画面は PC 向け）。
- Chrome 以外のブラウザ（Firefox・Safari）。検証は Edge のヘッドレスのみ。
- 光・氷・雷は「相手や状況に合わせると便利」な位置づけで、炎を鍛えて ×3 を重ねる組み方が強い。相性を強制するルールは、分かりやすさを優先して入れていない。
- ボットの組み方（工房での判断）は人間より機械的で、ボットの数値は人間の難しさの証明ではない。
