# 制作・検証メモ（ネタバレを含みます。先に遊ぶのがおすすめ）

## 1. 企画の比較（3案 → 1案）

| 案 | 遊びの核 | 評価 |
| --- | --- | --- |
| **A. 胞子ショットの森（採用）** | 胞子を引っぱって飛ばす。落ちた場所がキノコになり、次の発射台＋はじくバンパーになる | 基本行動（引く・放す・跳ねる）自体が気持ちよい。「自分の過去の一打が盤面になる」ので、同じ行動の意味が進行で変わる。夜の森が自分の灯りで埋まる絵と直結 |
| B. 菌糸ネットワーク戦略 | 糸を伸ばして木々をつなぎ、糖を巡らせて枯れ木を蘇らせるターン制 | 見た目は強いが、面白さが経済バランス頼みで、1クリックの手応えが弱い。数値調整の割に「発見」が少ないと判断 |
| C. しずく水路の庭 | 溝を掘って水滴を導き、花を咲かせる自動化 | 眺める快さはあるが判断が薄く、「掘って水を導く」既存作に寄りやすい |

選んだ中心の喜び：**爽快感（跳ねる・連鎖・音）× 発見（キノコの使い道が増える）× 成長（森が灯り、連鎖が伸びる）**。

## 2. ルール（これで全部）

1. 胞子は苔の上で止まるとキノコになる（かれ地では消える、いばらで弾ける）。
2. 自分のキノコはどれも発射台。キノコに当たると最低速度まで「ぽん」と再加速される。
3. キノコは叩かれると育ち（2回→中、計5回→大）、大きいほど強くはじく。大は自分の全力ショットより遠くへ飛ばす。
4. 鈴は通り抜けると鳴る。門は、その鈴を**ひと飛びのあいだに全部**鳴らすと開く（1→2→3→4→5個）。
5. 川に落ちた胞子は流され、苔の岸で芽吹く。
6. ほたるを集めるほど、ねらいの光（軌道予測）が先まで伸びる。

## 3. 同じ行動の意味がどう変わるか（設計意図）

- 序盤：キノコ＝**足場**（苔の島を渡る）。
- 小川：野生の大キノコ＝**中継ブースター**。失敗して川に落ちると下流の洲に流れ着き、「失敗が輸送だった」と分かる（別ルートになる）。
- 第3の門：置いてあるキノコで**曲げる**。向こう岸：届かないキノコを叩くと育って届く＝**育てる**。
- 隠れ庭：いばらに囲まれ、川でしか入れない。第4の門は**自分で角にキノコを置いて曲げる**。
- 大樹の根のくぼ地：キノコを増やし育てるほど連鎖が長くなり、5つの鈴が一度に鳴る＝自分の**ピンボール台を作る**。
- 結末：大樹が灯り、朝になる。カメラが自分の植えたキノコを順に鳴らしながら出発点まで戻る。

## 4. アートディレクション

夜の森の地面を真上から。暗い藍〜紫の地に、発光する苔（青緑）、暖色に光る自分のキノコ、青白く眠る野生キノコ、赤紫のいばら、金に灯る鈴。
画面全体に暗がりをかけ、キノコ・鈴・ほたるの周りだけ光で抜く → **進むほど森が物理的に明るくなる**（タイトルの回収）。
音はすべて WebAudio 合成。ぽんの音は連鎖するほどペンタトニックを上る。BGMは短いループではなく、和音とまばらな撥音をランダムに重ねる生成式。

## 5. 検証（実施したもの）

### 5.1 機能検証（実ブラウザ：アプリ内蔵ブラウザ Chromium、localhost 配信）
- タイトル→開始→**実マウスのドラッグ発射**→着地・発芽→アクティブ切替を確認。
- 合成ポインタ/キーイベントで：極小ドラッグ=キャンセル、Shift微調整、右クリック引き抜き、Z引き抜き、親キノコは抜けない、Escメニューで時間停止/再開、自動保存、リロード→「つづきから」復帰、「さいしょから」で初期化＆保存消去 … すべて期待どおり。
- **初期状態から結末まで**：ボットが見つけた手順を実ブラウザ上でアニメーション付きで再生（最終版の配置で31発の手順を1回、調整途中の配置でも33発の手順を1回）。全ショットの結果が Node 実行と一致（不一致0）、4つの門→大樹→エンディング→結果カードまで到達。コンソールエラーなし。効果音関数20種を全呼び出しして例外なし。

### 5.2 ゲームシステム検証（Node 上で本番と同じ `sim.js` を実行）
- **完走**：先読みつき貪欲ボット（`tools/bot.js smart`）が3シードとも完走（下の結果参照）。
- **単純方針との比較**：「最寄りのキノコから全力で目標へ直進」ボット（`naive`）は 5シード×約400発で全滅、最初の門しか開かない。
- **封鎖**：門が閉じた状態で、各部屋の苔 290地点×720方向・強さから計20万発 → 門の向こうへの着地 0。隠れ庭への着地は空路 0／川経由 4,183。
- **別解の実在**：小川は ①野生の大キノコ経由（554通り）②川に流されて洲→東岸（洲から1,278通り）③自分で岸のキノコを最大まで育てる（159通り）。直接越えは 0/129,600。向こう岸は岸のキノコが中サイズでは 0/44,400、大サイズで 68/42,000。
- **門の成立と難度**：成功する角度の幅を0.1°刻みで計測。第2の門は最大11°、第3は最大約2°（1°以上の発射地点16か所）、第4（角に1本置いた後）は約1〜1.3°。意図した道具（野生キノコ／自分のキノコ）なしでは第3・第4・第5とも解0。

## 6. 検証で見つけた問題 → 改善

**ゲームデザイン**
1. 鈴を「当たると跳ね返る杭」にしていた → 2個の門で成功するショットが全体の0.03%。**通り抜けて鳴る方式に変更**（第2の門の許容角 最大11°）。
2. 最終局面を「大樹を一周して5つ鳴らす」にしていた → 模擬プレイヤーが80発・キノコ約80本でも 0/10。**根のくぼ地での連鎖型に作り直し**、20/20・中央値13発に。
3. キノコの隙間に挟まると1発で2,000回以上ヒットする不具合 → **同じキノコは0.2秒あけないと再キックしない**規則を追加。
4. くぼ地にキノコが増えると鈴の上に生えて鳴らせなくなり、雑なプレイで 3/10 が詰み → **鈴の石の輪には根づかない**規則を追加（混んだら抜けるヒントも）。
5. 第4の門の配置が厳しすぎた（模擬プレイヤー中央値63発）→ 鈴3つの列＋角の1つに再配置（同20発、許容角1°以上）。
6. 「叩くと育つ」に気づけず向こう岸で止まる懸念 → 岸の野生キノコを**あと1回で育つ状態**にし、育ちゲージ（頭上の点）を追加。試せば必ず育ち、届くようになる。

**ビジュアル／操作感**
1. 全体が暗すぎて岩・壁・丸太が沈んでいた → 暗がりを弱め、岩と丸太に縁の光、地面に小石と枯れ草。
2. 鈴が灯ると白飛びして周囲が読めなかった → 発光を抑制。夜明けは一律の茶色がけをやめ、朝焼けの斜光に。
3. 川が「運ぶ」ことの手がかりが無かった → 落ち葉が流れて岸へ寄る常時アニメを追加。
4. 許容角1°前後の門に対し狙いが粗かった → 引きしろを150→200pxに延長、Shift微調整、ドラッグ中の矢印キー微調整。

## 7. 限界・未確認

- **人間による初見プレイは未実施。** 「楽しい」「気づける」「15〜30分」は設計上の見込みで、確認済みではありません。ボットは正解手順と完全な狙いを持つため、難度の体感は別物です。
- 音は「例外なく鳴らせる」ことのみ確認。音色・音量バランスの良し悪しは耳で未確認。
- 検証用ブラウザペインは描画が間引かれるため、60fpsでの体感速度・演出テンポは目視できていません（更新を手動で進めて画面を確認）。
- Firefox / Safari、タッチ操作、`file://` 直開きでの保存は未確認（Chromium + localhost のみ）。
- 第3・第4の門は許容角が1°前後で、人によっては細かい狙いが面倒に感じる可能性があります。
