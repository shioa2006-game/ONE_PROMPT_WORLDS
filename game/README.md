# ぽん、と森は灯る

胞子をとばすと、落ちた場所にキノコが生える。
生えたキノコは、つぎの発射台になり、胞子をはじく「ぽん」になる。
くらい森を、自分のキノコで灯しながら、いちばん奥の大樹をめざす小さなゲームです。

## あそびかた（起動）

`index.html` をブラウザ（Chrome / Edge 推奨）で開くだけです。インストールもサーバーも不要です。

- 音が出ます（すべてブラウザ内で合成。外部素材なし）。
- 進行は自動保存されます（タイトルの「つづきから」）。
- 想定プレイ時間：初見で 15〜30 分。

## 操作

| 操作 | できること |
| --- | --- |
| キノコをドラッグ → はなす | 胞子をとばす（ひっぱった逆へ飛ぶ。長くひくほど強い） |
| Shift をおしながらドラッグ / ドラッグ中の矢印キー | ねらいを細かく調整 |
| キノコをクリック | とばすキノコをえらぶ |
| 右クリック / Z | 自分のキノコをぬく / さいごに生えた1本をぬく |
| 地面をドラッグ / WASD | 見わたす |
| ホイール | ズーム |
| Space | えらんだキノコへ視点をもどす ・ 飛行中は早送り |
| Esc / M | メニュー（操作一覧・音量・さいしょから） / ミュート |

あとは森にさわって確かめてください。

## フォルダ

- `index.html` / `js/` … ゲーム本体（`sim.js` 物理とルール、`world.js` 森の配置、`game.js` 描画・入力・進行、`audio.js` 音）
- `tools/` … 検証用のヘッドレスボットと計測スクリプト（Node.js。遊ぶだけなら不要）
- `NOTES_ネタバレ注意.md` … 企画の比較、仕掛けの意図、検証と改善の記録（**先に遊んでから読むのがおすすめ**）
