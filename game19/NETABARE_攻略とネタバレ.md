# せーの、星見の露台へ ― 攻略とネタバレ

**遊ぶ前に読まないことをおすすめします。** 各区画の解き方の一例、寄り道（ハレの覚え書き4枚）、結末を書いています。
座標は (x, y)。x は画面の右下へ、y は左下へ増える（見る向きを回していないとき）。

## 第一区画　大洞の入口

1. ガルドで、小さな高台の上の木箱を奥（右上）へ押す。木箱が段の下へ落ち、上の段へ上がる足場になる。
2. 上の段の左端から、リコの鉤縄で谷の向こうの鉄の輪へ渡る。縄はみんなの道になる。
3. 向こう岸で小鬼2体と戦い。セナで凍らせた小鬼をガルドが押すと、すべって谷へ落ちる（連携）。谷・池のそばへ押しだすだけでも倒せる。
4. セナで池を凍らせ、氷の上を歩いて奥の門へ。
- **覚え書き1**：左奥の小さな滝をセナで凍らせると、滝の上（壁の上）へのぼれる。

## 第二区画　見張りの段々

- 塔の上に骨の射手2体、段の上に小鬼3体。射手は高い所から射ると傷が1増える。リコが塔の鉄の輪へ縄をかけると、塔の上へ上がれる（戦いの最中でも縄を渡れる。2歩ぶん）。小鬼は段の奥の谷へ押し落とせる。
- 戦いのあと、跳ね橋のわきの壁の的をリコで射ると、跳ね橋が下りる。
- **覚え書き2**：右手前の池の小島。木箱を池に押し込むと飛び石になる（セナで池を凍らせても渡れる）。

## 第三区画　地下水路

1. セナで手前の水路を凍らせて渡る。粘体4体と戦い。粘体を凍らせると、すぐに氷のかたまりになる（押せる・のれる）。
2. 右の溝は流れが速く、凍らせられない。セナで石の前の水路を凍らせ（2回）、ガルドで石を押すと、氷の上をすべって溝に沈み、飛び石になる（連携）。氷のかたまり（凍らせた粘体）を溝へ押し込んでもよい。
3. 右奥の滝をセナで凍らせ、氷の段をのぼって棚の宝箱へ。**長い鉤縄**（届く距離が5→8）。
4. 棚の上から、左奥の向こう岸の鉄の輪へ縄をかけて渡り、門へ。

## 第四区画　吊り谷

- 長い鉤縄で、柱から柱へ渡っていく（スタート → 中央の柱 → 右の柱 → 奥の棚）。最初の柱に渡るとコウモリ4体が来る。コウモリは凍らせると谷へ落ちる。奥の棚に近づくと骨の射手2体。
- **覚え書き3**：左の高い柱の上。中央の柱の木箱の上に立てば、鉤縄の「2段上まで」に届く（輪を押せば、リコが自分で木箱にのぼって投げる）。

## 第五区画　石像の大広間

- 岩人形（体力8）と小鬼3体。岩人形は重くて押せないが、セナで凍らせるとガルドが押せて、すべっていく。中央の穴へすべらせると一押しで倒せる。
- 戦いのあと、左奥の台の宝箱で**巨人の籠手**。石柱を押し倒せるようになる。倒れた石柱は3升ぶんの橋や足場になる。
- 谷のふちの石柱を右（谷のほう）へ倒すと橋になり、向こうの門へ。
- **覚え書き4**：右の高い棚。手前の石柱を奥へ倒すと、棚にのぼる足場になる。ハレからガルドへの手紙。

## 第六区画　大階段

- 入るとすぐ戦い。下から小鬼と射手が階段をのぼってくる。上の踊り場の大岩をガルドで押すと、段を転がり落ちて、通り道の敵をなぎ倒す。左右の石柱を倒すと、3升ぶんの敵を押しつぶす。上からのリコの矢は小鬼を一発で倒す。
- 階段を下りると、下の群れ（小鬼3体・射手2体）。倒して地底湖への門へ。

## 最後の区画　凍らぬ滝

- 湖の水霊3体とコウモリ2体。水霊は押せないが、まわりの水ごと凍らせると閉じこめられる。
- 滝は二筋の水が注いでいて、そのままでは凍らない（「水の勢いが強すぎて、凍らせても砕ける」）。
  1. 左の崖の水門の的をリコで射る → 左の水路の水が止まる。
  2. 右手前の岸から、リコの長い鉤縄で右の棚の鉄の輪へ。ガルドも縄で渡り、棚の大岩を水路へ押し落とす → 右の流れをせき止める。
  3. 滝の勢いが弱まったら、セナで湖の石の道の先と滝を凍らせ、氷の段をのぼって露台へ。
- 三人とも大灯籠のそばにそろって灯籠を押すと「せーの！」で火が入る。

## 結末

大灯籠に火が入ると、露台の天井いっぱいの水晶が灯りを映して星空のようにまたたく。セナはハレが見たかったものを知り、その夜、町の広場から大洞の底に星がひとつ増えたのが見える。記録画面に、かかった時間、三人それぞれの働き、覚え書きの枚数、「この遠征の名場面」（道を大きくひらいた一手・連携・凍らぬ滝）が出る。
