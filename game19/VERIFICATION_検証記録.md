## 1. 企画：3案の比較

題材「少人数のクォータービュー・ダンジョン遠征」から、遠征の目的と、最も多く繰り返す行動が違う3案を考え、実際に遊んでいる一場面で比べた。

### 案A「せーの、星見の露台へ」― 二十年前に引き返した滝の向こうで、大灯籠に火を入れる（仲間を選んで地形に働きかけ、道をひらく）【採用】

- **目的**：二十年前、ガルドの遠征隊は「凍らぬ滝」で引き返した。術師ハレが凍らせようとして倒れたからだ。ハレの死後、弟子のリコとハレの教え子セナが「三人で灯しに行こう」と言う。底の露台の大灯籠に火を入れれば、光は町の広場から見える。
- **一場面**：区画に入ると、正面の池の向こうに高台、そこに小鬼が2体。右の崖の上には鉄の輪が光り、左奥には小さな滝。セナを選ぶと池が水色に光る（凍らせられる）。リコを選ぶと鉄の輪に緑の縁。輪を指すと「鉤縄をかけて渡る。縄はみんなの道になる。道がひらける！（25マス）」。押すと縄が弧を描いて飛び、リコが渡りきった瞬間、向こう岸の床に金色の光の波が広がる。小鬼が目を覚まし、赤い線で「次の手番でセナに−2」と出る。セナが小鬼を凍らせ、ガルドが押すと、氷のかたまりは谷へすべり落ち、字幕に「連携！ガルド・セナ」。勝ったあと、池を凍らせると奥の門に「！」。
- **繰り返す行動**：仲間を選び（または物を指して）、地形に一つ働きかける。押す・射る/縄をかける・凍らせるの三つで、段差・谷・水・滝・敵の位置が変わる。
- **評価**：見えている「行けない場所」と、三人の働きが一対一で結びつく。成功が「新しく行ける床」として目に見え、その先に次の行き先が見える。戦いも同じ地形と同じ働きかけで進むので、探索で覚えたことがそのまま効く。

### 案B「灯り運び」― 消えかけた種火を運び、暗いダンジョンの灯台をつないでいく

- **一場面**：真っ暗な部屋。ランタンを持つ仲間の周りだけ床が見える。高い柱の上の燭台に火を移せば、部屋の半分が照らされて、影の魔物が退く。
- **繰り返す行動**：灯りを持つ者の位置取りと、火を移す順番。
- **評価**：雰囲気は強いが、暗闇は「地形をひと目で読む」という依頼の中心とぶつかる。仲間の個性が「照らす係・守る係」に寄り、三人の働きの違いが出しにくい。

### 案C「しんがりの撤退戦」― 取り残された測量隊を、最深部から連れ帰る

- **一場面**：段差の多い坑道で、測量隊の二人を守りながら、上から射る弓兵と、坂を押し寄せる敵の群れをさばく。高台を取れば有利、崖から押し落とせば一撃。
- **繰り返す行動**：手番制の戦いで、一人ずつ動いて攻撃する。
- **評価**：クォータービューの戦いは映えるが、毎手番、人数分の指示を繰り返す手数が多い。行き先は与えられるので「あそこに行きたい」が弱い。15〜30分では戦いの数が少なく、地形の見せ場が戦場ごとに限られる。

### 比較と採用理由

| | 案A 地形に働きかける | 案B 灯り運び | 案C 撤退戦 |
| --- | --- | --- | --- |
| 繰り返す行動の手触り | ◎ 一手で地形が変わり、光の波と字幕で結果が見える | ○ 照らす | ○ 攻撃 |
| 地形を見わたすことが効く | ◎ 段差・谷・水・滝・輪・的がすべて手掛かり | △ 暗闇で見えない | ○ 高台と崖 |
| 仲間の働きが印象に残る | ◎ 三人の働きが別々で、連携で重なる | △ 役割が偏る | ○ |
| 次を見たくなる | ◎ ひらけた先に次の「行けない場所」 | ○ | △ 行き先は与えられる |
| 15〜30分に仕上がるか | ○ 7区画 | ○ | ○ |

**採用：案A**。依頼の「この仲間なら、ここでこんなことができそうだ」を、遊びの単位そのものにできる。三人の働き（押す・射る/縄・凍らせる）は互いに組み合わさり（凍らせて押すとすべる、凍らせた水路を石がすべる、縄で渡った先から押す）、成功が「新しく行ける床」として目に見える。案Bは読みやすさと両立しにくく、案Cは手数と「行きたい場所」が弱いので見送った。

### 採用案で決めたこと

- **画面**：640×360 に描いて2倍に拡大するドット絵のクォータービュー。升は 32×16、1段は 8 画素。崖の側面に1段ごとの帯と目地を入れ、段の数を数えられるようにした。上面は高いほど少し明るい。見る向きは Q・E で90度ずつ回せる。
- **キャラクター**：三人と敵6種。手前向き・奥向きの2方向を描き、左右反転で4方向。姿は「待機・歩き2枚・行動」（脚の入れかえ、上半身を前へ）。外枠は自動。仲間は色と形（大きな盾と兜／緑の頭巾と黄色い襟巻／とんがり帽子と水晶の杖）で見分ける。8方向は今回は描いていない（升の動きが4方向で足りるため）。
- **探索**：床を押すと、選んだ仲間が先頭で歩き、二人がついてくる（人数分の指示はいらない）。物を指すと、その物に働きかけられる仲間が自動で選ばれ、どこに立って何が起きるかが先に見える（半透明の姿・矢印・道すじ・「道がひらける！（○マス）」）。押すと、その場所まで歩いてから行う。
- **三人の働き**：ガルド「押す」（一升。段から落ちた物は足場、水に沈んだ物は飛び石、凍った物と大岩は止まるまで進む。籠手を得ると石柱を倒して3升の橋）／リコ「射る・鉤縄」（的で仕掛け、鉄の輪へ縄。縄は双方向の道。下から届くのは2段上まで。長い鉤縄で距離5→8）／セナ「凍らせる」（水を3×3で氷に、滝を氷の段に、敵は次の手番うごけず押すとすべる。粘体は氷のかたまりに）。
- **段差**：のぼれるのは1段、飛びおりられるのは2段まで。行けない升を指すと、行ける範囲のふちで「段差が高い（2段）」「谷にさえぎられて行けない」などの理由を出す。
- **道がひらける瞬間**：働きかけの前後で「三人で行ける範囲」を比べ、新しく行ける床に、行動した仲間のまわりから金色の光の波を走らせる。和音は広さで長くなる。新しく手が届いた門・宝・輪・的に「！」、遠ければカメラが一度そちらを見る。字幕に、だれの働きで何が変わったかを出す（二人の働きが重なれば「連携！」と二人の名前）。
- **戦い**：眠っている敵に近づくと手番制。三人それぞれ「移動（ガルド3・リコ4・セナ3、縄は2歩）と一つの行動」。敵は決まった考え方で動き、「いま手番を終えたら、どの敵がどこへ行き、だれが何点受けるか」を赤い線と数字で常に予告する。行動を指すと「このあと敵から受ける見こみ」が増えるか減るかも出る。手番を終えるまでは何度でも戻せる。全員倒れたら、その手番の始めか戦いの前から。勝つと全員回復。
- **目的と結末**：区画をぬけて凍らぬ滝へ。滝は二筋の水を止めないと凍らない。三人で大灯籠のそばに立って押すと「せーの！」で火が入り、天井の水晶が星空のようにまたたく。記録に三人の働きと「この遠征の名場面」。
- **寄り道**：ハレの覚え書き4枚（終盤の手掛かりと、ハレからガルドへの手紙）。

## 2. 早めに遊んで確かめたこと（第一区画）

最初に、第一区画（木箱 → 縄 → 小鬼2体との戦い → 池を凍らせて門、寄り道の小さな滝）だけを遊べる形にし、実際の画面と通常の操作（Playwright の本物のクリックとキー）で確かめた。

### 依頼の4点

| 確認点 | 画面で読み取れたこと（作者が正解を知った状態での確認） |
| --- | --- |
| 地形を読み、意図した場所に動けるか | 崖の側面の帯で段の数が数えられる。床を指すと白い菱形、行けない所は赤い菱形と理由（はじめの状態で上の段を指すと「段差が高い（2段）。のぼれるのは1段まで」、谷の向こうを指すと「谷にさえぎられて行けない」）。行ける所は歩く道に点が並ぶ。Q・E で見る向きを回すと、手前の壁に隠れていた池の奥が見える。壁の陰に立つ仲間は、隠れた部分だけが仲間の色で透けて見え、選んでいる仲間の手前の壁は半透明になる。壁の奥の床も、壁ごしに指して歩ける |
| 選択を一つ変えて、違いを読めるか | 戦いの最初の手番、同じ局面で比べた（`戻す`で戻して）。A：ガルドが小鬼をそのまま押す → 小鬼は一升動いて「−1」、崖っぷちに残る。字幕「小鬼を押した」。予告はリコ−2・セナ−2。B：先にセナが凍らせてからガルドが押す → 小鬼は氷のかたまりのまま谷へすべり落ちる。字幕「連携！ ガルド・セナ　小鬼は谷底へ落ちていった」。予告はリコ−2だけ。押す前の見こみにも「▶ 小鬼は谷底へ落ちていく／小鬼 −1（倒れる）／このあと敵から受ける見こみ：2」と出る |
| 反復操作の軽快さ | 探索は「物を押す」一回で、働きかけられる仲間が自動で選ばれ、立ち位置まで歩いてから行う。三人はついてくるので、人数分の移動は不要。第一区画は 木箱1・移動1・輪1・移動1（戦いへ）・池1・門1 の6クリック＋戦い。戦いは仲間の選択（1・2・3 か札）と対象のクリックで一人2入力、行動した仲間のあとは次の仲間が自動で選ばれる。敵の手番は小鬼1体で約2秒（その後、敵の歩きと見出しを短くした） |
| 次へ進みたくなる手掛かり | 成功の直後、新しく行ける床に光の波と「道がひらけた！ 新しく24マスに行ける」。縄を渡ると、向こう岸の小鬼と池、その奥の門が見える。池を凍らせると、門と寄り道の滝に「！」。上の段に着くとリコが「谷の向こうに鉄の輪！ あたしの鉤縄なら届くよ」 |

### この区画で見つけて直した問題

| 見つけた問題 | 直したこと |
| --- | --- |
| 二人の吹き出しが重なり、区画名の見出しにもかぶる | 吹き出しは一つずつ。大きな見出しが出ている間は待つ |
| 上の段を指すと「いまは行く道がない」としか出ず、段差のせいだと分からない | 行ける範囲のふちで、目的の升にいちばん近い「越えられない境目」を探し、段差の数・谷・水を言う |
| 押す前の見こみが「足場になった」と過去形 | 見こみは「足場になる」と、これからの言い方にする |
| 池の升を押したのに、手前の岸に立つ仲間を選んだことになり、何も起きない | 仲間の絵は、その仲間の升を指したときか、後ろが立てない所のときだけ拾う。升の境目の判定もわずかに奥寄りに |
| 倒した小鬼の絵が残る | 倒れた敵は描かない |
| 壁の陰の透かしが、隠れていない仲間まで単色で塗りつぶす | その仲間を描いた後に描いた壁や物だけを写しとり、仲間の形と重なる部分だけを透かす |
| 壁の奥の床が、壁に隠れて指せない | 選んでいる仲間の手前をふさぐ柱は半透明にして、指すときは無視する。物のない立てない壁は、奥に升があればそちらを選ぶ |
| まだ届かない宝にまで「！」が付く | 「！」は、その物に本当に手が届いたときだけ（宝・門は自分の升が行ける、輪・的・滝は届く距離） |
| 縄で渡ったあと、ついてくる仲間の一人が谷の向こう側に残る | ついてくる仲間は、先頭から縄を渡らずに行ける升を選ぶ |
| 戦いで、隣り合う仲間と敵の体力の目盛りが重なる | 仲間の体力は下の札に。頭上は敵だけ、小さく。受ける見こみは札にも出す |

## 3. 全体の仕上げ

第一区画のあと、6区画を足した。

| 区画 | 主な見せ場 |
| --- | --- |
| 第二区画 見張りの段々 | 塔の上の骨の射手（高い所から射ると傷+1）。縄で塔に上がる。壁の的を射ると跳ね橋が下りる。寄り道：木箱を池に沈めて飛び石 |
| 第三区画 地下水路 | セナの区画。粘体を凍らせて氷のかたまりに。凍らない速い流れ。凍らせた水路の上を石がすべって流れに沈み、飛び石になる（連携）。滝を凍らせて棚へ → 長い鉤縄 → すぐ使う遠い輪 |
| 第四区画 吊り谷 | リコの区画。谷底から伸びる柱を、長い鉤縄で渡っていく。凍らせたコウモリは谷へ落ちる。寄り道：木箱の上に立つと「2段上まで」に届く |
| 第五区画 石像の大広間 | 押せない岩人形を、凍らせてすべらせ、中央の穴へ。巨人の籠手で石柱を倒し、谷に橋をかける |
| 第六区画 大階段 | 覚えた遊び方で気持ちよく進む区間。上を取った状態で、下から上がってくる群れを、大岩（段を転がり落ちる）・石柱・高所からの矢でなぎ倒す |
| 最後の区画 凍らぬ滝 | 二筋の水（左の水門の的、右の棚の大岩）を止めてから滝を凍らせる。三人で灯籠に火を入れる |

足した仕組み：流れの速い水（凍らない。重い物は沈んで飛び石）、鉤縄の高さの決まり（2段上まで）、上に載った物もいっしょに押される、滝の勢い（二筋）、水霊（水の上だけを動き、水ごと凍らせると閉じこめられる）、区画に入ったときに遠くの目的地を一度見せるカメラ、押した物のたどる道すじと巻きこまれる敵の印。

## 4. ゲームシステム・バランス（ボット）

### 区画を通せるか（`node tools/solve_check.js`）

`tools/routes.js` の解き方の一例（探索の手順）と、戦いのボット（greedy）で、全7区画を新規開始から大灯籠まで通せる。寄り道の覚え書き4枚も取る手順。

### 戦い（`node tools/bot.js <区画> <方針> -q`、各区画の最初の戦い）

ボットが知る情報は、画面と同じ（地形・敵の位置と体力・予告）。乱数はない。

- greedy：三人の順番を全部ためし、一人ずつ「その場でいちばん良くなる行動」を選ぶ。良さ＝敵の残り体力と数が減る／手番を終えたとき受ける見こみ（画面の予告と同じ計算）が減る。
- simple：地形を考えない。いちばん多く直接ダメージを与える行動を選ぶ。受ける見こみは見ない。

| 区画 | greedy：手番・受けたダメージ | simple：手番・受けたダメージ・倒れた数 |
| --- | --- | --- |
| 第一 | 2・0 | 2・2・0 |
| 第二 | 4・4 | 4・10・1 |
| 第三 | 3・0 | 3・2・0 |
| 第四 | 3・0 | 3・2・0 |
| 第五 | 5・0 | 5・10・1 |
| 第六 | 5・2 | 7・11・1 |
| 最後 | 3・1 | 3・3・0 |

（仲間の体力はガルド9・リコ6・セナ6。勝つと全員回復）

### 最初の版で見つかった問題と変更

| 問題（ボットで観察） | 変更 |
| --- | --- |
