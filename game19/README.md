# せーの、星見の露台へ ― 三人で行く、大洞の遠征

町はずれの大穴「大洞（おおうろ）」の底には、昔の人が建てた大灯籠がある。火を入れれば、その光は大洞をのぼって町の広場からも見えるという。
二十年前、盾の戦士ガルドの遠征隊は、露台の手前の「凍らぬ滝」で引き返した。いま、ガルドと、弟子の斥候リコと、亡き術師ハレの教え子だった氷の術師セナの三人が、もう一度その底をめざす。

斜め上から見わたすクォータービューのダンジョンで、段差・谷・水・滝を読み、
**ガルドが押し、リコが射て縄をかけ、セナが凍らせて**、行けなかった場所への道をひらいていくゲーム。
道がひらけると、新しく行ける床に光の波が走り、だれの働きで何が変わったのかが字幕に残る。敵との戦いも同じ地形の上で、手番制で行う。

ONE PROMPT WORLDS の第19作。Claude Opus 5.5 が1つの依頼から企画・実装・検証・改善まで自律的に制作した。

- PCブラウザ向け。マウスだけで遊べる（キーボードも使える）。音が出る。
- 1回の目安：20〜30分（設計上の目安。人間のプレイ時間は未計測）。全7区画。

## 起動

`game19/index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動く。サーバー・ビルド・外部ライブラリ・外部素材は使っていない。

簡易サーバーで開く場合は、リポジトリ直下で次を実行して <http://127.0.0.1:8019/> を開く。

```bash
python -m http.server 8019 --bind 127.0.0.1 --directory game19
```

進み具合はブラウザの localStorage に保存され、タイトルの「つづきから」で再開できる。

## 操作

| 操作 | マウス | キー |
| --- | --- | --- |
| 歩く（探索中は三人で） | 床を押す | ― |
| 仲間を選ぶ | 下の札・本人を押す | 1・2・3、Tab |
| 働きかける | 木箱・鉄の輪・的・水・滝・敵を押す | ― |
| 押す向きを選ぶ（ガルド） | 物の、押したい側にマウスを寄せる（矢印が出る） | ― |
| 吹き出しを送る | 吹き出しを押す | ― |
| ひとつ戻す | 「戻す」・右クリック | Z |
| 見る向きを回す | 「回す」 | Q・E |
| 見わたす | ホイール・右ドラッグ | 矢印・WASD |
| 手番を終える（戦い） | 「手番を終える」 | Space・Enter |
| 演出の早送り・区画に入ったときの見わたしを飛ばす | 演出中に押す | Space |
| ヒント（場所に光る印が出る）／あそびかた／音／メニュー | 右上のボタン | H・?・M・Esc |

物や敵を指すと、だれが・どこに立って・どうなるかが先に出る（半透明の姿・矢印・「道がひらける！」など）。押すと、その場所まで歩いてから行う。

## 遊びの流れ

- **三人の働き**
  - ガルド「押す」：木箱・石・大岩・敵を押す。段から落ちた物は足場に、水に沈んだ物は飛び石になる。凍った物はすべっていく。
  - リコ「射る・鉤縄」：的を射ると仕掛けが動く。鉄の輪に鉤縄をかけて渡ると、縄はみんなの道になる（下から届くのは2段上まで）。
  - セナ「凍らせる」：水を凍らせて氷の床に、滝を凍らせて氷の段に。敵を凍らせると次の手番うごけない。
- **段差**：のぼれるのは1段、飛びおりられるのは2段まで。崖の側面の帯の数が段の数。
- **戦い**：敵に気づかれると手番制になる。三人それぞれ「動いて、一つ行動」。赤い線は「いま手番を終えたら敵がどう動き、だれが何点受けるか」の予告。崖・谷・水へ押しだすと一押しで倒せる。手番を終えるまでは何度でも戻せる。負けても、その手番の始めか戦いの前からやり直せる。
- **寄り道**：区画のあちこちに、亡き術師ハレの「覚え書き」が4枚ある。

## 検証用ツール（開発者向け）

- `node tools/rules_test.js` … ルールの自動確認
- `node tools/solve_check.js` … 全区画を、解き方の一例（`tools/routes.js`）と戦いのボットで通す
- `node tools/bot.js s5 greedy -q` … 区画の最初の戦いをボットで戦う（方針 greedy / simple）
- `python tools/playthrough.py [--fast] [--reload] [--shots DIR]` … タイトルから結末まで、本物のクリックとキーで通す（Playwright＋Edge）
- `python tools/shot.py DIR steps.json` … 画面の撮影
- URL に `?sheet` を付けると、ドット絵の一覧を表示する
